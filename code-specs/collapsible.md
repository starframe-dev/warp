# Collapsible

## Назначение

`Collapsible` оборачивает `Panel`, показывает заголовок и позволяет сворачивать содержимое в одну строку.

## Состояние и рендеринг

- Заголовок виден и в раскрытом, и в свёрнутом состоянии.
- В раскрытом состоянии первая строка содержит `▼` и `Title`; содержимое занимает оставшиеся `max(0, h-1)` строк.
- В свёрнутом состоянии отображается только строка заголовка с `▶`; внутренняя панель не рендерится.
- Заголовок обрезается по терминальным ячейкам. При `h <= 0` вывод пустой; при `w <= 0` заголовок пустой, а раскрытый режим сохраняет ровно `h` пустых строк.
- При `Content == nil` заголовок всё равно отображается, а оставшиеся строки раскрытого представления пусты.

## API

```go
type Collapsible struct {
    Title     string
    Collapsed bool
    Content   Panel
}

func NewCollapsible(title string, content Panel) *Collapsible
func (c *Collapsible) View(w, h int) string
func (c *Collapsible) Elements(w, h int) []Element
func (c *Collapsible) Update(msg tea.Msg) tea.Cmd
func (c *Collapsible) Toggle()
```

`Toggle` инвертирует `Collapsed`. Методы `Tab.Collapse` и `Tab.Expand` синхронно задают явное состояние `Collapsible` и его `FlexItem`, поэтому повторные вызовы Collapse/Expand идемпотентны.

## Семантические элементы

`Elements(w, h)` возвращает nil для свёрнутой панели. В раскрытом состоянии
запрашивает `Content.Elements(w, max(0, h-1))`, ограничивает результат
прямоугольником содержимого и сдвигает Y на `+1`. Заголовок не
экспонируется как отдельный семантический элемент.

## Маршрутизация сообщений

- Tab переключает состояние при клике левой кнопкой по видимой строке заголовка.
- Координаты `MouseMsg` внутри содержимого сдвинуты на одну строку: первый ряд содержимого получает `Y == 0`. События заголовка и мышь по скрытому содержимому не передаются внутренней панели.
- Раскрытое содержимое получает `ResizeMsg` с высотой `max(0, h-1)`; свёрнутое получает высоту `0`. Остальные сообщения передаются без изменений.

## Стили

`collapsibleStyle` оформляет левую часть строки заголовка с уголком, индикатором и названием; `collapsibleBorderStyle` — горизонтальную линию и правый угол.

## Регрессии

Проверяются заголовок в обоих состояниях, высота контента `h-1`, nil-content, корректировка mouse/resize координат, переключение по заголовку и согласованная геометрия вложенных flex-layouts.
