# Dropdown

Компонент выпадающего меню для TUI-приложений на базе Bubble Tea.

## Обзор

`DropdownMenu` — панель с кнопкой и раскрывающимся списком элементов. Компонент поддерживает обработку мыши и клавиатуры, отображает выбранные элементы и вызывает callback при выборе.

## Типы

### DropdownItem

Представляет отдельный элемент меню.

| Поле | Тип | Описание |
|------|-----|----------|
| Label | string | Текст элемента |
| Selected | bool | Признак выбранного элемента |

### DropdownMenu

| Поле | Тип | Описание |
|------|-----|----------|
| Label | string | Текст кнопки меню |
| Items | []DropdownItem | Элементы меню |
| Open | bool | Открыто ли меню |
| Hovered | int | Индекс элемента под курсором/клавиатурным выделением; конструктор устанавливает -1 |
| OnSelect | func(idx int) | Необязательный callback, вызываемый при выборе элемента |

Поля экспортированы. При рендеринге меню и обработке клавиатуры недопустимый `Hovered`, включая индекс вне текущих видимых строк после определения геометрии, сбрасывается в `-1`. Геометрия меню считается известной после первого рендеринга открытого меню.

## Публичный API

### NewDropdownMenu

```go
func NewDropdownMenu(label string, items []DropdownItem) *DropdownMenu
```

Создаёт меню с переданными `Label` и `Items`, устанавливает `Hovered = -1`; меню изначально закрыто, `OnSelect` не задан.

### View

```go
func (d *DropdownMenu) View(w, h int) string
```

Отрисовывает кнопку или открытое меню. Отрицательные `w` и `h` перед рендерингом заменяются нулём. В закрытом состоянии рисуется только кнопка, высота `h` на неё не влияет. В открытом состоянии количество строк ограничено `min(len(Items)+1, h)`; при нулевой высоте возвращается пустая строка. Рендеринг открытого меню запоминает количество отображаемых строк пунктов и делает эту геометрию известной для последующей обработки ввода.

### Update

```go
func (d *DropdownMenu) Update(msg tea.Msg) tea.Cmd
```

Обрабатывает `tea.MouseMsg` и `tea.KeyMsg`; во всех случаях возвращает `nil`.

Для мыши:
- При `MouseActionMotion`, если меню открыто, устанавливает `Hovered = y-1` для строки пункта в пределах числа hoverable-пунктов; иначе сбрасывает значение в `-1`. До первого рендеринга открытого меню видимое число неизвестно, и hoverable считаются все элементы. После рендеринга учитываются только помещающиеся в доступную высоту строки. Наведение не выбирает пункт. Когда меню закрыто, состояние не меняет.
- Другие действия, кроме `MouseActionPress`, игнорируются.
- Нажатие при закрытом меню открывает его только при `y == 0` и устанавливает `Hovered = -1`.
- Нажатие при открытом меню закрывает его при `y == 0`; нажатие на строку пункта в пределах числа hoverable-пунктов выбирает пункт с индексом `y-1`; прочие координаты не меняют состояние. До первого рендеринга открытого меню hoverable считаются все элементы, после — только видимые.

Для клавиатуры события обрабатываются только при открытом меню. После рендеринга `up`, `down` и `enter` ограничены `hoverableItemCount()` — числом видимых строк пунктов. До первого рендеринга открытого меню геометрия неизвестна, поэтому сохраняется fallback на весь список.
- `up` уменьшает `Hovered`, не выходя ниже 0.
- `down` увеличивает `Hovered`, не выходя за последний видимый индекс.
- `enter` выбирает только пункт с допустимым hoverable-индексом.
- `esc` закрывает меню.
- Остальные клавиши игнорируются.

### Close

```go
func (d *DropdownMenu) Close()
```

Устанавливает `Open = false`.

## Выбор элемента

Внутренняя функция `selectItem(idx)` сбрасывает `Selected` у всех пунктов, помечает выбранным пункт с индексом `idx`, закрывает меню и вызывает `OnSelect(idx)`, если callback задан. Функция не проверяет границы `idx`; обработчики мыши и клавиатуры вызывают её только для существующего hoverable-пункта.

## Рендеринг и стили

- Кнопка закрытого меню отображает `Label + " ▼"`, открытого — `Label + " ▲"`.
- В открытом меню первая строка — кнопка; следующие строки содержат пункты, пока они помещаются в доступную высоту.
- Пункт имеет префикс `  `, выбранный пункт — `✓ `.
- Текст кнопки и пунктов обрезается с `…` при превышении ширины. Ширина измеряется в терминальных ячейках с помощью ANSI-библиотеки, а не по байтовой длине. После обрезки строки дополняются пробелами до ширины `w` и оборачиваются соответствующим стилем.
- Для кнопки и текста применяется очистка framework labels перед отображением. Для кнопки используются `dropdownButtonStyle`; для пунктов — `dropdownItemStyle`, `dropdownItemHoverStyle` и `dropdownItemSelectedStyle`. Для выбранного пункта стиль selected имеет приоритет над hover.

## Семантические элементы

`Elements(w, h)` публикует `nil`, если ширина или высота неположительны. Иначе кнопка публикуется как `combobox` с action `toggle` и границами ширины `w`, высоты 1; при закрытом меню на этом список заканчивается. При открытом меню добавляются только помещающиеся в высоту пункты как `option` с action `select`, по одному на строку, начиная с `Y = 1`. Пункты за пределами текущей высоты semantic tree не получают.

## Пример

```go
items := []DropdownItem{
    {Label: "Option 1"},
    {Label: "Option 2"},
    {Label: "Option 3", Selected: true},
}

dropdown := NewDropdownMenu("Options", items)
dropdown.OnSelect = func(idx int) {
    fmt.Printf("Selected option %d\n", idx)
}
```
