# Dropdown

Компонент выпадающего меню для TUI-приложений на базе Bubble Tea.

## Обзор

`DropdownMenu` — панель с кнопкой и раскрывающимся списком элементов. Компонент поддерживает обработку мыши и клавиатуры, отображает выбранные элементы и вызывает callback при выборе.

## Типы

### DropdownItem

Представляет отдельный элемент меню.

| Поле | Тип | Описание |
|------|-----|----------|
| Label | string | Текст элемента |
| Selected | bool | Признак выбранного элемента |

### DropdownMenu

| Поле | Тип | Описание |
|------|-----|----------|
| Label | string | Текст кнопки меню |
| Items | []DropdownItem | Элементы меню |
| Open | bool | Открыто ли меню |
| Hovered | int | Индекс элемента под курсором/клавиатурным выделением; конструктор устанавливает -1 |
| OnSelect | func(idx int) | Необязательный callback, вызываемый при выборе элемента |

Поля экспортированы. При рендеринге меню и обработке клавиатуры недопустимый `Hovered`, включая индекс вне текущих видимых строк, сбрасывается в `-1`.

## Публичный API

### NewDropdownMenu

```go
func NewDropdownMenu(label string, items []DropdownItem) *DropdownMenu
```

Создаёт меню с переданными `Label` и `Items`, устанавливает `Hovered = -1`; меню изначально закрыто, `OnSelect` не задан.

### View

```go
func (d *DropdownMenu) View(w, h int) string
```

Отрисовывает кнопку или открытое меню. Отрицательные `w` и `h` перед рендерингом заменяются нулём. В закрытом состоянии рисуется только кнопка, высота `h` на неё не влияет. В открытом состоянии количество строк ограничено `min(len(Items)+1, h)`; при нулевой высоте возвращается пустая строка.

### Update

```go
func (d *DropdownMenu) Update(msg tea.Msg) tea.Cmd
```

Обрабатывает `tea.MouseMsg` и `tea.KeyMsg`; во всех случаях возвращает `nil`.

Для мыши:
- При `MouseActionMotion`, если меню открыто, устанавливает `Hovered = y-1` только для видимой строки пункта; движение над кнопкой, вне меню или по обрезанной строке сбрасывает значение в -1. Наведение не выбирает пункт. Когда меню закрыто, состояние не меняет.
- Другие действия, кроме `MouseActionPress`, игнорируются.
- Нажатие при закрытом меню открывает его только при `y == 0` и устанавливает `Hovered = -1`.
- Нажатие при открытом меню закрывает его при `y == 0`; нажатие на видимую строку пункта выбирает пункт с индексом `y-1`; прочие координаты не меняют состояние.

Для клавиатуры события обрабатываются только при открытом меню. После рендеринга `up`, `down` и `enter` ограничены `hoverableItemCount()` — числом видимых строк пунктов. До первого рендеринга открытого меню геометрия неизвестна, поэтому сохраняется fallback на весь список.
- `up` уменьшает `Hovered`, не выходя ниже 0.
- `down` увеличивает `Hovered`, не выходя за последний видимый индекс.
- `enter` выбирает только видимый пункт с допустимым индексом.
- `esc` закрывает меню.
- Остальные клавиши игнорируются.

### Close

```go
func (d *DropdownMenu) Close()
```

Устанавливает `Open = false`.

## Выбор элемента

Внутренняя функция `selectItem(idx)` сбрасывает `Selected` у всех пунктов, помечает выбранным пункт с индексом `idx`, закрывает меню и вызывает `OnSelect(idx)`, если callback задан. Функция не проверяет границы `idx`; обработчики мыши и клавиатуры вызывают её только для существующего видимого пункта.

## Рендеринг и стили

- Кнопка закрытого меню отображает `Label + " ▼"`, открытого — `Label + " ▲"`.
- В открытом меню первая строка — кнопка; следующие строки содержат пункты, пока они помещаются в доступную высоту.
- Пункт имеет префикс `  `, выбранный пункт — `✓ `.
- Текст кнопки и пунктов обрезается с `…` при превышении ширины. Ширина измеряется в терминальных ячейках с помощью ANSI-библиотеки, а не по байтовой длине. После обрезки строки дополняются пробелами до ширины `w` и оборачиваются соответствующим стилем.
- Для кнопки используются `dropdownButtonStyle`; для пунктов — `dropdownItemStyle`, `dropdownItemHoverStyle` и `dropdownItemSelectedStyle`. Для выбранного пункта стиль selected имеет приоритет над hover.

## Пример

```go
items := []DropdownItem{
    {Label: "Option 1"},
    {Label: "Option 2"},
    {Label: "Option 3", Selected: true},
}

dropdown := NewDropdownMenu("Options", items)
dropdown.OnSelect = func(idx int) {
    fmt.Printf("Selected option %d\n", idx)
}
```
