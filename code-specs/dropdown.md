# Dropdown

Компонент выпадающего меню для TUI-приложений на базе Bubble Tea.

## Обзор

`DropdownMenu` — это панель с кнопкой и раскрывающимся списком элементов. Поддерживает навигацию клавиатурой и мыши, а также обработку выбранных опций.

## Типы

### DropdownItem

Представляет отдельный элемент в выпадающем меню.

| Поле | Тип | Описание |
|------|-----|----------|
| Label | string | Текстовое отображение элемента |
| Selected | bool | Флаг выбранного состояния элемента |

### DropdownMenu

Основной тип выпадающего меню.

| Поле | Тип | Описание |
|------|-----|----------|
| Label | string | Текст кнопки меню (с индикатором состояния) |
| Items | []DropdownItem | Массив доступных элементов |
| Open | bool | Флаг открытого/закрытого состояния |
| Hovered | int | Индекс текущего выделенного элемента (-1 если ни один) |
| OnSelect | func(idx int) | Каллбэк вызываемый при выборе элемента |

## Публичный API

### NewDropdownMenu

Создаёт новый экземпляр выпадающего меню.

```go
func NewDropdownMenu(label string, items []DropdownItem) *DropdownMenu
```

**Параметры:**
- `label` — текст кнопки меню
- `items` — массив элементов меню

**Возвращает:** указатель на новый `DropdownMenu`

### View

Отрисовывает компонент в зависимости от состояния.

```go
func (d *DropdownMenu) View(w, h int) string
```

**Параметры:**
- `w` — доступная ширина терминала
- `h` — доступная высота терминала

**Возвращает:** строковое представление компонента

**Поведение:**
- Если `Open == false` — рендерит кнопку меню
- Если `Open == true` — рендерит открытое меню с элементами

### Update

Обрабатывает сообщения от Bubble Tea.

```go
func (d *DropdownMenu) Update(msg tea.Msg) tea.Cmd
```

**Параметры:**
- `msg` — сообщение от Bubble Tea (MouseMsg или KeyMsg)

**Возвращает:** nil (команды не возвращаются)

**Обработка событий:**

**Мышь (MouseMsg):**
- `Action == MouseActionPress` — обрабатывается
- Клик по кнопке (`y == 0`) — открывает/закрывает меню
- Клик по элементам меню — выбирает элемент по индексу `y-1`

**Клавиатура (KeyMsg):**
- `up` — уменьшается `Hovered` (если > 0)
- `down` — увеличивается `Hovered` (если < len(Items)-1)
- `enter` — выбирает элемент на `Hovered`
- `esc` — закрывает меню

### Close

Завершает работу выпадающего меню.

```go
func (d *DropdownMenu) Close()
```

**Поведение:** устанавливает `Open = false`

## Внутренние детали

### selectItem

Внутренняя функция выбора элемента.

**Поведение:**
1. Сбрасывает `Selected` у всех элементов
2. Устанавливает `Selected = true` для элемента по `idx`
3. Закрывает меню (`Open = false`)
4. Вызывает `OnSelect(idx)` если он задан

### Стилизация

Компонент использует следующие стили:
- `dropdownButtonStyle` — стиль кнопки меню
- `dropdownItemStyle` — стиль элемента списка
- `dropdownItemHoverStyle` — стиль выделенного элемента
- `dropdownItemSelectedStyle` — стиль выбранного элемента

### Рендеринг

**Кнопка меню:**
- Отображает `Label + " ▼"` при закрытом состоянии
- Отображает `Label + " ▲"` при открытом состоянии
- Обрезает текст по ширине `w` с добавление `…` если не влезает

**Меню:**
- Первая строка — заголовок с индикатором состояния
- Каждая строка элемента — с префиксом `  ` или `✓ ` если выбран
- Обрезка текста по ширине аналогично кнопке

## Ограничения

- Максимальная высота меню: `min(h, len(Items) + 1)`
- Индекс `Hovered` всегда в пределах `[0, len(Items)-1]` или `-1`
- Клик/нажатие клавиши за пределами элементов — игнорируется

## Пример использования

```go
func main() {
    items := []DropdownItem{
        {Label: "Option 1", Selected: false},
        {Label: "Option 2", Selected: false},
        {Label: "Option 3", Selected: true},
    }

    dropdown := NewDropdownMenu("Options", items)
    dropdown.OnSelect = func(idx int) {
        fmt.Printf("Selected option %d\n", idx)
    }

    p := tea.NewProgram(func() tea.Cmd {
        // ...
        return nil
    })
}
```

## Интеграция с Bubble Tea

Компонент работает в рамках программы Bubble Tea:
- Сообщения `tea.MouseMsg` и `tea.KeyMsg` обрабатываются в `Update`
- Рендеринг через `View` передаётся в модель программы
- Команды не используются (возвращается nil)
