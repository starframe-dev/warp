# Element — Semantic UI Elements Specification

## Назначение

Package `warp` определяет модель семантических UI-элементов для работы с элементами интерфейса на основе сетки (cells). Элементы имеют границы (bounds), роль, имя и действие, поддерживают иерархическую структуру с дочерними элементами.

## Публичный API

### Типы

#### `Element`

Семантический UI-элемент с позиционированием на экране.

| Поле | Тип | Описание |
|------|-----|----------|
| `Role` | string | Роль элемента (например, "button", "text", "container") |
| `Name` | string | Имя элемента (human-readable identifier) |
| `Action` | string | Действие элемента (опционально) |
| `Bounds` | Bounds | Экранные границы элемента |
| `Children` | `[]Element` | Дочерние элементы (опционально) |

#### `Bounds`

Прямоугольная область экрана в координатах клеток.

| Поле | Тип | Описание |
|------|-----|----------|
| `X` | int | Начальная X-координата |
| `Y` | int | Начальная Y-координата |
| `W` | int | Ширина области |
| `H` | int | Высота области |

#### `ElementProvider`

Интерфейс для объектов, экспонирующих свои UI-элементы.

| Метод | Описание |
|-------|----------|
| `Elements(width, height int)` | Возвращает список элементов для заданных размеров экрана |

#### `ElementProviderFunc`

Адаптер функции под интерфейс `ElementProvider`. Позволяет использовать обычные функции как поставщики элементов.

### Функции

#### `collectElements(panel Panel, width, height int) []Element`

Извлекает элементы из панели, если она реализует интерфейс `ElementProvider`.

**Поведение:**
- Если `panel == nil`, возвращает `nil`
- Если панель реализует `ElementProvider`, вызывает его метод `Elements`
- Иначе возвращает `nil`

#### `FindElement(elems []Element, role, name, action string) (Element, bool)`

Рекурсивно ищет первый элемент, совпадающий с заданными критериями.

**Поведение:**
- Проверяет `role`, `name`, `action` (пустая строка означает "любой")
- Рекурсивно ищет в `Children`
- Возвращает найденный элемент и флаг `ok = true`, если найдено
- Возвращает пустой `Element` и `ok = false`, если не найдено

## Поведение

### `Bounds.Center()`

Возвращает центральную клетку прямоугольной области.

**Формула:**
```
centerX = X + W / 2
centerY = Y + H / 2
```

Целочелое деление на 2.

### `FindElement` — поиск

Поиск выполняется в предпорядке:
1. Сначала проверяется текущий элемент
2. Затем рекурсивно ищется в `Children`

Возвращает первый попавшийся совпадение.

### `collectElements` — агрегация

Поддерживает duck-typing через интерфейс `ElementProvider`. Функция автоматически вызывает метод `Elements` на панелях, реализующих интерфейс.

## Реализация

### Интерфейсная композиция

Используется композиция интерфейсов (не наследование):
- `ElementProviderFunc` реализует `ElementProvider` через метод `Elements`
- Это позволяет динамически добавлять функциональность без изменения базовых типов

### Рекурсия в поиске

`FindElement` использует рекурсию для обхода иерархии элементов. Глубина рекурсии ограничена глубиной дерева элементов.

### Опциональные поля

Поля `Action` и `Children` имеют теги `json:"...omitempty"`, что означает:
- В JSON выводят только если непусто
- При парсинге из JSON игнорируются, если отсутствуют в потоке

## Ограничения

- `Bounds` всегда должен иметь `W > 0` и `H > 0` (не проверяется в публичном API)
- `FindElement` возвращает только первый найденный элемент
- `collectElements` возвращает `nil`, а не пустой слайс, если панель не реализует `ElementProvider`

## Использование

```go
// Создание элемента
elem := Element{
    Role:  "button",
    Name:  "submit",
    Bounds: Bounds{X: 10, Y: 5, W: 2, H: 1},
}

// Поиск элемента
target, found := FindElement(elements, "button", "submit", "")

// Агрегация элементов
elements := collectElements(panel, 800, 600)
```

## Ключевые Принципы

1. **Маленькие интерфейсы** — `ElementProvider` имеет один метод
2. **Принимай интерфейсы** — `collectElements` принимает `Panel`, а не конкретный тип
3. **Композиция** — `ElementProviderFunc` использует композицию для адаптации
4. **Явная модель** — пустая строка означает "любой" в критериях поиска
5. **Рекурсия** — поиск в иерархии использует рекурсию, а не стек

## Примечания

- Тип `Element` используется для представления семантических элементов UI
- Тип `Bounds` определяет прямоугольные области на сетке
- Интерфейс `ElementProvider` позволяет панелям экспонировать свои элементы
- Функция `collectElements` реализует duck-typing через интерфейс
- Функция `FindElement` рекурсивно ищет элементы по критериям
