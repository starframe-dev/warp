# Element — спецификация семантических UI-элементов

## Назначение

Package `warp` определяет модель семантических UI-элементов в координатах клеток, интерфейсы поставщиков элементов и вспомогательные операции поиска, clipping и сериализации снимков.

## Публичные типы

### `Element`

Семантический элемент с полями:

| Поле | Тип | JSON |
|---|---|---|
| `Role` | `string` | `role` |
| `Name` | `string` | `name` |
| `Action` | `string` | `action` |
| `Bounds` | `Bounds` | `bounds` |
| `Children` | `[]Element` | `children` |

Поля `Action` и `Children` помечены `omitempty` и не сериализуются, когда имеют нулевое значение.

### `Bounds`

Прямоугольная область в координатах клеток с целочисленными полями `X`, `Y`, `W`, `H`, сериализуемыми как `x`, `y`, `w`, `h`.

Метод `Center()` возвращает `(X + W/2, Y + H/2)` с целочисленным делением.

### `ElementProvider`

Интерфейс с методом `Elements(width, height int) []Element` для выдачи элементов с учётом размеров.

### `ViewportElementProvider`

Интерфейс с методом `ElementsAt(width, height, offset int) []Element`. Он выдаёт элементы, пересекающие заданную content-область; возвращаемые границы остаются относительно начала полного содержимого.

### `SemanticStableMsg`

Интерфейс сообщения с методом `SemanticStateUnchanged() bool`. Значение `true` является обещанием производителя сообщения, что обработка сообщения не меняет дерево семантических элементов. При включённом HTTP inspector Warp может сохранить предыдущий immutable snapshot после `Update` и отложить пересборку до следующего `View`; обычные сообщения обрабатываются консервативно. В этом файле определены интерфейс и вспомогательная проверка сообщения, а не сам цикл Warp.

### `ElementProviderFunc`

Тип функции `func(width, height int) []Element`, реализующий `ElementProvider`: метод `Elements` вызывает функцию с переданными аргументами и возвращает результат.

## Функции и внутреннее поведение

### `collectElements(panel Panel, width, height int) []Element`

Для nil-панели, включая nil-подобные значения, возвращает `nil`. Если панель реализует `ElementProvider`, вызывает `Elements(width, height)` и возвращает результат; иначе возвращает `nil`.

### `FindElement(elems []Element, role, name, action string) (Element, bool)`

Выполняет поиск в глубину в предпорядке: сначала проверяет элемент, затем его дочерние элементы. Пустая строка в любом критерии означает совпадение с любым значением этого поля. Возвращает первое совпадение или пустой `Element` и `false`.

Поиск ограничен глубиной 128 уровней и бюджетом 100 000 посещаемых узлов. При достижении ограничений оставшаяся часть дерева не просматривается.

### Clipping

`clipElements` оставляет только элементы, чьи bounds имеют положительную ширину и высоту и пересекают viewport. Границы оставленных элементов заменяются пересечением; дочерние элементы clipping-обрабатываются рекурсивно с тем же viewport. Пустой список или viewport неположительного размера даёт `nil`.

`intersectBounds` возвращает пересечение двух прямоугольников и признак его видимости. `elementBoundsEnd` защищает сложение начала и размера от переполнения максимального `int`, насыщая результат до максимума.

### Снимок и JSON

Внутренний `elementSnapshot` хранит элементы и однократно кодирует их в JSON при первом вызове `jsonBytes`. К закодированным байтам добавляется завершающий перевод строки, результат и ошибка кэшируются через `sync.Once`. После попытки кодирования ссылка на дерево элементов освобождается. Для nil snapshot `jsonBytes` возвращает `[]\n` без ошибки. `newElementSnapshot` заменяет nil-срез элементов на пустой ненулевой срез, чтобы JSON-представление было массивом.

### Проверка стабильности сообщения

Внутренняя `semanticStateUnchanged` возвращает `true`, только если сообщение реализует `SemanticStableMsg` и его метод вернул `true`.

## Ограничения

- `FindElement` возвращает только первое найденное совпадение и безопасно обрезает поиск по указанным лимитам.
- Clipping является отдельной вспомогательной операцией; `collectElements` само по себе не изменяет и не нормализует bounds.
- `ViewportElementProvider`, snapshot и вспомогательные функции clipping/проверки стабильности являются частью реализации этого файла; их функции описаны выше.
