# Element — Semantic UI Elements Specification

## Назначение

Package `warp` определяет модель семантических UI-элементов для работы с элементами интерфейса на основе сетки (cells). Элементы имеют границы (bounds), роль, имя и действие, поддерживают иерархическую структуру с дочерними элементами.

## Публичный API

### Типы

#### `Element`

Семантический UI-элемент с позиционированием на экране.

| Поле | Тип | Описание |
|------|-----|----------|
| `Role` | string | Роль элемента (например, "button", "text", "container") |
| `Name` | string | Имя элемента (human-readable identifier) |
| `Action` | string | Действие элемента (опционально) |
| `Bounds` | Bounds | Экранные границы элемента |
| `Children` | `[]Element` | Дочерние элементы (опционально) |

Поля сериализуются в JSON с именами `role`, `name`, `action`, `bounds` и `children`. Для `Action` и `Children` задан тег `omitempty`, поэтому пустые значения не включаются при сериализации.

#### `Bounds`

Прямоугольная область экрана в координатах клеток.

| Поле | Тип | Описание |
|------|-----|----------|
| `X` | int | Начальная X-координата |
| `Y` | int | Начальная Y-координата |
| `W` | int | Ширина области |
| `H` | int | Высота области |

Поля сериализуются в JSON как `x`, `y`, `w` и `h`.

#### `ElementProvider`

Интерфейс для объектов, экспонирующих свои UI-элементы.

| Метод | Описание |
|-------|----------|
| `Elements(width, height int) []Element` | Возвращает список элементов для заданных размеров экрана |

#### `ElementProviderFunc`

Тип функции `func(width, height int) []Element`, реализующий интерфейс `ElementProvider`: метод `Elements` вызывает эту функцию с переданными размерами и возвращает результат.

### Функции

#### `collectElements(panel Panel, width, height int) []Element`

Извлекает элементы из панели, если она реализует интерфейс `ElementProvider`.

**Поведение:**
- Если интерфейс `panel` равен `nil`, возвращает `nil`
- Если панель реализует `ElementProvider`, вызывает его метод `Elements(width, height)` и возвращает результат
- Иначе возвращает `nil`

#### `FindElement(elems []Element, role, name, action string) (Element, bool)`

Рекурсивно ищет первый элемент, совпадающий с заданными критериями.

**Поведение:**
- Проверяет `role`, `name`, `action` (пустая строка означает «любой»)
- Рекурсивно ищет в `Children`
- Возвращает найденный элемент и флаг `ok = true`, если найдено
- Возвращает пустой `Element` и `ok = false`, если не найдено

## Поведение

### `Bounds.Center()`

Возвращает центральную клетку прямоугольной области.

**Формула:**
```
centerX = X + W / 2
centerY = Y + H / 2
```

Используется целочисленное деление на 2.

### `FindElement` — поиск

Поиск выполняется в предпорядке:
1. Сначала проверяется текущий элемент
2. Затем рекурсивно ищется в `Children`

Возвращает первый попавшийся совпадающий элемент.

### `collectElements` — получение элементов

Проверяет, реализует ли значение `panel` интерфейс `ElementProvider`, и в таком случае вызывает его метод `Elements`. Автоматической регистрации провайдеров нет.

## Реализация

### Интерфейс и адаптер функции

`ElementProviderFunc` реализует `ElementProvider` через метод `Elements`, который вызывает функцию-значение.

### Рекурсия в поиске

`FindElement` использует рекурсию для обхода иерархии элементов. Глубина рекурсии зависит от глубины дерева элементов.

### Опциональные поля

Теги `json:"action,omitempty"` и `json:"children,omitempty"` исключают соответствующие пустые значения при JSON-сериализации. При разборе JSON отсутствующие поля остаются с нулевыми значениями Go.

## Ограничения

- Код не проверяет значения `Bounds`; в частности, он не обеспечивает положительность `W` и `H`.
- `FindElement` возвращает только первый найденный элемент.
- `collectElements` возвращает `nil`, если интерфейс `panel` равен `nil` или значение не реализует `ElementProvider`.

## Использование

```go
// Создание элемента
elem := Element{
    Role:   "button",
    Name:   "submit",
    Bounds: Bounds{X: 10, Y: 5, W: 2, H: 1},
}

// Поиск элемента
target, found := FindElement(elements, "button", "submit", "")

// Получение элементов
elements := collectElements(panel, 800, 600)
```

## Примечания

- Тип `Element` используется для представления семантических элементов UI.
- Тип `Bounds` определяет прямоугольные области на сетке.
- Интерфейс `ElementProvider` позволяет реализующим его значениям предоставлять элементы.
- `FindElement` рекурсивно ищет элементы по критериям.
