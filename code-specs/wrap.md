# wrap.md — Спецификация модуля wrap

## Обзор

Пакет `warp` предоставляет утилиты для переноса текста в терминале. Он поддерживает два режима:

- **WordWrap** — перенос с помощью `ansi.Wrap`; длинные фрагменты могут разбиваться, а строки, ширина которых всё ещё превышает лимит, усекаются через `ansi.Truncate`.
- **SpaceWrap** — перенос с помощью `ansi.Wordwrap`; слова не разрываются и могут выходить за заданную ширину.

Для работы с шириной отображения и ANSI-последовательностями используется `github.com/charmbracelet/x/ansi`.

## Публичный API

### `WordWrap`

```go
func WordWrap(text string, width int) []string
```

Разбивает `text` по `\n`, отдельно обрабатывает каждую полученную строку функцией `wrapLine` и объединяет результаты.

- При `width <= 0` возвращает `nil`.
- Ширина рассчитывается в терминальных ячейках средствами `ansi`.
- Для одной входной строки применяется ANSI-aware перенос и последующее усечение строк, ширина которых больше `width`.
- Пустые элементы, возникающие при разделении текста по `\n`, также передаются на обработку.

### `SpaceWrap`

```go
func SpaceWrap(text string, width int) []string
```

Разбивает `text` по `\n`, отдельно обрабатывает каждую полученную строку функцией `wrapAtSpaces` и объединяет результаты.

- При `width <= 0` возвращает `nil`.
- Использует `ansi.Wordwrap` с разделителем-пробелом.
- Слова не разрываются; слово длиннее лимита может превысить ширину строки.

### `WrapToString`

```go
func WrapToString(text string, width int, useSpaceWrap bool) string
```

При `useSpaceWrap == true` вызывает `SpaceWrap`, иначе вызывает `WordWrap`. Соединяет полученные строки символом `\n`. Для `width <= 0` результатом будет пустая строка, поскольку выбранная функция переноса возвращает `nil`.

## Внутренние функции

### `wrapLine`

```go
func wrapLine(line string, width int) []string
```

При положительной ширине вызывает `ansi.Wrap(line, width, " ")`, разделяет результат по `\n` и заменяет каждую строку, чья ширина по `ansi.StringWidth` превышает лимит, результатом `ansi.Truncate` до `width`. При `width <= 0` возвращает `nil`.

### `wrapAtSpaces`

```go
func wrapAtSpaces(line string, width int) []string
```

При положительной ширине возвращает части результата `ansi.Wordwrap(line, width, " ")`, разделённые по `\n`. При `width <= 0` возвращает `nil`.

### `isWordBreak`

```go
func isWordBreak(b byte) bool
```

Проверяет `unicode.IsSpace(rune(b))` и возвращает результат. Функция определена в пакете, но в текущей реализации другими функциями не вызывается. Поскольку аргумент имеет тип `byte`, она проверяет значение одного байта, преобразованное в `rune`.

## Зависимости

Пакет импортирует:

- `strings` — разделение и соединение строк;
- `unicode` — проверка пробельного символа в `isWordBreak`;
- `github.com/charmbracelet/x/ansi` — перенос, измерение ширины и усечение ANSI-текста.

Перенос и измерение ширины делегированы библиотеке `ansi`; детали обработки Unicode-графем определяются её реализацией.
