# focus.go — Спецификация

## Обзор

Файл `focus.go` пакета `warp` определяет интерфейсы для клавиатурного фокуса и приёма необработанных клавиш, а также вспомогательные функции для поиска и переключения фокусируемых панелей в дереве UI.

## Интерфейсы

### `Focusable`

```go
type Focusable interface {
    Panel
    Focus()
    Blur()
    Focused() bool
}
```

Панель, реализующая `Focusable`, должна реализовывать `Panel`, уметь принимать фокус (`Focus`), терять его (`Blur`) и сообщать о состоянии фокуса (`Focused`).

### `RawKeyReceiver`

```go
type RawKeyReceiver interface {
    Panel
    WantsRawKeys() bool
}
```

Панель, реализующая этот интерфейс, сообщает через `WantsRawKeys`, хочет ли она получать необработанные клавиши. Комментарий в коде указывает, что `TabGroup` передаёт клавиши сфокусированной панели до обработки горячих клавиш Warp; в частности, `Ctrl+C` не считается командой выхода, если получатель запрашивает необработанные клавиши.

## Вспомогательные функции

### `isFocusable`

```go
func isFocusable(panel Panel) (Focusable, bool)
```

Возвращает `(nil, false)`, если `panel` равен nil, включая типизированный nil, либо не реализует `Focusable`. Иначе возвращает значение типа `Focusable` и `true`. Типизированный nil обнаруживается с помощью `isNilPanel`.

### `isNilPanel`

Проверяет nil для интерфейса `Panel`, включая nil-значения динамических типов chan, func, interface, map, pointer и slice. Для остальных динамических типов возвращает `false`.

### `samePanel`

Считает две панели одинаковыми, если обе nil в смысле `isNilPanel`, либо их динамические типы совпадают и значения равны. Для сравнимого динамического типа используется `==`, для несравнимого — `reflect.DeepEqual`. Если nil только одна панель или динамические типы различаются, панели различны.

### `collectFocusables`

```go
func collectFocusables(node *Node) []Focusable
```

Рекурсивно собирает фокусируемые панели. Для nil-узла возвращает nil. Для листового узла возвращает срез из панели, если она реализует `Focusable` и не является nil; иначе возвращает nil. Для нелистового узла сначала добавляет результаты обхода `Split.First`, затем `Split.Second`, если `Split` задан; после этого обходит элементы `Flex.Items` в порядке среза, пропуская nil-элементы. Если заданы и `Split`, и `Flex`, обрабатываются обе структуры в указанном порядке.

### `focusIndex`

```go
func focusIndex(list []Focusable, current Panel) int
```

Возвращает индекс первой панели списка, совпадающей с `current` согласно `samePanel`. Если `current` nil или совпадение не найдено, возвращает `-1`.

### `focusNext`

```go
func focusNext(list []Focusable, current Panel) Focusable
```

Возвращает nil для пустого списка. Иначе возвращает элемент с индексом `(focusIndex(list, current) + 1) % len(list)`. Поэтому при nil или отсутствующей в списке текущей панели возвращается первый элемент; при найденной панели происходит циклический переход вперёд.

### `focusPrev`

```go
func focusPrev(list []Focusable, current Panel) Focusable
```

Возвращает nil для пустого списка. Иначе берёт `focusIndex(list, current) - 1`; если индекс отрицательный, заменяет его на `len(list) - 1`. Таким образом, для первой, nil или отсутствующей в списке текущей панели возвращается последний элемент, а для остальных — предыдущий.

### `applyFocus`

```go
func applyFocus(current, next Focusable)
```

Если `current` и `next` совпадают согласно `samePanel`, ничего не делает. Иначе вызывает `Blur()` у ненулевого `current`, а затем `Focus()` у ненулевого `next`. Нулевые аргументы соответствующие вызовы не вызывают.

## Структура дерева и порядок обхода

Дерево представлено узлами `*Node`. В листе проверяется `Node.Panel`; внутренний узел может содержать `Split` с `First` и `Second`, а также `Flex` со списком `Items`. Обход следует порядку, реализованному в коде: сначала две ветви `Split`, затем дочерние узлы элементов `Flex`.
