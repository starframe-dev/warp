# Modal

## Роль

Диалоговое окно, отображаемое поверх контента панели. Оно затемняет фон и предоставляет обработку кликов и перетаскивания.

## API

### Типы

- `ShowModalMsg`: поля `Title`, `Content`, `Buttons`, `OnClose`, `Width` для заголовка, ANSI-контента, кнопок, callback закрытия и желаемой ширины.
- `CloseModalMsg`: пустое сообщение для закрытия текущей модалки.
- `ModalButton`: `Label string` и `Action func()`.
- `Modal`: публичные поля `Title`, `Content`, `Buttons`, `OnClose`, `Width`; внутренние поля хранят геометрию, состояние перетаскивания и последние размеры viewport.

### `NewModal`

`NewModal(title, content string, buttons []ModalButton, onClose func()) *Modal` создаёт модалку, устанавливая соответствующие поля. Ширину явно установить через этот конструктор нельзя; её можно задать в поле `Width`.

### `EnsureDimensions`

`EnsureDimensions(totalW, totalH int)` ничего не делает для nil receiver. Иначе размеры viewport ограничиваются снизу нулём. Ширина берётся из `Width`, если она положительна, иначе вычисляется как 3/5 ширины viewport; затем ограничивается диапазоном 30–50 и шириной viewport. Высота рамки фиксирована и равна 7. Модалка центрируется с учётом `offsetX`/`offsetY`, а позиция ограничивается viewport; offsets сохраняются относительно центра.

### `Overlay`

`Overlay(lines []string, totalW, totalH int) []string` возвращает исходный `lines`, если `totalW <= 0` или строк нет. Иначе вызывает `EnsureDimensions`, формирует рамку RoundedBorder с Padding(1,2), затемняет строки фона и накладывает рамку, сохраняя доступные части фона слева и справа.

Внутренняя ширина равна `boxWidth - 6`. Рамка содержит заголовок с символом `✕`, одну строку контента и одну строку кнопок формата `[Label]`, разделённых двумя пробелами. Заголовок и кнопки обрезаются до ширины; контент обрезается с `…` при необходимости, после чего дополняется пробелами. Для вычисления визуальной ширины и обрезки используются ANSI-aware функции.

Фон очищается от ANSI-последовательностей через `ansi.Strip` (вспомогательная `stripANSI`); Unicode-текст сохраняется. Затем строки рендерятся стилем затемнения с фоном `gbDark0`.

### `HandleMouse`

`HandleMouse(msg tea.MouseMsg) bool` возвращает false для nil receiver или при `boxHeight == 0`; иначе обрабатывает:

- левый клик по `✕` на координатах X `startX + boxWidth - 4`, Y `startY + 2`: вызывает `OnClose`, если callback задан;
- левый клик в области кнопки: вызывает её `Action`, если задана;
- начало перетаскивания левым кликом на полоске `startY + 1` в пределах ширины рамки;
- движение во время перетаскивания: обновляет позицию и offsets с ограничением по viewport;
- отпускание кнопки во время перетаскивания: сбрасывает состояние.

Проверка клика по кнопкам выполняется для строк `startY + 4` и `startY + 5`. При этом `Overlay` рисует все кнопки одной строкой и обрезает её по ширине; переноса кнопок на вторую строку нет. Обработка координат мыши предполагает, что вызывающая сторона передаёт координаты относительно строк контента.

Клик по закрытию вызывает callback при каждом соответствующем событии; `Modal` не обеспечивает однократность вызова. Перетаскивание начинается только на полоске `startY + 1`, а не на строке заголовка `startY + 2`.

### Геометрия и вспомогательные методы

- `StartX()`, `StartY()`, `BoxWidth()`, `BoxHeight()` возвращают сохранённые координаты и размеры.
- `buildButtonLine()` создаёт строку кнопок с разделителем `  `.
- `findBracketPair(s string, pos int)` ищет ближайшие `[` и последующую `]`; при отсутствии пары возвращает `(-1, -1)`.
- `visualBytePos(s string, targetW int)` определяет byte-позицию с учётом ANSI parser и графем `uniseg`; если ширина не достигается, возвращает `len(s)`.
- `stripANSI(s string)` удаляет ANSI-последовательности с помощью `ansi.Strip`.
- `max(a, b int)` возвращает большее значение.

### Стили

- `modalBorderStyle`: фон `gbDark1`, передний план `gbLight1`, RoundedBorder с цветом `gbBlue`, Padding(1,2).
- `dimStyle`: передний план `gbGray`, фон `gbDark0`.

## Ограничения и порядок использования

- При `Width <= 0` ширина рассчитывается автоматически как 3/5 viewport, затем ограничивается 30–50 и доступной шириной. Положительная ширина также ограничивается 30–50 и шириной viewport.
- Высота рамки равна 7 линиям.
- Перед обработкой мыши геометрию следует инициализировать вызовом `EnsureDimensions` либо `Overlay`.
- `Overlay` следует вызывать для отрисовки модалки; он обновляет сохранённую геометрию.
