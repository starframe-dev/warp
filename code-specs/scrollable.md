# Scrollable — спецификация

## Назначение

`Scrollable` оборачивает `Panel` и показывает viewport высотой `h` строк с вертикальным смещением `Offset`.

## Публичный API

```go
func NewScrollable(content Panel) *Scrollable
func (s *Scrollable) View(w, h int) string
func (s *Scrollable) Elements(w, h int) []Element
func (s *Scrollable) Update(msg tea.Msg) tea.Cmd
```

`Offset` измеряется в строках. Отрицательные `w`, `h` и `Offset` нормализуются к нулю.

## Рендеринг

1. При nil-панели возвращаются ровно `h` пустых строк: `""` при `h == 0`, иначе `h-1` переводов строки (`"\n\n"` для трёх строк).
2. Для `h == 0` возвращается пустая строка без рендеринга содержимого.
3. Панель рендерится с высотой `Offset + h`, то есть только до конца запрошенного viewport; произвольная высота вроде `9999` не используется.
4. Если сложение размеров переполняется, запрошенная высота насыщается на максимальном `int`.
5. Смещение ограничивается диапазоном существующих строк, после чего выбираются `h` строк.
6. Каждая видимая строка обрезается или дополняется до `w` терминальных ячеек с ANSI- и Unicode-aware геометрией.

Вызов `View` может уменьшить `Offset`, если содержимое стало короче.

## Прокрутка

- Колесо мыши вверх/вниз меняет смещение на 3 строки.
- `up` / `down` меняют его на 1 строку.
- `pgup` / `pgdown` меняют его на 10 строк.
- Смещение не становится отрицательным и не переполняет целое число.
- Сообщения передаются обёрнутой панели после обработки прокрутки.

## Геометрия

Ширина вычисляется в terminal cells, а не в байтах или рунах. ANSI escape-последовательности не занимают ячеек; широкая Unicode-графема не разрезается при обрезке.

`Elements(w, h)` запрашивает вложенные элементы на высоту `Offset + h`, отсекает Bounds вне прямоугольника `[0, w) × [Offset, Offset+h)`, обрезает частичные пересечения и сдвигает Y на `-Offset`. Дочерние элементы преобразуются рекурсивно, без изменения слайсов провайдера.

## Проверки

Регрессии покрывают короткий viewport, ограниченный запрос высоты, отрицательные значения, переполнение `Offset + h`, ANSI-строки и Unicode-графемы.
