# Спецификация: panel.go

## Обзор

`panel.go` определяет интерфейс панели, дополнительные необязательные интерфейсы, вспомогательную функцию для получения высоты контента и базовую реализацию `Panel`.

## Интерфейс Panel

```go
type Panel interface {
    View(width, height int) string
    Update(msg tea.Msg) tea.Cmd
}
```

- `View` возвращает строковое представление содержимого для заданных размеров.
- `Update` обрабатывает сообщения Bubble Tea и возвращает команду.
- Клавиатурный ввод обычно следует фокусу. `Tab`/`TabGroup` могут распространять resize-, framework-, custom- и неизвестные сообщения на панели без фокуса.

## Дополнительные интерфейсы

### ContentHeightProvider

```go
type ContentHeightProvider interface {
    ContentHeight(width int) (height int, known bool)
}
```

Необязательный интерфейс сообщает intrinsic-высоту контента при заданной ширине. Для определения высоты реализация не должна рендерить контент. Если `known` равен `false`, высота считается неизвестной. Потребители нормализуют известные отрицательные значения высоты до нуля.

Внутренняя функция `panelContentHeight` возвращает неизвестную высоту для nil-панели, панели без `ContentHeightProvider` или результата с `known == false`. Перед вызовом провайдера отрицательная ширина нормализуется до нуля; известный отрицательный результат высоты также нормализуется до нуля.

### ViewportRenderer

```go
type ViewportRenderer interface {
    ViewAt(width, height, offset int) string
}
```

Необязательный интерфейс рендерит только запрошенные строки контента для известного смещения. `Scrollable` использует его только если обёрнутая панель сообщает известную высоту контента.

### Unmounter

```go
type Unmounter interface {
    Unmount()
}
```

Необязательный интерфейс для освобождения ресурсов. Warp вызывает `Unmount` после отсоединения панели, когда на неё больше не ссылается соответствующий домен владения. Его следует реализовывать на панелях с указательной идентичностью.

## BasePanel

```go
type BasePanel struct{}

func (BasePanel) View(width, height int) string {
    return ""
}

func (BasePanel) Update(msg tea.Msg) tea.Cmd {
    return nil
}
```

`BasePanel` предоставляет пустую реализацию `Panel`, которую можно встраивать и переопределять только при необходимости.

## Правила

- `Panel` содержит только методы `View` и `Update`; остальные интерфейсы необязательны и независимы.
- Комментарии в исходном коде написаны на английском языке.
