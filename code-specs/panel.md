# Specification: panel.go

## Overview

`panel.go` определяет интерфейс и базовую реализацию для панелей в Warp-приложении. Панели являются основным строительным блоком для создания контента в терминальных интерфейсах.

## Purpose

Панели позволяют создавать разнообразный контент: терминалы, тексты, графики, формы и другие компоненты. Интерфейс следует паттерну Model/Update/View из библиотеки Bubble Tea.

## Types

### Panel Interface

```go
type Panel interface {
    View(width, height int) string
    Update(msg tea.Msg) tea.Cmd
}
```

**Методы интерфейса:**

| Метод | Описание |
|-------|----------|
| `View(width, height int) string` | Рендерит содержимое панели на заданных размерах. Возвращает строковое представление. |
| `Update(msg tea.Msg) tea.Cmd` | Обрабатывает сообщения Bubble Tea (клавиши, мышь и т.д.). Возвращает команду для асинхронного выполнения. |

**Особенности:**

- Панель получает только сообщения, которые пришли в момент, когда панель была сфокусирована.
- `View` принимает размеры экрана и рендерит контент соответствующего размера.
- `Update` обрабатывает события ввода и состояния.

### Необязательный ContentHeightProvider

```go
type ContentHeightProvider interface {
    ContentHeight(width int) (height int, known bool)
}
```

- Дополнительный интерфейс сообщает intrinsic-высоту контента с учётом ширины и не расширяет `Panel`.
- `known == false` означает неизвестную высоту; реализация не вызывает `View` для её определения.
- Потребители нормализуют отрицательную известную высоту до нуля.
- Известная intrinsic-высота нужна для точной ограниченной прокрутки, поскольку `View` вправе дополнять строки до запрошенной высоты.

### Необязательные viewport-интерфейсы

```go
type ViewportRenderer interface {
    ViewAt(width, height, offset int) string
}

type ViewportElementProvider interface {
    ElementsAt(width, height, offset int) []Element
}
```

`Scrollable` вызывает эти интерфейсы только при известной intrinsic-высоте. `ViewAt` возвращает только строки viewport. `ElementsAt` возвращает только пересекающие viewport элементы, но сохраняет bounds относительно начала полного содержимого; `Scrollable` выполняет общие clipping и перевод координат. Если интерфейсы не реализованы, используется прежний путь `View`/`Elements`.

### Необязательный Unmounter

```go
type Unmounter interface {
    Unmount()
}
```

- `Unmount` вызывается после отсоединения панели, только когда её последний экземпляр удалён из иерархии владельца.
- Повторные ссылки на один экземпляр в одном домене учитываются один раз. Скрытие, сворачивание, смена фокуса и reparenting не являются удалением.
- Идентичность указательных панелей определяется типом и адресом экземпляра, не deep equality; метод следует реализовывать на pointer-backed панелях.
- Корень `Warp` владеет всей вложенной иерархией. Самостоятельные `TabGroup` и `Tab` образуют отдельные домены. Совместное использование экземпляра между независимыми доменами не поддерживается и остаётся ответственностью вызывающего кода; глобального реестра нет.

### BasePanel Struct

```go
type BasePanel struct{}

func (BasePanel) View(width, height int) string {
    return ""
}

func (BasePanel) Update(msg tea.Msg) tea.Cmd {
    return nil
}
```

**Назначение:**

- Предоставляет тривиальную реализацию `Panel` интерфейса.
- Встраивайте `BasePanel` в свои панели и переопределяйте только нужные методы.
- Это позволяет избежать дублирования методов, которые вы не используете.

## Rules

1. **Интерфейс Panel** содержит только два метода: `View` и `Update`; `ContentHeightProvider` остаётся отдельным необязательным интерфейсом.
2. **BasePanel** предоставляет тривиальную реализацию, которую можно встраивать.
3. **Английская документация** — все комментарии в коде на английском.
