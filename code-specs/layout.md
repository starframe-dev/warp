# Геометрия раскладки — спецификация

## Назначение

`layout.go` строит дерево прямоугольников для узла и заданной области. Эта геометрия используется при рендеринге, построении `Elements`, поиске панели под курсором, сборе границ для hit-testing и рассылке `ResizeMsg`.

## Координаты

- `layoutRect` хранит начало `x/y` и размеры `w/h` в терминальных ячейках.
- При создании раскладки ширина и высота нормализуются к неотрицательным значениям.
- Прямоугольники используют полуоткрытые интервалы: `[x, x+w)` и `[y, y+h)`.
- Граница split занимает одну ячейку, если обе стороны не свёрнуты и размер соответствующей оси больше нуля.
- Границы flex размещаются только между соседними несвёрнутыми элементами; их количество ограничено размером оси раскладки.
- `BorderHit` хранит абсолютную позицию границы, её длину, содержащий прямоугольник, направление и ссылку на split/flex-конфигурацию. Для flex также хранится индекс границы.

## Распределение размеров

- Split вычитает размер видимой границы из доступной оси перед распределением между дочерними узлами.
- Flex вычитает из доступной оси число видимых границ перед распределением размеров элементов.
- При тесной области размеры дочерних элементов остаются неотрицательными и не выходят за выделенную ось; минимальные пожелания могут быть не выполнены.
- Размер свёрнутой стороны split берётся из конфигурации свёртывания (не менее одной ячейки, если область позволяет). У свёрнутого `FlexItem` базовый размер равен одной ячейке независимо от `Basis`; при нехватке пространства распределённый размер может быть меньше, включая ноль. Граница рядом со свёрнутым элементом не отображается.

## Использование геометрии

- Рендерер использует layout для размещения дочерних областей и границ.
- `Elements` смещает координаты дочерних элементов на начало их layout-области.
- Поиск панели через `findLayoutPanel` использует полуоткрытые прямоугольники; потребитель layout использует собранные `BorderHit` для проверки границ.
- `ResizeMsg` получает ширину и высоту листовой области.
- Перетаскивание использует содержащую границу область при вычислении доли.

## Ограничения

Текстовая ширина измеряется отдельно ANSI-aware функциями. Координаты layout и событий мыши задаются в ячейках терминала; байтовая длина строки не является геометрической величиной.
