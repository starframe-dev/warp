# Спецификация: компонент Input

## Обзор

`Input` — однострочный компонент текстового ввода для TUI на Bubble Tea. Он поддерживает значение, позицию курсора в рунах, фокус, обработку клавиатуры, семантическое представление textbox и отображение в рамке или inline.

## Публичный API и состояние

```go
func NewInput(prompt string) *Input
```

Создаёт пустой `Input`: `Value` пуст, `Cursor` равен 0, `Prompt` содержит переданный текст. `Width` остаётся нулём.

Экспортированные поля состояния:

```go
Value  string
Cursor int // позиция в рунах
Prompt string
Width  int // хранится, но View его не использует
```

Внутреннее состояние содержит флаг фокуса и кэш разметки значения на grapheme clusters (смещения в байтах, рунах и терминальных ячейках). Кэш инвалидируется при изменении значения методами компонента; при прямом изменении экспортированного `Value` соответствие проверяется по сохранённой строке.

`SetValue(v)` заменяет значение, ставит курсор в конец в рунах и инвалидирует кэш разметки. `SetCursor(pos)` задаёт позицию в рунах, ограничивает её диапазоном значения и при попадании внутрь grapheme cluster нормализует к правой границе кластера.

`Focused() bool` возвращает состояние фокуса. `Focus()` устанавливает его в `true`, `Blur()` — в `false`. Фокус влияет на цвет рамки в режиме бокса.

Поскольку `Value` и `Cursor` экспортированы, вызывающий код может напрямую задать для них некорректное состояние. Методы `SetValue`, `SetCursor`, `Update` для обрабатываемого клавишного сообщения и рендеринг нормализуют курсор; поэтому валидность курсора не гарантируется непрерывно между такими вызовами.

## Семантический элемент

`Elements(w, h)` приводит размеры к минимуму 0. Если хотя бы один размер равен нулю, возвращает `nil`. Иначе возвращает один элемент с ролью `textbox`, действием `focus`, bounds `W: w, H: h` и именем из prompt, очищенного `sanitizeFrameworkLabel` и обрезанного по краям пробелов; если имя пусто, используется `Input`.

## Отображение

```go
func (in *Input) View(w, h int) string
```

Отрицательные `w` и `h` приводятся к нулю. При `w >= 3` и `h >= 3` используется бокс, иначе inline-режим. Поле `Width` на выбор геометрии и рендеринг не влияет.

В боксовом режиме рисуются границы `╭─╮`, `╰─╯` и `│`; внутреннее содержимое находится в центральной строке (формула индекса строки: `1 + (h-3)/2`). Остальные строки заполняются пробелами. Рамка использует `inputBorderStyle` без фокуса и `inputFocusBorderStyle` с фокусом; содержимое использует `inputStyle`.

В inline-режиме одна и та же отрисованная строка повторяется `h` раз; при `h == 0` возвращается пустая строка. Строка дополняется пробелами до заданной ширины по видимой ширине.

Внутренний `renderLine(maxW)` ограничивает отображение терминальными ячейками, но не меняет `Value`. Подсказка очищается `sanitizeFrameworkLabel`, затем обрезается ANSI-aware функцией `ansi.Truncate`; если она занимает всю доступную ширину, значение не выводится. Иначе значение отображается с учётом ширины терминальных ячеек и grapheme clusters. Grapheme cluster под курсором выделяется ANSI reverse-видео (`\x1b[7m`); если курсор находится в конце видимого значения и осталось место, выделяется пробел курсора.

При переполнении `truncateInputAtCursor` выбирает видимое окно вокруг курсора. Если граница окна пересекает широкую графему, её видимая часть заменяется пробелами, а не выводится частично. Нулевые по ширине графемы при таком усечении пропускаются. В обычном, неусечённом случае значение возвращается без изменения. Функция возвращает также видимую позицию курсора в рунах результата.

`Cursor` измеряется в рунах, тогда как ширина и усечение отображения — в терминальных ячейках. ANSI-последовательности в подсказке учитываются при её усечении и измерении ширины. Для значения с ANSI-последовательностями разметка графем использует ширину, вычисленную `ansi.StringWidth`.

## Обработка клавиатуры

```go
func (in *Input) Update(msg tea.Msg) tea.Cmd
```

Для не-`tea.KeyMsg` и при отсутствии фокуса ничего не меняет и возвращает `nil`. Для сфокусированного клавишного сообщения перед и после обработки нормализует курсор. Возвращаемая команда всегда `nil`.

- `backspace` удаляет grapheme cluster перед курсором; `delete` удаляет кластер под курсором.
- `left` и `right` перемещают курсор к предыдущей/следующей границе grapheme cluster.
- `home` и `end` перемещают курсор в начало/конец значения.
- `tab` и `shift+tab` не обрабатываются (предназначены родителю).
- `enter` — no-op.
- Для `tea.KeyRunes` вставляются все руны события в позицию курсора.
- Иные клавиши не меняют значение.

Вставка нормализует курсор до и после изменения и инвалидирует кэш разметки. Удаление затрагивает целый grapheme cluster и инвалидирует кэш. Публичная позиция курсора задаётся в рунах, но нормализация ограничивает её границами кластеров.

## Нормализация курсора

`clampCursor()` ограничивает курсор диапазоном от 0 до количества рун в `Value` и, если позиция находится внутри grapheme cluster, сдвигает её к правой границе. `SetValue`, `SetCursor`, обработка сфокусированного клавишного сообщения и рендеринг вызывают нормализацию в соответствующих местах.

## Основные свойства реализации

- Фокус хранится в самом компоненте до `Blur` или прямого изменения состояния недоступного извне поля.
- Ширина отображения не ограничивает длину значения.
- Методы отображения возвращают строку; `Update` команды не создаёт.
