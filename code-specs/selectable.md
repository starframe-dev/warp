# Selectable

## Назначение

`Selectable` — это обёртка для `Panel`, которая добавляет поддержку выделения текста. Пользователь может выделять текст перетаскиванием мыши или с помощью клавиш со стрелками в сочетании со Shift. Выделенная область отображается с инверсией цветов.

---

## Публичный API

### Конструктор

```go
func NewSelectable(content Panel) *Selectable
```

Создаёт новый экземпляр `Selectable` с предоставленным контентом.

### Методы

| Метод | Возврат | Описание |
|-------|----------|----------|
| `SelectedText()` | `string` | Возвращает текуще выделенный текст |
| `ClearSelection()` | `-` | Снимает текущее выделение |
| `Copy()` | `tea.Cmd` | Возвращает команду для копирования выделенного текста в буфер обмена (OSC 52) |
| `SelectAll(w, h int)` | `-` | Выделяет всё доступное содержимое в пределах заданных размеров |
| `View(w, h int)` | `string` | Отрисовывает контент с выделением |
| `Update(msg tea.Msg)` | `tea.Cmd` | Обрабатывает события мыши и клавиатуры для управления выделением |

### Типы данных

| Поле | Тип | Описание |
|------|-----|----------|
| `Content` | `Panel` | Обёртываемый панелей контент |
| `AnchorX, AnchorY` | `int` | Координаты якоря выделения (фиксированы при нажатии) |
| `CursorX, CursorY` | `int` | Координаты курсора (активный конец выделения) |
| `HasSelection` | `bool` | Флаг наличия выделения |
| `Selecting` | `bool` | Флаг активности перетаскивания мыши |
| `lastW, lastH` | `int` | Последние отрисованные размеры |
| `lastLines` | `[]string` | Последняя отрисованная строки содержимого |

## Обработка событий

### Мышь

| Действие | Поведение |
|----------|-----------|
| `MouseActionPress` (левая кнопка) | Устанавливает якорь выделения в точке клика, начинает режим перетаскивания |
| `MouseActionMotion` (левая кнопка) | Обновляет курсор выделения при перетаскивании |
| `MouseActionRelease` (левая кнопка) | Завершает перетаскивание, сохраняет выделение |

### Клавиатура

| Клавиша | Поведение |
|---------|----------|
| `Shift+Стрелка` | Движение курсора выделения (якорь остаётся на месте) |
| `Ctrl+A` | Выделяет весь видимый контент |
| `Esc` | Снимает выделение |
| `Shift+Tab` | Проксирован на обёрнутый `Panel` (не обрабатывается здесь) |

## Внутренние детали реализации

### `sortedBounds()`

Возвращает границы выделения с начальной точкой <= конечной. Переставляет координаты, если якорь находится справа или ниже курсора (режим обратного выделения).

### `highlightRange()`

Применяет стилизацию выделения к визуальной области `[startX, endX)`. Обрабатывает многобайтовые UTF-8 символы и ANSI-последовательности.

### `extractVisRange()`

Извлекает текст из визуальной области, учитывая ANSI-кодировку и UTF-8.

### Константы

```go
var (
    selectionStyleANSI = "\x1b[7m"  // Инвертированный фон для выделения
    resetStyle         = "\x1b[0m"  // Сброс стилей
)
```

### `View()`

- Сохраняет отрисованные строки для последующего извлечения текста
- Обрезает координаты выделения к границам панели
- Применяет инверсию цветов к выделенной области

### `SelectedText()`

- Использует сохранённые строки `lastLines` для точного сопоставления координат
- При отсутствии отрисовки делает полный рендер для получения контента

---

## Ограничения

1. Координаты выделения обрезаны к границам панели
2. Обратное выделение (от якоря к курсору в обратном направлении) поддерживается
3. ANSI-последовательности обрабатываются корректно при извлечении текста
4. UTF-8 символы обрабатываются через `utf8.DecodeRuneInString`

---

## Пример использования

```go
func main() {
    panel := NewPanel(...)
    selectable := NewSelectable(panel)

    tea.Program{
        Init: func() tea.Cmd {
            return func() tea.Msg { return nil }
        },
        Update: func(msg tea.Msg) (tea.Cmd, tea.Model) {
            return selectable.Update(msg), selectable
        },
        View: func() string {
            return selectable.View(80, 24)
        },
    }.Run()
}
```
