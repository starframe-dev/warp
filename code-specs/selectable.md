# Selectable

## Назначение

`Selectable` — обёртка над `Panel`, добавляющая выделение текста мышью и клавиатурой. Выделенная область отображается инверсией цветов. Текст для извлечения берётся из тех же отрисованных строк, что и для отображения выделения.

## Публичный API

| Метод | Возврат | Описание |
|-------|---------|----------|
| `NewSelectable(content Panel)` | `*Selectable` | Создаёт обёртку над панелью. |
| `SelectedText()` | `string` | Возвращает выделенный текст; при отсутствии выделения или nil-панели возвращает пустую строку. |
| `ClearSelection()` | — | Снимает выделение и прекращает активное выделение мышью. |
| `Copy()` | `tea.Cmd` | Возвращает команду, выводящую выбранный текст в системный буфер через OSC 52; при пустом тексте возвращает nil. |
| `SelectAll(w, h int)` | — | Выделяет viewport заданного размера; при неположительной ширине или высоте очищает выделение. |
| `View(w, h int)` | `string` | Отрисовывает панель и визуально выделяет выбранный диапазон. |
| `Elements(width, height int)` | `[]Element` | Прозрачно передаёт семантические элементы вложенной панели с теми же границами. |
| `Update(msg tea.Msg)` | `tea.Cmd` | Обрабатывает события мыши и клавиатуры, остальные события передаёт вложенной панели. |

Структура содержит публичные поля `Content Panel`, `AnchorX, AnchorY int`, `CursorX, CursorY int`, `HasSelection bool` и `Selecting bool`. Координаты якоря и курсора задаются в терминальных ячейках относительно панели. Внутренние поля хранят координаты начала мышиного жеста, последние размеры отрисовки и последние отрисованные строки.

## Обработка событий

### Мышь

Обрабатываются только события левой кнопки. Нажатие устанавливает начало жеста и якорь, сбрасывает старое выделение и включает `Selecting`. Движение при активном жесте обновляет диапазон и устанавливает `HasSelection`. Отпускание завершает жест; если было выделение, его конечная позиция обновляется. Выделение одинаковых координат якоря и курсора снимается. Координаты ограничиваются последними известными размерами, если они доступны.

### Клавиатура

- `shift+up`, `shift+down`, `shift+left`, `shift+right` перемещают курсор выделения, сохраняя якорь. При первом таком событии якорь берётся из прежней позиции курсора. Вертикальное и горизонтальное движение ограничивается известными размерам viewport; если соответствующий размер ещё неизвестен, движение в положительном направлении не ограничивается.
- Все сообщения `KeyMsg`, строка которых начинается с `shift+`, кроме `shift+tab`, считаются обработанными здесь. Для неизвестного Shift-комбинированного ключа курсор не перемещается, но включается выделение.
- `ctrl+a` выделяет весь viewport последних известных размеров; если они неизвестны, используются 80×24.
- `esc` очищает выделение, только если оно установлено.
- Необработанные клавиши, включая `shift+tab`, передаются вложенной панели.

При `ResizeMsg` сообщение передаётся вложенной панели. Если вложенная панель равна nil, вызовы `Update` безопасно возвращают nil. Nil-панель в `View` отображается ровно в `h` пустых строк: `""` при `h == 0`, иначе `h-1` переводов строки.

## Координаты и границы

Границы диапазона end-exclusive: выделяется `[start, end)`. Координаты ограничиваются в `View` шириной `w` (включительно для X) и строками `0..h-1`; при неположительных размерах выделение очищается. `SelectAll(w, h)` задаёт диапазон от `(0, 0)` до `(w, h-1)`, тем самым включая всю ширину каждой строки viewport.

Мышиная координата обозначает ячейку. При движении вперёд конечная граница устанавливается в `x+1`; при обратном движении якорь начинается с `originX+1`, чтобы включить исходную ячейку. Границы сортируются по строке и столбцу, поэтому поддерживается обратное выделение.

## Отрисовка и извлечение текста

`View` нормализует отрицательные размеры до нуля, сохраняет отрисованные строки и размеры, ограничивает координаты выделения и применяет инверсию к диапазону ячеек. ANSI-последовательности не занимают ячеек. Ширина текста считается по ширине графем; если диапазон пересекает широкую графему, целая графема визуально выделяется.

`SelectedText` использует сохранённые строки. Если кэшированных строк нет, он вызывает `Content.View` с последними известными размерами, заменяя неположительную ширину на 80, а неположительную высоту на 24. `Elements(w, h)` прозрачно пересылает семантические элементы `Content` без изменения координат. Извлечение удаляет ANSI-последовательности и возвращает целые графемы, пересекающие диапазон. Каждый выбранный ряд `sy..ey` добавляет фрагмент, в том числе пустой; после соединения переводами строк пустые строки и завершающие переводы строк сохраняются.

`highlightRange` применяет ANSI reverse-video `\x1b[7m`, а при выходе из выделения сбрасывает стиль через `\x1b[0m`. ANSI-последовательности сохраняются при обработке строки и не учитываются в ширине.

## Внутренние функции

- `sortedBounds()` возвращает упорядоченные end-exclusive границы.
- `clampSelection(w, h)` ограничивает координаты и очищает нулевой диапазон, если мышиное выделение не активно.
- `setMouseSelection(x, y)` вычисляет границы мышиного диапазона.
- `highlightRange(line, startX, endX)` подсвечивает пересекающие диапазон графемы.
- `ansiSequenceEnd(text, start)` определяет конец CSI, OSC и двухбайтовой escape-последовательности.
- `extractVisRange(line, startX, endX)` извлекает полные графемы из видимого текста без ANSI.

## Пример использования

```go
selectable := NewSelectable(panel)
view := selectable.View(80, 24)
cmd := selectable.Update(msg)
```
