# Спецификация Popover

## Назначение

`Popover` — компонент контекстного меню для TUI-приложений на `charmbracelet/bubbletea`. Меню отображается поверх строк контента, сохраняя видимые части исходных строк слева и справа от меню.

## Публичный API

### `PopoverItem`

Один элемент меню:

```go
type PopoverItem struct {
    Name   string
    Action func()
}
```

`Name` — отображаемое имя. Перед выводом оно обрабатывается функцией `sanitizeFrameworkLabel`. `Action` — необязательное действие; nil безопасен при выборе.

### `Popover`

```go
type Popover struct {
    Items   []PopoverItem
    X, Y    int
    Width   int
    OnClose func()

    boxW, boxH int
    clampedX, clampedY int
    selected int
}
```

`X`, `Y` задают позицию в экранных координатах (`Y=0` — строка заголовка). `Width` — ширина содержимого; значение не больше нуля означает ширину по умолчанию 20. `OnClose` вызывается при закрытии. `boxW`, `boxH` сохраняют размеры отрисованного меню, `clampedX`, `clampedY` — его последнюю вычисленную позицию, а `selected` — индекс выбранного элемента. Последние поля используются внутри реализации.

## Методы

### `Overlay(lines []string, totalW, totalH int) []string`

Накладывает меню на строки и возвращает их.

- Если `Items` пуст, возвращает `lines` без изменений.
- Ширина содержимого равна `Width`, если она положительна, иначе 20; затем она ограничивается сверху значением `totalW`.
- Формирует по строке на каждый элемент, предваряя имя пробелом, применяя базовый или выбранный стиль, и оборачивает строки рамкой.
- Сохраняет фактические ширину первой строки рамки и число строк рамки в `boxW` и `boxH`.
- По горизонтали, если `menuX+boxW > totalW`, устанавливает `menuX = totalW-boxW`, после чего ограничивает `menuX` снизу нулём. Поэтому меню шире `totalW` может выходить за правую границу. По вертикали позиция ограничивается снизу нулём; если рамка не помещается в `len(lines)`, она сдвигается вверх до `len(lines)-boxH`, но не ниже нуля. `totalH` в реализации не используется.
- Сохраняет вычисленные координаты в `clampedX` и `clampedY`.
- Для строк, перекрываемых меню, оставляет слева исходные визуальные колонки до `menuX` (дополняя пробелами при необходимости), вставляет строку меню и добавляет исходную часть после `menuX+boxW` визуальных колонок. ANSI-последовательности учитываются используемыми функциями `ansi` и `visualBytePos`.

### `HandleMouse(msg tea.MouseMsg) bool`

Если `boxW` равен нулю, возвращает `false`. Иначе для hit-test использует сохранённые размеры меню и координаты последнего `Overlay`; если сохранённая координата отрицательна, соответствующая координата берётся из `X` или `Y`.

- **Press:** событие внутри прямоугольника рамки поглощается. Если вертикальная координата соответствует строке элемента (с вычитанием верхней рамки), вызываются его `Action`, если не nil, и затем `OnClose`, если не nil. Нажатие по рамке внутри меню только поглощается. Нажатие вне меню вызывает `OnClose`, если он задан, и поглощается.
- **Motion:** событие поглощается. Если X строго больше левой границы меню и строго меньше правой границы минус один, а Y находится между верхней и нижней строками рамки, обновляет `selected` на индекс строки элемента, если индекс допустим. Таким образом, горизонтальная координата должна находиться внутри меню, но не на боковых границах.
- **Release:** поглощается без дополнительных действий.
- Остальные действия возвращают `false`.

### `HandleKey(msg tea.KeyMsg) bool`

Если `boxW` равен нулю, возвращает `false`.

- **Esc:** вызывает `OnClose`, если он задан, и возвращает `true`.
- **Enter:** вызывает `Action` выбранного элемента, если индекс допустим и действие не nil; затем вызывает `OnClose`, если он задан, и возвращает `true`.
- **Up:** уменьшает `selected`, ограничивая снизу нулём (без циклического перехода), и возвращает `true`.
- **Down:** увеличивает `selected`, ограничивая сверху последним индексом элемента (без циклического перехода), и возвращает `true`.
- Остальные клавиши возвращают `false`.

## Стили

- `popoverBaseStyle`: фон `gbDark1`, текст `gbLight1`.
- `popoverSelectedStyle`: фон `gbBlue`, текст `gbDark0`.

Строки элементов рендерятся с шириной содержимого; перед именем добавляется пробел. Меню имеет стандартную рамку Lipgloss с цветом переднего плана `gbDark4` и фоном `gbDark1`.

## Вспомогательная обработка строк

Для обрезки и измерения визуальных колонок применяются `ansi.Truncate()` и `ansi.StringWidth()` из `github.com/charmbracelet/x/ansi`. `visualBytePos()` используется для определения позиции байта, соответствующей визуальной колонке, при выделении правой части исходной строки.
