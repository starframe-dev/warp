# FloatPane — спецификация

## Обзор

`FloatPane` — структура плавающей панели пакета `warp`. Этот файл реализует отрисовку рамки и содержимого, обработку мыши, drag/resize, удаление ANSI-последовательностей и наложение панели на строки экрана. Управление жизненным циклом панели и нормализация при изменении viewport за пределами описанных здесь методов могут выполняться владельцем (например, `Tab`); эти действия не реализуются данным файлом.

## Структура и состояние

`FloatPane` содержит:

- `Panel Panel` — отображаемая и получающая события мыши внутренняя панель.
- `X, Y int` — координаты панели.
- `Width, Height int` — размеры панели.
- `Title string` — заголовок.
- `preferredWidth`, `preferredHeight int` — сохранённые предпочтительные размеры, используемые при clamp позиции и размера.
- `dragging`, `resizing bool`, `resizeEdge string` — состояние перетаскивания/изменения размера.
- `dragStartX`, `dragStartY`, `origX`, `origY`, `origW`, `origH int` — исходные координаты и размеры операции.
- `CloseRequested bool` — устанавливается при нажатии на кнопку ×; владелец может обработать запрос и закрыть панель.
- `CloseOnOutsideClick bool` — поле состояния; обработка клика вне панели в этом файле не выполняется.

Внутренние константы: `floatMinWidth = 10`, `floatMinHeight = 3`, `floatTitleH = 1`. Последняя константа объявлена, но методы этого файла её не используют.

## Отрисовка

`(*FloatPane).render(_, _ int) []string` игнорирует аргументы ширины и высоты. Для nil-получателя или `Width <= 0`/`Height <= 0` возвращает nil. Иначе возвращает ровно `Height` строк:

- верхняя граница содержит заголовок, линию и кнопку ×; заголовок обрезается `ansi.Truncate` с учётом ширины терминальных ячеек;
- если высота равна 1, возвращается только верхняя строка;
- иначе между верхней и нижней границами помещается содержимое `Panel.View(contentW, contentH)`, где `contentW = max(0, Width-2)`, `contentH = max(0, Height-2)`. Для nil-панели используется пустое содержимое;
- нижняя граница выводится последней.

Строки дополняются/ограничиваются визуальной шириной с помощью `padVisualLine`, содержимое обрабатывается `padContent`. Используются стили `floatBgStyle`, `floatBorderStyle`, `floatTitleStyle`, `floatCloseStyle`, определённые в пакете.

## Обработка мыши

`handleMouse(msg, mx, my)` делегирует `handleMouseWithin` с размерами viewport 0. `handleMouseWithin` принимает координаты мыши и размеры viewport; при неактивном drag/resize игнорирует события вне прямоугольника панели. Nil-получатель и неположительные размеры также игнорируются.

Обрабатываются только события с левой кнопкой:

- Press на заголовке в позиции `Width-2` устанавливает `CloseRequested = true`.
- Press на оставшейся части заголовка, кроме крайних колонок, начинает drag и сохраняет исходные координаты.
- Press на границе, найденной `hitEdge`, начинает resize и сохраняет координаты и исходный размер.
- Press внутри контента передаётся в `Panel.Update` с координатами относительно внутренней области (с вычетом рамки).
- Motion при drag смещает панель относительно начала операции и вызывает `clampPosition`. Motion при resize вызывает `applyResizeWithin` с перемещением мыши относительно начала операции и текущими размерами viewport.
- Release сбрасывает флаги drag/resize и `resizeEdge`.

Методы не реализуют закрытие по `CloseOnOutsideClick` и не передают в `Panel.Update` другие события, кроме указанного Press.

`hitEdge(x, y)` возвращает обозначение стороны или угла (`n`, `s`, `e`, `w`, `ne`, `nw`, `se`, `sw`) по совпадению с координатами границ; углы проверяются прежде сторон. Если координата не на границе, возвращается пустая строка.

## Clamp и изменение размера

`ensurePreferredSize` инициализирует неположительные preferred-размеры как максимум соответствующего минимума и текущего размера.

`clampPosition(totalW, totalH)` (для ненулевого получателя) обеспечивает неотрицательные координаты. При положительном размере viewport ограничивает видимый размер минимумом preferred-размера и размера viewport, затем ограничивает координату так, чтобы панель помещалась. Для неположительного размера viewport устанавливает соответствующий видимый размер в preferred-размер. Метод не уменьшает preferred-размер при clamp.

`applyResize(dx, dy)` делегирует `applyResizeWithin(dx, dy, 0, 0)`, то есть сам не получает ограничения viewport. `applyResizeWithin` изменяет края согласно `resizeEdge`, сохраняет противоположный край при resize с запада/севера, обеспечивает минимальные размеры (10×3 либо доступный меньший размер положительного viewport), ограничивает края viewport, если его размеры положительны, и обновляет `X`, `Y`, `Width`, `Height`. Итоговые видимые размеры записываются в `preferredWidth`/`preferredHeight`. Ограничение координат к нулю применяется также при viewport нулевого размера; верхняя граница экрана в этом случае неизвестна.

`clampInt` ограничивает целое число заданным диапазоном; если `high < low`, возвращает `high`.

## ANSI и наложение

`StripANSI(s)` возвращает `ansi.Strip(s)` — строку без распознанных ANSI-последовательностей.

`overlayFloat(lines, fp, totalW, totalH)` ничего не делает при nil-панели/внутреннем `Panel`, неположительных размерах float или viewport. Также пропускает панель, начало которой находится за правым/нижним краем viewport. Для остальных случаев рисует `fp.render`, обрезает и дополняет строки до видимой ширины, заменяет соответствующую область исходных строк и дополняет итоговую строку до `totalW`. Обработка ширины использует ANSI-aware функции пакета `ansi`; перед суффиксом добавляется `ansi.ResetStyle`, чтобы стили float не влияли на последующий текст. Строки экрана и панель могут быть видимо обрезаны; высота наложения ограничена высотой viewport и количеством строк `lines`.

`visualBytePosAfter(s, targetW)` находит байтовую позицию после целевой визуальной ширины с учётом grapheme cluster через `uniseg`; при неположительной ширине возвращает 0.

## Зависимости

Файл использует стандартный пакет `strings`, `github.com/charmbracelet/bubbletea`, `github.com/charmbracelet/x/ansi` и `github.com/rivo/uniseg`. Другие упомянутые выше функции, типы, стили и панельные вспомогательные функции должны предоставляться пакетом `warp`.
