# TabGroup — Спецификация

## Описание

`TabGroup` — компонент `Panel`, который отображает панель вкладок и переключение между вкладками. Предназначен для использования внутри splits, flex layouts или как корневой panel.

## Публичный API

### Конструкторы

```go
// NewTabGroup создаёт TabGroup panel с одной дефолтной вкладкой "main".
func NewTabGroup(pos TabPosition) *TabGroup
```

```go
// NewTab создаёт новую вкладку и переключается на неё.
func (tg *TabGroup) NewTab(name string) *Tab
```

### Методы доступа

```go
// ActiveTab возвращает текущую активную вкладку или nil при недопустимом индексе.
func (tg *TabGroup) ActiveTab() *Tab
```

```go
// NextTab переключает на следующую вкладку циклически, если вкладок больше одной.
func (tg *TabGroup) NextTab()
```

```go
// PrevTab переключает на предыдущую вкладку циклически, если вкладок больше одной.
func (tg *TabGroup) PrevTab()
```

### Panel interface

```go
// View рендерит таббар и контент активной вкладки.
func (tg *TabGroup) View(w, h int) string

// Update обрабатывает сообщения и передаёт их вкладкам.
func (tg *TabGroup) Update(msg tea.Msg) tea.Cmd

// Elements возвращает элементы активной вкладки со сдвигом относительно таббара.
func (tg *TabGroup) Elements(w, h int) []Element
```

## Внутреннее устройство и поведение

`TabGroup` хранит вкладки, индекс активной вкладки, последнюю геометрию, позицию таббара и области клика. `NewTabGroup` создаёт вкладку `main`; `NewTab` добавляет вкладку, переключается на неё и возвращает её.

`closeTab(idx)` игнорирует неверный индекс и попытку закрыть последнюю вкладку. Перед удалением очищает focus удаляемой вкладки, затем удаляет и очищает её ссылки. После detach проверяет reachability кандидатов во всём домене владения; `Unmount` получают только экземпляры, больше нигде в домене не используемые. Повторные ссылки на один экземпляр дедуплицируются. При закрытии вкладки перед активной корректирует индекс активной; при закрытии активной выбирает вкладку на её позиции либо последнюю оставшуюся и восстанавливает её focus.

`switchTab(idx)` игнорирует неверный индекс и текущую вкладку. При переключении приостанавливает focus старой вкладки и восстанавливает focus новой. `NextTab` и `PrevTab` переключают циклически, только если вкладок больше одной.

### Рендеринг и геометрия

`View(w, h)` сохраняет неотрицательные ширину и высоту. При отсутствии активной вкладки возвращает `emptyView(h)`. В остальных случаях отображает активный контент и таббар согласно `TabPosition`:

- `TabTop`: таббар сверху, контент ниже.
- `TabBottom`: контент сверху, таббар снизу.
- `TabLeft`: таббар слева, контент справа.
- `TabRight`: контент слева, таббар справа.
- `TabNone`: только контент.

Ширина контента уменьшается на ширину вертикального таббара для `TabLeft`/`TabRight`; высота уменьшается на одну строку для `TabTop`/`TabBottom`. Размеры контента не бывают отрицательными. `contentOffset()` возвращает `(0,1)` для `TabTop`, `(verticalTabWidth,0)` для `TabLeft` и `(0,0)` для остальных позиций.

Горизонтальные названия ограничиваются 20 терминальными ячейками, вертикальные — 15; усечение учитывает ширину Unicode-текста. Активная вкладка отображается с `▎` и `×`, остальные — без кнопки закрытия; кнопка `+` создаёт вкладку с именем `tab`. Ширина вертикального таббара вычисляется по меткам с учётом доступной ширины. Таббар по высоте обрезается до `tg.height`.

`Elements(w,h)` собирает элементы активной вкладки и сдвигает их координаты (включая вложенные элементы) на смещение таббара. Для вертикальной позиции ширину таббара вычисляет непосредственно из меток и переданной ширины, не вызывая рендеринг и не изменяя сохранённую `verticalTabWidth`; поэтому результат не зависит от предшествующего `View`.

Области клика пересчитываются при рендеринге горизонтального или вертикального таббара. В горизонтальном таббаре `newTabRegion` — отдельная область `+` справа от вкладок. В вертикальном таббаре отдельная `newTabRegion` не используется: строка `+` хранится в `tabRegions` с индексом `-1`. `tabRegion` хранит индекс вкладки (либо `-1` для `+`), горизонтальные границы и позицию кнопки закрытия (`-1`, если её нет).

### Обработка ввода и сообщений

`Update` направляет:

- `tea.KeyMsg` в `handleKeyMsg`;
- `tea.MouseMsg` в `handleMouseMsg`;
- `tea.WindowSizeMsg` и `ResizeMsg` — всем вкладкам, обновляя сохранённые размеры;
- прочие сообщения — всем вкладкам через `broadcastMsg`.

`handleKeyMsg` сначала передаёт клавишу активной вкладке, если её сфокусированная панель реализует `RawKeyReceiver` и `WantsRawKeys()` возвращает `true`. Иначе `Ctrl+Tab`/`Ctrl+Shift+Tab` переключают вкладку, `Ctrl+W` закрывает активную вкладку, `Ctrl+T` создаёт вкладку `tab`, `Ctrl+C` завершает программу; остальные клавиши передаются активной вкладке.

`handleMouseMsg` передаёт клик в обработчик таббара, если он попал в его область, иначе передаёт мышиное сообщение активной вкладке с координатами и размерами контента. Обрабатываются только нажатия левой кнопки. Клик по вкладке переключает её, по `+` создаёт вкладку, по `×` закрывает вкладку с этой областью. Кнопка `×` отображается только у активной вкладки. Для правого вертикального таббара X преобразуется из экранных координат в координаты таббара.

Область таббара определяется первой строкой для `TabTop`, последней строкой для `TabBottom`, левой вертикальной полосой для `TabLeft` и правой полосой для `TabRight`; для `TabNone` её нет.

## Владение ресурсами

Standalone `TabGroup` владеет своими вкладками и их панелями; вложенный в `Warp` `TabGroup` использует домен внешнего корня. Совместное использование панели независимыми корнями не отслеживается и должно контролироваться вызывающим кодом.

## Стили

- `inactiveTabStyle` — неактивные вкладки.
- `activeTabStyle` — активная вкладка.
- `newTabStyle` — кнопка `+`.
- `tabBarStyle` — фон горизонтального таббара.

## Ключевые правила

1. Нельзя закрыть последнюю вкладку.
2. Переключение вкладок циклическое.
3. `Elements` вычисляет вертикальную ширину независимо от предшествующего рендеринга и не изменяет сохранённое состояние ширины.
4. Имена усекаются с учётом терминальной ширины: до 20 ячеек по горизонтали и до 15 по вертикали.
5. Закрыть вкладку можно через `Ctrl+W` (активную) или кликом по отображаемой кнопке `×` активной вкладки.
