# Split

## Назначение

Файл объявляет типы дерева панелей, split/flex-конфигурации и вспомогательные методы обхода и состояния узлов. Раскладку и расчёт размеров он не реализует.

## Типы и константы

### Direction

`Direction` — целочисленный тип направления. `Vertical` имеет значение `0` и означает расположение слева/справа; `Horizontal` имеет значение `1` и означает расположение сверху/снизу.

### ResizeMsg

Сообщение с шириной и высотой панели в ячейках (контент без границ и отступов). Сам файл не отправляет это сообщение и не обрабатывает его.

### MinPanelSize

Константа равна `3`. В этом файле она лишь объявлена; ограничения размеров раскладки здесь не вычисляются.

### SplitConfig

Содержит направление, долю пространства первого потомка (`Fraction`), указатели на `First` и `Second`, признак `Dragging`, строку `CollapseRow` (индекс с нуля) и callback `OnCollapse func() tea.Cmd`. Callback предназначен для реакции на нажатие «<»; файл не вызывает его. Значение `Fraction` здесь не проверяется и не ограничивается диапазоном.

### NodeCollapse

Хранит `Active`, фиксированные `Width` и `Height`, а также сохранённую долю `Saved`. Этот тип только объявлен; логика изменения состояния узла в файле отсутствует.

### Node

Узел содержит поля `Panel`, `Split`, `Flex` и `Collapse`. Код не проверяет и не обеспечивает взаимоисключение этих полей.

### FlexItem и FlexConfig

`FlexItem` содержит узел, веса `Grow` и `Shrink`, базовый размер `Basis` и флаг `Collapsed`. Комментарий указывает, что `Shrink` пока не используется. `FlexConfig` содержит направление, список элементов и признак `Dragging`. Расчёта flex-размеров в файле нет.

## Методы Node

### IsLeaf

Возвращает `true`, только если получатель не nil, `Panel` не nil согласно `isNilPanel`, а `Split` и `Flex` равны nil. Поле `Collapse` на результат не влияет.

### IsCollapsed

Возвращает `true`, если узел не nil, `Collapse` не nil и `Collapse.Active` равно `true`.

### CollapsedSize

Возвращает `0`, если узел nil или не активен. При направлении `Vertical` возвращает положительное заданное `Width`, иначе `1`. Для любого другого направления возвращает положительное заданное `Height`, иначе `1`.

### findNode

Рекурсивно ищет лист с указанной панелью. Возвращает nil, если получатель nil, аргумент панели nil или совпадение не найдено. Сначала проверяет текущий узел (только если он лист), затем обходит `Split.First`, `Split.Second` и элементы `Flex.Items` по порядку. Элементы Flex, равные nil, пропускаются. Для сравнения используются `isNilPanel` и `samePanel`.

### findSplitParent

Ищет узел, у которого непосредственно в `Split.First` или `Split.Second` находится лист с указанной панелью. Если прямого совпадения нет, рекурсивно обходит обе ветви Split и узлы ненулевых элементов Flex. Возвращает первый найденный родительский узел либо nil; сам узел не считается родителем своей панели. Аргумент nil или nil-получатель дают nil.

### replaceNode

Заменяет первое в глубинном обходе совпадение указателя `old` на `new` в дочерних узлах Split или элементах Flex и возвращает true. При отсутствии совпадения или nil-получателе возвращает false. При рекурсии nil-потомок безопасно даёт false. Метод меняет только ссылку на узел и не очищает другие поля заменяемого узла.

### collectLeafNodes

Возвращает nil для nil-узла. Для листа возвращает срез с этим узлом. Иначе собирает листья в порядке обхода: сначала First, затем Second для Split; затем узлы элементов Flex в порядке списка. Nil-элементы Flex пропускаются. Узлы без листа и без дочерних узлов дают пустой срез.

## Границы реализации

Файл не выполняет компоновку, не гарантирует неотрицательные размеры или соблюдение минимального размера, не управляет перетаскиванием и сворачиванием и не поддерживает инварианты взаимоисключения вариантов `Node`. Эти действия должны реализовываться в других частях проекта.
