# Tab

Спецификация `warp/tab.go`: компонент управления деревом панелей вкладки, их раскладкой, фокусом и событиями Bubble Tea.

## Типы и начальное состояние

`TabPosition` — целочисленный тип позиции панели вкладок; константы `TabTop`, `TabBottom`, `TabLeft`, `TabRight`, `TabNone` получают значения 0–4 через `iota`.

`Tab` хранит имя, корневой `Node`, сфокусированную панель, плавающие панели, родительскую `TabGroup`, размеры и внутреннее состояние перетаскивания. `FlexItemSpec` содержит `Panel` и вес `Grow`.

`newTab(name, parent)` создаёт вкладку с родителем, а `NewTab(name)` — самостоятельную вкладку. Обе начинают с корневого `emptyPanel`. Самостоятельная вкладка создаёт собственный домен владения; вкладка с родителем использует домен владения родителя. `ensureRoot` восстанавливает пустой корень, если он отсутствует. `RootPanel` возвращает панель корня; `SetRootPanel` заменяет корень, заменяет nil-панель пустой, очищает фокус и состояние раскладки/перетаскивания.

## Построение раскладки

- `SplitVertical(parent, fraction, newPanel)` и `SplitHorizontal(...)` заменяют узел найденной панели split-узлом. Первая доля соответствует левой или верхней панели; доля ограничивается диапазоном 0.1–0.9. Nil-панель заменяется пустой. При отсутствии подходящей панели операция ничего не меняет.
- `FlexRow(parent, items)` и `FlexColumn(...)` заменяют узел flex-раскладкой горизонтального или вертикального направления. При пустом списке или не найденном узле ничего не меняется. Отрицательный `Grow` становится нулём, nil-панели заменяются пустыми. После замены фокус очищается, если сфокусированная панель больше не входит во вкладку.
- `Float(panel, x, y, width, height)` добавляет плавающую панель только при ненулевой панели и положительных исходных размерах. Размеры доводятся до минимальных размеров float-панели, координаты — не ниже нуля, позиция ограничивается текущим viewport. Новая панель получает заголовок `Float`.
- `CloseFloat(fp)` удаляет совпадающую плавающую панель. Если сфокусированная панель после удаления больше не входит во вкладку, фокус очищается.

## Фокус

`Focus()` возвращает текущую сфокусированную панель. `SetFocus(panel)` задаёт её и возвращает nil-команду. `FocusNext`, `FocusPrev` циклически переходят между фокусируемыми панелями; `FocusFirst` выбирает первую, а `FocusPanel` выбирает указанную, если она фокусируема. Список состоит из focusable панелей root layout, затем focusable floats в порядке их списка; одинаковый экземпляр панели дедуплицируется. При смене фокуса старый target получает `Blur`, новый — `Focus` только для активной вкладки. Для standalone-вкладки она считается активной. `handleKeys` передаёт клавишу только сфокусированной панели; Tab/Shift+Tab автоматически не перехватываются.

`ToggleCollapsible(panel)` переключает состояние найденного `Collapsible`; если панель является прямым элементом flex, обновляет также флаг `FlexItem.Collapsed`.

## Сворачивание и split

`SetSplitCollapse(parent, collapseRow, onCollapse)` находит split, содержащий панель, задаёт строку символа сворачивания и callback. При срабатывании callback переключает `Collapse.Active` у первого дочернего узла; пользовательский callback вызывается, если он задан. `ToggleSplitCollapse` выполняет такое же переключение для найденного split.

`SetSplitFraction(panel, fraction)` ограничивает долю [0.1, 0.9], изменяет долю стороны split, содержащей панель, и возвращает, найден ли узел панели внутри split. `GetSplitFraction` возвращает долю стороны, содержащей панель, или `(0, false)`, если split не найден.

`Collapse(panel, size)` возвращает true, если узел панели найден внутри split или flex. Для split сохраняет размер и прежнюю долю для восстановления; для flex выставляет `FlexItem.Collapsed` и, если панель — `Collapsible`, её состояние `Collapsed`. `Expand(panel)` возвращает true, если узел найден внутри split или flex, независимо от предшествующего состояния; для split снимает флаг сворачивания и восстанавливает сохранённую долю, если она положительна, а для flex сбрасывает `Collapsed` и синхронизирует `Collapsible`.

## Отрисовка, размеры и события

`View(width, height)` рендерит дерево и накладывает float-панели поверх. `Elements(w, h)` возвращает элементы float сверху вниз по z-порядку; для каждого float сначала добавляются chrome-элементы (кнопка закрытия, затем titlebar, если позволяют размеры), затем semantic elements содержимого. Элементы содержимого обрезаются по bounds float. Далее идут кнопки настроенных split-collapse (`button` / `toggle-collapse`), затем элементы root layout. Кнопка закрытия имеет роль `button` и действие `close-float`; titlebar — роль `titlebar` и действие `move-float`.

`HandleMouse(msg)` обрабатывает мышь без смещения, используя текущие размеры вкладки; внутренний `handleMouse` принимает смещения и размеры области содержимого. Обработка мыши проверяет плавающие панели сверху вниз, затем символы сворачивания, границы split/flex и панели под курсором. Клики по панели устанавливают фокус и пересылаются ей с координатами относительно панели. Клик внутри float может поднять его наверх по z-порядку; float может закрываться по outside-click согласно настройке. Перетаскивание границ обновляет раскладку и рассылает resize; отпускание завершённого drag также рассылает resize.

`Update(msg)`:
- на `tea.WindowSizeMsg` сохраняет размеры, ограничивает позиции float, рассылает листовым панелям вычисленные `ResizeMsg`, а также исходное сообщение для обратной совместимости;
- на `ResizeMsg` сохраняет размеры, ограничивает позиции float и рассылает вычисленные `ResizeMsg` листовым панелям;
- прочие сообщения рассылает листовым панелям дерева и float-панелям.

`BroadcastResize()` возвращает `tea.BatchMsg` команд, полученных от листовых панелей после рассылки resize с текущими размерами вкладки. `broadcastMsg` передаёт сообщение листьям дерева и float-панелям.

## Владение ресурсами

При `SetRootPanel`, Flex replacement и `CloseFloat` код собирает кандидатов из удаляемой структуры, отсоединяет её и затем проверяет достижимость панелей в домене владения. `Unmount` вызывается только для недостижимых экземпляров, однократно на экземпляр. Reparenting, скрытие, сворачивание и смена focus не освобождают панель. Указательные панели сравниваются по типу и адресу, не через deep equality.

## Внутренние функции

Внутренние методы включают `ensureRoot`, `resetLayoutState`, `setLastBorders`, `clearAfterRemoval`, `renderContent`, `clampFloatsToViewport`, `clampFloats`, `floatChromeElements`, `floatElements`, `floatBoundsForViewport`, `layoutControlElements`, `focusStep`, `focusables`, `setFocusedFocusable`, `setFocus`, `isActive`, `suspendFocus`, `resumeFocus`, `handleMouse`, `handleKeys`, `panelAt`, `collapseNode`, `expandNode`, `saveCollapse`, `saveFractionForNode`, `restoreCollapse`, `setSplitFractionNode`, `getSplitFractionNode`, методы рассылки и изменения размеров (`appendResizeCommands`, `broadcastResize`, `appendBroadcastMsg`, `appendBroadcastNode`), а также методы обработки границ и перетаскивания (`hitBorder`, `updateDrag`, `updateDragWithLayout`, `updateSplitDrag`, `updateFlexDrag`, `updateFlexCollapsed`, `updateFlexCollapsedNode`). `emptyPanel` — пустая реализация `Panel`, возвращающая пустую строку и nil-команду.
