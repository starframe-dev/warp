# warp.md — Спецификация пакета warp

## Обзор

Пакет `warp` предоставляет корневую модель Bubbletea-приложения с поддержкой вложенных панелей и HTTP-API для экспорта элемента дерева UI.

## Публичный API

### Тип `Warp`

Корневая модель Bubbletea, которая содержит:

- **root Panel** — корневая панель (по умолчанию `TabGroup`), к которой делегируются все сообщения и рендеринг
- **width/height** — последние известные размеры окна
- **httpServer** — HTTP-сервер (опционально)
- **httpAddr** — адрес HTTP-сервера (опционально)
- **mu sync.RWMutex** — защищает корневую панель, размеры окна и состояние HTTP-сервера
- Неизменяемый snapshot элементов — формируется на UI-потоке после `Update`/`View`; HTTP читает только последний завершённый snapshot

#### Конструкторы и фабричные методы

| Метод | Возвращает | Описание |
|-------|-----------|----------|
| `New()` | `*Warp` | Создаёт новый Warp с корневой `TabGroup` (один вкладка по умолчанию) |

#### Методы управления корнем

| Метод | Возвращает | Описание |
|-------|-----------|----------|
| `SetRoot(panel Panel)` | `void` | Заменяет корневую панель. Используется для установки кастомных layouts |
| `Root() Panel` | `Panel` | Возвращает текущую корневую панель |

#### Комиссионные методы (делегирование корневой панели)

Эти методы делегируются корневой панели, если она реализует `TabGroup`:

| Метод | Возвращает | Описание |
|-------|-----------|----------|
| `tabGroup() *TabGroup` | `*TabGroup` | Внутренний метод для получения `TabGroup` из корня |
| `Width() int` | `int` | Возвращает последнюю известную ширину |
| `Height() int` | `int` | Возвращает последнюю известную высоту |
| `NewTab(name string) *Tab` | `*Tab` | Создаёт новую вкладку в корневой `TabGroup` |
| `ActiveTab() *Tab` | `*Tab` | Возвращает активную вкладку |
| `SetTabPosition(pos TabPosition)` | `void` | Устанавливает позицию вкладок |
| `NextTab()` | `void` | Переходит к следующей вкладке |
| `PrevTab()` | `void` | Переходит к предыдущей вкладке |

#### Bubbletea методы

| Метод | Возвращает | Описание |
|-------|-----------|----------|
| `Init()` | `tea.Cmd` | Инициализация Bubbletea (возвращает nil) |
| `Update(msg tea.Msg) (tea.Model, tea.Cmd)` | `(tea.Model, tea.Cmd)` | Делегирует все сообщения корневой панели. Обновляет размеры при `tea.WindowSizeMsg` |
| `View() string` | `string` | Рендерит корневую панель. Возвращает "Loading..." если размеры не известны |

#### HTTP API

| Метод | Возвращает | Описание |
|-------|-----------|----------|
| `ServeHTTP(addr string) error` | `error` | Запускает HTTP-сервер с маршрутами `/elements` и `/healthz`; при пустом адресе слушает loopback и использует `WARP_HTTP_PORT` либо порт 0 |
| `CloseHTTP() error` | `error` | Очищает сохранённый адрес под mutex и останавливает HTTP-сервер вне mutex |
| `HTTPAddr() string` | `string` | Возвращает текущий адрес HTTP-сервера |

#### Вложенные панели

| Метод | Возвращает | Описание |
|-------|-----------|----------|
| `AsPanel() Panel` | `Panel` | Возвращает адаптер `Warp` для реализации интерфейса `Panel`, позволяющий вложенные warps |

## Тип `warpPanel`

Внутренний тип, реализующий интерфейс `Panel` для адаптации `Warp`:

| Метод | Возвращает | Описание |
|-------|-----------|----------|
| `View(width, height int) string` | `string` | Устанавливает размеры и рендерит warp |
| `Update(msg tea.Msg) tea.Cmd` | `tea.Cmd` | Обновляет warp и возвращает команду |

## Интерфейс Panel

Описывает базовый интерфейс панели для Bubbletea. Реализуется через `warpPanel`.

| Метод | Возвращает | Описание |
|-------|-----------|----------|
| `View(width, height int) string` | `string` | Рендеринг панели |
| `Update(msg tea.Msg) tea.Cmd` | `tea.Cmd` | Обработка сообщений |

## HTTP API

### Эндпоинты

#### `/elements`

Возвращает JSON-массив `Element` с полями `role`, `name`, `action`, `bounds` и `children`. Пустая или не заданная ширина/высота Warp заменяется на 80×24.

**Заголовки:**
- `Content-Type: application/json`
- `Access-Control-Allow-Origin: *`

**Ответ:**
```json
[
  { "role": "button", "name": "Save", "bounds": { "x": 0, "y": 0, "w": 8, "h": 1 } }
]
```

**Привязка и безопасность:**
- Пустой `addr`: `127.0.0.1:<WARP_HTTP_PORT>`; если переменная не задана, порт выбирается системой.
- Непустой `addr` используется без изменения. Адрес вида `:8080` может слушать все сетевые интерфейсы.
- `/elements` не имеет аутентификации и разрешает CORS для `*`; внешний адрес следует защищать отдельно.
- HTTP-запросы могут обрабатываться параллельно и читают только последний завершённый неизменяемый snapshot; запрос не обходит живое дерево панелей и не вызывает `ElementProvider.Elements`.
- Snapshot строится на UI-потоке после `Update` и `View`; `/elements` может кратковременно отражать предыдущее завершённое UI-состояние, но не частично изменённое дерево.
- Построение snapshot вызывает `ElementProvider.Elements` без удержания mutex Warp.
- `CloseHTTP` не удерживает mutex Warp во время `http.Server.Shutdown`, чтобы активные обработчики могли читать Warp.

#### `/healthz`

Эндпоинт здоровья для проверки доступности сервера.

**Ответ:**
```
ok
```

## Внутренние функции

### `parsePort(addr string) string`

Извлекает порт из адреса. Возвращает пустую строку, если адрес не содержит порта.

## Правила проектирования

### Явные границы

- Все HTTP-эндпоинты явно определены через `mux.HandleFunc`
- `mu` защищает состояние Warp; пользовательские методы панели вызываются после снятия блокировки
- HTTP-сервер запускается в отдельной гору

### Парси, не валидируй

- HTTP-эндпоинт `/elements` парсит размеры, используя дефолтные значения (80x24), если они не заданы
- Не валидируется входной адрес HTTP

### Ошибки как значения

- Ошибки оборачиваются через `fmt.Errorf("context: %w", err)`
- Возвращаются без игнорирования (кроме логированных)

### Композиция

- `Warp` не наследуется, а компонуется с `Panel` через `SetRoot`
- `warpPanel` реализует `Panel` через композицию

### TDD

- Реализация следует паттерну Red-Green-Refactor
- Тесты должны выполняться за < 1 сек

### Именование

- Экспортируемые типы: PascalCase (`Warp`, `Panel`)
- Внутренние типы: camelCase (`warpPanel`)
- Пакеты: lowercase (`warp`)

## Архитектурные решения

### Bubbletea Model/Update/View

Пакет использует архитектурный паттерн Elm (Model/Update/View) через Bubbletea.

### Делегирование

Все сообщения делегируются корневой панели без перехвата, что позволяет легко менять layouts.

### HTTP API для элемента дерева

Внешний API для взаимодействия с UI экспортирует дерево элементов через JSON. Это позволяет:
- Интеграции с внешними сервисами
- Асинхронному рендерингу
- Инструментированию UI

### Вложенность

Через `AsPanel()` любой `Warp` может быть вложен в другую панель, обеспечивая гибкую компоновку layouts (сplits, flex, nested tab groups).

## Таргет Terminal

Пакет предназначен для терминального таргета Human Horizon:

- Использует `bubbletea` для TUI
- Поддерживает ANSI-escape коды через `charmbracelet`
- Может запускать дочерние процессы через `creack/pty` (если будет добавлено)
