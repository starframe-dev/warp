# Исправления корректности компонентов

## Контекст

На ревизии `4bbccc9ed0832bdf1a9c204c8206131e3e522dad` обнаружены локальные ошибки отдельных компонентов: вызовы nil callbacks, неверные границы выделения, несогласованность состояния collapse/focus, некорректная маршрутизация мыши и рендеринга, а также несколько случаев неточного ANSI/viewport-обработчика.

## Цель

Исправить только перечисленные component-level дефекты без переработки архитектуры layout, HTTP snapshot, drag, grapheme-aware Input, float preferred-size, общей focus API или theme. Каждый дефект должен иметь отдельную регрессию.

## Что изменится

- `popover.go`, `selectable.go`, `tab.go`, `collapsible.go`, `input.go`, `dropdown.go`, `scrollable.go`, `modal.go`, `tabgroup.go` и соответствующие тесты.
- Затронутые спецификации `code-specs/*.md` и связанные страницы документации.
- `.lore/weft/.env`, `.lore/.gitignore` и при необходимости manifest-конфигурация Weft; pipeline сохраняется.

## Детали реализации

1. `Popover` пропускает nil `Action`, но сохраняет обычное закрытие и `OnClose`.
2. `Selectable` использует end-exclusive границы `[start, end)`, допускает активный конец `x == width` и возвращает весь текст через `SelectAll`; View, подсветка, извлечение, мышь и Shift+стрелки используют согласованные границы.
3. `Tab.Collapse`/`Expand` устанавливают состояние `FlexItem` и `Collapsible` явно; `SetSplitCollapse` сохраняет внутреннюю логику при nil внешнем callback.
4. Закрытие float/tab снимает фокус с удаляемой focusable-панели. Переключение вкладок снимает фактический focus с неактивной панели и восстанавливает его у выбранной панели при возврате.
5. Раскрытый `Collapsible` всегда отображает строку заголовка. Содержимое использует высоту `h-1`, координаты мыши и resize учитывают смещение заголовка; свёрнутое состояние остаётся высотой в одну строку.
6. `Input` отображает ровно одну строку значения в boxed режиме. `DropdownMenu` обновляет `Hovered` на mouse motion и снимает hover вне строк пунктов без выбора пункта.
7. Nil-content wrappers возвращают ровно запрошенное число строк; одинаковые `strings.Repeat("\n", h)` в scope проверяются и нормализуются.
8. `Modal` удаляет ANSI escape sequences через `ansi.Strip` вместо ограниченной regexp.
9. Установленная версия Weft читает конфигурацию только из `.lore/weft/.env`. Файл остаётся отслеживаемым для не-секретного model mapping, получает явное предупреждение не помещать туда секреты; альтернативные локальные secret-файлы игнорируются, pipeline сохраняется.

## Критерии приёмки

- [x] Nil Action в Popover не вызывает panic при мыши/Enter; `OnClose` вызывается.
- [x] `SelectAll`, forward/reverse mouse и Shift+Right возвращают точные строки `abc`, `Привет`, `界A`, `👩‍💻x`, `éx`.
- [x] Повторные Collapse и Expand остаются идемпотентными; геометрия и UI-состояние совпадают.
- [x] Nil callback `SetSplitCollapse` безопасен и внутренний state меняется.
- [x] Закрытие сфокусированного float и tab вызывает Blur; переключение вкладок размывает старую и восстанавливает focus новой/возвращённой вкладки.
- [x] Click по видимому заголовку Collapsible переключает состояние, click по первой строке раскрытого содержимого передаётся контенту.
- [x] Input boxed режим показывает значение ровно один раз при высотах 3, 4, 5 и 8.
- [x] Dropdown hover следует за мышью только по видимым строкам; выход снимает hover, clipped-строка не выбирается, выбор происходит только при click.
- [x] Nil-content `Scrollable`, `Selectable` и отсутствующий `TabGroup` возвращают ровно `h` строк для `h=0..5`; `Collapsible` сохраняет высоту с постоянной строкой заголовка.
- [x] Modal background корректно очищает SGR, OSC и styled Unicode ANSI-последовательности.
- [x] Отслеживаемый `.lore/weft/.env` содержит только не-секретный alias модели и предупреждение; локальные secret-файлы игнорируются; resolver Weft сохраняет прежний mapping.
- [x] Проходят `gofmt -w .`, `go vet ./...`, `go test ./...`, `go test -race ./...`, `pnpm install --frozen-lockfile` в `docs` и `pnpm vitepress build`.
