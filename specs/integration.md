# Интеграция Warp

## Встраивание в Bubble Tea

Warp сам реализует `tea.Model`; `AsPanel()` даёт адаптер `Panel`, который устанавливает переданные размеры и проксирует View/Update. Внешний layout отвечает за размер адаптера, внутренний Warp — за собственное дерево.

```go
inner := warp.New()
outerTab.SplitVertical(outerTab.RootPanel(), 0.5, inner.AsPanel())
```

Вложенный Warp включается в ownership domain внешней структуры. Его HTTP inspector не запускается автоматически: каждый Warp требует отдельного явного `ServeHTTP`.

## Семантические элементы и E2E

Панели, реализующие `ElementProvider`, возвращают semantic tree `[]Element` в терминальных координатах. Wrapper-ы должны учитывать собственные смещения и viewport. `FindElement` ищет первое совпадение по role/name/action (пустой фильтр означает любое значение); `Bounds.Center()` пригоден для вычисления точки клика. Запрос дерева не рендерит UI и доступен по HTTP только при включённом inspector.

`GET /elements` возвращает опубликованный JSON snapshot; пока размер окна неизвестен, провайдеры получают fallback `80×24`. Snapshot может отражать последний Update/View, а не состояние, синхронно вычисленное HTTP-запросом. `GET /healthz` возвращает `ok`.

## HTTP inspector

```go
err := w.ServeHTTP(":8080")
addr := w.HTTPAddr()
err = w.CloseHTTP()
```

Пустой адрес использует порт из `WARP_HTTP_PORT`; если переменная не задана, используется случайный порт на loopback `127.0.0.1`. Для сетевого адреса можно передать конкретный bind address. Повторный запуск уже запущенного/закрывающегося сервера безопасно игнорируется. `Warp.Close()` останавливает HTTP и освобождает панели, которыми владеет корень Warp.

`ServeHTTP` эквивалентен `ServeHTTPWithOptions(addr, InspectorOptions{})`. По умолчанию CORS не разрешён, bearer token не требуется. `InspectorOptions{AllowedOrigin: ..., BearerToken: ...}` включает точный origin либо `*` и/или обязательный Bearer token для `/elements`. Префлайт OPTIONS поддерживается; endpoint не принимает другие методы. `/healthz` предназначен для проверки доступности. Сервер задаёт read-header, idle и write timeouts; shutdown ограничен пятью секундами с принудительным закрытием при timeout.

Inspector — интерфейс чтения состояния, не событийный API. HTTP-запросы не посылают клавиатурные/мышиные события обратно в Bubble Tea. При доступе извне bind-адрес и параметры авторизации/CORS должны выбираться осознанно.

## Размеры и coordinate space

Размеры панелей, `Bounds` элементов и мышиные координаты выражены в терминальных ячейках. При вложении внешняя система определяет границы Panel, а адаптер Warp применяет переданные размеры к внутреннему окну. Провайдеры semantic tree обязаны возвращать bounds в системе координат своей панели; обёртки переводят их в родительскую систему.

## Тестирование и эксплуатация

Обычная проверка библиотеки: `go test ./...`, `go test -race ./...`, `go vet ./...`. Unit-тесты располагаются рядом с кодом; E2E может сочетать `/elements`, `FindElement`, ввод Bubble Tea и повторную проверку snapshot. Benchmark suite запускается отдельно вручную и не требуется для обычного запуска приложения.
