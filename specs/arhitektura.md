# Архитектура проекта warp

## Обзор архитектуры

Библиотека `warp` представляет собой набор UI-компонентов для Go, построенных на основе системы рендеринга на основе элементов (element-based rendering system). Архитектура библиотеки спроектирована для обеспечения модульности, расширяемости и простоты композиции компонентов.

## Структура модулей

Библиотека состоит из следующих основных модулей:

### Ядро (core)

- **`render.go`** — Основной модуль рендеринга. Содержит систему элементов, обработчики событий и механизмы отрисовки UI.
- **`element.go`** — Базовый тип элемента UI. Определяет контракт для всех элементов и обработчики событий.
- **`styles.go`** — Система стилей. Предоставляет механизмы для определения и применения CSS-подобных стилей.
- **`wrap.go`** — Обёртки для элементов. Позволяют создавать кастомные контейнеры вокруг элементов.

### Компоненты (components)

Каждый компонент представляет собой самодостаточную единицу с собственной логикой:

- **`modal.go`** — Модальные окна с обработчиком событий и состоянием открытости.
- **`tab.go`** — Табы с переключением между содержимым.
- **`dropdown.go`** — Выпадающие списки с поддержкой выбора и отрисовки опций.
- **`input.go`** — Поля ввода с поддержкой валидации и обработки событий.
- **`scrollable.go`** — Скроллящие контейнеры с поддержкой прокрутки.
- **`selectable.go`** — Компоненты с поддержкой выделения (checkbox, radio, select).
- **`panel.go`** — Панели с возможностью раскрытия/скрытия.
- **`popover.go`** — Всплывающие подсказки с позиционированием.
- **`float.go`** — Плавающие элементы с позиционированием.
- **`drag.go`** — Перетаскивание элементов.
- **`split.go`** — Разделители с возможностью перетаскивания границ.
- **`wrap.go`** — Обёртки для создания кастомных контейнеров.
- **`focus.go`** — Управление фокусом элементов.
- **`collapsible.go`** — Раскрываемые секции.

### Группы компонентов (component groups)

- **`tabgroup.go`** — Группировка табов в единую структуру.
- **`dropdown.go`** — Группировка выпадающих списков.

## Композиция компонентов

Компоненты библиотеки спроектированы для простой композиции:

1. **Иерархия элементов**: Каждый компонент может содержать вложенные элементы.
2. **События**: События всплывают по иерархии элементов.
3. **Состояние**: Состояние каждого компонента изолировано и не зависит от других.

## Рендеринг

Система рендеринга основана на:

1. **Элементы**: Базовый тип `Element`, определяющий контракт для UI-элементов.
2. **Стек вызовов**: Рендеринг происходит через стек вызовов, где каждый элемент знает о своих родителях.
3. **Отрисовка**: Элементы отрисовываются в порядке их добавления на стек.

## Событийная модель

Событийная модель включает:

1. **Обработчики событий**: Каждый элемент может регистрировать обработчики событий.
2. **Всплытие событий**: События всплывают по иерархии элементов.
3. **Прекращение всплытия**: События могут быть остановлены обработчиками.

## Стили

Система стилей предоставляет:

1. **CSS-подобный синтаксис**: Стили определяются в декларативном формате.
2. **Иерархия стилей**: Стили наследуются от родительских элементов.
3. **Динамические стили**: Стили могут изменяться в зависимости от состояния.
