# Финальные edge cases Warp

## Контекст

После предыдущего исправления компонентов остались узкие ошибки: `SelectedText` теряет пустые строки между выбранными строками; прозрачные wrappers скрывают семантические `Element`; `DropdownMenu` разрешает клавиатурный выбор обрезанных пунктов; документация Selectable указывает неверный размер fallback.

## Цель

Сохранить точную структуру выделенного текста и сделать semantic Elements wrappers согласованными с видимым рендерингом. Ограничить Dropdown клавиатурную навигацию видимыми пунктами и синхронизировать fallback-документацию с реализацией `80×24`.

## Что изменится

- `selectable.go`, `scrollable.go`, `collapsible.go`, `dropdown.go`, `element.go` — forwarding, translation, clipping и границы навигации.
- Узкие Go-регрессии для пустых строк, wrapper composition, координат, `/elements` snapshot и обрезанного меню.
- Только API-документация Selectable, Scrollable, Collapsible и Dropdown и соответствующие code-specs, непосредственно затронутые новой семантикой; без перезаписи несвязанных спецификаций.

## Детали реализации

1. `SelectedText` добавляет фрагмент для каждой выбранной строки `sy..ey`, включая пустые строки, затем соединяет фрагменты переводами строк.
2. `collectElements` безопасно обрабатывает nil и typed-nil панели. `Selectable.Elements` прозрачно передаёт те же размеры вложенной панели.
3. `Scrollable.Elements` запрашивает дочерние элементы до `Offset+h`, отбирает Bounds, пересекающие видимый viewport, обрезает частично видимые Bounds и сдвигает Y на `-Offset`.
4. Развёрнутый `Collapsible.Elements` запрашивает высоту `max(0,h-1)`, ограничивает результаты прямоугольником содержимого и сдвигает Y на `+1`. Свёрнутый компонент возвращает nil для скрытого содержимого.
5. Клиппинг рекурсивно сохраняет видимую структуру Children и не изменяет слайсы, принадлежащие провайдеру.
6. Клавиатура Dropdown использует число видимых строк из `hoverableItemCount`; Up, Down и Enter не выходят за этот диапазон. При неизвестной геометрии до первого рендеринга сохраняется прежний fallback на весь список.
7. Английская и русская API-документация вместе с русскими code-specs описывают фактический fallback `80×24`, прозрачные Elements и видимые keyboard-границы; обновления ограничены четырьмя затронутыми компонентами.

## Критерии приёмки

- [x] `SelectAll`, forward/reverse мышь и клавиатурное выделение сохраняют пустые строки для указанных многострочных и Unicode-примеров.
- [x] ANSI-only пустая строка не удаляет соответствующие переводы строк.
- [x] Прямой provider и `Selectable` сохраняют исходные Elements Bounds.
- [x] `Scrollable` смещает координаты, обрезает частичные Bounds и исключает полностью невидимые элементы.
- [x] Раскрытый `Collapsible` добавляет к видимым дочерним Bounds один ряд; свёрнутый не возвращает элементы контента.
- [x] Вложение `Collapsible(Scrollable(Selectable(provider)))` сохраняет элементы в координатах, совпадающих с отрисованным viewport и `/elements` snapshot.
- [x] Dropdown не фокусирует и не выбирает клавиатурой пункты вне видимого диапазона.
- [x] В Selectable документации нет устаревших ссылок на `9999`, большие размеры или рендеринг большого размера; fallback описан как `80×24`.
- [x] Пройдены `gofmt -w .`, `go vet ./...`, `go test ./...`, `go test -race ./...`, frozen pnpm install и VitePress build.
