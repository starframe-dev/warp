# Управление состоянием и поток данных

## Обзор системы состояния

Библиотека `warp` использует реактивную систему управления состоянием, основанную на подписках и эмиттерах событий. Состояние изолировано для каждого компонента и может быть синхронизировано с внешними источниками данных.

## Источники состояния

### Локальное состояние

Каждый компонент имеет собственное локальное состояние, хранящееся внутри экземпляра элемента:

```go
type State struct {
    isOpen    bool
    value     string
    selected  []string
    focused   bool
    // и т.д.
}
```

### Глобальное состояние

Для общих данных используется глобальный хранилище состояния:

```go
var globalState = StateStore{
    data: make(map[string]interface{}),
    subscribers: make(map[string][]func(interface{})),
}
```

## Подписки на изменения

### Регистрация слушателя

```go
// Подписка на изменение состояния
element.Subscribe(func(newValue interface{}) {
    // Обработка нового значения
})

// Отписка от изменений
element.Unsubscribe(func(newValue interface{}) {})
```

### Внутренние события

Компоненты эмитируют события при изменении своего состояния:

- `stateChange` — изменение любого поля состояния
- `valueChange` — изменение значения
- `visibilityChange` — изменение видимости
- `selectionChange` — изменение выделения

## Поток данных

### Входной поток (input)

Данные поступают из внешних источников:

1. **События ввода**: Пользовательские действия (клики, ввод текста)
2. **Системные события**: Изменения состояния системы
3. **Внешние данные**: Загрузка данных из API или хранилища

### Обработка данных

```
Входные данные → Валидация → Преобразование → Хранение → Отрисовка
```

### Выходной поток (output)

1. **События**: Эмитирование событий при изменении состояния
2. **Анимации**: Запуск анимаций при изменениях
3. **Сохранение**: Сохранение состояния в хранилище

## Синхронизация

### Вложенные состояния

Состояния вложенных компонентов синхронизируются автоматически:

```go
// Родительское состояние влияет на дочерние
parentState.Subscribe(func(val interface{}) {
    // Обновление дочерних компонентов
})
```

### Изоляция состояний

Состояния разных компонентов изолированы, если нет явной подписки:

```go
// Компонент A и компонент B имеют независимые состояния
// Изменение A не влияет на B без явной подписки
```

## Восстановление состояния

### Сохранение состояния

```go
// Сохранение состояния в хранилище
func SaveState(component Element, prefix string) error

// Восстановление состояния из хранилища
func LoadState(component Element, prefix string) error
```

### Персистентность

Состояние может сохраняться между сеансами при правильной настройке хранилища.
