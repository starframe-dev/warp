Модуль Warp

Warp — это инструмент UI для терминала, построенный на Bubble Tea, который предоставляет менеджер корневых приложений для терминальных приложений.

Модуль предоставляет корневой компонент Warp для управления макетами и HTTP-сервер для экспонирования древовидной структуры элементов в виде JSON.

Основные типы

Warp

type Warp struct {

Корневой компонент Warp, который управляет всей структурой приложения.

Интерфейс Panel

type Panel interface {
    View(width, height int) string
    Update(msg tea.Msg) tea.Cmd
}

Основной строительный блок Warp. Любой тип, реализующий этот интерфейс, может использоваться как содержимое терминала.

Методы

Метод Сигнатура Описание
View View(width, height int) string Отображает содержимое терминала заданного размера.
Update Update(msg tea.Msg) tea.Cmd Обрабатывает сообщения Bubble Tea (клавиши, мышь, изменение размера).

HTTP-сервер

При вызове ServeHTTP(addr string) запускается HTTP-сервер на указанном адресе (или переменной окружения WARP_HTTP_PORT, или порту 0).

Конечные точки

Путь Метод Описание
/elements GET Возвращает дерево элементов в виде JSON.
/healthz GET Точка проверки работоспособности, возвращающая "ok".

Ответ на /elements включает заголовки CORS (Access-Control-Allow-Origin: *).

Утилиты

parsePort

func parsePort(addr string) string

Извлекает порт из сетевого адреса. Возвращает пустую строку, если addr не является валидным host:port.

Пример использования

package main

import (
    "fmt"
    warp "yourmodule/warp"
)

type MyPanel struct {
    title string
}

func (m *MyPanel) View(width, height int) string {
    return fmt.Sprintf("Привет %s!\n", m.title)
}

func (m *MyPanel) Update(msg tea.Msg) tea.Cmd {
    return nil
}

func main() {
    // Создание warp с дефолтной вкладкой
    w := warp.New()

    // Создание пользовательской панели
    mp := &MyPanel{title: "Мир"}

    // Установка в качестве корня
    w.SetRoot(mp)

    // Запуск приложения
    if err := w.Run(); err != nil {
        fmt.Println("Ошибка:", err)
    }

Или с вкладками:

package main

import (
    "fmt"
    warp "yourmodule/warp"
)

func main() {
    // Создание группы вкладок с вкладками сверху
    tg := warp.NewTabGroup(warp.TabTop)

    // Добавление второй вкладки
    tg.NewTab("вторичная")

    // Установка в качестве корня
    w := warp.New()
    w.SetRoot(tg)

    // Запуск
    w.Run()
}
