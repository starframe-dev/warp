Модальное окно — Starframe Warp

Пакет Modal реализует систему перетаскиваемых диалоговых окон для терминальных пользовательских интерфейсов (TUI), созданных с помощью bubbletea. Он отображает стилизованные диалоговые окна, которые перекрывают основное содержимое панели, поддерживая перемещение перетаскиванием, кнопки закрытия и кнопки действий.

Обзор

Модальные окна отображаются поверх содержимого панели с затемненным фоном. Они обладают следующими возможностями:

  • Перемещение перетаскиванием — Пользователи могут изменить положение модального окна, перетаскивая верхнюю полосу
  • Функция закрытия — Нажмите на кнопку ✕ или Esc, чтобы закрыть окно
  • Действия кнопок — Настраиваемые кнопки внизу, вызывающие функции
  • Автоширина — Если ширина не указана, модальное окно использует 3/5 ширины экрана (заблокировано 30-50 символов)
  • ANSI-стилизация — Использует lipgloss для стилизованного отображения со скругленными границами

Функции

NewModal

func NewModal(title, content string, buttons []ModalButton, onClose func()) *Modal

Создает новый экземпляр Modal из его частей. Возвращает указатель на готовое к использованию модальное окно.

EnsureDimensions

func (m *Modal) EnsureDimensions(totalW, totalH int)

Вычисляет и хранит размеры коробки, если они еще не установлены. Должно быть вызвано перед Overlay, если Overlay еще не вызывался.

Эта функция:

  • Вычисляет ширину коробки (авто или указанная, заблокирована 30-50 символов)
  • Вычисляет высоту коробки (фиксированная на 7 строках для скругленной границы + отступ + 3 строки контента)
  • Вычисляет центральную позицию со смещением перетаскивания

Overlay

func (m *Modal) Overlay(lines []string, totalW, totalH int) []string

Отрисовывает модальное окно поверх существующих строк контента. Возвращает перекрывающиеся строки.

Функция:

  1. Убеждается, что размеры вычислены (вызывает EnsureDimensions)
  2. Создает коробку модального окна с заголовком, содержимым и кнопками
  3. Затемняет фон контента
  4. Перекрывает коробку модального окна, сохраняя затемненный контент слева и справа

HandleMouse

func (m *Modal) HandleMouse(msg tea.MouseMsg) bool

Обрабатывает события мыши для модального окна. Возвращает true, если событие было обработано.

Поддерживаемые взаимодействия:

  • Кнопка закрытия — Нажмите на ✕ в правой части строки заголовка
  • Нажатия на кнопки — Нажмите на кнопки внизу для запуска действий
  • Перетаскивание — Перетащите верхнюю полосу отступа, чтобы изменить положение модального окна

Расположение коробки модального окна

Коробка модального окна использует RoundedBorder с отступом. Расположение:

box[0]: верхняя граница              → startY + 0
box[1]: верхний отступ (перетаскивание) → startY + 1
box[2]: заголовок + ✕                 → startY + 2
box[3]: содержимое                   → startY + 3
box[4]: кнопки (первая строка)       → startY + 4
box[5]: кнопки (вторая строка)        → startY + 5 (при переносе)
box[6]: нижняя граница               → startY + 6

Общая высота фиксирована на 7 строках, чтобы соответствовать RoundedBorder lipgloss + отступ + 3 строки контента.

Пример использования

package main

import (
    "fmt"
    warp "yourproject/warp"
)

func main() {
    // Create a modal
    modal := warp.NewModal(
        "Confirmation",
        "Do you want to proceed?",
        []warp.ModalButton{
            {Label: "Yes", Action: func() {
                // Handle yes
            }},
            {Label: "No", Action: func() {
                // Handle no
            }},
        },
        func() {
            // Called when modal is closed
            fmt.Println("Modal closed")
        },
    )

    // Get initial panel lines
    lines := getPanelLines()

    // Render modal on top
    renderedLines := modal.Overlay(lines, 80, 24)

    // Handle mouse input
    for {
        msg, ok := chan.Read()
        if !ok {
            break
        }
        if modal.HandleMouse(msg) {
            // Modal handled the event
        }
    }

    // Render again with new positions
    renderedLines = modal.Overlay(renderedLines, 80, 24)
}

Важные замечания

  • Порядок размеров — Всегда вызывайте EnsureDimensions() перед Overlay(), если еще не вызывался
  • Смещение перетаскивания — Модальное окно запоминает свое смещение от центральной позиции; это позволяет перетаскивание
  • Замок — Модальное окно заблокировано к границам экрана при перетаскивании до краев
  • Автоширина — Ширина 0 или отрицательная означает автоширину (3/5 экрана, заблокирована 30-50)
  • Обработка ANSI — Функция visualBytePos обрабатывает многосимвольные символы и последовательности экранирования корректно, используя parser ansi
