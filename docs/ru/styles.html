стили

Пакет warp styles предоставляет полный набор стилей для TUI (терминальных пользовательских интерфейсов) на основе цветовой палитры Gruvbox Dark. Он использует библиотеку lipgloss для создания богатых компонентов терминального UI с поддержкой фоновых цветов, передних цветов, жирного текста и многого другого.

Обзор

Этот пакет определяет цветовые палитры и предварительно настроенные стили для различных компонентов UI, включая:

  • Панель вкладок - стили для активных, неактивных, новых и закрываемых вкладок
  • Разделители/границы - стили для обычных границ, состояний наведения и перетаскивания
  • Плавающие панели - стили для границ и заголовков плавающих окон
  • Сворачиваемые заголовки - стили для сворачиваемых элементов UI
  • Выпадающие меню - стили для кнопок и элементов выпадающих меню с состояниями наведения/выбора

Публичный API

Стили вкладок

Стили компонента панели вкладок:

var tabBarStyle = lipgloss.NewStyle().
        Background(tabBarBg)

var activeTabStyle = lipgloss.NewStyle().
        Background(activeTabBg).
        Foreground(activeTabFg).
        Bold(true)

var inactiveTabStyle = lipgloss.NewStyle().
        Background(tabBarBg).
        Foreground(inactiveTabFg)

var newTabStyle = lipgloss.NewStyle().
        Foreground(newTabFg)

var closeTabStyle = lipgloss.NewStyle().
        Foreground(closeTabFg)
  • tabBarStyle - Стиль фона для всей панели вкладок
  • activeTabStyle - Стиль для текущей активной вкладки (жирный передний план)
  • inactiveTabStyle - Стиль для неактивных вкладок
  • newTabStyle - Стиль для индикаторов новой вкладки (зелёный передний план)
  • closeTabStyle - Стиль для индикаторов кнопки закрытия (красный передний план)

Стили границ

Стили для разделительных/граничных компонентов:

var borderStyle = lipgloss.NewStyle().
        Foreground(borderColor)

var borderHoverStyle = lipgloss.NewStyle().
        Foreground(borderHoverColor)

  • BorderStyle() - Возвращает стиль, используемый для обычных разделительных границ
  • BorderDragStyle() - Возвращает стиль, используемый во время перетаскивания разделительной границы
  • BorderHoverStyle() - Возвращает стиль, используемый при наведении мыши на разделительную границу

Реализация

Использование lipgloss

Все стили создаются с помощью библиотеки lipgloss, которая предоставляет простой API для создания богатых компонентов терминального UI. Библиотека поддерживает:

  • Фоновые цвета
  • Передние цвета
  • Жирный текст
  • Подчёркивание, мигание, инверсия и т.д.
  • Отступы и интервалы

Составление стилей

Стили создаются с помощью цепочки методов:


style := lipgloss.NewStyle().
        Background(bgColor).
        Foreground(fgColor).
        Bold(true)

Цветовые переменные

Отдельные цветовые переменные можно использовать напрямую в стилях или экспортировать для настройки:


// Пример: Создание пользовательского стиля с существующими цветовыми переменными
customStyle := lipgloss.NewStyle().
        Background(gbDark1).
        Foreground(gbLight1).
        Bold(true)

Примеры использования

Создание панели вкладок


tabBar := lipgloss.JoinHorizontal(
    lipgloss.Top,
    tabBarStyle.Render("Tabs"),
    activeTabStyle.Render("1"),
    inactiveTabStyle.Render("2"),
    inactiveTabStyle.Render("3"),
)

Создание разделительных границ


border := lipgloss.NewStyle().
        BorderStyle(BorderStyle()).
        Render("Content")

borderHover := lipgloss.NewStyle().
        BorderStyle(BorderHoverStyle()).
        Render("Hovered Border")
