Collapsible

Обзор

Collapsible — это UI-компонент, представляющий панель, которую можно свернуть до однострочной панели заголовка. При развернутом состоянии она отображает полный контент через внутреннюю реализацию Panel.

Определение типа

type Collapsible struct {
  Title string
  Collapsed bool
  Content Panel
}

Тип Collapsible содержит:

  • Title — Строка заголовка, отображаемая при свернутом состоянии. Обрезается по ширине.
  • Collapsed — Флаг, указывающий, находится ли панель в свернутом состоянии.
  • Content — Опциональная реализация интерфейса Panel для отображения при развернутом состоянии.

Публичный API

NewCollapsible

func NewCollapsible(title string, content Panel) *Collapsible

Создаёт и возвращает новый экземпляр Collapsible с заданным заголовком и панелью контента.

View

func (c *Collapsible) View(w, h int) string

Отрисовывает представление для панели со сворачиванием. Когда Collapsed истинно, возвращает однострочную панель заголовка. Когда Collapsed ложно и Content не nil, делегирует вызов Content.View(w, h). Возвращает пустую строку, если контент nil и панель развернута.

Update

func (c *Collapsible) Update(msg tea.Msg) tea.Cmd

Перенаправляет сообщения во внутреннюю панель контента, если она существует. Возвращает nil, если нет содержимого для обновления.

Toggle

func (c *Collapsible) Toggle()

Переключает панель между свернутым и развернутым состояниями, инвертируя флаг Collapsed.

renderCollapsed

func (c *Collapsible) renderCollapsed(w int) string

Вспомогательный метод для отрисовки панели заголовка для свернутой панели. Обрабатывает:

  • Указатель стрелки (▶ при свернутом, ▼ при развернутом)
  • Обрезка заголовка по доступной ширине
  • Подушки для заполнения оставшегося пространства

Подробности реализации

Отрисовка свернутого представления

Метод renderCollapsed создаёт однострочную панель заголовка со следующей структурой:

  • Левый угловой символ: ┌
  • Стрелка указателя: ▶ (свернуто) или ▼ (развёрнуто)
  • Разделитель пробел
  • Текст заголовка (обрезается при необходимости)
  • Правый угловой символ: ┐

Обрезка заголовка

Когда заголовок превышает доступную ширину (после резервирования места для указателя и углов), заголовок обрезается с троеточием (...):

if len(title) > w-reserve {
    maxLen := w - reserve - 3
    if maxLen < 0 {
        maxLen = 0
    }
    if maxLen == 0 {
        title = ""
    } else {
        title = title[:maxLen] + "..."
    }
}

Пример использования

collapsible := NewCollapsible(
    "Example Panel",
    &warp.Panel{
        Title: "Content",
        View: func(w, h int) string {
            return "This is the panel content."
        },
    },
)

// Toggle the panel
collapsible.Toggle()
