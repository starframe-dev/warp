wrap

wrap — это пакет на Go, предоставляющий функциональность упаковки текста. Он предлагает две основные стратегии упаковки: упаковку по словам и упаковку по пробелам.

Публичный API

Пакет экспортирует следующие публичные функции:

func WordWrap(text string, width int) []string
func SpaceWrap(text string, width int) []string
func WrapToString(text string, width int, useSpaceWrap bool) string

Функции

WordWrap

func WordWrap(text string, width int) []string

WordWrap упаковывает текст в границах слов так, чтобы ни одна строка не превышала указанной ширины. Если слово длиннее ширины, оно будет разорвано посередине для соответствия ограничению.

Параметры:

  • text — Входной текст для упаковки
  • width — Максимальная ширина в символах для каждой строки

Возвращает:

  • Массив упакованных строк

Поведение:

  • Возвращает nil, если ширина <= 0
  • Обрабатывает многострочный ввод (разбивает по переносам строк)
  • Использует простую длину-базирующую вычисление ширины
  • Разрывает слова при необходимости для соответствия ширине
result := WordWrap("Hello World this is a test", 10)
// Output:
// [Hello Worl
// d this is
// a test]

SpaceWrap

func SpaceWrap(text string, width int) []string

SpaceWrap упаковывает текст только по пробелным символам. Если слово длиннее ширины, оно вытекает без разрыва слова.

Параметры:

  • text — Входной текст для упаковки
  • width — Максимальная ширина в символах для каждой строки

Возвращает:

  • Массив упакованных строк

Поведение:

  • Возвращает nil, если ширина <= 0
  • Обрабатывает многострочный ввод (разбивает по переносам строк)
  • Использует простую длину-базирующую вычисление ширины
  • Сохраняет целостность слов — слова длиннее ширины вытекают
  • Использует strings.Fields() для разбиения по пробелам
result := SpaceWrap("Hello World this is a test", 10)
// Output:
// [Hello Worl
// d this is a
// test]

WrapToString

func WrapToString(text string, width int, useSpaceWrap bool) string

WrapToString — это вспомогательная функция, которая упаковывает текст и соединяет строки с переносами строк, чтобы получить единую строку.

Параметры:

  • text — Входной текст для упаковки
  • width — Максимальная ширина в символах для каждой строки
  • useSpaceWrap — Использовать упаковку по пробелам (true) или упаковку по словам (false)

Возвращает:

  • Упакованный текст как единая строка с переносами строк
wrapped := WrapToString("Hello World this is a test", 10, false)
// Returns:
// Hello Worl
// d this is
// a test

Детали реализации

Внутренние функции

Следующие внутренние функции поддерживают публичный API:

func wrapLine(line string, width int) []string

Внутренняя вспомогательная функция, которая упаковывает одиночную строку в границах слов. Обрабатывает проверку ширины строки и обнаружение границ слов.

func wrapAtSpaces(line string, width int) []string

Внутренняя вспомогательная функция, которая упаковывает одиночную строку только по пробелам. Обрабатывает случаи переполнения слов.

func isWordBreak(b byte) bool

Вспомогательная функция, которая проверяет, является ли байт символом пробела, используя unicode.IsSpace().

Основные примечания к реализации

  • Простое вычисление ширины: Использует простое вычисление ширины на основе длины вместо вычисления ширины, осведомлённого о терминале.
  • Обработка многострок: Обе основные функции разбивают входной текст по переносам строк и обрабатывают каждую строку независимо.
  • Обработка пробельных символов: После упаковки ведущие пробельные символы в последующих строках пропускаются.
  • Крайние случаи: Возвращает nil для некорректных ширин (<= 0).
  • String builder: Использует strings.Builder для эффективного соединения строк в wrapAtSpaces.

Примеры

Базовая упаковка по словам

package main

import (
    "fmt"
    "warp"
)

func main() {
    text := "This is a sample text that should be wrapped to fit a certain width."
    
    // Word-based wrapping
    lines := warp.WordWrap(text, 30)
    for _, line := range lines {
        fmt.Println(line)
    }
}

Использование WrapToString

package main

import (
    "fmt"
    "warp"
)

func main() {
    text := "Short text"
    
    // Using word-based wrapping
    result1 := warp.WrapToString(text, 15, false)
    fmt.Println("WordWrap result:")
    fmt.Println(result1)
    
    // Using space-based wrapping
    result2 := warp.WrapToString(text, 15, true)
    fmt.Println("SpaceWrap result:")
    fmt.Println(result2)
}
