# Сгенерированный справочник

code-check создаёт HTML-страницу для каждого Go-файла. Это низкоуровневый справочник по деталям реализации; для работы с API рекомендуются страницы [руководства](./getting-started) и [API](../api/).

Сгенерированные файлы намеренно находятся в `docs/en/` и `docs/ru/`. Эти каталоги входят в контракт code-check, поэтому следующая синхронизация сохраняет те же пути.
