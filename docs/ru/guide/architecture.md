# Архитектура

Warp — это Bubbletea `Model`, который управляет деревом панелей, вкладок, split/flex-компоновок и плавающих окон.

## Корневая панель

Warp оборачивает корневую `Panel`. По умолчанию корнем является `TabGroup`.

`Panel` — базовый интерфейс для визуальных элементов Warp:

- `View(w, h)` отрисовывает панель в заданных размерах;
- `Update(msg)` обрабатывает Bubbletea-сообщения.

## Дерево Node

Внутри вкладки содержимое описывается деревом `Node`.

Основные типы узлов:

- листовые панели;
- `SplitConfig` — разделение по вертикали или горизонтали с `fraction`;
- `FlexConfig` — строка или колонка с весами `grow`.

`SplitConfig` удобен для фиксированного деления области, а `FlexConfig` — для распределения пространства между несколькими дочерними элементами.

## Float

Float-окна накладываются поверх основного контента. Они не меняют дерево базовой компоновки, а рисуются отдельным слоем.

## TabGroup и Tab

`TabGroup` — это `Panel` с таб-баром и областью контента.

Каждый `Tab` управляет своим деревом:

- splits;
- flex;
- floats.

Так вкладки могут иметь независимую структуру интерфейса.

## Фокус

Фокус поддерживается через `Focusable`.

Warp предоставляет явное управление фокусом:

- `FocusNext()`;
- `FocusPrev()`;
- `FocusFirst()`;
- `FocusPanel(panel)`.

Warp не навязывает биндинги клавиш. Разработчик сам решает, какие клавиши переключают фокус.

## Стили

Встроенная тема описана в `styles.go`. По умолчанию используется Gruvbox Dark.

## Element tree

Для E2E-тестов Warp предоставляет дерево элементов через `ElementProvider`. Это позволяет тестам находить и проверять элементы интерфейса без привязки только к текстовому выводу.
