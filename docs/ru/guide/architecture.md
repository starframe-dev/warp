# Архитектура

Warp — TUI layout engine на Bubble Tea. Он владеет корневой `Panel`; `warp.New()` создаёт `TabGroup` с одной вкладкой.

## Дерево панелей

В компоновку можно вставить любое значение, реализующее:

```go
type Panel interface {
    View(width, height int) string
    Update(msg tea.Msg) tea.Cmd
}
```

`Tab` хранит панели в дереве `Node`:

- лист содержит `Panel`;
- `SplitConfig` делит область между двумя дочерними узлами;
- `FlexConfig` распределяет область между несколькими узлами;
- `NodeCollapse` хранит состояние сворачивания.

Методы `Tab` изменяют это дерево. Сам `TabGroup` тоже является `Panel`, поэтому целую группу вкладок можно вложить в другое дерево.

## Отрисовка и события

Warp рекурсивно отрисовывает дерево, подгоняет дочерние панели под выделенные терминальные ячейки и рисует float поверх результата. Сначала мышь получает верхний float, затем границы split, затем активная панель. Клик внутри float не попадает к панелям под ним.

Клавиатурный ввод обычно получает сфокусированная панель. Resize-, framework- и пользовательские/неизвестные сообщения могут рассылаться и несфокусированным панелям, поэтому их `Update` должен корректно обрабатывать такие сообщения. Warp не назначает `Tab` и `Shift+Tab` для переключения фокуса.

## Фокус

Фокусируемая панель реализует `Focusable`. Методы `Tab.FocusNext`, `FocusPrev`, `FocusFirst` и `FocusPanel` дают явный обход. Клавиши выбирает приложение.

## Тема

По умолчанию используется Gruvbox Dark. `SetTheme` заменяет стили компонентов пакета на основе семантических цветов. Настраивайте тему до запуска Bubble Tea: изменение темы во время отрисовки не синхронизировано. См. страницу [Тема](../api/theme).

## Жизненный цикл панелей

Панель, владеющая ресурсами, может реализовать `Unmounter`. Warp вызывает `Unmount`, только когда панель окончательно отсоединена и больше не встречается в принадлежащей владельцу иерархии; переключение вкладок, скрытие, сворачивание и смена фокуса не завершают её жизненный цикл. Для стабильной идентичности используйте панели-указатели. Совместное использование одного ресурсного экземпляра между независимыми корнями Warp не поддерживается и остаётся ответственностью вызывающего кода.

## HTTP-инспектор

Необязательный инспектор обслуживает `/elements` на основе последнего завершённого снимка UI-потока; HTTP-запросы не обходят живые панели. При пустом адресе `ServeHTTP` слушает `127.0.0.1` и порт из `WARP_HTTP_PORT` либо автоматически назначенный порт, если переменная не задана. Межсайтовый доступ по умолчанию отключён. Явный нелокальный адрес может открыть UI-данные в сети; перед использованием за пределами доверенной локальной среды настройте bearer token через `ServeHTTPWithOptions`.

## Дерево элементов

Панель может реализовать `ElementProvider` и отдавать семантические элементы с `Role`, `Name`, `Action` и `Bounds`. Warp предоставляет это дерево через необязательный HTTP-эндпоинт `/elements`; E2E-тесты не зависят от разбора терминального текста.
