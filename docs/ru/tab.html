Документация API Tab

tab.go реализует тип Tab и связанную функциональность для управления вкладками терминала с гибкой схемой панелей. Он предоставляет API для разбиения панелей, flex-расположений, плавающих окон, управления фокусом и обработки событий мыши/клавиатуры.

Tab

Представляет собой отдельную вкладку с деревом панелей, плавающими окнами и состоянием фокуса.

type Tab struct {

Публичный API

Создание Tab

// NewTab creates a standalone Tab with no parent TabGroup.
// Useful for embedding a warp layout inside a Panel.
func NewTab(name string) *Tab

Создаёт новый независимый Tab с заданным именем. Вкладка будет иметь пустую корневую панель, которую можно будет наполнить позже.

func newTab(name string, parent *TabGroup) *Tab

Внутренний конструктор, создающий вкладку с родительским TabGroup.

Доступ к корневой панели

func (t *Tab) ensureRoot()

func (t *Tab) RootPanel() Panel
func (t *Tab) SetRootPanel(panel Panel)

Эти методы управляют корневой панелью вкладки. RootPanel() возвращает текущую корневую панель, а SetRootPanel() заменяет её. ensureRoot() создаёт корневую панель, если она ещё не существует.

Операции разделения

// SplitVertical splits the panel vertically (left/right).
// fraction is the share for the left panel (0.0–1.0).
func (t *Tab) SplitVertical(parent Panel, fraction float64, newPanel Panel)

// SplitHorizontal splits the panel horizontally (top/bottom).
// fraction is the share for the top panel (0.0–1.0).
func (t *Tab) SplitHorizontal(parent Panel, fraction float64, newPanel Panel)

Методы разделения делят текущую панель на две части. Первый параметр — существующая панель для разбиения, второй — доля для первой части, третий — новая панель для вставки.

Операции flex-расположения

// FlexRow replaces the parent panel with a horizontal flex layout.
func (t *Tab) FlexRow(parent Panel, items []FlexItemSpec)

// FlexColumn replaces the parent panel with a vertical flex layout.
func (t *Tab) FlexColumn(parent Panel, items []FlexItemSpec)

Методы flex создают flex-расположения с несколькими панелями. items — срез FlexItemSpec, где каждый элемент указывает панель и её вес grow.

Плавающие окна

func (t *Tab) Float(panel Panel, x, y, width, height int)
func (t *Tab) CloseFloat(fp *FloatPane)

Float() делает панель плавающей над основным расположением в указанной позиции. CloseFloat() удаляет плавающее окно.

Управление фокусом

func (t *Tab) Focus() Panel
func (t *Tab) SetFocus(panel Panel) tea.Cmd
func (t *Tab) FocusNext()
func (t *Tab) FocusPrev()
func (t *Tab) FocusFirst()
func (t *Tab) FocusPanel(panel Panel)

Методы фокуса управляют тем, какая панель принимает ввод:

  • Focus() возвращает текущую панель с фокусом
  • SetFocus() устанавливает новую панель фокуса и возвращает любые команды из её обновления
  • FocusNext() / FocusPrev() перемещают фокус на следующую/предыдущую панель
  • FocusFirst() перемещает фокус на первую панель
  • FocusPanel() устанавливает фокус на конкретную панель, если она реализует Focusable

Операции с долей разделения

func (t *Tab) SetSplitFraction(panel Panel, fraction float64) bool
func (t *Tab) GetSplitFraction(panel Panel) (float64, bool)

SetSplitFraction() обновляет долю разделения, содержащую панель. GetSplitFraction() возвращает текущую долю.

Операции сворачивания/разворачивания

func (t *Tab) Collapse(panel Panel, size int) bool
func (t *Tab) Expand(panel Panel) bool

Collapse() сужает панель до фиксированного размера. Expand() восстанавливает её до сохранённой доли разделения.

func (t *Tab) ToggleCollapsible(panel Panel)

Переключает состояние свёрнутой панели.

Обработка мыши

func (t *Tab) HandleMouse(msg tea.MouseMsg) tea.Cmd

HandleMouse() — публичный входная точка для встроенных вкладок. Он обрабатывает события мыши, включая:

  • Взаимодействия с плавающими окнами (фокус, перетаскивание, закрытие)
  • Перетаскивание границ для изменения размера разделения
  • Нажатие на панели для фокуса и переключения сворачивания
  • Переадресация событий панелям

Обработка клавиш

func (t *Tab) handleKeys(msg tea.KeyMsg) tea.Cmd

Переадресует сообщения с клавишами на панель фокуса. Warp не перехватывает Tab/Shift+Tab автоматически; используйте FocusNext() и FocusPrev() для явного переключения фокуса.

Обработка изменения размера

func (t *Tab) Update(msg tea.Msg) tea.Cmd
func (t *Tab) broadcastMsg(msg tea.Msg) []tea.Cmd
func (t *Tab) broadcastResize(node *Node, x, y, w, h int) []tea.Cmd
func (t *Tab) broadcastNode(node *Node, msg tea.Msg) []tea.Cmd

Update() реализует интерфейс обновления Panel. Обрабатывает изменения размера окна, сообщения resize и передаёт сообщения всем листовым панелям. BroadcastResize() отправляет сообщения resize всем панелям после завершения перетаскивания.
