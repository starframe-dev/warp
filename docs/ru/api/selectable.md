# Выделение

Тип `Selectable` добавляет поддержку выделения текста к оборачиваемой
`Panel`. Перетаскивание мышью и Shift+стрелки создают выделение, которое
отображается с инвертированными цветами и может быть извлечено как
обычный текст.

```go
package warp

type Selectable struct {
    Content Panel
    AnchorX, AnchorY int
    CursorX, CursorY int
    HasSelection bool
    Selecting bool
    // Приватные поля также хранят начало перетаскивания мышью и последний отображённый контент.
}
```

## Обзор

`Selectable` оборачивает любую `Panel` и добавляет:

- Выделение мышью (нажатие, перемещение и отпускание левой кнопки)
- Выделение с клавиатуры при помощи Shift+стрелки
- Ctrl+A для выделения всего, Esc для сброса
- Копирование выделенного текста в системный буфер обмена через OSC 52

Выделенная область отображается с использованием ANSI-стиля обратного
видео (`\x1b[7m`), чтобы пользователь видел точно то, что выделено.

## Типы

### Selectable

Публичная структура со следующими экспортированными полями:

| Поле | Тип | Описание |
|----|----|----|
| Content | `Panel` | Оборачиваемая панель контента, к которой добавляется выделение. |
| AnchorX, AnchorY | `int` | Одна из границ выделения в координатах терминальных ячеек. |
| CursorX, CursorY | `int` | Активная граница, не включающая конечную позицию; `CursorX` может быть равен ширине области просмотра. |
| HasSelection | `bool` | `true`, если существует непустое выделение. |
| Selecting | `bool` | `true`, пока выполняется перетаскивание мышью. |

Приватные поля включают начало перетаскивания мышью (`mouseStartX` и
`mouseStartY`), а также последние отображённые размеры и строки (`lastW`,
`lastH` и `lastLines`). Кэшированные строки позволяют `SelectedText`
извлекать текст в той же системе координат, что и при отображении.

## Публичный API

```go
func NewSelectable(content Panel) *Selectable
```

Создаёт новый `Selectable`, оборачивающий заданную панель. Всё состояние
выделения изначально пустое.

```go
func (s *Selectable) SelectedText() string
```

Возвращает текущий выделенный текст как обычную строку. Использует
кэшированные отображённые строки, чтобы система координат совпадала с
тем, что видно на экране. Если кэшированных строк нет, отображает
`Content` с последними известными размерами, подставляя `80` вместо
неположительной ширины и `24` вместо неположительной высоты. Возвращает
пустую строку, если выделения нет или `Content` равен `nil`.

```go
func (s *Selectable) ClearSelection()
```

Удаляет текущее выделение, сбрасывая `HasSelection` и `Selecting`.

```go
func (s *Selectable) Copy() tea.Cmd
```

Возвращает `tea.Cmd`, копирующий непустой выделенный текст в системный
буфер обмена через OSC 52. Предназначен для вызова при нажатии Ctrl+C.
Возвращает `nil`, если извлечённый выделенный текст пуст.

```go
func (s *Selectable) SelectAll(w, h int)
```

Выделяет весь контент в заданных положительных границах ширины и высоты.
Если хотя бы один размер неположительный, выделение сбрасывается.

```go
func (s *Selectable) View(w, h int) string
```

Отображает оборачиваемый контент с подсветкой выделения и кэширует
строки для последующего извлечения текста. Диапазоны выделения не
включают конечную позицию (`[start, end)`); горизонтальные границы
ограничиваются диапазоном `[0, w]`, поэтому допустима граница сразу
после последней видимой ячейки. Если `Content` равен `nil`, `View`
возвращает ровно `h` пустых строк, предварительно приводя `h` к минимуму
`0` (`""` при `h == 0`, иначе `h-1` символов перевода строки).

```go
func (s *Selectable) Elements(width, height int) []Element
```

Возвращает копии семантических элементов, собранных из оборачиваемой
панели, с неположительными значениями ширины и высоты, приведёнными к
нулю.

```go
func (s *Selectable) ContentHeight(width int) (int, bool)
```

Передаёт известную внутреннюю высоту оборачиваемой панели для заданной
ширины.

```go
func (s *Selectable) Update(msg tea.Msg) tea.Cmd
```

Обрабатывает сообщения мыши и клавиатуры для выделения. Сообщения, не
обработанные логикой выделения, передаются оборачиваемой `Panel`.
Сообщения об изменении размера также напрямую передаются оборачиваемой
панели.

## Поведение

### Выделение мышью

- **Нажатие (левая кнопка):** Запоминает исходную ячейку и начинает перетаскивание.
- **Перемещение:** Во время перетаскивания преобразует координату ячейки указателя `x` в границу `x+1` (не включая конечную позицию) при движении вперёд; при обратном движении используется граница после исходной ячейки. `HasSelection` становится `true`.
- **Отпускание:** Фиксирует конечную границу, не включающую конечную позицию. Нажатие и отпускание без перемещения не создают выделение.

### Выделение с клавиатуры

- **Shift+Up / Shift+Down / Shift+Left / Shift+Right:** Расширяет или создаёт выделение в заданном направлении. Shift+Tab намеренно *не* обрабатывается и передаётся оборачиваемой панели (например, терминалу), чтобы TUI-приложения внутри PTY получили это нажатие.
- **Ctrl+A:** Выделяет всё в пределах последних известных размеров (если размеры неизвестны, используются 80×24).
- **Esc:** Сбрасывает выделение, если оно существует.

### Отображение

`View` отображает контент и применяет стиль обратного видео к
выделенному диапазону. `sortedBounds` нормализует анкер и курсор в
границы диапазона, не включающие конечную позицию. Строки за пределами
выделения передаются без изменений. Подсветка учитывает ширину
терминальных ячеек и границы графем: если выделена часть широкой графемы,
подсвечивается графема целиком. При отображении координаты выделения
ограничиваются текущей областью просмотра; пустая область просмотра
сбрасывает выделение.

### Извлечение текста

`SelectedText` проходит по кэшированным отображённым строкам и извлекает
целые графемы, пересекающие выбранный диапазон терминальных ячеек.
Последовательности ANSI escape пропускаются, поэтому извлечённый текст
соответствует видимому выделению. Для каждой выбранной строки добавляется
фрагмент, даже если он пуст; при объединении фрагментов сохраняются
пустые строки и завершающие переводы строк.

### Обработка ANSI / Unicode

`highlightRange` и `extractVisRange` отслеживают позиции в терминальных
ячейках с учётом ANSI и целые кластеры графем, а не индексы байтов или
рун. Последовательности CSI и OSC не сдвигают визуальную позицию;
выделение любой ячейки графемы включает графему целиком.

## Детали реализации

- **Буфер обмена OSC 52:** Метод `Copy` кодирует непустой выделенный текст в base64 и отправляет последовательность `\x1b]52;c;<data>\x07`. Это работает в альтернативном экранном буфере Bubbletea.
- **Границы, не включающие конечную позицию:** `SelectAll(w, h)` устанавливает конечную горизонтальную границу в `w`, включая последнюю ячейку. Перетаскивание мышью и Shift+Right используют ту же систему границ.
- **Сброс выделения:** Отпускание кнопки мыши в точке анкера сбрасывает выделение. При отображении также сбрасывается выделение с клавиатуры, если после ограничения координат анкер и курсор совпадают.
- **Передача сообщений:** Любое сообщение, не обработанное логикой выделения (нераспознанные клавиши, Shift+Tab и т. п.), передаётся в `Content.Update(msg)`; сообщения об изменении размера также передаются. Если оборачиваемая панель равна `nil`, сообщения ей не передаются.

## Пример использования

```go
sel := NewSelectable(myPanel)
model.SetProgramView(sel)

// В обработчике обновления модели:
case tea.KeyMsg:
    if msg.String() == "ctrl+c" {
        return sel.Copy()
    }
    if msg.String() == "esc" {
        sel.ClearSelection()
    }

// Получение выделенного текста (например, для вставки или отображения):
text := sel.SelectedText()
```
