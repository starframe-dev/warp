# Сворачиваемый блок

`Collapsible` оборачивает `Panel`, постоянно показывает строку заголовка и позволяет сворачивать и разворачивать содержимое.

## Публичный API

```go
type Collapsible struct {
    Title     string
    Collapsed bool
    Content   Panel
}

func NewCollapsible(title string, content Panel) *Collapsible
func (c *Collapsible) View(w, h int) string
func (c *Collapsible) Elements(w, h int) []Element
func (c *Collapsible) ContentHeight(width int) (int, bool)
func (c *Collapsible) Update(msg tea.Msg) tea.Cmd
func (c *Collapsible) Toggle()
```

`NewCollapsible` создаёт раскрытую панель. `Toggle` переключает значение `Collapsed`; отсутствие `Content` не мешает менять состояние. Левый клик по строке заголовка (`Y == 0`) обрабатывается самим `Collapsible.Update`, поэтому компонент остаётся интерактивным и вне `Tab`.

`ContentHeight` возвращает общую высоту, включая строку заголовка. В свёрнутом состоянии возвращается `(1, true)`. В раскрытом состоянии к сообщаемой содержимым панели высоте прибавляется единица; если высота содержимого неизвестна, возвращается `(0, false)`. Если панель содержимого отсутствует, её высота считается равной нулю.

## Рендеринг

Строка заголовка видна в обоих состояниях: `▼` при раскрытом и `▶` при свёрнутом. В раскрытом режиме внутренняя панель отображается под заголовком с высотой `max(0, h-1)`, обрезается и дополняется пустыми строками до размеров доступной области просмотра. В свёрнутом режиме отображается только строка заголовка. При неположительной высоте представление пустое; при неположительной ширине заголовок пуст, а раскрытый режим сохраняет ровно `h` строк.

Если `Content` отсутствует, заголовок всё равно отображается при `h > 0`; оставшиеся строки раскрытого представления пусты.

## Семантические элементы

`Elements(w, h)` при ненулевой геометрии всегда предоставляет постоянную строку заголовка как `button` с действием `toggle-collapse`. В раскрытом состоянии за ней следуют видимые дочерние элементы, обрезанные по области просмотра содержимого и сдвинутые вниз на одну строку. В свёрнутом состоянии единственным семантическим элементом остаётся переключатель заголовка.

## Сообщения и координаты мыши

`Update` передаёт обычные сообщения в `Content`. Для `ResizeMsg` раскрытое содержимое получает высоту `max(0, h-1)`, а свёрнутое — `0`. Изменение размера не передаётся, если `Content` отсутствует. События мыши по строке заголовка и события, направленные скрытому свёрнутому содержимому, не передаются. Для видимого содержимого координата `Y` уменьшается на единицу, поэтому первая строка содержимого получает `Y == 0`.

При использовании внутри `Tab` левый клик по видимой строке заголовка переключает состояние компонента. `Tab.Collapse` и `Tab.Expand` явно синхронизируют состояние компонента с его flex-элементом и идемпотентны при повторных вызовах.

## Стилизация

Левая часть заголовка использует `collapsibleStyle`, а горизонтальная линия и правый угол — `collapsibleBorderStyle`. Заголовок обрезается с учётом ширины символов в терминальных ячейках.

## Пример

```go
section := NewCollapsible("Настройки", settingsPanel)
view := section.View(40, 8) // заголовок и до семи строк содержимого
section.Toggle()
```
