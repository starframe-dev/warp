# Collapsible

`Collapsible` оборачивает `Panel`, постоянно показывает строку заголовка и позволяет сворачивать/разворачивать содержимое.

## Публичный API

```go
type Collapsible struct {
    Title     string
    Collapsed bool
    Content   Panel
}

func NewCollapsible(title string, content Panel) *Collapsible
func (c *Collapsible) View(w, h int) string
func (c *Collapsible) Update(msg tea.Msg) tea.Cmd
func (c *Collapsible) Toggle()
```

`NewCollapsible` создаёт раскрытую панель. `Toggle` инвертирует `Collapsed`; nil в `Content` не мешает менять состояние.

## Рендеринг

Строка заголовка видна в обоих состояниях: `▼` при раскрытом и `▶` при свёрнутом. В раскрытом режиме внутренняя панель отображается ниже заголовка с высотой `max(0, h-1)` и подгоняется под viewport. В свёрнутом режиме показывается только строка заголовка. При неположительной высоте представление пустое; при неположительной ширине заголовок пустой, а раскрытый режим сохраняет ровно `h` строк.

Если `Content` равен nil, заголовок всё равно отображается при `h > 0`; оставшиеся строки раскрытого представления пусты.

## Сообщения и координаты мыши

`Update` передаёт обычные сообщения в `Content`. Для `ResizeMsg` раскрытое содержимое получает высоту `max(0, h-1)`, а свёрнутое — `0`. События по заголовку и события для скрытого свёрнутого содержимого не передаются. Для видимого содержимого координата мыши `Y` уменьшается на единицу, поэтому первая строка контента получает `Y == 0`.

Внутри `Tab` клик левой кнопкой по видимой строке заголовка переключает состояние. `Tab.Collapse` и `Tab.Expand` явно синхронизируют состояние компонента и flex-элемента и остаются идемпотентными при повторных вызовах.

## Стилизация

Левая часть заголовка использует `collapsibleStyle`, горизонтальная линия и правый угол — `collapsibleBorderStyle`. Заголовок обрезается по ширине терминальных ячеек.

## Пример

```go
section := NewCollapsible("Настройки", settingsPanel)
view := section.View(40, 8) // заголовок и до семи строк содержимого
section.Toggle()
```
