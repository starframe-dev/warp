# split.go

Файл `split.go` в пакете `warp` определяет структуры данных для иерархического дерева раскладки панелей, а также вспомогательные функции для запросов к дереву и его изменения. Он не реализует расчёт раскладки, рендеринг или проверку попаданий.

## Публичный API

### `Direction`

```go
type Direction int

const (
    Vertical Direction = iota
    Horizontal
)
```

`Direction` определяет ориентацию. `Vertical` означает расположение рядом друг с другом (слева/справа), а `Horizontal` — расположение сверху/снизу.

### `ResizeMsg`

```go
type ResizeMsg struct {
    Width  int
    Height int
}
```

Сообщение об изменении размера, содержащее выделенный панели размер содержимого в клетках, без учёта границ и отступов. Сам тип не отправляет сообщения и не определяет поведение команд.

### `MinPanelSize`

```go
const MinPanelSize = 3
```

Минимальный размер в клетках, когда пространства достаточно. В этом файле объявлена константа, но принудительное ограничение размера не реализовано.

### `SplitConfig`

```go
type SplitConfig struct {
    Direction   Direction
    Fraction    float64
    First       *Node
    Second      *Node
    Dragging    bool
    CollapseRow int
    OnCollapse  func() tea.Cmd
}
```

Описание внутреннего узла с указателями на двух дочерних элементов. Согласно комментарию в коде, `Fraction` — доля первого дочернего элемента в диапазоне 0.0–1.0; этот файл не ограничивает и иначе не применяет её. `Dragging` хранит состояние перетаскивания. `CollapseRow` — номер строки, начиная с нуля, в которой на границе отображается символ `"<"`; при нажатии на этот маркер вызывается `OnCollapse`, возвращающий `tea.Cmd` для повторного рендеринга.

### `NodeCollapse`

```go
type NodeCollapse struct {
    Active bool
    Width  int
    Height int
    Saved  float64
}
```

Хранит состояние сворачивания и размеры: `Width` используется для вертикальных раскладок, `Height` — для горизонтальных, а `Saved` хранит долю для восстановления при разворачивании. Сам по себе этот тип не выполняет сворачивание или разворачивание.

### `Node`

```go
type Node struct {
    Panel    Panel
    Split    *SplitConfig
    Flex     *FlexConfig
    Collapse *NodeCollapse
}
```

Узел дерева может содержать панель и/или конфигурацию split либо flex; структура не гарантирует, что задано ровно одно из этих полей. `Collapse` хранит необязательное состояние сворачивания.

### Методы `Node`

| Сигнатура | Описание |
|---|---|
| `func (n *Node) IsLeaf() bool` | Возвращает `true`, если `n` не равен nil, его `Panel` не равен nil (с учётом обнаружения типизированного nil через `isNilPanel`), а `Split` и `Flex` равны nil. |
| `func (n *Node) IsCollapsed() bool` | Возвращает `true`, если `n` не равен nil, `Collapse` не равен nil и `Collapse.Active` имеет значение `true`. |
| `func (n *Node) CollapsedSize(d Direction) int` | Возвращает 0 для nil-узла, отсутствующего или неактивного состояния сворачивания; в противном случае возвращает активную ширину при `Vertical` или высоту при других направлениях, используя 1, если выбранный размер не положительный. |

### `FlexItem` и `FlexConfig`

```go
type FlexItem struct {
    Node      *Node
    Grow      int
    Shrink    int
    Basis     int
    Collapsed bool
}

type FlexConfig struct {
    Direction Direction
    Items     []*FlexItem
    Dragging  bool
}
```

Эти структуры хранят конфигурацию flex-раскладки. `Shrink` пока помечен как неиспользуемый; этот файл не реализует взвешенное распределение размеров и не использует флаг `Collapsed`.

## Вспомогательные функции для дерева

Следующие непубличные методы работают с деревом:

- `findNode` возвращает лист, содержащий указанную панель, или nil, если получатель либо панель равны nil или подходящий лист не найден. Метод обходит дочерние узлы split в порядке `First`, затем `Second`, а flex-элементы — в порядке среза; nil-элементы flex пропускаются.
- `findSplitParent` возвращает split-узел с непосредственным дочерним листом, соответствующим указанной панели, либо выполняет рекурсивный поиск и возвращает nil, если совпадение не найдено. Метод также обходит flex-элементы в порядке среза и пропускает nil-элементы.
- `replaceNode` заменяет указатель на дочерний узел, равный `old`, на `new` и возвращает `true`; иначе рекурсивно ищет его среди потомков и возвращает `false`, если узел не найден. Для nil-получателя возвращает `false`. Nil-элементы flex пропускаются.
- `collectLeafNodes` возвращает листовые узлы в порядке обхода: сначала `First`, затем `Second` для split, после чего flex-элементы в порядке среза. Для nil-получателя возвращает nil; nil-элементы flex пропускаются.

`IsLeaf` определяет лист как узел с ненулевой панелью и без конфигурации split или flex. Вспомогательные функции не проверяют корректность структуры дерева и не предотвращают циклы.
