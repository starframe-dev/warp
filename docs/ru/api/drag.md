# drag.go

Этот файл существует как маркер документации на уровне пакета для пакета
`warp`. Он намеренно не содержит кода, экспортных идентификаторов и
реализации. Единственная его цель — хранить документационный комментарий
пакета, описывающий, где действительно находится поведение drag-and-drop
для разделённых границ.

## Назначение

В файле задокументировано, что взаимодействия drag-and-drop для
разделённых границ не реализованы в этом файле. Они обрабатываются в
`tab.go` и отображаются в `render.go`:

- `tab.go` реализует обработку ввода и управление состоянием при
  перетаскивании границы между разделёнными панелями. Соответствующие
  функции — `handleMouse`, `updateDrag` и `hitBorder`.
- `render.go` вычисляет экранные позиции границ через `findBorders`.

## Публичный API

Файл не объявляет ни экспортируемых функций, ни типов, ни переменных, ни
констант. Единственным публичным символом, присутствующим здесь,
является имя пакета `warp`.

## Детали реализации

Тело файла — единственный документационный комментарий, начинающийся с
пустой строки. В нём нет исполняемого кода, импортов и побочных
эффектов. Файл безопасно можно рассматривать как чистую документацию.

## Связанные файлы

| Файл | Ответственность |
|----|----|
| `tab.go` | Обработка ввода и управление состоянием при перетаскивании границы между разделёнными панелями. |
| `render.go` | Вычисляет экранные позиции границ. |
