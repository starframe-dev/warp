# drag.go

В `drag.go` объявлен пакет `warp` и содержится комментарий о том, где реализовано перетаскивание границ разделённых панелей. Сам файл не реализует это поведение и не объявляет экспортируемых идентификаторов.

## Назначение

В комментарии указано, что взаимодействие с перетаскиванием границ разделённых панелей не реализовано в этом файле. Оно обрабатывается в `tab.go` и отображается в `render.go`:

- `tab.go` реализует обработку ввода и управление состоянием при перетаскивании границы между разделёнными панелями. Соответствующие функции — `handleMouse`, `updateDrag` и `hitBorder`.
- `render.go` вычисляет экранные позиции границ с помощью `findBorders`.

## Детали реализации

Файл содержит конструкцию `package warp`, за которой следует однострочный комментарий Go. В нём нет импортов, исполняемых инструкций или экспортируемых идентификаторов.

## Связанные файлы

| Файл | Ответственность |
|----|----|
| `tab.go` | Обработка ввода и управление состоянием при перетаскивании границы между разделёнными панелями. |
| `render.go` | Вычисляет экранные позиции границ. |
