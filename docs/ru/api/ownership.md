# Владение панелями

`ownership.go` реализует внутреннее отслеживание владения панелями в пакете `warp`. В файле не объявлены экспортируемые типы или функции, поэтому он не добавляет прямых элементов публичного API. Вспомогательные функции управляют присоединением панелей к дереву, обнаруживают панели, удалённые из дерева, и обеспечивают, чтобы удалённые панели размонтировались не более одного раза за проход удаления.

## Состояние владения

### `panelOwnership`

`panelOwnership` хранит корневую `Panel` и защищает доступ к ней с помощью `sync.RWMutex`.

- `newPanelOwnership(root)` создаёт запись о владении с указанной корневой панелью.
- `setRoot(root)` заменяет корень под блокировкой на запись. Для nil-получателя ничего не происходит.
- `rootPanel()` возвращает корень под блокировкой на чтение; для nil-получателя возвращается nil.

Мьютекс защищает только ссылку на корень. Он не обеспечивает общую потокобезопасность панелей или содержимого их дерева.

### `panelInstanceKey`

`panelInstanceKey` идентифицирует панель для сохранения и обнаружения дубликатов. Для панелей-указателей ключом служат их динамический `reflect.Type` и адрес указателя. Сравнимые панели, не являющиеся указателями, идентифицируются по типу и значению. Для nil-подобных панелей и несравнимых значений, не являющихся указателями, создать ключ нельзя.

`panelInstance` использует `isNilPanel` для отбрасывания nil-панелей (включая типизированные nil-значения, распознаваемые этой функцией). Тип входит в ключ, поэтому значения разных динамических типов не столкнутся только из-за совпадения адреса или равенства значений.

## Обход дерева

`collectPanelInstances` обходит панель и вложенные в неё структуры панелей. `collectNodePanelInstances` начинает обход с узла макета `Node`. Сборщик распознаёт следующие встроенные связи между панелями:

| Панель | Вложенные посещаемые панели |
| --- | --- |
| `*TabGroup` | Её вкладки |
| `*Tab` | Панели в корневом узле и плавающие панели |
| `*Scrollable`, `*Selectable`, `*Collapsible` | `Content` |
| `*warpPanel` | Корень, возвращаемый связанной с ней warp, если он есть |

Обход узлов посещает их панель, оба дочерних узла разделённого контейнера и узел каждого ненулевого элемента flex. Nil-узлы, панели и элементы flex пропускаются. Множество посещённых элементов предотвращает повторный обход встроенных типов панелей-указателей, включая циклы. Другие реализации `Panel` добавляются как конечные узлы; их внутреннее содержимое не анализируется.

## Присоединение и обеспечение владения

`attachPanelOwnership(root, ownership)` обходит переданное дерево панелей и связывает владение там, где это поддерживается:

- Группы вкладок и вкладки получают указатель владения.
- Для вкладок, найденных в группе, поле `parent` устанавливается в эту группу.
- `warpPanel` с ненулевой warp получает владение под мьютексом warp, а для `ownsDomainRoot` устанавливается `false`.

Если указатель владения равен nil, присоединение ничего не делает.

`(*Tab).ensureOwnership` и `(*TabGroup).ensureOwnership` лениво создают владение и возвращают его. Вкладка, если возможно, наследует владение от родительской группы; в противном случае она создаёт владение с корнем в самой себе. Группа создаёт владение с корнем в самой себе. После инициализации обе функции присоединяют владение ко всему текущему дереву панелей. Для nil-получателей возвращается nil.

`collectTabPanels` обходит содержимое вкладки, а `tabContainsPanel` сравнивает ключи экземпляров, чтобы определить, находится ли целевая панель в этом дереве. `removeSliceAt` — обобщённая функция для срезов: если индекс вне диапазона, она возвращает исходный срез; иначе сдвигает последующие элементы влево, очищает прежний последний элемент до нулевого значения его типа и возвращает укороченный срез.

## Удаление панелей и размонтирование

`(*panelOwnership).unmountRemoved(candidates)` сравнивает панели-кандидаты с панелями, которые на момент вызова всё ещё доступны из корня владения:

1. Собирает панели текущего корня и отмечает как сохранённые те из них, для которых можно создать корректный ключ экземпляра.
2. Пропускает nil-подобные панели, панели без пригодного ключа и кандидатов с ключом, уже рассмотренным в этом вызове.
3. Не затрагивает кандидатов, которые всё ещё находятся в дереве корня.
4. Для каждого уникального кандидата, которого больше нет в дереве, вызывает `Unmount()`, если панель реализует публичный интерфейс `Unmounter`, а затем отсоединяет от неё это владение в поддерживаемых встроенных типах панелей.

Для nil-получателя или пустого списка кандидатов функция ничего не делает. При отсоединении указатель владения очищается только в том случае, если он всё ещё совпадает с удаляемым владением, поэтому новая связь не будет стёрта. Для отсоединённого `warpPanel` обновление защищено мьютексом warp; при очистке соответствующего владения `ownsDomainRoot` также устанавливается в `true`. Указатели владения вкладок и групп вкладок очищаются, только если связь совпадает.

Размонтирование и отсоединение выполняются один раз для каждого уникального ключа кандидата в рамках вызова, но не глобально: последующие вызовы могут повторно обработать ту же панель, если она снова передана как удалённый кандидат. Кандидаты без ключа экземпляра невозможно отслеживать, поэтому этот метод не размонтирует и не отсоединяет их.

## Примечание о публичном API

Все объявления в этом файле — неэкспортируемые детали реализации. Единственные публичные контракты, на которые он непосредственно опирается, — `Panel` и необязательный интерфейс `Unmounter`; настройка и очистка владения выполняются другими операциями пакета, которые изменяют деревья панелей.
