# focus.go — Управление фокусом клавиатуры

Этот модуль определяет интерфейсы панелей, связанные с фокусом, и внутренние
вспомогательные функции для сбора панелей, принимающих фокус, и перемещения
фокуса между ними.

## Публичный API

### Интерфейс `Focusable`

```go
type Focusable interface {
    Panel
    Focus()
    Blur()
    Focused() bool
}
```

Панель, способная принимать фокус клавиатуры, реализует интерфейс `Panel` и
три метода для работы с фокусом. Метод `Focus` вызывается при назначении фокуса,
`Blur` — при его снятии, а `Focused` сообщает, находится ли панель сейчас в
фокусе.

| Метод | Сигнатура | Описание |
|---|---|---|
| `Focus` | `Focus()` | Вызывается, когда панель получает фокус. |
| `Blur` | `Blur()` | Вызывается, когда панель теряет фокус. |
| `Focused` | `Focused() bool` | Сообщает, находится ли панель сейчас в фокусе. |

### Интерфейс `RawKeyReceiver`

```go
type RawKeyReceiver interface {
    Panel
    WantsRawKeys() bool
}
```

Панель, реализующая этот интерфейс, может указать, нужны ли ей необработанные
нажатия клавиш. Как описано в комментарии к коду, `TabGroup` перед обработкой
сочетаний клавиш Warp передаёт каждое нажатие панели в фокусе. В частности,
Ctrl+C не считается командой выхода, если метод `WantsRawKeys()` у получателя в
фокусе возвращает `true`.

## Внутренний API (неэкспортируемый)

Эти вспомогательные функции используются для определения фокуса и навигации
внутри пакета.

### `isFocusable`

```go
func isFocusable(panel Panel) (Focusable, bool)
```

Возвращает панель как `Focusable` и `true`, если она реализует этот интерфейс.
Панели со значением `nil`, включая типизированные nil-значения, дают результат
`nil, false`.

### `collectFocusables`

```go
func collectFocusables(node *Node) []Focusable
```

Обходит дерево с корнем `node` и возвращает его конечные панели, принимающие
фокус, в порядке визуального обхода: сначала первый ребёнок split, затем второй;
элементы flex — в объявленном порядке. Для nil-узла возвращается пустой список.

### `focusIndex`

```go
func focusIndex(list []Focusable, current Panel) int
```

Возвращает индекс первого элемента `list`, совпадающего с `current`, или `-1`,
если `current` равен nil либо совпадений нет. Панели сравниваются по равенству,
если их значения сравнимы; в противном случае используется глубокое сравнение.

### `focusNext` / `focusPrev`

```go
func focusNext(list []Focusable, current Panel) Focusable
func focusPrev(list []Focusable, current Panel) Focusable
```

Возвращают соответственно следующую или предыдущую панель с переходом по кругу;
для пустого списка возвращают `nil`. Если `current` отсутствует в непустом
списке, `focusNext` возвращает первый элемент, а `focusPrev` — последний.

### `applyFocus`

```go
func applyFocus(current, next Focusable)
```

Если значения не совпадают, вызывает `Blur` для текущей панели, если она не nil,
а затем `Focus` для следующей панели, если она не nil. Для сравнения используется
тот же способ сопоставления панелей, что и в `focusIndex`; если значения
совпадают, вызовы методов не выполняются.

### `isNilPanel` / `samePanel`

```go
func isNilPanel(panel Panel) bool
func samePanel(a, b Panel) bool
```

`isNilPanel` обнаруживает как nil-интерфейс, так и типизированные nil-значения
типов, допускающих nil. `samePanel` считает две nil-панели равными; ненулевые
значения с разными динамическими типами — неравными; для сравнимых типов
использует равенство, а для несравнимых — `reflect.DeepEqual`.

### `appendFocusables`

```go
func appendFocusables(result *[]Focusable, node *Node)
```

Добавляет конечные панели, принимающие фокус, из `node` в `result`, используя тот
же порядок обхода, что и `collectFocusables`; nil-узлы игнорируются.

## Особенности поведения

- Навигация по списку панелей, принимающих фокус, выполняется по кругу. Если
  текущей панели нет в списке, следующей становится первая, а предыдущей —
  последняя.
- `applyFocus` избегает повторных вызовов методов, если текущая и следующая
  панели совпадают согласно `samePanel`.
- Вспомогательные функции для работы с фокусом не поддерживают глобальное
  состояние фокуса: они работают только с явно переданными аргументами и
  вызывают методы `Focus` и `Blur`.

## Пример использования

```go
// Псевдокод обработчика клавиш, управляющего навигацией по Tab.
list := collectFocusables(root)
next := focusNext(list, current)
applyFocus(current, next)
```
