# focus.go — Управление фокусом клавиатуры

Этот модуль реализует управление фокусом клавиатуры для движика
раскладки терминального UI `warp`. Он определяет возможность
`Focusable`, на которую должен подписываться панель, и предоставляет
вспомогательные функции обхода дерева, вычисляющие упорядоченный список
панелей, принимающих фокус, и примитивы навигации (вперёд / назад),
используемые для перемещения курсора по этому списку.

## Публичный API

### Интерфейс `Focusable`

``` go
type Focusable interface {
    Panel
    Focus()
    Blur()
    Focused() bool
}
```

Панель, способная принимать фокус клавиатуры, должна внедрять `Panel` и
дополнительно реализовывать три метода: `Focus` (вызывается, когда
панель получает фокус), `Blur` (вызывается, когда она теряет фокус) и
`Focused`, сообщающий, удерживает ли панель в данный момент фокус.

| Метод | Сигнатура | Описание |
|----|----|----|
| `Focus` | `Focus()` | Вызывается, когда фокус передаётся этой панели. |
| `Blur` | `Blur()` | Вызывается, когда фокус покидает эту панель. |
| `Focused` | `Focused() bool` | Возвращает `true`, если панель является текущим владельцем фокуса. |

### Интерфейс `RawKeyReceiver`

``` go
type RawKeyReceiver interface {
    Panel
    WantsRawKeys() bool
}
```

Панель, которой нужно получать *все* нажатия клавиш без перехвата
(например, эмулятор терминала, работающий внутри PTY). Рантайм
обращается к `WantsRawKeys`, чтобы решить, нужно ли пропустить обычную
диспетчеризацию клавиш и передать сырые события клавиш напрямую
получателю.

## Внутренний API (неэкспортируемый)

Приведённые ниже вспомогательные функции неэкспортируемы и являются
частью внутреннего пайплайна разрешения фокуса внутри пакета.

### `isFocusable`

``` go
func isFocusable(panel Panel) (Focusable, bool)
```

Выполняет безопасное приведение типов. Возвращает значение `Focusable`
(или `nil`) и булевый флаг, указывающий, реализует ли переданный `Panel`
на самом деле этот интерфейс.

### `collectFocusables`

``` go
func collectFocusables(node *Node) []Focusable
```

Проходит дерево раскладки, корнем которого является `node`, и возвращает
все панели `Focusable` в *визуальном порядке* (детей первого разбиения —
до детей второго; элементы flex — в порядке их объявления). Результат
используется как список навигации по фокусу для обработчиков клавиш
«вперёд» / «назад».

### `focusIndex`

``` go
func focusIndex(list []Focusable, current Panel) int
```

Находит позицию `current` внутри `list`. Возвращает `-1`, если панели
нет в списке.

### `focusNext` / `focusPrev`

``` go
func focusNext(list []Focusable, current Panel) Focusable
func focusPrev(list []Focusable, current Panel) Focusable
```

Примитивы навигации с возвратом по кругу. `focusNext` перемещает фокус к
следующей панели в `list`, переходя от последнего элемента обратно к
первому. `focusPrev` двигается в противоположном направлении. Оба
возвращают `nil`, если список пуст.

### `applyFocus`

``` go
func applyFocus(current, next Focusable)
```

Выполняет побочные эффекты перехода фокуса: вызывает `Blur` для панели,
теряющей фокус (если это отдельное ненулевое значение) и `Focus` для
панели, получающей фокус.

## Замечания о поведении

- Обход фокуса уважает *визуальный порядок* дерева раскладки: для узлов
  разбиения первый ребёнок всегда посещается до второго; для узлов flex
  элементы посещаются в порядке объявленного среза.
- Возврат по кругу — осознанное решение: нажатие «вперёд» на последней
  панели переводит на первую, а «назад» на первой — на последнюю.
- `applyFocus` подавляет вызов `Blur`, если уходящая панель равна `nil`
  или совпадает по объекту с входящей, предотвращая лишнее мельтешение
  фокуса.
- Модуль не содержит глобального состояния и скрытых побочных эффектов,
  помимо задокументированных колбэков `Focus` / `Blur`; все данные
  передаются через явные параметры функций, приведённые выше.

## Пример использования

``` go

// Псевдокод обработчика клавиш, управляющего навигацией по Tab.
list := collectFocusables(root)
next  := focusNext(list, current)
applyFocus(current, next)

```
