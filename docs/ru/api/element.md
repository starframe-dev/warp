# Элемент

`element.go` определяет семантические UI-элементы, их экранные границы, а также вспомогательные средства для предоставления, обрезки и поиска в деревьях элементов.

Элемент содержит роль, имя, необязательное действие, границы в координатах ячеек терминала и необязательные дочерние элементы.

## Типы

### `Element`

```go
type Element struct {
    Role     string    `json:"role"`
    Name     string    `json:"name"`
    Action   string    `json:"action,omitempty"`
    Bounds   Bounds    `json:"bounds"`
    Children []Element `json:"children,omitempty"`
}
```

`Role`, `Name` и `Bounds` всегда включаются в JSON. `Action` опускается, если он пуст, а `Children` — если в нём нет элементов.

### `Bounds`

```go
type Bounds struct {
    X int `json:"x"`
    Y int `json:"y"`
    W int `json:"w"`
    H int `json:"h"`
}
```

Задаёт прямоугольник в координатах ячеек терминала: его левый верхний угол находится в точке `(X, Y)`, размеры — `W` на `H`.

### `Bounds.Center`

```go
func (b Bounds) Center() (int, int)
```

Возвращает `(X + W/2, Y + H/2)` с использованием целочисленного деления.

### `ElementProvider`

```go
type ElementProvider interface {
    Elements(width, height int) []Element
}
```

Панели могут реализовать этот интерфейс, чтобы предоставлять корневые элементы для заданных размеров панели в ячейках. Дочерние элементы вложены в срез `Children` каждого элемента.

### `ViewportElementProvider`

```go
type ViewportElementProvider interface {
    ElementsAt(width, height, offset int) []Element
}
```

Провайдер может реализовать этот интерфейс, чтобы возвращать семантические элементы, пересекающие заданную область просмотра содержимого. Возвращаемые границы остаются относительно начала всего содержимого. Размеры области просмотра и смещение содержимого задаются в ячейках.

### `ElementProviderFunc`

```go
type ElementProviderFunc func(width, height int) []Element

func (f ElementProviderFunc) Elements(width, height int) []Element
```

Адаптирует функцию к интерфейсу `ElementProvider`: передаёт ей размеры и возвращает результат функции.

### `SemanticStableMsg`

```go
type SemanticStableMsg interface {
    SemanticStateUnchanged() bool
}
```

Тип сообщения может реализовать этот интерфейс, чтобы гарантировать, что обработка конкретного сообщения не изменит дерево семантических элементов. Если HTTP-инспектор включён, сообщение, для которого метод возвращает `true`, позволяет Warp сохранить ранее опубликованный неизменяемый снимок после `Update` и отложить перестроение элементов до следующего `View`. Это явная гарантия корректности; для сообщений, не реализующих интерфейс или возвращающих `false`, используется консервативное поведение обновления.

## Функции

### `collectElements`

```go
func collectElements(panel Panel, width, height int) []Element
```

Внутренняя функция пакета. Возвращает `nil`, если `panel` равен nil или не реализует `ElementProvider`; в противном случае вызывает `Elements(width, height)` и возвращает результат.

### `FindElement`

```go
func FindElement(elems []Element, role, name, action string) (Element, bool)
```

Рекурсивно выполняет поиск в глубину с обходом в прямом порядке и возвращает первый элемент, совпадающий по всем непустым критериям. Пустые аргументы `role`, `name` или `action` считаются подстановочными знаками. Если совпадение не найдено или достигнут предел безопасности поиска, возвращает нулевое значение и `false`.

```go
if el, ok := FindElement(panel.Elems, "", "submit", ""); ok {
    x, y := el.Bounds.Center()
    // Use (x, y) as the element's center cell.
}
```

## Примечания о поведении

- Обход и клонирование дерева ограничены 128 уровнями и 100 000 узлами. При клонировании деревья, превышающие эти пределы, обрезаются; `FindElement` прекращает поиск при достижении предела.
- Warp клонирует принадлежащие провайдеру семантические данные до их смещения или обрезки, поэтому провайдерам не следует рассчитывать на изменение возвращаемых ими срезов со стороны Warp.
- Границы задаются в координатах ячеек терминала, а не пикселях.
