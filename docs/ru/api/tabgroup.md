# TabGroup

`TabGroup` — панель Bubble Tea, которая отображает строку вкладок и переключает
между дочерними вкладками. Её можно встраивать в сплиты и flex-раскладки
или использовать как корневую панель TUI-приложения. Положение вкладок
настраивается через `TabPosition` (сверху, снизу, слева, справа или без строки).

## Типы

### TabGroup

`TabGroup` хранит упорядоченный список панелей `*Tab`, отслеживает индекс
активной вкладки и хранит её положение, владельца, состояние раскладки и
обработки попаданий.

## Публичный API

| Символ | Тип | Описание |
|----|----|----|
| `NewTabGroup(pos TabPosition) *TabGroup` | функция | Создаёт `TabGroup` с одной вкладкой по умолчанию с именем "main". |
| `ActiveTab() *Tab` | метод | Возвращает текущую активную вкладку или `nil`, если не выбрана допустимая вкладка. |
| `NewTab(name string) *Tab` | метод | Создаёт новую вкладку, переключается на неё и возвращает её. |
| `NextTab()` | метод | Переключается на следующую вкладку (по кругу). |
| `PrevTab()` | метод | Переключается на предыдущую вкладку (по кругу). |
| `View(w, h int) string` | метод | Отображает строку вкладок и содержимое активной вкладки. |
| `Elements(w, h int) []Element` | метод | Возвращает элементы активной вкладки со смещением в соответствии с положением строки вкладок, а также семантические элементы строки вкладок. |
| `Update(msg tea.Msg) tea.Cmd` | метод | Обрабатывает сообщения клавиатуры, мыши, изменения размера и широковещательные сообщения. |

## Поведение

### Переключение вкладок

`NextTab` и `PrevTab` переключают вкладки по кругу, используя модульную
арифметику. Если вкладка только одна, методы ничего не делают. Внутренний
метод `switchTab(idx)` игнорирует недопустимые индексы и ничего не делает,
если запрошенная вкладка уже активна.

### Создание и закрытие вкладок

`NewTab` добавляет новую вкладку и сразу активирует её. `closeTab` удаляет
вкладку по индексу; если закрыта активная вкладка, активируется вкладка на
том же индексе либо последняя оставшаяся вкладка, если была удалена последняя.
Закрытие по недопустимому индексу или закрытие единственной вкладки ничего
не делает.

### Жизненный цикл фокуса

При переключении вкладок у старой вкладки вызывается `Blur` для её
сфокусированного `Focusable`, при этом цель фокуса сохраняется; затем у
сохранённой цели новой активной вкладки вызывается `Focus`. Поэтому у
неактивной вкладки нет дочернего элемента в состоянии фокуса, но её цель
фокуса восстанавливается при повторной активации. При закрытии вкладки её
сфокусированная панель теряет фокус и очищается; при закрытии активной
вкладки фокус восстанавливается в новой активной вкладке. После удаления
панели, реализующие `Unmounter`, размонтируются только в том случае, если на
этот экземпляр больше не ссылается ни одна вкладка или плавающая панель в той
же иерархии владения. Самостоятельный `TabGroup` владеет своей иерархией;
если он встроен в `Warp`, владельцем становится внешний `Warp`.

### Рендеринг

`View` объединяет строку вкладок и содержимое активной вкладки с помощью
`lipgloss.JoinVertical` / `lipgloss.JoinHorizontal` в зависимости от
`TabPosition`. Строка вкладок отображается как горизонтальный ряд меток (для
положений сверху и снизу) или вертикальный столбец (для положений слева и
справа). Метки обрезаются с учётом ширины отображения в терминале: максимум
до 20 столбцов для горизонтальной строки и до 15 для вертикальной; в
указанных случаях используется многоточие посредством `ansi.Truncate`.
Метка активной вкладки начинается с `▎` и содержит глиф закрытия `×`. Если
`ActiveTab()` возвращает `nil`, `View` возвращает `emptyView(h)` (запрошенная
высота нормализуется до значения не меньше нуля).

### Семантические элементы строки вкладок

Помимо содержимого активной вкладки, `Elements` предоставляет элементы
управления строки вкладок, принадлежащие фреймворку. Метки вкладок имеют
роль `tab` и действие `activate-tab`; ячейка закрытия активной вкладки —
дочерняя кнопка `button` с действием `close-tab`; ячейка `+` — кнопка
`button` с действием `new-tab`. Границы вычисляются по геометрии меток строки
вкладок и не требуют предварительного вызова `View`.

### Взаимодействие с мышью

Области попадания на строку вкладок (`tabRegion`) заполняются во время её
рендеринга. Щелчок по вкладке переключает на неё, щелчок по глифу закрытия
закрывает её, а щелчок по области `+` создаёт новую вкладку. Логика проверки
попаданий различается для горизонтальной и вертикальной раскладок строки.

### Диспетчеризация сообщений

`Update` обрабатывает `tea.KeyMsg`, `tea.MouseMsg`, `tea.WindowSizeMsg` и
`ResizeMsg`. Сочетания клавиш группы вкладок: ctrl+c, ctrl+tab,
ctrl+shift+tab, ctrl+w и ctrl+t. Если сфокусированная панель активной вкладки
запрашивает получение клавиш без обработки, сообщения клавиатуры сначала
передаются ей, а затем проверяются сочетания клавиш. Остальные сообщения
клавиатуры передаются активной вкладке. Сообщения об изменении размера окна
и `ResizeMsg` передаются всем вкладкам; прочие сообщения рассылаются всем
вкладкам, чтобы дочерние панели (например, эмуляторы PTY) могли их получить.

## Детали реализации

- `padRight` дополняет строку пробелами до заданной ширины отображения в
  терминале, используя `ansi.StringWidth`.
- `tabRegion` хранит границы областей щелчка для каждой вкладки; `idx == -1`
  обозначает область создания новой вкладки.
- Области горизонтальной строки вычисляются слева направо, с завершающей
  областью `+`; области вертикальной строки располагаются сверху вниз, а
  область `+` находится последней.
- Геометрия содержимого корректируется в соответствии с положением строки
  вкладок, чтобы дочерние панели размещались правильно.
- `shiftElements` рекурсивно смещает границы элементов, чтобы проверка
  попаданий оставалась согласованной после смещения координат дочерних
  элементов строкой вкладок.

## Пример

```go
tg := warp.NewTabGroup(warp.TabTop)
tg.NewTab("editor")
tg.NewTab("logs")

// Переключение на следующую вкладку
tg.NextTab()
```
