# TabGroup

`TabGroup` — панель Bubble Tea, которая отображает строку вкладок и
переключает между дочерними вкладками. Её можно встраивать внутри
splits, flex-раскладок или использовать как корневую панель
TUI-приложения. Положение вкладок настраивается через `TabPosition`
(top, bottom, left, right, none).

## Типы

### TabGroup

``` go
type TabGroup struct {
    tabs      []*Tab
    activeTab int
    width     int
    height    int

    tabPosition      TabPosition
    tabRegions       []tabRegion
    newTabRegion     *tabRegion
    verticalTabWidth int
}
```

`TabGroup` хранит упорядоченный список панелей `*Tab`, отслеживает
индекс активной вкладки и кэширует геометрию каждого кадра (ширину,
высоту, области срабатывания вкладок), используемую для обработки кликов
мыши.

## Публичный API

| Символ | Тип | Описание |
|----|----|----|
| `NewTabGroup(pos TabPosition) *TabGroup` | функция | Создаёт `TabGroup` с одной вкладкой по умолчанию с именем "main". |
| `ActiveTab() *Tab` | метод | Возвращает текущую активную вкладку или `nil`, если валидная вкладка не выбрана. |
| `NewTab(name string) *Tab` | метод | Создаёт новую вкладку, переключает на неё и возвращает новую вкладку. |
| `NextTab()` | метод | Переключает на следующую вкладку (по кругу). |
| `PrevTab()` | метод | Переключает на предыдущую вкладку (по кругу). |
| `View(w, h int) string` | метод | Отображает строку вкладок и содержимое активной вкладки. |
| `Elements(w, h int) []Element` | метод | Возвращает элементы активной вкладки со смещением по положению строки вкладок. |
| `Update(msg tea.Msg) tea.Cmd` | метод | Обрабатывает сообщения о клавишах, мыши, изменении размера и broadcast-сообщения. |

## Поведение

### Переключение вкладок

`NextTab` и `PrevTab` переключают по кругу по списку вкладок с помощью
модульной арифметики. Если вкладка одна, они ничего не делают.
Внутренняя `switchTab(idx)` игнорирует некорректный индекс и ничего не
делает, если запрошенная вкладка уже активна.

### Создание и закрытие вкладок

`NewTab` добавляет новую вкладку и сразу активирует её. `closeTab`
удаляет вкладку по индексу; при закрытии активной выбирается вкладка на
том же индексе, а если закрыта последняя — новая последняя. Закрытие
единственной вкладки ничего не делает.

### Lifecycle фокуса

При переключении старая вкладка вызывает `Blur` у текущего
`Focusable`, сохраняя target; новая активная вкладка вызывает `Focus` у
своего сохранённого target. Поэтому дочерняя панель неактивной вкладки
не считается сфокусированной, но получает фокус при повторной
активации. Закрытие вкладки вызывает `Blur` и очищает её target; при
закрытии активной вкладки фокус восстанавливается у новой активной.

### Рендеринг

`View` собирает строку вкладок и содержимое активной вкладки, используя
`lipgloss.JoinVertical` / `lipgloss.JoinHorizontal` в зависимости от
`TabPosition`. Строка вкладок отображается как горизонтальный ряд меток
вкладок (для top/bottom) или как вертикальный столбец (для left/right).
Метки вкладок обрезаются до 20 символов (горизонтально) или до 15
символов (вертикально) с многоточием. У активной вкладки метка
отображается с префиксом `▎` и глифом закрытия `×`. Если `ActiveTab()`
равен nil, `View` возвращает ровно `h` пустых строк (`""` при `h == 0`,
иначе `h-1` символов перевода строки).

### Взаимодействие с мышью

Область срабатывания строки вкладок (`tabRegion`) вычисляется заново
каждый кадр во время рендеринга. Клик по вкладке переключает на неё,
клик по глифу закрытия закрывает вкладку, а клик по области `+ /`
создаёт новую вкладку. Логика обработки кликов различается для
горизонтальной и вертикальной раскладок строки.

### Диспетчер сообщений

`Update` перехватывает `tea.KeyMsg` (ctrl+c, ctrl+tab, ctrl+shift+tab,
ctrl+w, ctrl+t), `tea.MouseMsg`, `tea.WindowSizeMsg` и `ResizeMsg`. Все
остальные сообщения broadcast'ятся на каждую вкладку, чтобы дочерние
панели (например, PTY-эмуляторы) их получали.

## Детали реализации

- `padRight` дополняет строку пробелами до целевой ширины, используя
  подсчёт ширины с учётом rune в lipgloss.
- `tabRegion` хранит границы кликов по вкладкам; `idx == -1` отмечает
  область «новая вкладка».
- Горизонтальная строка: области вычисляются слева направо с хвостовой
  областью `+`; вертикальная строка: области выстраиваются сверху вниз с
  областью `+` последней.
- Геометрия содержимого (`contentWidth`, `contentHeight`,
  `contentOffset`) подстраивается под положение строки вкладок, чтобы
  дочерние панели выстраивались правильно.
- `shiftElements` рекурсивно сдвигает границы элементов, чтобы обработка
  кликов оставалась согласованной после сдвига координат дочерних
  элементов строкой вкладок.

## Пример

``` go
tg := warp.NewTabGroup(warp.TabTop)
tg.NewTab("editor")
tg.NewTab("logs")

// Переключение на следующую вкладку
tg.NextTab()
```
