render.go — движок рендеринга Warp

Этот файл содержит рекурсивную логику рендеринга, которая преобразует дерево Node (листья, сплиты и flex-контейнеры) в сетку текстовых ячеек. Также реализовано hit-тестирование перетаскиваемых границ, чтобы взаимодействие с мышью/указателем могло определить, какой сплит или flex-граница находится под данной ячейкой.

Публичный API

Ни одна из функций в этом файле не экспортируется (все имена написаны строчными буквами). Единственным экспортируемым типом является BorderHit. Файл является внутренним модулем реализации пакета warp; потребители взаимодействуют с публичной точкой входа рендеринга пакета (определённой в другом месте), которая управляет этими внутренними помощниками.

type BorderHit struct { Split *SplitConfig Flex *FlexConfig Direction Direction X, Y int // Start position of the border Length int // Length of the border in cells }

BorderHit описывает одну перетаскиваемую границу в конкретной позиции терминальной сетки. Ровно одно из Split или Flex является не-nil, указывая, какая конфигурация владеет границей. Direction указывает, проходит ли граница вертикально (разделяя ширину) или горизонтально (разделяя высоту).

Основные функции рендеринга

renderNode

func renderNode(node *Node, w, h int) []string

Центральный диспетчер. По заданному узлу и его выделенному прямоуголу из w × h ячеек возвращает ровно h строк, каждая с визуальной шириной w. Поведение определяется тем, какое поле макета установлено:

  • nil-узел — возвращает пустые строки через makeEmptyLines.
  • Лист (node.IsLeaf()) — запрашивает контент у View(w, h) панели и нормализует его с помощью padContent.
  • Вертикальный / горизонтальный сплит — делегирует в renderVerticalSplit / renderHorizontalSplit.
  • Flex — делегирует в renderFlex.

renderVerticalSplit / renderHorizontalSplit

Обе вычисляют размеры дочерних элементов через computeSplitSizes, рекурсивно рендерят каждый дочерний элемент, затем объединяют две половины. Между ними рисуется граница в одну ячейку из │ (вертикальная) или ─ (горизонтальная). Ключевое поведение:

  • Если хотя бы одна сторона свёрнута, граница пропускается, чтобы свёрнутая панель прилегала вплотную к развернутой.
  • Когда split.Dragging равно true, граница оформляется стилем borderDragStyle; в противном случае borderStyle.
  • Символ границы обёрнут в ansi.ResetStyle с обеих сторон, чтобы стили панелей не могли затечь в строку границы.
  • Необязательный индикатор сворачивания (<) рисуется в split.CollapseRow только когда установлено OnCollapse и ни одна сторона не свёрнута.

renderFlex

Делегирует в renderFlexRow (Direction=Horizontal, дочерние элементы выстраиваются слева направо с вертикальными границами) или renderFlexColumn (Direction=Vertical, дочерние элементы сверху вниз с горизонтальными границами). Количество границ — len(items) − 1; доступное пространство уменьшается соответственно перед тем, как computeFlexSizes распределяет его.

computeFlexSizes

Двухпроходный flexbox-подобный алгоритм:

  1. Каждому элементу назначается basis (его Basis или MinPanelSize, если не свёрнут; 1 если свёрнут).
  2. Если остаточное пространство после базисов не положительно, возвращается базис как есть.
  3. Остаточное пространство распределяется пропорционально по весам Grow среди несвёрнутых элементов; если общая сумма grow равна 0, делится поровну среди несвёрнутых элементов.
  4. Остаточные пиксели назначаются последнему несвёрнутому элементу, чтобы сохранить точные суммарные ширину/высоту.

padContent

func padContent(content string, w, h int) []string

Нормализует сырую строку панели ровно до w колонок × h строк. Урезание использует ansi.Truncate (учитывающее визуальную ширину), поэтому многобайтовые UTF-8 и ANSI-последовательности никогда не разрываются. Каждая возвращаемая строка дополняется пробелами справа и дополняется суффиксом ansi.ResetStyle, чтобы предотвратить утечку стилей между смежными панелями.

computeSplitSizes

Определяет точные пиксельные ширины/высоты для сплита из двух дочерних элементов: свёрнутые дочерние получают свой фиксированный CollapsedSize; в противном случае доля fraction от avail уходит первому дочернему. Обе стороны ограничиваются MinPanelSize перед выведением второй.

Hit-тестирование границ

findBorders

func findBorders(node *Node, x, y, w, h int) []BorderHit

Рекурсивно обходит дерево узлов и возвращает абсолютные позиции каждой видимой границы. Границы сплитов сообщаются только когда оба дочерних элемента развернуты (свёрнутая сторона подавляет границу). Flex-границы собираются через findFlexBorders.

findFlexBorders

Итерирует flex-элементы, накапливая смещения, чтобы вычислить (X, Y) и Length каждой межэлементной границы. Граница между элементами i и i+1 опускается, если хотя бы один из смежных элементов свёрнут.

Ключевые инварианты

  • Возвращаемые срезы строк всегда имеют длину ровно h (или пусты/nil, если узел nil или размер ≤ 0).
  • Каждая строка имеет ровно w визуальных колонок шириной.
  • Ни один стиль не может утечь из одной панели в соседнюю, поскольку каждая строка сбрасывается через ansi.ResetStyle.
  • Видимость границ — функция состояния сворачивания дочерних; проходы рендеринга и hit-теста делят одни и те же вычисления размеров, сохраняя их согласованность.
