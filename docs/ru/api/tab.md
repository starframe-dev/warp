# Вкладка

Тип `Tab` в `tab.go` — это самодостаточная компоновка warp: она владеет
корневым деревом панелей (`Node`), необязательным набором плавающих
панелей и фокусом клавиатуры. Реализует интерфейс `Panel`
(`View`/`Update`), поэтому вкладку можно встраивать как панель в более
крупную компоновку (например, внутрь `Container`).

Вкладку можно создать отдельно с помощью `NewTab` (без родительской
группы) или внутри пакета с помощью `newTab(name, parent)`, если она
принадлежит `TabGroup`. В обоих случаях в корне изначально находится
пустая панель-заполнитель, поэтому вкладку всегда можно отрисовать.

## Публичный API

| Метод | Назначение |
|----|----|
| `NewTab(name string) *Tab` | Создаёт отдельную вкладку с пустым корнем. |
| `RootPanel() Panel` | Возвращает корневую панель (её можно безопасно передать как родителя первого разделения). |
| `SetRootPanel(panel Panel)` | Заменяет корневую панель. |
| `SplitVertical(parent Panel, fraction float64, newPanel Panel)` | Разделяет панель на левую и правую (fraction — доля левой части). |
| `SplitHorizontal(parent Panel, fraction float64, newPanel Panel)` | Разделяет панель на верхнюю и нижнюю (fraction — доля верхней части). |
| `FlexRow(parent Panel, items []FlexItemSpec)` | Заменяет панель горизонтальным гибким рядом. |
| `FlexColumn(parent Panel, items []FlexItemSpec)` | Заменяет панель вертикальным гибким столбцом. |
| `Float(panel Panel, x, y, width, height int)` | Добавляет плавающую панель поверх компоновки. |
| `CloseFloat(fp *FloatPane)` | Удаляет плавающую панель. |
| `Focus() Panel` | Возвращает текущую панель в фокусе. |
| `SetFocus(panel Panel) tea.Cmd` | Устанавливает фокус на панель. |
| `FocusNext() / FocusPrev()` | Перемещает фокус на следующую/предыдущую доступную для фокусировки панель (по кругу). |
| `FocusFirst()` | Перемещает фокус на первую доступную для фокусировки панель. |
| `FocusPanel(panel Panel)` | Устанавливает фокус на указанную панель, если она реализует `Focusable`. |
| `SetSplitFraction(panel Panel, fraction float64) bool` | Устанавливает долю разделения, содержащего `panel`. |
| `GetSplitFraction(panel Panel) (float64, bool)` | Возвращает долю разделения, содержащего `panel`. |
| `Collapse(panel Panel, size int) bool` | Сжимает `panel` до фиксированного размера, сохраняя долю разделения для восстановления. |
| `Expand(panel Panel) bool` | Восстанавливает для свёрнутой панели сохранённую долю разделения. |
| `ToggleSplitCollapse(parent Panel)` | Переключает состояние свёрнутости разделения, содержащего `parent`. |
| `SetSplitCollapse(parent, collapseRow, onCollapse)` | Добавляет символ сворачивания и обработчик к границе разделения. |
| `ToggleCollapsible(panel Panel)` | Переключает состояние свёрнутости панели с поддержкой сворачивания. |
| `BroadcastResize() tea.Msg` | Рассылает `ResizeMsg` каждому конечному узлу с вычисленным размером. |
| `HandleMouse(msg tea.MouseMsg) tea.Cmd` | Публичная точка обработки событий мыши для встроенных вкладок. |
| `View(width, height int) string` | Отрисовывает содержимое вкладки (реализует `Panel`). |
| `Update(msg tea.Msg) tea.Cmd` | Рассылает сообщения по дереву панелей (реализует `Panel`). |
| `Elements(w, h int) []Element` | Собирает интерактивные элементы из дерева. |

## Типы

### TabPosition

Целочисленный тип, задающий расположение панели вкладок: `TabTop`,
`TabBottom`, `TabLeft`, `TabRight` или `TabNone`.

### FlexItemSpec

Описывает один элемент гибкой компоновки: `Panel` (панель) и `Grow`
(коэффициент её растяжения, ограниченный снизу нулём).

### emptyPanel

Внутренняя панель-заполнитель, используемая в качестве начального корня,
чтобы вкладка могла предоставлять элементы ещё до добавления настоящих
панелей.

## Поведение и детали реализации

- **Разделение:** `SplitVertical`/`SplitHorizontal` объединяют существующую
  и новую панели в `SplitConfig`, ограничивая долю диапазоном
  (`clampFraction` удерживает значения в пределах \[0.1, 0.9\]).
- **Гибкая компоновка:** `FlexRow`/`FlexColumn` заменяют содержимое узла
  на `FlexConfig`. Отрицательные коэффициенты растяжения ограничиваются
  нулём; пустой список элементов игнорируется.
- **Поток сообщений:** `Update` обрабатывает `tea.WindowSizeMsg`
  (сохраняет размер, рассылает `ResizeMsg` и исходное сообщение о размере
  окна), `ResizeMsg` (рассылает только изменение размера), а все остальные
  сообщения (например, `PtyOutputMsg`) пересылает каждому конечному узлу.
- **Отрисовка:** `View` отрисовывает дерево узлов, обновляет данные для
  обработки нажатий на границы, затем накладывает плавающие панели.
- **Мышь:** `handleMouse` (публично доступен как `HandleMouse`) сначала
  обрабатывает плавающие панели (порядок наложения, поднятие на передний
  план, закрытие при щелчке снаружи), затем перетаскивание границ
  (разделения или гибкой компоновки), символы сворачивания и, наконец,
  пересылает события панели под курсором в относительных координатах.
  Во время перетаскивания изменения размера рассылаются в реальном
  времени, чтобы панели обновлялись прямо в процессе.
- **Клавиатура:** `handleKeys` пересылает события только панели в фокусе;
  warp не перехватывает Tab/Shift+Tab автоматически — для перехода между
  панелями используйте методы `FocusNext`/`FocusPrev`. Обход фокуса сначала
  проходит корневую компоновку, затем плавающие панели, доступные для
  фокусировки, в порядке наложения; панель, присутствующая и в корне, и
  среди плавающих, учитывается только один раз.
- **Очистка фокуса:** `CloseFloat` вызывает `Blur` и очищает цель фокуса,
  если удаляет плавающую панель, находящуюся в фокусе. После щелчка снаружи
  фокус может быть установлен на панель под указателем.
- **Жизненный цикл ресурсов:** отдельная `Tab` владеет корневым деревом
  и плавающими панелями; вкладка внутри `TabGroup`/`Warp` использует
  внешнего владельца. После отсоединения панели, на которую больше нет
  ссылок, вызывается её необязательный метод `Unmount`. Смена родителя
  и изменение видимости в интерфейсе не вызывают `Unmount`.
- **Сворачивание и разворачивание:** `Collapse` сохраняет долю разделения
  и сжимает панель до фиксированного размера; `Expand` восстанавливает
  сохранённую долю. Для элементов гибкой компоновки и панелей `Collapsible`
  нужное состояние задаётся явно, поэтому повторные вызовы
  `Collapse`/`Expand` идемпотентны. Если передать `nil` в обработчик
  `SetSplitCollapse`, внутреннее переключение состояния всё равно работает.
- **Сбор элементов:** `Elements` рекурсивно обходит разделения и гибкие
  компоновки, затем добавляет элементы оформления интерфейса и содержимое
  плавающих панелей в координатах области просмотра. Для каждой плавающей
  панели доступны области `titlebar` / `move-float` и `button` /
  `close-float`; настроенные значки сворачивания разделений представлены
  как `button` / `toggle-collapse`. Элементы оформления и содержимое
  плавающих панелей возвращаются первыми, в порядке от верхних к нижним,
  а затем следуют элементы корневой компоновки. Благодаря этому средства
  автоматизации сначала видят наложенные элементы, а не закрытый ими фон.

Использование одного экземпляра панели в нескольких независимых корнях
не поддерживается; управление этим возложено на вызывающий код. Учёт
жизненного цикла ведётся локально, а не глобально.

## Использование

```go
tab := warp.NewTab("main")
tab.SplitVertical(tab.RootPanel(), 0.6, rightPanel)
tab.SplitHorizontal(leftPanel, 0.7, bottomPanel)
tab.FlexRow(centerPanel, []warp.FlexItemSpec{{Panel: a, Grow: 1}, {Panel: b, Grow: 2}})
tab.Float(overlay, 0, 0, 40, 10)

// переход между панелями в фокусе
tab.FocusNext()
tab.FocusPrev()
tab.FocusFirst()

// геометрия разделения
tab.SetSplitFraction(leftPanel, 0.7)
frac, ok := tab.GetSplitFraction(leftPanel)

// сворачивание и разворачивание
tab.Collapse(leftPanel, 2)
tab.Expand(leftPanel)

// передача размера конечным узлам
cmd := tab.BroadcastResize()
```
