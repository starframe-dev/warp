# Выпадающее меню (`dropdown.go`)

Файл `dropdown.go` реализует переиспользуемый компонент выпадающего меню для TUI на базе фреймворка Bubble Tea. Компонент представляет собой кнопку и раскрываемый список элементов, один из которых можно выбрать.

## Публичный API

### `DropdownItem`

Представляет один элемент выпадающего списка.

```go
type DropdownItem struct {
    Label    string
    Selected bool
}
```

### `DropdownMenu`

Хранит состояние выпадающего меню и необязательную функцию обратного вызова для обработки выбора.

```go
type DropdownMenu struct {
    Label    string
    Items    []DropdownItem
    Open     bool
    Hovered  int // index of hovered item, -1 if none
    OnSelect func(idx int)
}
```

Реализация также хранит приватное состояние компоновки, которое ограничивает взаимодействие видимыми элементами после отрисовки открытого меню.

### `NewDropdownMenu`

```go
func NewDropdownMenu(label string, items []DropdownItem) *DropdownMenu
```

Создаёт закрытое меню с указанной меткой и элементами. Начальное значение `Hovered` — `-1`.

### `DropdownMenu.View(w, h int) string`

Отрисовывает свёрнутую кнопку или открытое меню в зависимости от `Open`. Отрицательные значения ширины и высоты считаются равными нулю. Открытое меню занимает не более `h` строк, включая строку кнопки; свёрнутая кнопка занимает одну строку.

### `DropdownMenu.Elements(w, h int) []Element`

Возвращает семантические элементы кнопки и, если меню открыто, видимых пунктов. Возвращает `nil`, если `w` или `h` равны нулю или меньше. В остальных случаях кнопка представлена как `combobox` с действием `toggle` и границами `(0, 0, w, 1)`. В открытом меню также представлены не более `h-1` пунктов типа `option` с действием `select`; обрезанные пункты не включаются.

### `DropdownMenu.Update(msg tea.Msg) tea.Cmd`

Обрабатывает сообщения мыши и клавиатуры. Для всех сообщений возвращает `nil`.

- Нажатие мыши в строке `y = 0` открывает закрытое меню или закрывает открытое. При обработке мыши учитывается строка (`Y`), а не горизонтальная координата.
- В открытом меню движение мыши устанавливает `Hovered` в `y-1` для видимой строки пункта и сбрасывает его в `-1` для строки кнопки или любой невидимой строки. Наведение не выбирает пункт.
- Нажатие мыши в строке видимого пункта выбирает его.
- В открытом меню клавиши `up` и `down` перемещают `Hovered` между видимыми пунктами; `enter` выбирает видимый наведённый пункт; `esc` закрывает меню.
- До первой отрисовки открытого меню число видимых пунктов неизвестно, поэтому при выборе мышью и клавиатурой в качестве запасного варианта используется весь список.

### `DropdownMenu.Close()`

Закрывает меню, устанавливая `Open` в `false`. Состояния наведения и выбора не изменяются.

## Поведение

### Отрисовка и состояние

- В закрытом состоянии кнопка отображает `Label + " ▼"`; в открытом — `Label + " ▲"` над списком пунктов.
- Метки очищаются от недопустимых символов и обрезаются с многоточием, если не помещаются в доступную ширину. Строки дополняются до указанной ширины.
- Выбранный пункт отображается выбранным стилем, который имеет приоритет над стилем наведения, если пункт одновременно выбран и наведён. Для остальных наведённых пунктов применяется стиль наведения.
- При отрисовке открытого меню фиксируется число помещающихся строк пунктов; последующее взаимодействие ограничено этими видимыми строками.

### Выбор

При выборе пункта у всех элементов сбрасывается `Selected`, у выбранного элемента устанавливается `Selected`, меню закрывается и вызывается `OnSelect(idx)`, если функция обратного вызова задана. Нажатие `esc` и вызов `Close()` не выбирают пункт.

## Интеграция с Bubble Tea

Внешняя модель должна вызывать `View(w, h)` при отрисовке собственного представления и передавать соответствующие значения `tea.Msg` в `Update`. Внешняя модель размещает возвращённую строку в итоговом кадре и при необходимости может вызвать `Close()`, чтобы закрыть меню.

## Пример

```go
menu := NewDropdownMenu("Color", []DropdownItem{
    {Label: "Red", Selected: false},
    {Label: "Green", Selected: true},
    {Label: "Blue", Selected: false},
})
menu.OnSelect = func(idx int) {
    fmt.Println("selected:", menu.Items[idx].Label)
}
```
