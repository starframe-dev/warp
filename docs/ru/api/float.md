# FloatPane

`FloatPane` отображается поверх основного layout вкладки. Панель хранит экранный прямоугольник (`X`, `Y`, `Width`, `Height`), рисует рамку с заголовком и кнопкой закрытия, поддерживает перетаскивание и изменение размера мышью. Владеющая `Tab` управляет фокусом, z-порядком, закрытием по клику снаружи и наложением float; ANSI-aware clipping удерживает стилизованный текст в пределах viewport.

## Публичный API

### `FloatPane`

Float состоит из обычной `Panel` и экранного прямоугольника. Экспортируемые поля:

- `Panel` — провайдер содержимого; `View` вызывается с внутренним размером (`Width-2`, `Height-2`), без ячеек рамки.
- `X`, `Y`, `Width`, `Height` — координаты и текущие видимые размеры.
- `Title` — текст в строке заголовка.
- `CloseRequested` — устанавливается при нажатии `×`; владеющая `Tab` удаляет этот float.
- `CloseOnOutsideClick` — просит `Tab` закрывать float при левом клике вне его прямоугольника.

Предпочтительные размеры хранятся отдельно во внутренних `preferredWidth` и `preferredHeight`.

## Поведение

### Preferred size и viewport

`Tab.Float(panel, x, y, width, height)` создаёт float и сохраняет запрошенные размеры как preferred size, увеличивая их при необходимости до минимума 10×3. `Width` и `Height` — текущий видимый размер; preferred-размеры хранятся отдельно.

При `tea.WindowSizeMsg`, `ResizeMsg` и перед рендерингом вкладка ограничивает видимый прямоугольник viewport, не меняя preferred-размеры. При увеличении viewport float восстанавливает preferred width/height и повторно ограничивает `X` и `Y`, чтобы панель помещалась. Изменение размера мышью записывает выбранный размер как новый preferred size; он восстанавливается при последующих изменениях viewport. Если viewport меньше 10×3, видимый float может быть меньше минимума, но автоматическое ограничение сохраняет preferred-размеры.

Float, созданный до получения размеров вкладки, сохраняет preferred-размеры. Первый resize или рендеринг ограничит видимый прямоугольник известным viewport.

### Рендеринг — `render(w, h)`

Создаёт срез строк фиксированной длины `Height`: строку заголовка, содержимое `Panel.View`, дополненное `padContent`, и нижнюю рамку.

- Верхняя рамка строится из `╭`, заголовка, горизонтальных линий, ` ×` и `╮`. Под кнопку закрытия резервируются четыре визуальные ячейки; слишком широкий заголовок обрезается с многоточием, чтобы кнопка оставалась доступной.
- Внутренняя область имеет размер `Width-2` на `Height-2`; строки содержимого обрамлены символами `│`.
- Нижняя рамка строится из `╰`, горизонтальных линий и `╯`.

### Обработка мыши — `handleMouse(msg, mx, my)`

Обрабатывает `tea.MouseMsg`; `tea.Cmd` возвращается, только если событие передано внутренней панели.

- Кнопка закрытия — ячейка `relY == 0` и `relX == fp.Width-2`. Устанавливается `CloseRequested`, событие не передаётся панели.
- Перетаскивание — нажатие в строке заголовка при `0 < relX < fp.Width-1` начинает drag и сохраняет исходную позицию.
- Изменение размера — `hitEdge` определяет одно из четырёх рёбер или углов (`n`, `s`, `e`, `w`, `nw`, `ne`, `sw`, `se`) и начинает resize.
- Нажатие внутри содержимого передаётся `fp.Panel.Update` с координатами, сдвинутыми на одну ячейку.

Во время drag/resize указатель может выйти за границы float. В остальных случаях обработчик игнорирует координаты вне `[X, X+Width) × [Y, Y+Height)`. Владеющая `Tab` поднимает float наверх при нажатии и передаёт фокус внутренней панели.

### Геометрия

| Константа | Значение |
|---|---|
| `floatMinWidth = 10` | Минимальная ширина, если viewport позволяет. |
| `floatMinHeight = 3` | Минимальная высота, если viewport позволяет. |
| `floatTitleH = 1` | Высота строки заголовка. |

`applyResizeWithin` соблюдает минимум, когда хватает места; в меньшем viewport видимый размер ограничивается доступными ячейками. Все восемь направлений resize используют общую логику. Результат ручного resize сохраняется как новый preferred size.

## ANSI-безопасность

Стили lipgloss и Bubble Tea нельзя корректно позиционировать по смещениям сырых байтов. Вспомогательные функции учитывают визуальную ширину, управляющие последовательности и широкие графемы.

### `StripANSI(s string) string`

Удаляет ANSI-последовательности управления, возвращая обычный текст для измерения ширины.

### `overlayFloat(lines []string, fp *FloatPane, totalW, totalH int)`

Рисует `fp.render(...)` поверх существующих строк. Для каждой строки функция находит визуальную позицию `fp.X` с учётом ANSI и grapheme clusters, обрезает float по доступной ширине, пропускает закрытые overlay ячейки исходной строки и добавляет оставшийся суффикс. Перед суффиксом добавляется ANSI reset, чтобы стили float не влияли на остальной экран.

## Стили float

Четыре lipgloss-стиля определены в `styles.go` и используют цвета темы из [`theme.go`](./theme.md):

- `floatBorderStyle` — символы рамки (`╭│─╮╰╯`).
- `floatTitleStyle` — жирный текст заголовка с цветами темы.
- `floatCloseStyle` — жирный глиф `×`.
- `floatBgStyle` — непрозрачный фон ячейки закрытия и углов.

## Пример

```go
// detailsPanel implements warp.Panel.
tab := warp.NewTab("details")
tab.Float(detailsPanel, 10, 5, 30, 10)
```

## Ограничения

- Float не реализует `Panel`: это экранный прямоугольник, содержащий панель. Клавиши обрабатываются внутренней панелью, а мышиные события — float и `Tab`.
- Кнопка закрытия занимает одну ячейку (`fp.Width-2`, `0`); ячейка угла `╮` не является целью попадания.
- Drag/resize использует исходный snapshot `(origX, origY, origW, origH)`, поэтому смещения не накапливаются от кадра к кадру.
- `render` создаёт стилизованные строки; `overlayFloat` и обработчик мыши используют их.
