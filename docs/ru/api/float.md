# warp — `float.go` (плавающая панель)

`FloatPane` отображается поверх основного макета вкладки. Она хранит экранный прямоугольник (`X`, `Y`, `Width`, `Height`), рисует рамку с заголовком и кнопкой закрытия, поддерживает перетаскивание и изменение размера мышью. Владеющая `Tab` управляет фокусом, z-порядком, закрытием по клику снаружи и отрисовкой наложения; обрезка с учётом ANSI удерживает стилизованный текст и рамки в пределах области просмотра.

## Публичный API

### `FloatPane`

```go
type FloatPane struct {
    Panel Panel
    X, Y, Width, Height int
    Title string

    preferredWidth int
    preferredHeight int

    CloseRequested bool
    CloseOnOutsideClick bool
    // Drag and resize bookkeeping is unexported.
}
```

Плавающая панель состоит из обычной `Panel` и экранного прямоугольника. Экспортируемые поля:

- `Panel` — провайдер содержимого. Он вызывается с *внутренним* размером (`Width-2`, `Height-2`), не включая одноклеточную рамку.
- `X`, `Y`, `Width`, `Height` — экранный прямоугольник.
- `Title` — текст в строке заголовка.
- `CloseRequested` — устанавливается в `true`, когда пользователь нажимает кнопку `×`; владеющая `Tab` замечает это и удаляет плавающую панель.
- `CloseOnOutsideClick` — если `true`, владелец может закрыть панель, когда пользователь нажимает за пределами её прямоугольника.

## Поведение

### Предпочтительный размер и область просмотра

`Tab.Float(panel, x, y, width, height)` создаёт плавающую панель и сохраняет запрошенные размеры как предпочтительные, увеличивая их при необходимости до минимума 10×3. `Width` и `Height` — текущие видимые размеры; предпочтительные размеры хранятся отдельно.

При `tea.WindowSizeMsg`, `ResizeMsg` и перед отрисовкой вкладка ограничивает видимый прямоугольник областью просмотра, не меняя предпочтительные размеры. Когда область просмотра увеличивается, плавающая панель восстанавливает предпочтительные ширину и высоту и корректирует `X` и `Y`, чтобы прямоугольник поместился. Изменение размера мышью записывает выбранные пользователем размеры как новые предпочтительные, поэтому они восстанавливаются при последующих изменениях области просмотра. Если область просмотра меньше 10×3, видимая панель может временно стать меньше; автоматическое ограничение сохраняет предпочтительный размер.

Плавающая панель, созданная до того, как вкладка получила размеры области просмотра, сохраняет предпочтительные размеры. Путь изменения размера/отрисовки вкладки ограничивает видимый прямоугольник известной областью просмотра; прямой вызов `FloatPane.render` этого не делает.

### Отрисовка — `render(w, h)`

Если получатель не равен `nil` и `Width`, `Height` положительны, функция создаёт срез строк длиной `Height`. В противном случае она возвращает `nil`. Аргументы `w` и `h` в настоящее время игнорируются. Первая строка — заголовок, последняя — нижняя рамка, а строки между ними содержат вывод `Panel.View`, дополненный с помощью `padContent`.

- Верхняя рамка состоит из `╭` + заголовка + тире + ` ×` + `╮`. Для кнопки закрытия всегда резервируются 4 визуальные ячейки (`╭` + `" ×"` + `╮`). Заголовок очищается от недопустимых символов и обрезается с многоточием (`...`), чтобы кнопка оставалась на месте.
- Если `Panel` не равна `nil`, область содержимого имеет вид `padContent(fp.Panel.View(fp.Width-2, fp.Height-2), fp.Width-2, fp.Height-2)`. Каждая строка содержимого обрамляется вертикальными символами рамки (`│ ... │`).
- Нижняя рамка имеет вид `╰ ─ ... ─ ╯`.

### Обработка мыши — `handleMouse(msg, mx, my)`

Обрабатывает одно сообщение `tea.MouseMsg` с левой кнопкой мыши в экранных координатах (`mx`, `my`) и возвращает `tea.Cmd` только в том случае, если событие передано внутренней `Panel`. Нажатия других кнопок мыши игнорируются.

Правила определения области нажатия:

- Кнопка закрытия — ровно ячейка, где `relY == 0` и `relX == fp.Width-2`. Устанавливается `CloseRequested`; событие не передаётся панели.
- Перетаскивание за заголовок — при `relY == 0` и `0 < relX < fp.Width-1` начинается перетаскивание и сохраняется исходная позиция.
- Края изменения размера — `hitEdge` сопоставляет ячейки рамки, не обработанные как перетаскивание за заголовок или нажатие кнопки закрытия, значениям `"n"`, `"s"`, `"e"`, `"w"` и четырём углам `"nw"`, `"ne"`, `"sw"`, `"se"`. Непустое значение начинает изменение размера.
- Нажатие внутри панели — передаётся в `fp.Panel.Update` с координатами, сдвинутыми на одну ячейку, чтобы панель получила координаты области содержимого, начинающиеся с нуля.

Во время активного перетаскивания или изменения размера проверка границ намеренно пропускается, поэтому указатель может покинуть прямоугольник панели. В остальных случаях обработчик прекращает работу, если указатель находится вне `[X, X+Width) × [Y, Y+Height)`.

### Геометрические инварианты

| Константа             | Значение                    |
|----------------------|-----------------------------|
| `floatMinWidth = 10` | Минимальная рабочая ширина. |
| `floatMinHeight = 3` | Минимальная рабочая высота. |
| `floatTitleH = 1`    | Число строк заголовка.      |

`applyResizeWithin` соблюдает минимальные размеры, если область просмотра это позволяет; в меньшей области видимый размер ограничивается доступными ячейками. Для всех восьми направлений используется общий расчёт изменения размера. Ручное изменение размера сохраняет получившиеся размеры как новые предпочтительные.

## Безопасность ANSI

Warp отображает стилизованный текст с помощью lipgloss и Bubble Tea, поэтому смещения в байтах не соответствуют визуальным столбцам. Две вспомогательные функции обеспечивают безопасное наложение плавающей панели:

### `StripANSI(s string) string`

Удаляет последовательности управляющих кодов ANSI из строки. Результат — обычный текст, ширину которого можно безопасно измерить с помощью `lipgloss.Width` или `ansi.StringWidth`.

### `overlayFloat(lines []string, fp *FloatPane, totalW, totalH int)`

Рисует `fp.render(totalW, totalH)` поверх существующих строк, не затрагивая остальную часть экрана. Если плавающая панель, её содержимое или размеры области просмотра некорректны, функция ничего не рисует. Для каждой видимой строки она:

1. Находит визуальный столбец `fp.X`, измеряя ширину с учётом ANSI и графем; широкие графемы не разделяются.
2. Обрезает стилизованную строку плавающей панели по ширине видимой области и добавляет сброс ANSI перед незакрытым суффиксом, чтобы стили не распространялись дальше.
3. Пропускает исходные байты, визуально закрытые плавающей панелью.
4. Добавляет оставшийся исходный суффикс без изменений.

## Токены стилей плавающей панели

Плавающая панель использует четыре стиля `lipgloss`, определённые в `styles.go`. Они используют цвета темы пакета и могут быть изменены через [theme.go](./theme.md).

- `floatBorderStyle` — символы рамки (`╭│─╮╰╯`).
- `floatTitleStyle` — текст заголовка; жирный, с цветами фона и текста из темы.
- `floatCloseStyle` — глиф `×`; жирный цвет текста.
- `floatBgStyle` — непрозрачный фон ячейки закрытия и угловых ячеек.

## Пример

```go
// detailsPanel implements warp.Panel.
tab := warp.NewTab("details")
tab.Float(detailsPanel, 10, 5, 30, 10)
```

## Примечания и ограничения

- Плавающая панель не является `Panel`. Это экранный прямоугольник, содержащий панель; сама плавающая панель не обрабатывает клавиши, кроме событий, потребляемых `handleMouse`.
- Кнопка закрытия занимает ровно одну ячейку (`fp.Width-2`, `0`). Всё справа от неё относится к углу `╮` и не является целью нажатия.
- Для перетаскивания и изменения размера используется исходный снимок `(origX, origY, origW, origH)`, поэтому длительное перетаскивание не накапливает ошибку округления. Автоматическое ограничение областью просмотра меняет только видимые размеры; ручное изменение размера обновляет предпочтительные размеры.
- `render` — единственная функция, создающая стилизованные байты; `overlayFloat` и обработчик мыши только используют их.
