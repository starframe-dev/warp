# Справочник API

Warp — движок компоновки TUI на Go для Bubbletea. Создайте экран из корневого [`Panel`](./panel), затем объединяйте вкладки, сплиты, flex-компоновки, плавающие панели и интерактивные компоненты.

## Основной API

| Тип | Назначение |
|-----|-----------|
| [`Warp`](./warp) | Модель Bubbletea, корневая панель и необязательный HTTP-метод дерева элементов |
| [`Panel`](./panel) | Интерфейс каждой панели в дереве |
| [`TabGroup`](./tabgroup) | Панель вкладок и управление активной вкладкой |
| [`Tab`](./tab) | Дерево компоновки, floats, фокус, изменение размеров и сворачивание |
| [`Node`](./split) | Узел дерева компоновки |
| [`SplitConfig`](./split) / [`FlexConfig`](./split) | Конфигурация split и flex |
| [`FloatPane`](./float) | Состояние плавающей панели |
| [`Element`](./element) / [`Bounds`](./element) | Семантическое дерево UI и координаты в ячейках |
| [`ThemeColors`](./theme) | Палитра runtime-темы |

## Компоненты

| Компонент | Назначение |
|-----------|-----------|
| [`Collapsible`](./collapsible) | Сворачиваемая секция панели |
| [`Scrollable`](./scrollable) | Область просмотра со скроллом мышью и клавиатурой |
| [`DropdownMenu`](./dropdown) | Кнопка с раскрывающимся списком |
| [`Selectable`](./selectable) | Выделение текста мышью и клавиатурой |
| [`Input`](./input) | Однострочный редактируемый ввод |
| [`Modal`](./modal) | Перетаскиваемый диалоговый overlay |
| [`Popover`](./popover) | Overlay контекстного меню |

## Компоновка и утилиты

- [`Split`](./split) — направления, сообщения resize, состояние collapse и типы flex
- [`Focus`](./focus) — интерфейсы явного фокуса
- [`Styles`](./styles) — публичные стили границ и палитра по умолчанию
- [`WordWrap`](./wrap) и `SpaceWrap` — перенос текста по ширине терминала
- [`StripANSI`](./float) — удаление CSI-последовательностей из строки
- [`FindElement`](./element) — рекурсивный поиск семантического элемента
- `WrapToString` — перенос текста с объединением строк

## Контракты

- Размеры панелей измеряются в ячейках терминала, а не в пикселях или байтах.
- `ResizeMsg` передаёт листовым панелям выделенный размер содержимого.
- Фокус переключается явно: приложение само выбирает клавиши и вызывает `FocusNext`, `FocusPrev` или `FocusPanel`.
- Warp не резервирует `Tab` и `Shift+Tab` для перехода фокуса.
- По умолчанию используется Gruvbox Dark; [`SetTheme`](./theme) меняет семантическую палитру во время работы.
