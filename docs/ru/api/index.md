# Справочник API

Warp — движок компоновки TUI на Go для Bubbletea. Создайте экран из корневого [`Panel`](./panel), затем объединяйте вкладки, сплиты, flex-компоновки, плавающие панели и интерактивные компоненты.

## Основной API

| Тип | Назначение |
|-----|-----------|
| [`Warp`](./warp) | Модель Bubbletea, корневая панель и необязательная HTTP-точка доступа к дереву элементов |
| [`Panel`](./panel) | Интерфейс, реализуемый каждой панелью компоновки |
| [`TabGroup`](./tabgroup) | Панель вкладок и управление активной вкладкой |
| [`Tab`](./tab) | Дерево компоновки, плавающие панели, фокус, изменение размеров и сворачивание |
| [`Node`](./split) | Узел дерева компоновки |
| [`SplitConfig`](./split) / [`FlexConfig`](./split) | Конфигурация разбиения и flex-компоновки |
| [`FloatPane`](./float) | Состояние плавающей панели |
| [`Element`](./element) / [`Bounds`](./element) | Семантическое дерево UI и координаты в ячейках |
| [`ThemeColors`](./theme) | Палитра темы во время выполнения |

## Компоненты

| Компонент | Назначение |
|-----------|-----------|
| [`Collapsible`](./collapsible) | Сворачиваемая секция панели |
| [`Scrollable`](./scrollable) | Область просмотра с прокруткой мышью и клавиатурой |
| [`DropdownMenu`](./dropdown) | Кнопка с раскрывающимся списком |
| [`Selectable`](./selectable) | Выделение текста мышью и клавиатурой |
| [`Input`](./input) | Однострочное поле ввода с возможностью редактирования |
| [`Modal`](./modal) | Перетаскиваемое диалоговое окно поверх содержимого |
| [`Popover`](./popover) | Контекстное меню поверх содержимого |

## Компоновка и утилиты

- [`Split`](./split) — направления, сообщения изменения размера, состояние сворачивания и типы flex-компоновки
- [`Focus`](./focus) — интерфейсы явного управления фокусом
- [`Styles`](./styles) — публичные стили границ и палитра по умолчанию
- [`WordWrap`](./wrap) и `SpaceWrap` — перенос текста с учётом ширины терминала
- [`StripANSI`](./float) — удаление CSI-последовательностей из строки
- [`FindElement`](./element) — рекурсивный поиск семантического элемента
- `WrapToString` — перенос текста и объединение полученных строк

## Контракты

- Размеры панелей измеряются в ячейках терминала, а не в пикселях или байтах.
- `ResizeMsg` передаёт листовым панелям выделенный размер содержимого.
- Переход между элементами с фокусом задаётся явно: приложение само выбирает клавиши и вызывает `FocusNext`, `FocusPrev` или `FocusPanel`.
- Warp не резервирует `Tab` и `Shift+Tab` для перехода фокуса.
- По умолчанию используется палитра Gruvbox Dark; [`SetTheme`](./theme) меняет семантическую палитру во время выполнения.
