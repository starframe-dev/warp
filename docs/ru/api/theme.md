# theme.go

## Обзор

`theme.go` предоставляет `ThemeColors` и `SetTheme` для изменения цветов, используемых стилями интерфейса Warp на уровне пакета. `SetTheme` присваивает переданные значения внутренним переменным палитры и перестраивает стили вкладок, рамок, плавающих панелей, раскрывающихся блоков, выпадающих списков, поповеров, модальных окон, приглушённого текста и полей ввода.

Палитра по умолчанию задаётся в `styles.go`. Вызов `SetTheme` заменяет соответствующие цвета и стили на уровне пакета; тема не сохраняется.

## Публичное API

### ThemeColors

`ThemeColors` — это структура из 15 строковых полей, принимаемых функцией `SetTheme`:

| Поле | Используется для |
|---|---|
| `Background` | Фон панели вкладок, плавающей панели, элемента выпадающего списка и приглушённого текста |
| `Surface` | Фон заголовка плавающей панели, рамки панели, тела раскрывающегося блока, поповера и модального окна |
| `Raised` | Фон кнопки выпадающего списка, элемента при наведении и выбранного элемента |
| `Border` | Рамки модального окна и раскрывающегося блока, а также рамка поля ввода |
| `BorderMuted` | Рамка разделителя при наведении |
| `Text` | В настоящее время не используется функцией `SetTheme` |
| `TextMuted` | Подписи неактивных вкладок, рамка плавающей панели и приглушённый текст |
| `TextStrong` | Цвет текста заголовка плавающей панели, раскрывающегося блока, выпадающего списка, поповера, модального окна и поля ввода |
| `Accent` | Рамка поля ввода в фокусе |
| `AccentMuted` | В настоящее время не используется функцией `SetTheme` |
| `Error` | Цвет текста закрытия вкладки и закрытия плавающей панели |
| `Success` | Цвет текста новой вкладки и выбранного элемента выпадающего списка |
| `Warning` | Рамка перетаскиваемого разделителя и цвет текста выпадающего списка при наведении |
| `SelectionBackground` | Фон активной вкладки и выбранного элемента поповера |
| `SelectionForeground` | Цвет текста активной вкладки и выбранного элемента поповера |

Значения передаются в `lipgloss.Color` без изменений; `SetTheme` не проверяет и не нормализует их. Хотя поля имеют тип обычной строки и могут содержать цвета, поддерживаемые Lipgloss, реализация не требует определённого формата.

### SetTheme

```go
func SetTheme(colors ThemeColors)
```

`SetTheme` не возвращает значение. Функция обновляет внутреннюю палитру и семантические цветовые переменные, а затем заново создаёт производные от них стили Lipgloss на уровне пакета. Повторный вызов заменяет те же значения, поэтому тему пакета определяет последний вызов.

Поля `Text` и `AccentMuted` в настоящее время этой функцией не считываются и поэтому не влияют на отображаемые стили.

## Использование

```go
warp.SetTheme(warp.ThemeColors{
    Background:          "#1e1e1e",
    Surface:             "#252525",
    Raised:              "#333333",
    Border:              "#555555",
    BorderMuted:         "#666666",
    Text:                "#cccccc",
    TextMuted:           "#999999",
    TextStrong:          "#eeeeee",
    Accent:              "#4f8aff",
    AccentMuted:         "#7aa0d4",
    Error:               "#e55",
    Success:             "#4c4",
    Warning:             "#ee8811",
    SelectionBackground: "#336699",
    SelectionForeground: "#ffffff",
})
```

## Примечания

- Палитра по умолчанию — Gruvbox Dark, объявленная в `styles.go`.
- `SetTheme` не выполняет проверку значений, не возвращает ошибку и не сохраняет настройки в файлы конфигурации или иным способом.
- Функция переназначает состояние на уровне пакета. Приложениям следует избегать одновременного вызова `SetTheme` и доступа других горутин к затрагиваемым стилям, если только они не обеспечивают собственную синхронизацию.
