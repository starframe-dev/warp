# wrap.go

Утилиты переноса текста для пакета `warp`. Ширина измеряется в ячейках терминала с помощью `github.com/charmbracelet/x/ansi`; ANSI escape-последовательности не учитываются как видимые колонки, а пакет корректно обрабатывает графемные кластеры Unicode.

## Публичный API

### `WordWrap`

```go
func WordWrap(text string, width int) []string
```

Переносит текст с помощью `ansi.Wrap`, используя пробелы как возможные места разрыва слов. Длинные слова при необходимости разрываются принудительно. Каждая входная строка переносится независимо: вход разделяется по `\n`, а выходные строки помещаются в отдельные элементы среза. Если ширина перенесённой строки всё ещё превышает `width`, она усекается до `width` ячеек терминала.

- Если `width <= 0`, результат — `nil`.
- Обработка пробелов и ANSI-последовательностей определяется нижележащим пакетом `ansi`; пробелы не нормализуются с помощью `strings.Fields`.

```go
lines := warp.WordWrap("the quick brown fox", 10)
// lines contains "the quick" and "brown fox"
```

### `SpaceWrap`

```go
func SpaceWrap(text string, width int) []string
```

Переносит текст с помощью `ansi.Wordwrap`, используя пробелы как возможные места разрыва слов. Слова, длина которых превышает `width`, не разрываются принудительно, поэтому такие слова могут образовать строки шире заданной ширины. Каждая входная строка переносится независимо после разделения входа по `\n`.

- Если `width <= 0`, результат — `nil`.
- Обработка пробелов определяется нижележащим пакетом `ansi`; пробелы не разбиваются на токены с помощью `strings.Fields`.

```go
lines := warp.SpaceWrap("hello   world foo", 12)
// The words are wrapped at available breakpoints; whitespace handling follows ansi.Wordwrap.
```

### `WrapToString`

```go
func WrapToString(text string, width int, useSpaceWrap bool) string
```

Вызывает `SpaceWrap`, если `useSpaceWrap` равно `true`, и `WordWrap` в противном случае, а затем объединяет полученные строки с помощью `\n`. Если `width <= 0`, перенесённый срез равен `nil`, а результатом будет пустая строка.

```go
s := warp.WrapToString("the quick brown fox", 10, false)
// s == "the quick\nbrown fox"
```

## Примечания по реализации

- `WordWrap` использует `ansi.Wrap(line, width, " ")`. Если визуальная ширина любой возвращённой строки, рассчитанная с учётом ANSI-последовательностей, превышает `width`, строка передаётся в `ansi.Truncate` с пустым суффиксом.
- `SpaceWrap` использует `ansi.Wordwrap(line, width, " ")` и не выполняет дополнительное усечение после переноса.
- `isWordBreak` — непубличная вспомогательная функция, не используемая этими функциями переноса.
- Обе функции возвращают `nil` при неположительной ширине. В противном случае каждая обрабатывает результаты `strings.Split(text, "\n")` и добавляет строки, возвращённые соответствующей функцией переноса.

## Зависимость

Логика переноса и измерения ширины терминала обеспечивается `github.com/charmbracelet/x/ansi`.
