# Popover

`Popover` — это наложение контекстного меню в пакете `warp`. Оно отображается поверх существующих строк содержимого, не добавляя строк, и поддерживает взаимодействие мышью и клавиатурой.

## Публичный API

```go
type PopoverItem struct {
    Name   string
    Action func()
}

type Popover struct {
    Items   []PopoverItem
    X, Y    int
    Width   int
    OnClose func()
}

func (p *Popover) Overlay(lines []string, totalW, totalH int) []string
func (p *Popover) HandleMouse(msg tea.MouseMsg) bool
func (p *Popover) HandleKey(msg tea.KeyMsg) bool
```

`Popover` также содержит неэкспортируемые поля для отслеживания размеров отрисованного меню, ограниченной позиции и выбранного пункта. `tea.MouseMsg` и `tea.KeyMsg` относятся к Bubble Tea.

## Поля

- `Items` — пункты меню. Имя каждого пункта (`Name`) очищается перед отрисовкой; поле `Action` необязательно.
- `X`, `Y` — запрошенная позиция на экране. Строка 0 соответствует строке заголовка.
- `Width` — желаемая ширина содержимого. Значение меньше или равное нулю означает ширину 20; ширина ограничивается значением `totalW`.
- `OnClose` — необязательный обратный вызов, выполняемый при поддерживаемом действии закрытия.

## Поведение

### `Overlay`

```go
func (p *Popover) Overlay(lines []string, totalW, totalH int) []string
```

Если `Items` пуст, возвращает `lines` без изменений. В противном случае отрисовывает по одной стилизованной строке содержимого на пункт, обрамляет их рамкой с обычной границей и накладывает рамку на входные строки, сохраняя видимое содержимое слева и справа от неё.

Горизонтальная позиция рамки ограничивается значением `totalW`, а вертикальная — длиной `lines`. Полученные размеры и позиция рамки сохраняются для последующей обработки событий. Параметр `totalH` принимается, но реализацией не используется. Наложение не добавляет строк; строки рамки за пределами входного среза пропускаются.

### `HandleMouse`

```go
func (p *Popover) HandleMouse(msg tea.MouseMsg) bool
```

Возвращает `false`, пока не будет отрисовано непустое меню (ширина сохранённой рамки равна нулю); в противном случае:

- Нажатие на строке пункта вызывает его `Action`, если она не равна `nil`, а затем вызывает `OnClose`, если задан.
- Нажатие в другом месте, включая границу рамки, вызывает `OnClose`, если задан. Нажатия внутри рамки поглощаются, даже если они не приходятся на строку пункта.
- Перемещение указателя обновляет выбор, когда указатель находится над строкой пункта. Событие перемещения поглощается и за пределами строк пунктов.
- Событие отпускания поглощается.

Проверка попадания использует ограниченную позицию, сохранённую при последнем вызове `Overlay`. Если сохранённая координата отрицательна, вместо неё используется соответствующее запрошенное значение `X` или `Y`.

### `HandleKey`

```go
func (p *Popover) HandleKey(msg tea.KeyMsg) bool
```

Возвращает `false`, пока не будет отрисовано непустое меню. В противном случае:

- `Esc` вызывает `OnClose`, если задан.
- `Enter` вызывает `Action` выбранного пункта, если она не равна `nil`, а затем вызывает `OnClose`, если задан.
- `Up` и `Down` меняют выбранный пункт, ограничивая индекс доступными пунктами.
- Для остальных клавиш возвращается `false`.

Обработанные клавиши возвращают `true`. Изначально выбран пункт с индексом 0.

## Стилизация

Для пунктов используются базовый и выбранный стили Lip Gloss. Рамка меню имеет обычную границу; её цвета берутся из общих констант пакета `gbDark4` и `gbDark1`.
