# render.go — движок рендеринга Warp

Этот файл реализует внутренние вспомогательные функции рендеринга пакета `warp`. Он преобразует скомпонованное дерево `Node` в строки терминала и определяет точки входа для hit-тестирования границ. Геометрия компоновки создаётся функцией `newLayout`; этот файл отображает полученную геометрию, а не выделяет прямоугольники дочерних элементов.

## Экспортируемый тип

```go
type BorderHit struct {
    Split     *SplitConfig
    Flex      *FlexConfig
    Direction Direction
    X, Y      int
    Length    int
    Bounds    Bounds
    FlexIndex int
}
```

`BorderHit` описывает перетаскиваемую границу и прямоугольник компоновки, которому она принадлежит. `Split` или `Flex` указывает связанную конфигурацию; `Direction`, `X`, `Y` и `Length` описывают границу, а `Bounds` и `FlexIndex` содержат границы-владельца и индекс flex-элемента. Определение типа само по себе не гарантирует, что ровно одно из полей `Split` и `Flex` не равно nil.

## Рендеринг

### `renderNode`

```go
func renderNode(node *Node, w, h int) []string
```

Создаёт с помощью `newLayout` прямоугольник компоновки с неотрицательными шириной и высотой, а затем отображает его. Если компоновка nil или её высота неположительна, результат не содержит строк. Пустая компоновка создаёт пустые строки; лист с панелью вызывает `Panel.View(w, h)` и дополняет результат. Лист с неположительной шириной или nil-панелью отображается пустыми строками. Компоновки типа split и flex обрабатываются согласно конфигурации узла компоновки.

Результат составляется из дочерних элементов и границ, выделенных компоновкой. Не следует рассчитывать, что каждый результат будет иметь в точности запрошенные ширину и высоту: в нескольких ветках рендеринга строки дочерних элементов возвращаются или объединяются напрямую.

### Компоновки split и flex

Компоновки split отображают первые два дочерних элемента. Для вертикального split строки объединяются по одной; вертикальная граница добавляется, только если она видима. Если это настроено и строка сворачивания неотрицательна, в этой строке границу может заменить индикатор сворачивания. Для горизонтального split срезы строк дочерних элементов объединяются с горизонтальной границей, если она видима.

Компоновки flex отображают все дочерние элементы. При горизонтальном направлении строки дочерних элементов объединяются построчно, а на видимых границах flex-элементов добавляются вертикальные границы. При вертикальном направлении срезы строк дочерних элементов добавляются друг за другом с горизонтальными границами на видимых стыках. Стиль границ отражает состояние перетаскивания в конфигурации. Пустые строки и строки границ кэшируются в контексте каждого рендеринга.

`renderVerticalSplit`, `renderHorizontalSplit` и `renderFlex` — вспомогательные функции-обёртки: они создают `Node` и вызывают `renderNode`. `renderFlexRow` и `renderFlexColumn` сейчас делегируют вызов `renderFlex`; их последний аргумент типа `[]int` не используется.

### `computeSplitSizes`

```go
func computeSplitSizes(avail int, fraction float64, firstCollapsed, secondCollapsed bool, firstSize, secondSize int) (first, second int)
```

Ограничивает доступный размер нулём снизу. Запрошенный размер свёрнутого дочернего элемента ограничивается диапазоном от одного до доступного пространства; если второй элемент развёрнут и места достаточно, для него сохраняется как минимум `MinPanelSize`. Если ни один элемент не свёрнут, значения NaN для долей заменяются на `0.5`, а сами доли ограничиваются диапазоном `[0, 1]`. Размер первого элемента равен целой части произведения доступного пространства на долю; он ограничивается так, чтобы при наличии места оба элемента имели размер не меньше `MinPanelSize`, иначе — доступным диапазоном. Размер второго элемента составляет остаток.

### `computeFlexSizes`

```go
func computeFlexSizes(avail int, items []*FlexItem) []int
```

Возвращает nil, если элементов нет; в противном случае ограничивает доступное пространство нулём снизу. Базовый размер каждого свёрнутого элемента равен единице; для остальных используется `Basis`, а если он неположительный — `MinPanelSize`. Если сумма базовых размеров превышает доступное пространство, оно распределяется пропорционально базовым размерам: для всех элементов, кроме последнего, используются округлённые вниз значения, а последний получает остаток. Если базовые размеры помещаются, сохраняются их целые значения, а оставшееся пространство распределяется между несвёрнутыми элементами пропорционально положительным значениям `Grow`. Если ни у одного подходящего элемента нет положительного значения роста, остаток поровну распределяется между несвёрнутыми элементами. Доли округляются вниз, кроме последнего подходящего элемента, который получает остаток. При нулевом доступном пространстве или если все элементы свёрнуты рост не распределяется.

## Содержимое панелей и текст терминала

### `padContent`

```go
func padContent(content string, w, h int) []string
```

При положительных ширине и высоте разбивает вывод панели по символам новой строки, оставляет не более `h` строк, обрезает каждую непустую строку до визуальной ширины `w`, дополняет её до этой ширины и добавляет `ansi.ResetStyle`. Отсутствующие или пустые строки заполняются пробелами с последующим сбросом стиля. При неположительной ширине или высоте функция делегирует работу `makeEmptyLines`, которая в этих случаях возвращает nil.

Фрагменты терминального текста приводятся к корректной UTF-8. Символы новой строки, возврата каретки и табуляции заменяются пробелами; остальные управляющие символы удаляются, а ESC и BEL сохраняются для разбора ANSI. Незавершённые конечные ANSI-последовательности удаляются перед объединением фрагментов с содержимым фреймворка. Метки фреймворка с некорректным UTF-8 или управляющими символами после нормализации очищаются от ANSI-стилей.

## Hit-тестирование границ

```go
func findBorders(node *Node, x, y, w, h int) []BorderHit
func findFlexBorders(flex *FlexConfig, x, y, w, h int) []BorderHit
```

Обе точки входа создают компоновку с заданным началом координат и неотрицательными шириной и высотой, а затем возвращают собранные для неё попадания в границы.

## Прочие вспомогательные функции

`renderBlankLines` создаёт `h` строк из пробелов шириной `w`, если высота положительна; `makeEmptyLines` возвращает nil, если хотя бы один размер неположителен. `emptyView` возвращает пустую строку при неположительной высоте, иначе — строку из `height - 1` символов новой строки. Функции рендеринга границ добавляют ANSI-сбросы вокруг стилизованных вертикальных или горизонтальных символов; горизонтальные границы пусты при неположительной ширине.
