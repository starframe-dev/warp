# Scrollable

`Scrollable` — компонент Bubble Tea UI, который оборачивает любой
`Panel` и добавляет поддержку прокрутки. Когда рендеруемый контент
превышает выделенную высоту, видимая часть ограничивается `h` строками,
а пользователь может прокручивать остальное содержимое колесом мыши или
клавиатурой.

## Публичный API

``` go
type Scrollable struct {
    Content Panel
    Offset  int
}
```

| Поле | Тип | Описание |
|----|----|----|
| `Content` | `Panel` | Вложенная панель, содержимое которой рендерится и прокручивается. |
| `Offset` | `int` | Запрошенное смещение прокрутки в строках. Отрицательные значения считаются равными 0; при известной высоте контента effective offset ограничивается последним полным viewport. |

### NewScrollable

``` go
func NewScrollable(content Panel) *Scrollable
```

Создаёт новый `Scrollable`, оборачивающий заданный `Panel`. Начальное
значение `Offset` равно нулю.

### ContentHeight

```go
func (s *Scrollable) ContentHeight(width int) (height int, known bool)
```

Возвращает `(0, false)`. Вложенный `Scrollable` не выдаёт содержимое
своей панели как intrinsic-высоту: назначенный viewport не определяет
надёжную высоту для внешней прокрутки.

### View

``` go
func (s *Scrollable) View(w, h int) string
```

Рендерит viewport с тем же effective offset, что и `Elements`. Если
intrinsic-высота известна и панель реализует `ViewportRenderer`,
`Scrollable` вызывает `ViewAt(w, h, effectiveOffset)`, чтобы не рендерить
префикс содержимого. Иначе при известной высоте запрашивает строки до
`effectiveOffset + h`; при неизвестной — делает probe на одну строку
дальше видимого конца и использует его результат. Сложение насыщается при
переполнении. Недостающие строки дополняются пробелами. При nil содержимом
возвращается ровно `h` пустых строк (`""` при `h == 0`, иначе `h-1`
символов перевода строки).

### Elements

``` go
func (s *Scrollable) Elements(w, h int) []Element
```

Использует тот же effective offset, что и `View`. Если intrinsic-высота
известна и панель реализует `ViewportElementProvider`, запрашивает только
этот viewport; иначе запрашивает элементы до `effectiveOffset + h`.
Элементы обрезаются по видимому viewport, затем effective offset
вычитается из координаты Y. Viewport provider возвращает bounds в
координатах полного содержимого. Полностью скрытые элементы исключаются,
частично видимые границы обрезаются. Инспекция не изменяет `s.Offset`.

### Необязательный быстрый путь viewport

Панель контента может дополнительно реализовать `ViewportRenderer` и/или
`ViewportElementProvider` вместе с `ContentHeightProvider`. `Scrollable`
использует эти интерфейсы только при известном extent. `ViewAt` возвращает
только запрошенные строки; `ElementsAt` — только пересекающие viewport
элементы с bounds в координатах полного содержимого. Для остальных панелей
сохраняется прежний fallback.

### Update

``` go
func (s *Scrollable) Update(msg tea.Msg) tea.Cmd
```

Обрабатывает входящие сообщения Bubble Tea. Изменяет `s.Offset` при
прокрутке колесом мыши и клавиатурой, запоминает размеры viewport из
`ResizeMsg` (или предварительно из `WindowSizeMsg`) и нормализует
сохранённое смещение после прокрутки или изменения viewport, если размеры
известны. Каждое сообщение, включая
сообщения прокрутки, передаётся в `s.Content`, если он не nil.

## Поведение прокрутки

Метод `Update` обрабатывает два типа сообщений:

- `tea.MouseMsg`:
  - `MouseButtonWheelUp` — уменьшает смещение на 3 (с ограничением до 0)
  - `MouseButtonWheelDown` — увеличивает смещение на 3
- `tea.KeyMsg`:
  - `"up"` — уменьшает смещение на 1 (с ограничением до 0)
  - `"down"` — увеличивает смещение на 1
  - `"pgup"` — уменьшает смещение на 10 (с ограничением до 0)
  - `"pgdown"` — увеличивает смещение на 10

При известной intrinsic-высоте effective offset равен
`min(max(0, Offset), max(0, contentHeight - viewportHeight))`. `View` и
`Elements` используют одно значение; `Elements` не меняет сохранённый
`Offset`.

## Детали реализации

- **Определение extent:** в первую очередь используется известный
  `ContentHeightProvider`. Иначе Scrollable проверяет `View` на одну
  строку дальше конца viewport. Если возвращено меньше строк, конец
  определён; если ровно запрошенное число — высота остаётся неизвестной.
  Поэтому панель, дополняющая каждый ответ до запроса, при fallback имеет
  неограниченную прокрутку. Для точной ограниченной прокрутки нужен
  provider intrinsic-высоты.
- **Дополнение/обрезка строк:** каждая видимая строка проходит через
  `padLine` / `padVisualLine`, которые учитывают ANSI и ширину
  терминальных ячеек, не разрезая графемы. Строки короче `w`
  дополняются пробелами справа.
- **Пересылка сообщений:** каждое сообщение передаётся в
  `s.Content.Update(msg)`, включая обработанные Scrollable сообщения
  прокрутки. Если `s.Content` равен nil, команда не возвращается.
