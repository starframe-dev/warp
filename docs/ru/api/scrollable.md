# Scrollable

`Scrollable` — компонент Bubble Tea UI, который оборачивает любой
`Panel` и добавляет поддержку прокрутки. Когда рендеруемый контент
превышает выделенную высоту, видимая часть ограничивается `h` строками,
а пользователь может прокручивать остальное содержимое колесом мыши или
клавиатурой.

## Публичный API

``` go
type Scrollable struct {
    Content Panel
    Offset  int
}
```

| Поле | Тип | Описание |
|----|----|----|
| `Content` | `Panel` | Вложенная панель, содержимое которой рендерится и прокручивается. |
| `Offset` | `int` | Текущее смещение прокрутки в строках. Отрицательные значения ограничиваются 0, значения выше максимального ограничиваются `len(lines) - h`. |

### NewScrollable

``` go
func NewScrollable(content Panel) *Scrollable
```

Создаёт новый `Scrollable`, оборачивающий заданный `Panel`. Начальное
значение `Offset` равно нулю.

### View

``` go
func (s *Scrollable) View(w, h int) string
```

Рендерит видимую область просмотра (viewport), запрашивая у вложенной
панели только `Offset + h` строк, а затем отображая `h` строк начиная с
`s.Offset`. Высота запроса насыщается при переполнении целого числа.
Строки за пределами содержимого дополняются пробелами. При nil
содержимом возвращается ровно `h` пустых строк (`""` при `h == 0`, иначе
`h-1` символов перевода строки).

### Update

``` go
func (s *Scrollable) Update(msg tea.Msg) tea.Cmd
```

Обрабатывает входящие сообщения Bubble Tea. Настройка `s.Offset` по
сообщениям прокрутки колесом мыши и клавиатуры, после чего сообщение
переправляется в `s.Content`, если он не nil.

## Поведение прокрутки

Метод `Update` обрабатывает два типа сообщений:

- `tea.MouseMsg`:
  - `MouseButtonWheelUp` — уменьшает смещение на 3 (с ограничением до 0)
  - `MouseButtonWheelDown` — увеличивает смещение на 3
- `tea.KeyMsg`:
  - `"up"` — уменьшает смещение на 1 (с ограничением до 0)
  - `"down"` — увеличивает смещение на 1
  - `"pgup"` — уменьшает смещение на 10 (с ограничением до 0)
  - `"pgdown"` — увеличивает смещение на 10

После обработки сообщения прокрутки смещение ограничивается в `View`:

``` go
maxOffset := len(lines) - h
if maxOffset < 0 { maxOffset = 0 }
if s.Offset < 0 { s.Offset = 0 }
if s.Offset > maxOffset { s.Offset = maxOffset }
```

Это гарантирует, что область просмотра никогда не прокручивается за
пределы содержимого.

## Детали реализации

- **Стратегия рендеринга:** вложенный `Panel` рендерится с высотой
  `Offset + h`, а не с произвольным sentinel-значением. Результат
  разбивается по `"\n"` на строки; переполнение насыщается до
  максимального `int`.
- **Дополнение/обрезка строк:** каждая видимая строка проходит через
  `padLine` / `padVisualLine`, которые учитывают ANSI и ширину
  терминальных ячеек, не разрезая графемы. Строки короче `w`
  дополняются пробелами справа.
- **Пересылка сообщений:** любое сообщение, не влияющее на прокрутку (то
  есть не-мышечное, не-клавиатурное или клавиши, отличные от
  up/down/pgup/pgdown), пересылается в `s.Content.Update(msg)`. Если
  `s.Content` равен nil, команда не возвращается.
