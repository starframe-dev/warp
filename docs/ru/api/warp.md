# Warp

`Warp` — корневая модель TUI-приложения Bubble Tea. Она оборачивает корневую панель `Panel` (по умолчанию — `TabGroup` с одной вкладкой), передаёт ей сообщения и предоставляет API для вкладок, вложения Warp и HTTP-инспектора снимка элементов.

## Публичный API

### Создание и корневая панель

```go
w := warp.New()
w.SetRoot(panel)
root := w.Root()
```

`New` создаёт Warp с `TabGroup` в позиции `TabTop` и одной вкладкой по умолчанию. `SetRoot` заменяет корневую панель; `Root` возвращает текущую.

### Размеры окна

`Width()` и `Height()` возвращают последние известные размеры терминала. Они обновляются при `tea.WindowSizeMsg`, а во вложенном Warp — также размерами из `AsPanel().View`. `View` использует размеры для рендеринга корня, UI-поток — для построения HTTP snapshot.

### Методы вкладок

`NewTab(name string) *Tab`, `ActiveTab() *Tab`, `SetTabPosition(pos TabPosition)`, `NextTab()` и `PrevTab()` делегируют вызовы корневой `*TabGroup`. Если корень имеет другой тип, методы ничего не делают, а методы, возвращающие значение, возвращают `nil`.

### Встраивание как панели

`AsPanel() Panel` возвращает адаптер `warpPanel`, реализующий `Panel` (`View(width, height)` и `Update(msg)`). Так Warp можно вложить в другую панель или Warp.

### Жизненный цикл

`Init() tea.Cmd` возвращает `nil`. `Run() error` запускает Bubble Tea с alt-screen и клеточным движением мыши, блокируется до завершения и возвращает ошибку программы.

### Владение ресурсами панелей

Корень `Warp` владеет всей иерархией панелей, включая вложенные
`TabGroup`, `Tab`, wrappers и float-панели. Самостоятельные `TabGroup` и
`Tab` владеют отдельными иерархиями, пока не вложены во внешнего владельца.
Для панелей с `Unmounter` метод вызывается однократно после отсоединения и
удаления последней ссылки из этого домена. Скрытие, сворачивание, смена
фокуса и reparenting не вызывают `Unmount`. Указательные панели используют
идентичность экземпляра. Совместное использование одного экземпляра между
независимыми корнями `Warp` не поддерживается и остаётся ответственностью
вызывающего кода; глобального реестра владения нет.

## HTTP-инспектор

```go
ServeHTTP(addr string) error
CloseHTTP() error
HTTPAddr() string
```

`ServeHTTP` запускает HTTP-сервер и регистрирует эндпоинты:

| Путь | Описание |
|---|---|
| `/elements` | JSON-массив из последнего завершённого snapshot элементов. |
| `/healthz` | Текстовый ответ `ok`. |

Если `addr` пуст, сервер слушает `127.0.0.1` на порту `WARP_HTTP_PORT`; если переменная окружения не задана, порт выбирается автоматически. Непустой адрес используется без изменений. Повторный запуск уже работающего сервера ничего не меняет. `HTTPAddr` возвращает адрес listener либо пустую строку, если сервер не запущен. `CloseHTTP` останавливает сервер и безопасно допускает повторный вызов.

## Модель Bubble Tea

```go
Init() tea.Cmd
Update(msg tea.Msg) (tea.Model, tea.Cmd)
View() string
```

`Update` записывает размеры из `tea.WindowSizeMsg`, затем передаёт сообщение корневой панели. После обновления UI-поток собирает элементы и публикует snapshot. Если корень nil, команда не создаётся.

`View` рендерит корневую панель с текущими размерами. Если хотя бы один размер равен нулю, возвращается `Loading...`; для nil-корня возвращается пустая строка. После рендеринга обновляется snapshot элементов.

## Вложенность

Адаптер `AsPanel` принимает размеры родителя во вложенный Warp, затем отображает его корень; `Update` передаёт сообщение вложенной модели и возвращает её команду.

```go
parent := warp.New()
inner := warp.New()
parent.SetRoot(inner.AsPanel()) // inner Warp embedded in parent
```

## Согласованность HTTP snapshot

- UI-поток строит snapshot после `Update` и `View`; перед публикацией `Children` каждого элемента глубоко копируются.
- `/elements` читает только последний завершённый snapshot. HTTP-обработчик не обходит живое дерево и не вызывает `Panel.Elements`, `Panel.View` или `Panel.Update`. Ответ может отражать предыдущее завершённое состояние UI, но не частично обновлённое дерево.
- `Panel.Elements` вызывается при построении snapshot без удержания mutex Warp. Ревизия корня не позволяет опубликовать снимок старой панели после `SetRoot`.
- Если размеры неизвестны, при построении snapshot используются 80×24. Для nil-корня возвращается пустой JSON-массив, а не `null`.
- `CloseHTTP` освобождает mutex до вызова `http.Server.Shutdown`, чтобы активные обработчики могли завершиться.
