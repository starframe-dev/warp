# Input

`Input` — компонент однострочного текстового ввода, построенный на Bubble Tea. Он управляет строковым значением, позицией курсора в индексах рун, необязательным префиксом-подсказкой и редактированием с клавиатуры. Компонент отображается как строка или как рамка — в зависимости от доступных высоты и ширины.

## Типы

### Input

Компонент однострочного текстового ввода.

```go
type Input struct {
    Value  string
    Cursor int // позиция курсора в рунах
    Prompt string
    Width  int // желаемая ширина; View использует переданный ему аргумент w
}
```

Компонент также хранит закрытое состояние фокуса и данные о расположении графем. Поле `Width` экспортировано, но не влияет на отображение: `View` использует переданную ему ширину.

### Input — конструктор

```go
func NewInput(prompt string) *Input
```

Создаёт пустой компонент ввода с указанной подсказкой.

## Методы

| Метод | Описание |
|----|----|
| `SetValue(v string)` | Заменяет значение и помещает курсор в конец. |
| `SetCursor(pos int)` | Задаёт позицию курсора в индексах рун; позиция внутри графемного кластера нормализуется до его правой границы. |
| `Focused() bool` | Возвращает `true`, если компонент сейчас в фокусе. |
| `Focus()` | Передаёт компоненту фокус. |
| `Blur()` | Снимает фокус с компонента. |
| `View(w, h int) string` | Отображает рамку при `w >= 3` и `h >= 3`; в противном случае — строку. Отрицательные размеры считаются равными нулю. |
| `Update(msg tea.Msg) tea.Cmd` | Обрабатывает редактирование с учётом графем, когда компонент в фокусе. |
| `Elements(w, h int) []Element` | Предоставляет семантический элемент `textbox`, охватывающий заданную область ввода, или не возвращает элементов, если один из размеров равен нулю. |

## Поведение

### Отображение

`View` вызывает `viewBoxed`, если ширина составляет не менее трёх ячеек, а высота — не менее трёх строк. При этом рисуется рамка со скруглёнными углами и стилем границы, зависящим от наличия фокуса. Значение отображается ровно в одной внутренней строке с индексом `1 + (h-3)/2`; остальные строки между границами остаются пустыми. В противном случае вызывается `viewInline`, отображающий подсказку и значение в виде одной стилизованной строки, повторённой по всей высоте.

Видимая строка формируется функцией `renderLine`. Подсказка очищается от недопустимых символов и обрезается до доступной ширины в ячейках терминала. Ширина значения измеряется в ячейках терминала с учётом широких символов; для значений с ANSI-последовательностями используются ANSI-aware вычисления ширины. Если значение не помещается, `truncateInputAtCursor` выбирает видимую область вокруг курсора, не разделяя графемные кластеры; кластер, пересечённый границей области, заменяется пробелами. Курсор отображается инверсной ANSI-последовательностью (`\x1b[7m ... \x1b[0m`) вокруг своего графемного кластера. Если курсор находится в конце видимого значения и для него есть место, вместо этого инвертируется завершающий пробел.

### Курсор и редактирование

`Update` обрабатывает `tea.KeyMsg` только тогда, когда компонент в фокусе. Распознаются следующие клавиши:

- `backspace` / `delete` — удаляют целый графемный кластер перед курсором или под ним соответственно.
- `left` / `right` — перемещают курсор к предыдущей или следующей границе графемного кластера.
- `home` / `end` — перемещают курсор в начало или конец значения.
- `tab` / `shift+tab` — ничего не делают; родительский компонент обрабатывает их для перемещения фокуса.
- `enter` — пока ничего не делает и зарезервирован для будущего сигнала отправки.
- `tea.KeyRunes` — вставляет все руны, содержащиеся в событии; одно событие может включать несколько рун.

Для совместимости API `Cursor` остаётся индексом руны. Нормализация курсора ограничивает его диапазоном рун значения и перемещает позицию внутри графемного кластера к правой границе этого кластера. Длина значения не ограничена доступной шириной отображения.

### Семантический элемент

`Elements` возвращает один элемент `textbox` с действием `focus`. Его имя — очищенная и обрезанная подсказка; если после этого она пуста, используется `Input`. Границы элемента соответствуют переданным размерам. Отрицательные размеры считаются равными нулю; если ширина или высота равна нулю, семантический элемент не возвращается.

## Внутренние помощники (package-private)

- `viewBoxed` / `viewInline` — варианты отображения в рамке и в строке.
- `renderLine` — формирует строку подсказки и значения с подсветкой курсора.
- `graphemeLayout` — кэширует границы графем и их позиции в байтах, рунах и ячейках терминала.
- `truncateInputAtCursor` — выбирает видимую область в ячейках терминала вокруг курсора, не разделяя графемные кластеры.
- `inputByteOffsetAtRune` / `spliceInputValue` — преобразуют позиции курсора и выполняют безопасные по отношению к байтам строковые вставки и удаления.
- `previousGraphemeBoundary` / `nextGraphemeBoundary` / `normalizeGraphemeCursor` — находят и нормализуют границы кластеров, заданные индексами рун.
- `insertAtCursor` / `deleteBeforeCursor` / `deleteAtCursor` — редактируют значение, сохраняя границы графем.
- `clampCursor` / `invalidateGraphemeLayout` — поддерживают корректность позиции курсора и сбрасывают кэш расположения графем после изменений.

## Стилизация

В конце файла определены стили lipgloss уровня пакета: `inputStyle` (светлый цвет текста), `inputBorderStyle` (тёмная граница) и `inputFocusBorderStyle` (синяя граница при фокусе). Эти стили используются при отображении компонента как в рамке, так и в строке.
