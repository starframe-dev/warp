# Input

`Input` — компонент однострочного текстового ввода на Bubble Tea. Он хранит строковое значение, позицию курсора в индексах рун, необязательный префикс-подсказку и обрабатывает клавиатурное редактирование. Компонент отображается как строка либо как рамка — в зависимости от доступных размеров.

## Тип и конструктор

```go
type Input struct {
    Value   string
    Cursor  int // Cursor position in runes
    Prompt  string
    Width   int // Desired width; zero uses the View width
    focused bool
}

func NewInput(prompt string) *Input
```

`NewInput` создаёт пустой ввод с указанным промптом.

## Методы

| Метод | Описание |
|---|---|
| `SetValue(v string)` | Заменяет значение и помещает курсор в конец. |
| `SetCursor(pos int)` | Задаёт позицию в индексах рун; позиция внутри grapheme cluster сдвигается к его правой границе. |
| `Focused() bool` | Возвращает состояние фокуса. |
| `Focus()` / `Blur()` | Устанавливают или снимают фокус. |
| `View(w, h int) string` | Рендерит рамку при `w >= 3` и `h >= 3`; иначе — строку. |
| `Update(msg tea.Msg) tea.Cmd` | Обрабатывает клавиатурное редактирование, когда компонент в фокусе. |

## Поведение

### Рендеринг

`View` вызывает `viewBoxed`, если ширина и высота не меньше трёх ячеек/строк; иначе использует `viewInline`. Рамка имеет скруглённые углы, а её цвет зависит от фокуса. Inline-режим отображает стилизованную строку «промпт + значение», повторённую по доступной высоте.

`renderLine` измеряет промпт и значение в терминальных ячейках с учётом ANSI-стилей и широких символов. Если значение не помещается, `truncateInputAtCursor` выбирает видимый диапазон вокруг курсора, не разрезая grapheme cluster; кластер, пересечённый краем диапазона, заменяется пробелами. Курсор подсвечивает целый grapheme cluster инверсным ANSI-стилем (`\x1b[7m ... \x1b[0m`); в конце значения подсвечивается завершающий пробел, если для него есть место.

### Курсор и редактирование

`Update` обрабатывает `tea.KeyMsg` только при активном фокусе:

- Backspace и Delete удаляют целый grapheme cluster перед курсором или под ним.
- Стрелки влево/вправо перемещают курсор к предыдущей/следующей границе кластера.
- Home и End перемещают курсор в начало и конец значения.
- Tab и Shift+Tab ничего не меняют: родитель может использовать эти клавиши для навигации фокуса.
- Enter пока ничего не делает.
- `tea.KeyRunes` вставляет все руны события; одно событие может содержать несколько рун.

`Cursor` остаётся индексом руны для совместимости API. `clampCursor` ограничивает его диапазоном `[0, RuneCountInString(value)]` и сдвигает позицию внутри grapheme cluster к его правой границе. Ширина рендеринга не ограничивает длину `Value`.

## Внутренние помощники (package-private)

- `viewBoxed` / `viewInline` — варианты отображения рамки и строки.
- `renderLine` — строит строку промпта и значения с подсветкой курсора.
- `truncateInputAtCursor` — выбирает видимые терминальные ячейки вокруг курсора, не разделяя кластеры.
- `previousGraphemeBoundary` / `nextGraphemeBoundary` / `normalizeGraphemeCursor` — находят и нормализуют границы, заданные индексами рун.
- `insertAtCursor` / `deleteBeforeCursor` / `deleteAtCursor` — изменяют срез рун, сохраняя целостность графем.
- `clampCursor` — поддерживает допустимую позицию курсора.

## Стилизация

В конце файла определены стили lipgloss: `inputStyle` (светлый текст), `inputBorderStyle` (тёмная рамка) и `inputFocusBorderStyle` (синяя рамка при фокусе). Стили используются в обоих режимах рендеринга.
