# Стили

Warp запускается с палитрой Gruvbox Dark. Замена темы во время работы описана на странице [Тема](./theme).

## Палитра по умолчанию

| Переменная | Hex | Использование |
|------------|-----|---------------|
| `gbDark0` | `#282828` | Фон корня и float |
| `gbDark1` | `#3c3836` | Поверхность панели и модалки |
| `gbDark2` | `#504945` | Приподнятые и активные элементы |
| `gbDark3` | `#665c54` | Граница при наведении |
| `gbDark4` | `#7c6f64` | Приглушённая граница |
| `gbGray` | `#928374` | Приглушённый текст |
| `gbLight1` | `#ebdbb2` | Основной текст |
| `gbRed` | `#fb4934` | Ошибки и закрытие |
| `gbGreen` | `#b8bb26` | Успех и создание вкладки |
| `gbYellow` | `#fabd2f` | Предупреждения и drag-состояние |
| `gbBlue` | `#83a598` | Фокус и выделение |

Палитровые переменные внутренние. Для изменения используйте `SetTheme`.

## Стили границ

```go
func BorderStyle() lipgloss.Style
func BorderDragStyle() lipgloss.Style
func BorderHoverStyle() lipgloss.Style
```

Функции возвращают стили обычной, перемещаемой и подсвеченной границы split.
