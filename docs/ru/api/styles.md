# Стили

Warp использует палитру Gruvbox Dark.

Все цвета определены в `styles.go`. Публичного API для кастомизации стилей нет.

## Основные цвета

```go
gbDark0
gbDark1
gbDark4
gbLight1
gbBlue
gbGray
gbGreen
gbYellow
gbRed
```

Эти значения используются внутренними компонентами Warp для базовой темы.
