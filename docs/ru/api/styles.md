# styles.go

Файл `styles.go` задаёт цветовую палитру Gruvbox Dark и готовые значения
`lipgloss.Style`, используемые панелью вкладок, границами разделения,
плавающими панелями, сворачиваемыми элементами и выпадающими меню. В нём
также определены функции для получения обычного стиля границы разделения,
а также стилей при перетаскивании и наведении. Стили всплывающих окон
определены отдельно в `popover.go`.

Файл содержит переменные уровня пакета и определения стилей; он не
реализует отрисовку интерфейса или переключение темы во время выполнения.
Цвета заданы непосредственно значениями `lipgloss.Color`.

## Цветовая палитра

Палитра основана на [Gruvbox Dark](https://github.com/morhetz/gruvbox):

- `gbDark0`–`gbDark4` — постепенно светлеющие тёмные оттенки.
- `gbGray` — нейтральный серый, а `gbLight1` — светлый цвет текста.
- `gbRed`, `gbGreen`, `gbYellow` и `gbBlue` — акцентные цвета. `gbBlue`
  определён в этом файле, но его стили не используют.

## Публичный API

```go
func BorderStyle() lipgloss.Style
func BorderDragStyle() lipgloss.Style
func BorderHoverStyle() lipgloss.Style
```

| Функция | Назначение |
| --- | --- |
| `BorderStyle` | Возвращает стиль с обычным цветом переднего плана границы разделения. |
| `BorderDragStyle` | Возвращает стиль границы разделения во время перетаскивания. |
| `BorderHoverStyle` | Возвращает стиль границы разделения при наведении указателя мыши. |

Каждая функция возвращает соответствующее значение стиля уровня пакета.
`lipgloss.Style` возвращается по значению, а не по указателю; вызывающий код
может использовать его с Lip Gloss, не обращаясь к непубличным переменным
стилей.

## Группы стилей

### Панель вкладок

Фон панели вкладок — `gbDark0`. Для активной вкладки используется `gbDark2`
и жирный текст `gbLight1`; для неактивных вкладок — `gbDark0` и текст
`gbGray`. Стиль новой вкладки использует `gbGreen`, а стиль закрытия —
`gbRed`.

### Границы разделения

Для обычной границы используется `gbDark1`, для границы при перетаскивании —
`gbYellow`, а при наведении — `gbDark3`. Внутренний стиль `collapseStyle`
использует `gbDark1` как цвет переднего плана.

### Плавающие панели

Для границы плавающей панели используется `gbGray`. Заголовок оформлен
фоном `gbDark1` и жирным текстом `gbLight1`. Стиль закрытия использует
жирный `gbRed`, а стиль фона панели — `gbDark0`.

### Сворачиваемые элементы

В `collapsibleStyle` используется `gbLight1` на фоне `gbDark1`, а
`collapsibleBorderStyle` использует `gbDark4` как цвет переднего плана.

### Выпадающие меню

Для кнопки выпадающего меню используется `gbDark2` с текстом `gbLight1`.
Для пунктов меню используются `gbDark0` с текстом `gbLight1`. У пунктов
при наведении используется `gbDark2` с текстом `gbYellow`, а у выбранных
пунктов — `gbDark2` с жирным текстом `gbGreen`.

## Пример

```go
border := warp.BorderStyle().Render("│")
```

В примере предполагается, что вызывающий файл импортирует этот пакет под
именем `warp`, а `github.com/charmbracelet/lipgloss` — только если напрямую
использует API Lip Gloss.

## Примечания по реализации

- Стили создаются как переменные уровня пакета при инициализации пакета; три
  экспортируемые функции доступа не пересоздают их.
- Цвета и стили — непубличные переменные, за исключением трёх функций
  доступа. Это не константы и не экспортируемые значения.
- Этот файл импортирует `github.com/charmbracelet/lipgloss` и определяет
  стили уровня пакета; другие файлы пакета `warp` могут использовать эти
  непубличные имена.
- Здесь не предусмотрена настройка темы; чтобы изменить заданную в коде
  палитру, необходимо изменить этот файл.
