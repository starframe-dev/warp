# panel.go

Файл `panel.go` определяет абстракцию `Panel`, используемую в
TUI-фреймворке Warp. **Panel** — это базовая единица контента для
панелей Warp: может представлять что угодно — от обычного текста до
интерактивной графики и форм. Файл также содержит `BasePanel` — базовый
тип-заглушка для удобного встраивания.

## Публичный API

### Panel (интерфейс)

` type Panel interface { View(width, height int) string Update(msg tea.Msg) tea.Cmd } `

`Panel` — это основной интерфейс, который реализуют пользователи для
отображения контента внутри панелей Warp. Он содержит два метода:

| Метод | Описание |
|----|----|
| `View(width, height int) string` | Отображает содержимое панели для заданных размеров. |
| `Update(msg tea.Msg) tea.Cmd` | Обрабатывает входящие сообщения Bubbletea (клавиши, мышь и т.д.) при фокусе на панели. |

### BasePanel (структура)

` type BasePanel struct{} func (BasePanel) View(width, height int) string { return "" } func (BasePanel) Update(msg tea.Msg) tea.Cmd { return nil } `

`BasePanel` предоставляет реализацию по умолчанию без действия для
интерфейса `Panel`. Встраивайте её в конкретный тип панели и
переопределяйте только те методы, которые вам нужны, — это избавляет от
лишнего кода, сохраняя контракт интерфейса.

## Использование

Реализуйте `Panel` напрямую или встраивайте `BasePanel` для частичного
переопределения. Панель получает только те сообщения, которые пришли,
пока она находилась в фокусе.

``` go

type MyPanel struct {
    BasePanel // встраивание для значений по умолчанию
    title string
}

func (p *MyPanel) View(width, height int) string {
    return fmt.Sprintf("[%s]", p.title)
}

func (p *MyPanel) Update(msg tea.Msg) tea.Cmd {
    // обрабатываем клавиши при фокусе
    return nil
}
```

## Заметки о реализации

- **Маршрутизация сообщений** — только сфокусированные панели получают
  вызовы `Update`; неактивные панели не получают входящих сообщений.
- **Учёт размеров при отрисовке** — метод `View` получает явные `width`
  и `height`, поэтому панели могут адаптировать свою раскладку под
  доступное пространство без обращения к глобальному состоянию.
- **Встраивание (embedding)** — встраивание структур в Go даёт чистый
  путь композиции: встраивайте `BasePanel` для получения поведения по
  умолчанию и переопределяйте только то, что нужно.
- **Интеграция с Bubbletea** — интерфейс зеркалит контракт `Model` из
  `github.com/charmbracelet/bubbletea` (конкретно пару `View`/`Update`),
  что делает панели полностью совместимыми с циклом обновления
  фреймворка.
