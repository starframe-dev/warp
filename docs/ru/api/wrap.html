wrap.go

Утилиты переноса текста для пакета warp. Все измерения ширины — это визуальные ширины, вычисляемые функцией lipgloss.Width (форк go-runewidth) — это значит, что ANSI-управляющие последовательности, символы нулевой ширины и другие управляющие символы корректно обрабатываются при определении места разрыва строки. Визуальная ширина в 0 символов означает «символы, которые видит человеческий глаз», а не длину строки в байтах.

Публичный API

WordWrap

func WordWrap(text string, width int) []string

Переносит текст по границам слов так, чтобы ни одна строка не превышала width визуальных колонок. Слова длиннее width разрываются посередине (жёсткий разрыв). Строка во входном тексте, сама по себе короче width, остаётся без изменений. Сначала входной текст разбивается по "\n", затем каждая строка переносится независимо — выходные строки никогда не содержат \n.

  • Если width <= 0, результатом будет nil.
  • Входной текст без каких-либо символов, шире width, возвращается без изменений.
  • Каждый элемент возвращаемого среза — одна визуальная строка шириной не более width колонок.
lines := warp.WordWrap("the quick brown fox", 10)
// lines[0] == "the quick"
// lines[1] == "brown fox"
// lines[2] == nil (if width <= 0)

SpaceWrap

func SpaceWrap(text string, width int) []string

Переносит текст по границам пространств так, чтобы ни одна строка не превышала width визуальных колонок. В отличие от WordWrap, здесь не разбиваются слова посередине — одиночное слово длиннее width вылезает за пределы строки, и результат всё равно формируется. Границы слов берутся из strings.Fields (любая последовательность пробельных символов схлопывается в одно пространство).

  • Если width <= 0, результатом будет nil.
  • Пустой вход возвращает одну пустую строку.
lines := warp.SpaceWrap("hello   world foo", 12)
// lines[0] == "hello"
// lines[1] == "world foo"

WrapToString

func WrapToString(text string, width int, useSpaceWrap bool) string

Удобная обёртка вокруг WordWrap / SpaceWrap, склеивающая полученные строки через "\n". Это единственный экспортируемый функция, возвращающая строку напрямую; функции, возвращающие срезы выше, дают вызывающему контроль над тем, как строки отображаются (например, TUI-рендереру, которому нужно знать, сколько строк было выдано).

s := warp.WrapToString("a b c d e f g h i j k", 8, false)
// s == "a b c d\nf g h i\nj k"

Заметки по реализации

  • wrapLine (используется в WordWrap) проходит строку посимвольно, отслеживая последнее место границы слова, которое она видела, поэтому длинное слово разрывается только если естественной точки переноса до превышения визуальной ширины не было.
  • wrapAtSpaces (используется в SpaceWrap) сначала токенизирует через strings.Fields, затем жадно упаковывает слова в строки, добавляя между ними одно пространство. Разделитель «пробел» учитывается в визуальную ширину.
  • Вспомогательная функция isWordBreak существует как байтовое удобство вокруг unicode.IsSpace; она в настоящее время не используется в пакете, но сохранена для потенциального внешнего использования.
  • Оба варианта опираются на lipgloss.Width для визуальной ширины. Это значит, что строку, например "\x1b[31mred\x1b[0m", измеряется как 3 символа, а не как длина управляющей последовательности.
  • Две стратегии различаются лишь в одном: WordWrap жёстко разбивает слова длиннее ширины; SpaceWrap этого не делает и выдаст единую строку, выходящую за ширину, если пространств не оказалось.

Зависимости

  • github.com/charmbracelet/lipgloss — предоставляет lipgloss.Width, форк go-runewidth, используемый как источник истины для визуальной ширины символов.

Ограничения

  • Обе функции обрабатывают только "\n" как разделитель строк; возврат каретки и другие юникодные переносы строк во входных данных не считаются разрывами строк и сохраняются в выводе как есть (обрабатываются логикой ширины).
  • Понятия дефисации или склейки слов через границу переноса не существует; перенос всегда происходит на границе пробельного символа (или посреди слова для WordWrap).
