styles.go

Файл styles.go является центральным источником палитры и стилей lipgloss для TUI приложения warp. Он определяет набор цветов Gruvbox Dark один раз, и от него выводится каждый стиль пользовательского интерфейса: панель вкладок, разделительная граница, плавающее окно, сворачиваемый элемент, выпадающее меню и другие элементы. В этом файле нет поведения во время выполнения; он только хранит константы (цвета) и заранее созданные стили, которые используются другими файлами.

Поведение модуля

Модуль не содержит функций, изменяющих состояние. Все выведенные значения — это неизменяемые значения lipgloss.Style и непубличные переменные цветов. Это сохраняет файл тривиально локальным: любой компонент пользовательского интерфейса может отрисовать себя, не зная, как стилизуются другие элементы.

Цветовая палитра следует схеме Gruvbox Dark:

  • Масштаб фона gbDark0..gbDark4 и нейтральный цвет gbGray
  • Светлый текст gbLight1
  • Набор акцентных цветов: gbRed, gbGreen, gbYellow, gbBlue

Публичный API

Все публичные экспортные значения — это неизменяемые значения стилей. Их безопасно передавать между горутинами, поскольку lipgloss.Style — это неизменяемая структура. 

func BorderStyle() lipgloss.Style
func BorderDragStyle() lipgloss.Style
func BorderHoverStyle() lipgloss.Style
Функция Возвращает Назначение
BorderStyle lipgloss.Style Фон (foreground) обычной разделительной границы между окнами.
BorderDragStyle lipgloss.Style Фон, используемый во время перетаскивания разделительной границы.
BorderHoverStyle lipgloss.Style Фон, отображаемый, когда курсор мыши находится над разделительной границей.

Три функции — это небольшие обёртки, а не значения, поскольку lipgloss.Style — это тип по значению, и пакету нужно избежать экспорта непубличных идентификаторов borderStyle, borderDragStyle и borderHoverStyle напрямую. Вызывающие стороны должны считать возвращаемое значение константой и никогда его не изменять.

Внутренняя палитра

Непубличные переменные цветов группируются в три концептуальных набора:

  1. Базовая палитра — gbDark0 до gbLight1, gbGray плюс акцентные цвета.
  2. Палитра разделительной границы — borderColor, borderDragColor, borderHoverColor и collapseStyle.
  3. Палитры элементов — цвета вкладки, плавающего окна, выпадающего меню и сворачиваемого элемента, каждый в паре со стилем lipgloss, который их использует.

Группы стилей

Панель вкладок

Панель вкладок переиспользует самый тёмный цвет фона (tabBarBg = gbDark0) и использует жирный, светлый текст для активной вкладки. Неактивные вкладки используют приглушённый серый цвет текста. Указатель для новой вкладки — зелёный, для закрытия вкладки — красный.

Разделительная граница

borderStyle и collapseStyle оба отрисовываются с текстом gbDark1. Во время перетаскивания цвет меняется на gbYellow, при наведении — на gbDark3.

Плавающее окно

Плавающие окна имеют собственную «хромию»: граница gbGray, заголовочная панель с фоном gbDark1 и жирным текстом gbLight1, кнопка закрытия красная, фон тела gbDark0.

Сворачивание

Свёрнутые окна используют gbLight1 на gbDark1, а граница вокруг свёрнутого окна использует gbDark4.

Выпадающее меню

Кнопки выпадающего меню используют фон gbDark2 с текстом gbLight1. Пункты находятся на фоне gbDark0, при наведении меняется на фон gbDark2 с жёлтым текстом, а выбранное состояние становится зелёным с жирным текстом.

Пример использования

// Render a split border in its normal state.
lipgloss.NewRenderer().Render(wrapText("pane", warp.BorderStyle()))

// While the user drags the border.
lipgloss.NewRenderer().Render(wrapText("pane", warp.BorderDragStyle()))

Детали реализации

  • Все стили конструируются один раз при инициализации пакета; они не переиспользуются при использовании.
  • Цвета — это захардкоженные шестнадцатеричные значения, а не система тем во время выполнения; переключение тем требует правки этого файла.
  • Здесь нет интерфейса тем или DI; файл является единственным источником правды, который другие файлы пакета импортируют неявно через имена на уровне пакета.
  • Стили — это значения, а не указатели; lipgloss считает их неизменяемыми, поэтому возврат по значению безопасен.
  • У файла нет зависимостей от остальной части пакета, кроме самой библиотеки lipgloss; о нём можно рассуждать локально.
