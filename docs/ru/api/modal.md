# Modal

Тип `Modal` реализует перетаскиваемый модальный диалоговый блок, который
рендерится поверх содержимого панели. Он состоит из коробки с заголовком
(скруглённые границы, фоновый цвет), области содержимого, ряда кнопок,
кнопки закрытия (✕) и необязательного поведения перетаскивания через
события мыши. Модальное окно спроектировано для встраивания в любую
панель в Bubble Tea TUI-приложении (проект `warp`).

## Пакет

Пакет `warp`, файл `modal.go`. Импорты:

- `github.com/charmbracelet/bubbletea` (как `tea`) — типы
  сообщений/событий TUI.
- `github.com/charmbracelet/lipgloss` — рендеринг коробок, границы,
  отступы, цвета.
- `github.com/charmbracelet/x/ansi` — ширина/обрезка ANSI-строк.
- `github.com/charmbracelet/x/ansi/parser` — конечный автомат ANSI,
  используемый в `visualBytePos`.
- `github.com/rivo/uniseg` — сегментация Unicode для вычисления ширины
  графемных кластеров.

## Типы

### ShowModalMsg

``` go
type ShowModalMsg struct {
    Title   string
    Content string
    Buttons []ModalButton
    OnClose func()
    Width   int
}
```

Сообщение Bubble Tea, указывающее панели показать модальный диалог.
Панель несёт ответственность за преобразование этого сообщения в
конкретный `Modal` и его хранение.

### CloseModalMsg

``` go
type CloseModalMsg struct{}
```

Сообщение Bubble Tea, указывающее панели закрыть текущий отображаемый
модальный диалог.

### Modal

``` go
type Modal struct {
    Title   string
    Content string
    Buttons []ModalButton
    OnClose func()
    Width   int

    startX, startY int
    boxWidth, boxHeight int

    dragging bool
    dragX, dragY int
    offsetX, offsetY int

    dimsSet bool
    totalW, totalH int
}
```

Диалоговое окно, отображаемое поверх содержимого панели. Любая панель
может встраивать и рендерить `Modal` в своём `View()`. Непубличные поля
(позиция/размеры коробки, состояние перетаскивания, кэшированные
размеры) управляются методами, описанными ниже, и не должны изменяться
напрямую.

| Поле | Описание |
|----|----|
| `Title` | Отображается в верхней граничной области коробки. |
| `Content` | Строка содержимого с рендерингом ANSI (может содержать ANSI escape-последовательности). |
| `Buttons` | Кнопки, отображаемые в нижней части коробки; каждая несёт собственный `Action`. |
| `OnClose` | Вызывается при закрытии модального окна через кнопку ✕, Esc или любой внешний путь. |
| `Width` | Требуемая ширина коробки; 0 означает авторазмер (3/5 ширины экрана, ограничено от 30 до 50 колонок). |

### ModalButton

``` go
type ModalButton struct {
    Label  string
    Action func()
}
```

Одна кнопка внутри модального окна. Подпись рендерится как `[Label]` и
её `Action` выполняется при нажатии кнопки.

## Конструкторы

``` go
func NewModal(title, content string, buttons []ModalButton, onClose func()) *Modal
```

Создаёт новый модальный диалог из его частей и возвращает его как
указатель. Ширина коробки оставляется при нулевом значении, чтобы логика
авторазмерения в `EnsureDimensions` применялась при первом рендеринге.

## Методы

### EnsureDimensions

``` go
func (m *Modal) EnsureDimensions(totalW, totalH int)
```

Вычисляет и сохраняет позицию/размер коробки, если они ещё не были
вычислены (`dimsSet == false`). Ширина коробки разрешается как: `Width`,
если положительна, иначе `totalW * 3 / 5`, с ограничением минимума 30 и
максимума 50, и никогда шире `totalW`. Высота коробки фиксирована в 7
строк (скруглённая граница + padding(1,2) + 3 строки содержимого).
Коробка центрируется горизонтально и вертикально, и любое существующее
смещение перетаскивания добавляется к отцентрированной позиции.
Последующие вызовы — noop.

Должен вызываться перед `HandleMouse`, если `Overlay` ещё не выполнялся.

### Overlay

``` go
func (m *Modal) Overlay(lines []string, totalW, totalH int) []string
```

Рендерит модальный диалог поверх предоставленных строк содержимого и
возвращает наложенные строки. Поведение:

1.  Гард-условия: возвращает вход без изменений, когда `totalW <= 0` или
    `lines` пусто.
2.  Вызывает `EnsureDimensions(totalW, totalH)` и дочитывает
    позицию/размер коробки.
3.  Строит три строки содержимого:
    - *Строка заголовка* — `Title` с выравниванием пробелами,
      завершённая глифом закрытия `✕`.
    - *Строка содержимого* — `Content`, обрезанная до
      `innerWidth = boxWidth - 6` колонок (визуальная ширина), с
      многоточием при обрезке, с выравниванием до той же ширины.
    - *Строка кнопок* — кнопки, отображённые как записи `[Label]`,
      объединённые двумя пробелами, с выравниванием до `innerWidth`.
4.  Оборачивает три строки в коробку со скруглёнными границами
    `lipgloss` с использованием общего `modalBorderStyle` (фон
    `gbDark1`, передний план `gbLight1`, цвет границы `gbBlue`, padding
    `(1, 2)`).
5.  Приглушает полный фон каждой строки с помощью `dimStyle` (фон
    `gbDark0`, серый передний план) после удаления исходных ANSI
    escape-последовательностей.
6.  Наложение строк коробки поверх затемнённого содержимого при
    сохранении содержимого слева и справа от коробки. Срезы слева и
    справа восстанавливаются по байтовой позиции с использованием
    `visualBytePos`, который обходит ANSI-строку и останавливается на
    первом байтовом смещении, где визуальная ширина достигает целевой
    колонки. Левая часть выравнивается пробелами, если её визуальная
    ширина короче `startX`.

### HandleMouse

``` go
func (m *Modal) HandleMouse(msg tea.MouseMsg) bool
```

Обрабатывает мышиное событие для модального окна и возвращает, было ли
событие поглощено. Ожидаемая раскладка (строки нумеруются от 1 внутри
коробки):

``` plaintext
startY + 0  верхняя граница
startY + 1  верхний padding (перетаскиваемая полоса)
startY + 2  заголовок + ✕
startY + 3  содержимое
startY + 4  ряд кнопок 1
startY + 5  ряд кнопок 2 (переносится при широких)
startY + 6  нижняя граница
```

Поведение:

- Noop (`false`), когда `boxHeight == 0` (размеры неизвестны).
- **MouseActionPress** + левая кнопка:
  - Если клик точно на кнопке закрытия `✕` (в позиции
    `(startX + boxWidth - 4, startY + 2)`) и `OnClose` установлен,
    `OnClose()` вызывается и событие поглощается.
  - Иначе выполняется hit-test ряда кнопок: `buildButtonLine()`
    перестраивает строку `[label]` и `findBracketPair` обходит её,
    вычисляя байтовые/визуальные диапазоны `[start, end)` каждой кнопки;
    прибавление `startX + 3` (1 граница + 2 padding) даёт диапазон X в
    экранных координатах. Нажатие, X которого попадает в
    `[btnX1, btnX2)`, а Y находится на одном из двух рядов кнопок,
    вызывает `Action` кнопки и поглощает событие.
  - Если нажатие на перетаскиваемую padding-полосу (`Y == startY + 1`, X
    внутри коробки), начинается перетаскивание и записывается якорь
    перетаскивания.
- **MouseActionMotion**: во время перетаскивания дельта применяется к и
  кумулятивному смещению (`offsetX`/`offsetY`), и к живой позиции
  (`startX`/`startY`). Позиция ограничивается экраном с использованием
  `totalW`/`totalH`.
- **MouseActionRelease**: завершает перетаскивание, если оно в процессе,
  и поглощает событие.

### Геттеры

Эти геттеры expose последнюю вычисленную геометрию коробки после
`Overlay` (или `EnsureDimensions`).

| Метод         | Возвращает                              |
|---------------|-----------------------------------------|
| `StartX()`    | `startX` — левый X коробки.             |
| `StartY()`    | `startY` — верхний Y коробки.           |
| `BoxWidth()`  | `boxWidth` — ширина коробки.            |
| `BoxHeight()` | `boxHeight` — высота коробки (7 строк). |

## Внутренние помощники

- `buildButtonLine() string` — повторно выводит строку ряда кнопок
  (идентична той, что рендерится `Overlay`), чтобы hit-test использовал
  тот же источник правды, что и рендеринг.
- `findBracketPair(s string, pos int) (int, int)` — находит следующую
  пару `[…]` на/после `pos`; возвращает `(-1, -1)`, если не найдена.
  Используется `HandleMouse` для итерации по кнопкам.
- `visualBytePos(s string, targetW int) int` — обходит `s` как
  ANSI-aware поток (через таблицу `parser` и графемные кластеры
  `uniseg`) и возвращает байтовую позицию, где визуальная ширина впервые
  достигает `targetW`; возвращает `len(s)`, если так и не достиг.
- `stripANSI(s string) string` — удаляет ANSI escape-последовательности,
  соответствующие `\x1b\[[0-9;]*[a-zA-Z]`.
- `max(a, b int) int` — небольшой int max-помощник (совместим с
  pre-Go-1.21).

## Стили

Два пакетно-уровневых значения `lipgloss.Style` разделяются с остальными
частями TUI:

- `modalBorderStyle` — фон `gbDark1`, передний план `gbLight1`,
  скруглённые границы в `gbBlue`, padding `(1, 2)`. Используется
  `Overlay` для оборачивания трёх строк содержимого.
- `dimStyle` — серый передний план на фоне `gbDark0`. Используется для
  затемнения содержимого панели за модальным окном.

## Замечания о интеграции

- Модальный диалог не владеет собственной поверхностью рендеринга;
  панель компонирует результат `Overlay` в вывод её `View()`.
- `msg.Y`, передаваемый в `HandleMouse`, ожидается в той же
  строочно-относительной системе координат, которую использует `Overlay`
  (0 = первая строка содержимого панели; родитель уже перевёл экранный Y
  в строочный Y).
- Перетаскивание инициируется только с верхней padding-полосы
  (`startY + 1`), а не с самой строки заголовка; строка заголовка всё
  ещё доступна для hit-test глифа закрытия `✕` и кнопок.
- Обрезка содержимого использует визуальную ширину:
  `ansi.Truncate(s, n, "")` с последующим добавлением `…`, когда
  исходное содержимое шире внутренней ширины.
- ANSI-последовательности в строках фона удаляются перед применением
  затемнённого фона, чтобы escape-байты не просачивались в левые/правые
  срезы каждой строки.
