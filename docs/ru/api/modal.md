# Модальное окно

Тип `Modal` реализует перетаскиваемый диалоговый блок, отображаемый поверх содержимого панели. Он содержит заголовок и глиф закрытия, область содержимого и ряд кнопок. Панель встраивает модальное окно, вызывает `Overlay` при рендеринге и передаёт события мыши в `HandleMouse`.

## Пакет

Пакет `warp`, файл `modal.go`. Импорты:

- `github.com/charmbracelet/bubbletea` (как `tea`) — типы событий мыши.
- `github.com/charmbracelet/lipgloss` — рендеринг коробок, границы, отступы и цвета.
- `github.com/charmbracelet/x/ansi` — вычисление ширины, обрезка и удаление ANSI-последовательностей в строках.
- `github.com/charmbracelet/x/ansi/parser` — конечный автомат ANSI, используемый в `visualBytePos`.
- `github.com/rivo/uniseg` — вычисление ширины кластеров Unicode-графем, используемое в `visualBytePos`.

## Типы

### ShowModalMsg

```go
type ShowModalMsg struct {
    Title   string
    Content string
    Buttons []ModalButton
    OnClose func()
    Width   int
}
```

Тип сообщения Bubble Tea, содержащий параметры для показа модального окна. Панель обрабатывает сообщение и создаёт или сохраняет модальное окно; сам этот тип такой обработкой не занимается.

### CloseModalMsg

```go
type CloseModalMsg struct{}
```

Тип сообщения Bubble Tea, с помощью которого панель может запросить закрытие текущего модального окна. Само сообщение окно не закрывает.

### Modal

```go
type Modal struct {
    Title   string
    Content string
    Buttons []ModalButton
    OnClose func()
    Width   int

    startX, startY int
    boxWidth, boxHeight int

    dragging bool
    dragX, dragY int
    offsetX, offsetY int

    totalW, totalH int
}
```

Диалог, отображаемый поверх содержимого панели. Непубличные поля содержат последние вычисленные геометрические параметры коробки, состояние перетаскивания, смещения и размеры области просмотра. Ими управляют методы модального окна.

| Поле | Описание |
|----|----|
| `Title` | Текст заголовка. Управляющие символы и последовательности фреймворка очищаются перед рендерингом. |
| `Content` | Строка содержимого; допустимое ANSI-форматирование сохраняется, управляющие символы нормализуются. |
| `Buttons` | Кнопки в нижней части коробки; каждая может содержать `Action`. |
| `OnClose` | Функция обратного вызова при нажатии на глиф закрытия. Эта реализация не обрабатывает Esc и внешние способы закрытия. |
| `Width` | Запрошенная ширина коробки. Неположительное значение выбирает 3/5 ширины области просмотра; результат ограничивается диапазоном 30–50 колонок, а затем шириной области просмотра. |

### ModalButton

```go
type ModalButton struct {
    Label  string
    Action func()
}
```

Кнопка модального окна. Её очищенная подпись отображается как `[Label]`; при нажатии в видимом диапазоне скобок вызывается `Action`, если функция обратного вызова задана.

## Конструктор

```go
func NewModal(title, content string, buttons []ModalButton, onClose func()) *Modal
```

Создаёт и возвращает модальное окно с указанными заголовком, содержимым, кнопками и функцией обратного вызова при закрытии. Значение `Width` остаётся нулевым, поэтому используется автоматический выбор ширины, если вызывающий код не задаст её.

## Методы

### EnsureDimensions

```go
func (m *Modal) EnsureDimensions(totalW, totalH int)
```

Ограничивает переданные размеры области просмотра неотрицательными значениями, вычисляет ширину коробки и фиксированную высоту (7 строк), а также обновляет позицию модального окна и сохранённые размеры области просмотра. Ширина равна `Width`, если она положительна, иначе `totalW * 3 / 5`; затем она ограничивается диапазоном 30–50 колонок и шириной `totalW`. Модальное окно располагается по центру с учётом сохранённого смещения перетаскивания, а результат ограничивается областью просмотра. Смещения обновляются с учётом ограниченной позиции. При каждом вызове размеры и позиция вычисляются заново; это не одноразовая инициализация. Вызов для nil-получателя игнорируется.

Вызовите этот метод перед `HandleMouse`, если `Overlay` ещё не запускался для текущих размеров области просмотра.

### Overlay

```go
func (m *Modal) Overlay(lines []string, totalW, totalH int) []string
```

Отображает модальное окно поверх переданных строк и возвращает строки с наложенным окном.

1. Возвращает входные данные без изменений, если `totalW <= 0` или `lines` пуст.
2. Вызывает `EnsureDimensions(totalW, totalH)` и использует полученную геометрию.
3. Формирует три строки содержимого в пределах `innerWidth = max(0, boxWidth - 6)`: очищенный заголовок с отступом перед глифом `✕`; нормализованное содержимое, обрезанное до доступной визуальной ширины (с `…`, если изначально оно шире этой ширины); очищенные подписи кнопок в скобках, разделённые двумя пробелами. Строки содержимого и кнопок дополняются до внутренней ширины.
4. Рендерит строки в коробке со скруглёнными границами Lip Gloss с помощью `modalBorderStyle` (фон `gbDark1`, передний план `gbLight1`, граница `gbBlue`, отступы `(1, 2)`).
5. Приглушает каждую переданную строку после удаления её ANSI-последовательностей, используя `dimStyle` (серый передний план и фон `gbDark0`).
6. Размещает строки коробки поверх приглушённых строк, сохраняя доступное содержимое слева и справа. Смещение правой части в байтах вычисляется с помощью `visualBytePosAfter`; левая часть обрезается до визуальной начальной колонки и при необходимости дополняется. Результирующие строки дополняются до `totalW`.

### HandleMouse

```go
func (m *Modal) HandleMouse(msg tea.MouseMsg) bool
```

Обрабатывает событие мыши и сообщает, было ли оно обработано. Структура коробки:

```text
startY + 0  верхняя граница
startY + 1  верхний отступ (полоса перетаскивания)
startY + 2  заголовок и глиф закрытия
startY + 3  содержимое
startY + 4  ряд кнопок
startY + 5  нижний отступ
startY + 6  нижняя граница
```

Возвращает `false` для nil-получателя или если `boxHeight == 0`.

- **Нажатие левой кнопки:** нажатие точно в точке `(startX + boxWidth - 4, startY + 2)` вызывает `OnClose`, если функция задана, и обрабатывается, даже если функция равна nil. Нажатие в видимом диапазоне скобок кнопки на строке `startY + 4` вызывает её `Action`, если функция задана, и обрабатывается. Обрезанные или скрытые кнопки не имеют активной области. Нажатие в любом месте коробки на строке `startY + 1` начинает перетаскивание и сохраняет позицию указателя.
- **Перемещение:** во время перетаскивания смещение указателя применяется к позиции, которая ограничивается сохранёнными границами области просмотра. Смещение перетаскивания пересчитывается относительно получившейся позиции.
- **Отпускание кнопки:** завершает активное перетаскивание и обрабатывается; в остальных случаях событие не обрабатывается.

Координаты мыши по Y должны использовать ту же систему координат относительно строк, что и строки, переданные в `Overlay` (0 — первая строка содержимого). При необходимости вызывающий код самостоятельно преобразует экранные координаты.

### Методы доступа к геометрии

Эти методы возвращают последние вычисленные геометрические параметры после вызова `Overlay` или `EnsureDimensions`:

| Метод | Возвращаемое значение |
|----|----|
| `StartX()` | `startX` — левая координата X коробки. |
| `StartY()` | `startY` — верхняя координата Y коробки. |
| `BoxWidth()` | `boxWidth` — ширина коробки. |
| `BoxHeight()` | `boxHeight` — высота коробки, фиксированная на уровне 7 строк. |

## Внутренние помощники

- `buildButtonLine() string` — формирует очищенные элементы `[Label]`, разделённые двумя пробелами.
- `findBracketPair(s string, pos int) (int, int)` — находит следующую пару скобок начиная с `pos` или после него; возвращает `(-1, -1)`, если пара не найдена. Используется для проверки попадания по кнопкам.
- `visualBytePos(s string, targetW int) int` — обходит поток с учётом ANSI и возвращает байтовое смещение, соответствующее визуальной ширине, либо `len(s)`, если целевая ширина не достигнута. Определён в этом файле, но не используется методом `Overlay`.
- `stripANSI(s string) string` — вызывает `ansi.Strip`.
- `max(a, b int) int` — возвращает большее из двух целых чисел.

При рендеринге также используются общие вспомогательные функции работы с текстом терминала, определённые в других местах пакета: нормализация управляющих символов, очистка меток фреймворка, обрезка фрагментов и дополнение визуальных строк.

## Стили

В модальном окне используются два значения `lipgloss.Style` уровня пакета:

- `modalBorderStyle` — фон `gbDark1`, передний план `gbLight1`, скруглённая граница `gbBlue`, отступы `(1, 2)`.
- `dimStyle` — серый передний план на фоне `gbDark0`.

## Замечания об интеграции

- У модального окна нет собственной поверхности рендеринга. Панель включает результат `Overlay` в вывод `View()`.
- `ShowModalMsg` и `CloseModalMsg` — только типы сообщений; родительская панель должна реализовать соответствующие изменения состояния.
- `HandleMouse` обрабатывает нажатие на глиф закрытия, но не реализует ввод с клавиатуры, например Esc.
- Перетаскивание начинается только на верхней полосе отступа (`startY + 1`), а не на строке заголовка.
