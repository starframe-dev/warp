Input

Input — компонент однострочного текстового ввода, построенный поверх Bubble Tea. Он управляет строковым значением, позицией курсора в символах (rune), необязательным префиксом-подсказкой и редактированием с клавиатуры, а рендерит себя либо как однострочную строку, либо как рамку с границами в зависимости от доступной высоты.

Поведение

Рендеринг

View вызывает viewBoxed, когда доступная высота составляет как минимум три строки, отрисовывая рамку со скруглёнными углами и стилем границы в сфокусированном или несфокусированном состоянии. Иначе переключается на viewInline, который рендерит промпт и значение как одну стилизованную строку, повторяющуюся на протяжении всей высоты.

Видимая строка формируется renderLine, который конкатенирует префикс-промпт со значением. Если суммарная ширина превышает доступную ширину, значение обрезаются слева так, чтобы курсор оставался видимым. Позиция курсора рендерится с помощью последовательности инвертирования видео (\x1b[7m ... \x1b[0m) вокруг символа (rune) в позиции курсора, либо завершающим инвертируемым пробелом, когда курсор находится в конце значения.

Курсор и редактирование

Update обрабатывает tea.KeyMsg только когда фокус на вводе. Распознаваемые клавиши:

  • backspace — удаляет символ перед курсором.
  • delete — удаляет символ под курсором.
  • left / right — сдвигает курсор на один символ, с ограничением границ.
  • home / end — перемещает курсор в начало или конец значения.
  • tab / shift+tab — бездействие; обрабатывается родительским компонентом для навигации фокуса.
  • enter — плейсхолдер бездействия для будущего сигнала отправки.
  • Клавиши с одним символом — вставляют символ в позиции курсора.

После каждого редактирования clampCursor гарантирует, что курсор остаётся в пределах [0, len(value)] в символах.

Внутренние помощники (package-private)

  • viewBoxed / viewInline — пути рендеринга, зависящие от макета.
  • renderLine — строит строку «промпт + значение» с подсветкой курсора.
  • truncateTailToWidth — центрирует видимое значение вокруг курсора, сдвигая стартовый индекс, когда курсор уходит за видимую ширину.
  • insertAtCursor / deleteBeforeCursor / deleteAtCursor — модификации текста на уровне символов (rune).
  • clampCursor — принуждение к инвариантам позиции курсора.

Стилизация

Стилевые определения на уровне пакета на основе lipgloss определены в конце файла: inputStyle (светлый цвет текста), inputBorderStyle (тёмная граница) и inputFocusBorderStyle (синяя граница при фокусе). Эти стили используются и в рамочном, и в однострочном путях рендеринга.
