Collapsible

Collapsible — обёртка bubbletea-панели в пакете warp. Она оборачивает любую панель Panel и добавляет поведение сворачивания/разворачивания. Когда панель развёрнута, она делегирует весь рендеринг и обработку сообщений во внутреннюю панель Content. Когда свернута, она рендерит однострочную строку заголовка, собранную из индикатора, заголовка (возможно с обрезкой) и декоративной горизонтальной линии.

Публичный API

Type

type Collapsible struct {
    Title     string
    Collapsed bool
    Content   Panel
}
Поле Тип Описание
Title string Отображаемый заголовок, показываемый в строке заголовка при свёрнутом состоянии. Обрезается с ..., если не помещается в доступную ширину.
Collapsed bool Свёрнута ли панель в строку заголовка. Публичное поле, чтобы вызывающий код мог напрямую читать или устанавливать состояние.
Content Panel Внутренняя панель контента, рендерится при развёрнутом состоянии. Может быть nil.

NewCollapsible

func NewCollapsible(title string, content Panel) *Collapsible

Создаёт новый Collapsible с заданным title и content. Панель стартует в развёрнутом состоянии (Collapsed == false). Возвращает указатель; вызывающий код должен удерживать его и управлять состоянием через Toggle.

View

func (c *Collapsible) View(w, h int) string

Рендерит панель при ширине w и высоте h. Поведение:

  • Если Collapsed равно true, рендерит однострочную строку заголовка в свёрнутом состоянии (см. renderCollapsed ниже).
  • Если Collapsed равно false и Content != nil, возвращает c.Content.View(w, h).
  • Если Content == nil, возвращает "".

В свёрнутом режиме параметр h игнорируется; строка заголовка всегда однострочная, независимо от высоты.

Update

func (c *Collapsible) Update(msg tea.Msg) tea.Cmd

Проваливает bubbletea-сообщение во внутреннюю панель Content и возвращает команду, порождённую обработчиком. Возвращает nil, если Content равно nil.

Состояние Collapsed не управляется сообщениями — за переключение отвечает вызывающий код через Toggle.

Toggle

func (c *Collapsible) Toggle()

Инвертирует Collapsed. Это единственный метод, изменяющий состояние, у данного типа. Повторные вызовы переключают состояние туда и обратно; nil в Content не мешает переключению.

renderCollapsed

func (c *Collapsible) renderCollapsed(w int) string

Непубличный хелпер, который собирает однострочную строку заголовка в свёрнутом состоянии. Макет, слева направо:

  • Левая ячейка, отренендеренная со стилем collapsibleStyle, содержащая ┌, глиф индикатора (▶ при свёрнутом состоянии, ▼ при развёрнутом), пробел и (возможно обрезанный) Title.
  • Правая ячейка, отрендеренная со стилем collapsibleBorderStyle, содержащая последовательность символов ─, за которой следует ┐ — правый верхний угол. Длина последовательности равна padding = w − len(title) − 5, ограничена снизу нулём.

Обрезка резервирует 5 колонок (индикатор, пробел и угловые символы) от доступной ширины. Если оставшаяся длина заголовка была бы отрицательной, заголовок выводится пустым, а строка заголовка всё равно рендерится. Неотрицательное w возвращает пустую строку.

Семантика пустого контента

Collapsible с Content == nil ведёт себя как чистый носитель состояния: он всё ещё переключается и рендерит строку заголовка, но при развёрнутом состоянии View возвращает "", а Update поглощает каждое сообщение. Это сделано намеренно — обёртка должна быть безопасной для встраивания в любое дерево без конструирования внутренней панели.

Стили

Строка заголовка собирается из двух package-level стилей lipgloss, определённых в styles.go и пересвязанных в theme.go:

  • collapsibleStyle — передний план gbLight1, фон gbDark1. Применяется к левой ячейке, содержащей угол, индикатор и заголовок.
  • collapsibleBorderStyle — передний план gbDark4. Применяется к правой ячейке, содержащей последовательность ─ и угол ┐.

Примеры использования

col := NewCollapsible("Settings", settingsPanel)

// Collapse
col.Toggle()

// Render the collapsed title bar at width 80
out := col.View(80, 1)

// Forward a message to the inner panel
cmd := col.Update(tea.KeyMsg{Type: tea.KeyCtrlC})

Зависимости

Collapsible зависит от github.com/charmbracelet/bubbletea для типов tea.Msg и tea.Cmd, package-level интерфейса Panel, и значений lipgloss collapsibleStyle / collapsibleBorderStyle из styles.go.
