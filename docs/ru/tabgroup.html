TabGroup

TabGroup — это Panel, отображающий панель вкладок и переключающий между ними. Может использоваться как компонент внутри splits, flex-расположений или как корневая панель.

Обзор

TabGroup предоставляет вкладочный интерфейс, похожий на эмуляторы терминала. Поддерживает:

  • Множество вкладок с пользовательскими именами
  • Горизонтальные или вертикальные панели вкладок (верх, низ, лево, право)
  • Переключение вкладок с помощью клавиатурных ярлыков
  • Создание и закрытие вкладок с помощью клавиатуры или мыши
  • Подсветка активной вкладки
  • Обрезка названий вкладок для длинных меток

Типы

tabRegion

type tabRegion struct {
    idx    int
    startX int
    endX   int
    closeX int // X позиция кнопки закрытия, -1 если отсутствует
}

tabRegion описывает кликабельную область в панели вкладок. Хранит:

Поле Тип Описание
idx int Индекс связанной вкладки, или -1 для области новой вкладки
startX int X-позиция, где начинается кликабельная область
endX int X-позиция, где заканчивается кликабельная область
closeX int X-позиция кнопки закрытия, -1 если отсутствует

TabGroup

type TabGroup struct {
    tabs      []*Tab
    activeTab int
    width     int
    height    int

    tabPosition      TabPosition
    tabRegions       []tabRegion
    newTabRegion     *tabRegion
    verticalTabWidth int
}

Поля:

Поле Тип Описание
tabs []*Tab Список всех вкладок в группе
activeTab int Индекс текущей активной вкладки
width int Текущая ширина панели
height int Текущая высота панели
tabPosition TabPosition Позиция панели вкладок (Top, Bottom, Left, Right, None)
tabRegions []tabRegion Вычисленные кликабельные области для панели вкладок
newTabRegion *tabRegion Область для создания новых вкладок (при клике на "+")
verticalTabWidth int Ширина вертикальной панели вкладок (вычисляется от самой широкой вкладки)

Функции

padRight

func padRight(s string, w int) string

Добавляет пробелы справа в строку до указанной ширины. Используется для отрисовки вертикальной панели вкладок, где все вкладки должны иметь одинаковую ширину.

Публичный API

NewTabGroup

func NewTabGroup(pos TabPosition) *TabGroup

Создает новый TabGroup с одной вкладкой по умолчанию, названной "main".

NewTab

func (tg *TabGroup) NewTab(name string) *Tab

Создает новую вкладку с заданным именем и переключается на неё. Возвращает созданную новую *Tab.

ActiveTab

func (tg *TabGroup) ActiveTab() *Tab

Возвращает текущую активную вкладку. Возвращает nil, если вкладок нет или индекс активного выходит за границы.

NextTab

func (tg *TabGroup) NextTab()

Переключается на следующую вкладку циклически. Работает только если вкладок больше одной.

PrevTab

func (tg *TabGroup) PrevTab()

Переключается на предыдущую вкладку циклически. Работает только если вкладок больше одной.

Ярлыки клавиатуры

Клавиша Действие
Ctrl+Tab Переключиться на следующую вкладку
Ctrl+Shift+Tab Переключиться на предыдущую вкладку
Ctrl+W Закрыть активную вкладку
Ctrl+T Создать новую вкладку
Ctrl+C Выйти из приложения

Поведение клика по панели вкладок

Клик по панели вкладок обрабатывает следующие действия:

  • Клик по вкладке: Переключение на эту вкладку
  • Клик по кнопке закрытия (×): Закрытие вкладки
  • Клик по кнопке "+": Создание новой вкладки
  • Клик по вертикальным вкладкам (лево/право): Клик по вкладке переключается на неё, клик по кнопке закрытия закрывает её

Отображение

View

func (tg *TabGroup) View(w, h int) string

Отрисовывает панель вкладок и содержимое активной вкладки. Поведение зависит от tabPosition:

  • TabTop / TabBottom: Отрисовывает панель вкладок выше или ниже содержимого
  • TabLeft / TabRight: Отрисовывает вертикальную панель вкладок слева или справа
  • TabNone: Отрисовывает только содержимое без панели вкладок

Elements

func (tg *TabGroup) Elements(w, h int) []Element

Реализует ElementProvider. Возвращает элементы активной вкладки со смещением, соответствующим позиции панели вкладок. Используется для тестирования попадания и позиционирования курсора.

Внутренние методы

closeTab

func (tg *TabGroup) closeTab(idx int)

Закрывает вкладку с заданным индексом. Если закрываемая вкладка была активной, переключается на последнюю вкладку (или первую, если осталась одна). Запрещает закрывание последней вкладки.

switchTab

func (tg *TabGroup) switchTab(idx int)

Устанавливает индекс активной вкладки. Внутренний метод, используемый другими методами.

contentWidth / contentHeight

func (tg *TabGroup) contentWidth(totalW int) int
func (tg *TabGroup) contentHeight(totalH int) int

Возвращает доступную ширину/высоту контента после вычитания ширины/высоты панели вкладок при наличии.

contentOffset

func (tg *TabGroup) contentOffset() (int, int)

Возвращает смещение (x, y) для контента на основе позиции панели вкладок. Используется для позиционирования элементов.

renderTabBar

func (tg *TabGroup) renderTabBar(width int) string

Делегирует либо renderHorizontalTabBar, либо renderVerticalTabBar на основе позиции панели вкладок.

renderHorizontalTabBar

func (tg *TabGroup) renderHorizontalTabBar(width int) string

Отрисовывает горизонтальную панель вкладок (верх или низ). Создает области вкладок, отрисовывает метки вкладок с обрезкой, и добавляет область новой вкладки ("+").

renderVerticalTabBar

func (tg *TabGroup) renderVerticalTabBar(_ int) string

Отрисовывает вертикальную панель вкладок (лево или право). Вычисляет максимальную ширину вкладки и отрисовывает все вкладки с правым подвалом. Создает область новой вкладки внизу ("+").

handleKeyMsg / handleMouseMsg

func (tg *TabGroup) handleKeyMsg(msg tea.Msg) tea.Cmd
func (tg *TabGroup) handleMouseMsg(msg tea.MouseMsg) tea.Cmd

Обработка клавиатурных и мышиных сообщений для группы вкладок. Делегирует сообщения, не обрабатываемые самой группой вкладок, на активную вкладку.

isOnTabBar

func (tg *TabGroup) isOnTabBar(x, y int) bool

Проверяет, находится ли заданная позиция (x, y) на панели вкладок. Возвращает true для позиций на панели вкладок, false иначе.

handleTabBarClick

func (tg *TabGroup) handleTabBarClick(msg tea.MouseMsg) tea.Cmd

Обрабатывает события клика по панели вкладок. Выполняет тестирование попадания по областям вкладок для определения действия (переключение вкладки, закрытие вкладки или создание новой).

shiftElements

func shiftElements(elems []Element, dx, dy int)

Рекурсивная вспомогательная функция, добавляющая смещения ко всем элементам и их дочерним. Используется Elements для применения смещения панели вкладок.

Update

func (tg *TabGroup) Update(msg tea.Msg) tea.Cmd

Обработка различных сообщений:

  • tea.KeyMsg: Делегируется handleKeyMsg
  • tea.MouseMsg: Делегируется handleMouseMsg
  • tea.WindowSizeMsg: Обновляет width/height и рассылает broadcast во вкладки
  • ResizeMsg: Обновляет width/height и рассылает broadcast во вкладки
  • PtyReadyMsg, PtyOutputMsg, и т.д.: Рассылается всем вкладкам

Пример использования

package main

import (
    "github.com/charmbracelet/bubbles/textarea"
    "github.com/charmbracelet/bubbles/tabgroup"
)

func main() {
    // Создать новую группу вкладок с вкладками сверху
    tg := tabgroup.NewTabGroup(tabgroup.TabTop)
    
    // Добавить начальную вкладку
    mainTab := tg.NewTab("main")
    
    // Добавить больше вкладок
    tg.NewTab("config")
    tg.NewTab("settings")
    
    // Отрисовать группу вкладок
    output := tg.View(80, 24)
    println(output)
}

Заметки

  • Названия вкладок обрезаются до 20 символов для горизонтальных вкладок и до 15 символов для вертикальных
  • Кнопка закрытия (×) появляется только на активной вкладке в горизонтальном режиме
  • В вертикальном режиме кнопки закрытия появляются на всех вкладках
  • Области вкладок вычисляются при каждой отрисовке
  • Кнопка "+" создает новую вкладку при клике или через Ctrl+T
  • Переключение вкладок обертывается (циклическое навигирование)
  • Последняя вкладка не может быть закрыта
