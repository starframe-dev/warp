TabGroup

TabGroup — панель Bubble Tea, которая отображает строку вкладок и переключает между дочерними вкладками. Её можно встраивать внутри splits, flex-раскладок или использовать как корневую панель TUI-приложения. Положение вкладок настраивается через TabPosition (top, bottom, left, right, none).

Типы

TabGroup хранит упорядоченный список панелей *Tab, отслеживает индекс активной вкладки и кэширует геометрию каждого кадра (ширину, высоту, области срабатывания вкладок), используемую для обработки кликов мыши.

Поведение

Переключение вкладок

NextTab и PrevTab переключают по кругу по списку вкладок с помощью модульной арифметики. Если вкладка одна, они ничего не делают. switchTab(idx) — внутренняя функция, которая ограничивает индекс до валидного диапазона перед обновлением activeTab.

Создание и закрытие вкладок

NewTab добавляет новую вкладку и сразу переключает на неё. closeTab удаляет вкладку по индексу; если закрывается активная вкладка, индекс активной ограничивается до последней оставшейся вкладки. Закрытие единственной вкладки не делает ничего.

Рендеринг

View собирает строку вкладок и содержимое активной вкладки, используя lipgloss.JoinVertical / lipgloss.JoinHorizontal в зависимости от TabPosition. Строка вкладок отображается как горизонтальный ряд меток вкладок (для top/bottom) или как вертикальный столбец (для left/right). Метки вкладок обрезаются до 20 символов (горизонтально) или до 15 символов (вертикально) с многоточием. У активной вкладки метка отображается с префиксом ▎ и глифом закрытия ×.

Взаимодействие с мышью

Область срабатывания строки вкладок (tabRegion) вычисляется заново каждый кадр во время рендеринга. Клик по вкладке переключает на неё, клик по глифу закрытия закрывает вкладку, а клик по области + / создаёт новую вкладку. Логика обработки кликов различается для горизонтальной и вертикальной раскладок строки.

Диспетчер сообщений

Update перехватывает tea.KeyMsg (ctrl+c, ctrl+tab, ctrl+shift+tab, ctrl+w, ctrl+t), tea.MouseMsg, tea.WindowSizeMsg и ResizeMsg. Все остальные сообщения broadcast'ятся на каждую вкладку, чтобы дочерние панели (например, PTY-эмуляторы) их получали.

Детали реализации

  • padRight дополняет строку пробелами до целевой ширины, используя подсчёт ширины с учётом rune в lipgloss.
  • tabRegion хранит границы кликов по вкладкам; idx == -1 отмечает область «новая вкладка».
  • Горизонтальная строка: области вычисляются слева направо с хвостовой областью +; вертикальная строка: области выстраиваются сверху вниз с областью + последней.
  • Геометрия содержимого (contentWidth, contentHeight, contentOffset) подстраивается под положение строки вкладок, чтобы дочерние панели выстраивались правильно.
  • shiftElements рекурсивно сдвигает границы элементов, чтобы обработка кликов оставалась согласованной после сдвига координат дочерних элементов строкой вкладок.
