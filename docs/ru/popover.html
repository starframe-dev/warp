Popover

Пакет popover предоставляет компонент контекстного меню, который накладывается поверх существующих строк контента в терминальном интерфейсе. Он отображает обводку с элементами меню и обрабатывает взаимодействия с мышью и клавиатурой для выбора элементов и выполнения действий.

Обзор пакета

Компонент popover построен с использованием bubbletea и lipgloss для стилизации и рендеринга. Он работает бесшовно с терминальным UI Warp, накладывая контент в указанной позиции, сохраняя существующий текст слева и справа от меню.

Popover

Контекстное меню, отображаемое в конкретной позиции, накладывающееся поверх существующего контента и сохраняющее его слева и справа.

type Popover struct {
    Items   []PopoverItem
    X, Y    int       // Позиция в координатах экрана (0 = строка заголовка)
    Width   int       // Ширина контента (0 = авто: 20)
    OnClose func()    // Вызывается при закрытии popover

    // отрисованные размеры (устанавливаются Overlay)
    boxW, boxH int

    // выбор
    selected int
}
Поле Тип Описание
Items []PopoverItem Массив элементов меню для отображения.
X int Горизонтальная позиция (в визуальных столбцах). 0 относится к строке заголовка.
Y int Вертикальная позиция (номер строки в координатах экрана). 0 = строка заголовка.
Width int Ширина контента в визуальных столбцах. 0 означает авто (по умолчанию 20).
OnClose func() Функция обратного вызова, вызываемая при закрытии popover (ESC, клик вне и т.д.).
boxW int Фактическая ширина отрисованного окна popover (устанавливается Overlay).
boxH int Фактическая высота отрисованного окна popover (устанавливается Overlay).
selected int Индекс текущего выбранного элемента (для навигации с клавиатуры).

Публичный API

Overlay

Отрисовывает popover поверх существующих строк контента.

func (p *Popover) Overlay(lines []string, totalW, totalH int) []string
Параметр Тип Описание
lines []string Исходные строки контента (одна на строку).
totalW int Общая ширина терминала в визуальных столбцах.
totalH int Общая высота терминала (количество строк).

Возвращает: Новый массив строк с отрисованным popover. Если элементы не заданы, возвращает исходные строки без изменений.

Подробности реализации:

  • Если Items пуст, возвращает исходные строки без изменений.
  • Автоматически ограничивает Width в пределах ширины терминала (минимум 20, если 0).
  • Ограничивает X и Y, чтобы popover оставался в пределах терминала.
  • Сохраняет исходный контент слева (leftPart) и справа (rightPart) от окна popover.
  • Использует стили lipgloss для создания обведённого окна с элементами меню.

HandleMouse

Обработчик событий мыши для popover.

func (p *Popover) HandleMouse(msg tea.MouseMsg) bool
Параметр Тип Описание
msg tea.MouseMsg Сообщение события мыши от bubbletea.

Возвращает: bool, указывающий, было ли событие обработано.

Поведение:

  • Нажатие мыши:
    • Если клик внутри окна меню, выполняется Action выбранного элемента и вызывает OnClose.
    • Если клик вне окна меню, вызывает OnClose для закрытия popover.
  • Движение мыши:
    • Обновляет индекс selected на основе позиции Y мыши для визуальной обратной связи при наведении.
    • Диапазон наведения исключает верхнюю и нижнюю границы.
  • Отпускание мыши: Обработчик события, но не выполняет никаких действий.

HandleKey

Обработчик событий клавиатуры для popover.

func (p *Popover) HandleKey(msg tea.KeyMsg) bool
Параметр Тип Описание
msg tea.KeyMsg Сообщение события клавиши от bubbletea.

Возвращает: bool, указывающий, было ли событие обработано.

Поведение:

  • ESC: Закрывает popover, вызывая OnClose.
  • ENTER: Выполняет действие текущего выбранного элемента. Вызывает OnClose после выполнения.
  • UP: Перемещает выбор вверх (зацикливание с первого элемента на последний).
  • DOWN: Перемещает выбор вниз (зацикливание с последнего элемента на первый).

Стили

Popover использует стили lipgloss для отрисовки:

var (
    popoverBaseStyle = lipgloss.NewStyle().
                    Background(lipgloss.Color(gbDark1)).
                    Foreground(lipgloss.Color(gbLight1))

    popoverSelectedStyle = lipgloss.NewStyle().
                    Background(lipgloss.Color(gbBlue)).
                    Foreground(lipgloss.Color(gbDark0))
)
Стиль Описание
popoverBaseStyle Базовый стиль для невыделенных элементов меню (тёмный фон, светлый текст).
popoverSelectedStyle Стиль для выбранного/подсвеченного элемента меню (синий фон, тёмный текст).

Пример использования

// Создание нового popover
items := []PopoverItem{
    {Name: "Copy", Action: func() { /* копирование в буфер обмена */ }},
    {Name: "Paste", Action: func() { /* вставка из буфера обмена */ }},
    {Name: "Cut", Action: func() { /* вырезание из источника */ }},
}

popover := Popover{
    Items: items,
    X:     10,
    Y:     5,
    Width: 20,
    OnClose: func() {
        // Обработка закрытия (например, очистка выбора, сброс UI)
    },
}

// Отрисовка popover поверх существующего контента
lines := []string{"Line 1", "Line 2", "Line 3"}
newLines := popover.Overlay(lines, 80, 24)

Важные примечания по реализации

  • Координаты позиции: X и Y являются относительными к экрану. Y=0 соответствует строке заголовка, как и координата Y мыши.
  • Ограничение ширины: Если Width равен 0 или отрицателен, он по умолчанию равен 20. Если он превышает ширину терминала, он ограничивается totalW.
  • Ограничение позиции: Popover автоматически ограничивается, чтобы оставаться в пределах терминала как в Overlay, так и в HandleMouse.
  • Сохранение контента: Наложение сохраняет исходный контент, разделяя строки на левую, короб и правую части.
  • Размеры коробки: boxW и boxH устанавливаются во время первого вызова Overlay и используются для тестирования попадания в HandleMouse.
  • Константы стилей: gbDark1, gbDark4, gbLight1, gbBlue, gbDark0 — это константы цветов из темы warp.
