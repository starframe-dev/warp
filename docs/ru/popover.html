popover

Пакет popover реализует контекстное всплывающее меню (поповер) для TUI на базе Bubbletea. Меню рендерится поверх существующих строк контента (без прокрутки основного представления) и поддерживает взаимодействие с мышью и клавиатурой: подсветка при наведении, активация по клику, обработка Enter/стрелок/Esc и автоматическое закрытие.

Типы

PopoverItem

type PopoverItem struct {
    Name   string
    Action func()
}

Описывает отдельный пункт меню. Name — подпись для рендеринга; Action — действие, вызываемое при активации пункта (кликом или Enter).

Popover

type Popover struct {
    Items   []PopoverItem
    X, Y    int
    Width   int
    OnClose func()
    boxW, boxH int
    clampedX, clampedY int
    selected int
}

Поля:

  • Items — пункты меню для рендеринга и активации.
  • X, Y — запрошенная позиция на экране (строка 0 соответствует строке заголовка).
  • Width — желаемая ширина контента; 0 означает авто (по умолчанию 20).
  • OnClose — обратный вызов, вызываемый при закрытии меню.

Оставшиеся поля (boxW/boxH, clampedX/clampedY, selected) — внутреннее состояние, поддерживаемое методами ниже.

Поведение

Overlay

func (p *Popover) Overlay(lines []string, totalW, totalH int) []string

Рендерит рамку меню поверх заданных строк контента и возвращает результирующие строки. Если Items пуст, входные строки возвращаются без изменений.

Метод:

  1. Строит строки контента (по одной на пункт), применяя стили выборки/базового состояния и ширину.
  2. Оборачивает меню в рамку с обычной границей lipgloss.
  3. Вычисляет размеры рамки и сохраняет их в boxW/boxH.
  4. Корректирует положение, удерживая его в пределах границ терминала, и сохраняет clampedX/clampedY.
  5. Вставляет каждую строку рамки в исходные строки, сохраняя контент слева и справа от рамки (используя ansi.Truncate и вспомогательную функцию для визуальной позиции байта).

HandleMouse

func (p *Popover) HandleMouse(msg tea.MouseMsg) bool

Обрабатывает события мыши для меню. Возвращает true, когда событие обработано и вызывающая сторона должна подавить обработку по умолчанию.

  • Нажатие внутри рамки: активирует пункт под курсором (с учётом верхней границы в 1 строку) и закрывает меню.
  • Нажатие снаружи: закрывает меню.
  • Движение: обновляет подсветку наведения, отслеживая пункт под курсором.
  • Отпуск: всегда потребляет событие.

Для проверки попадания используется корректированное положение, сохранённое при последнем вызове Overlay; если оно не установлено, используются X/Y.

HandleKey

func (p *Popover) HandleKey(msg tea.KeyMsg) bool

Обрабатывает события клавиатуры:

  • Esc — закрывает меню.
  • Enter — активирует выбранный пункт (если есть) и закрывает.
  • Up / Down — перемещает выборку с ограничением списком пунктов.

Любая другая клавиша возвращает false (не потребляется).

Стилизация

Используются два стиля lipgloss:

  • popoverBaseStyle — базовый цвет фона/текста пунктов.
  • popoverSelectedStyle — подсвеченное состояние выборки.

Граница рамки, цвета фона и переднего плана настраиваются в Overlay с использованием разделяемых констант цвета модуля (gbDark4, gbDark1).

Заметки о реализации

Меню компонируется из рамки с lipgloss и вставляется в существующие строки без их смещения, сохраняя контент слева/справа. Проверка попадания использует корректированное положение, сохранённое во время Overlay; предполагается, что координатное пространство мыши соответствует строкам/столбцам экрана.
