Selectable

Тип Selectable добавляет поддержку выделения текста к оборачиваемому Panel. Перетаскивание мышью и Shift+стрелки создают выделение, которое отображается с инвертированными цветами и может быть извлечено как обычный текст.

package warp

type Selectable struct {
    Content Panel
    AnchorX, AnchorY int
    CursorX, CursorY int
    HasSelection bool
    Selecting    bool
    lastW, lastH int
    lastLines    []string
}

Обзор

Selectable оборачивает любой Panel и добавляет:

  • Выделение мышью (нажатие/перемещение/отпускание левой кнопки)
  • Выделение с клавиатуры при помощи Shift+стрелки
  • Ctrl+A для выделения всего, Esc для сброса
  • Копирование выделенного текста в системный буфер обмена через OSC 52

Выделенная область отображается с использованием ANSI-стиля reverse-video (\x1b[7m), чтобы пользователь видел точно то, что выделено.

Не экспортированные поля lastW, lastH и lastLines кэшируют последние размеры рендеринга и строки, чтобы SelectedText мог извлекать текст, используя точно ту же систему координат, которая применялась при рендеринге.

Публичное API

func NewSelectable(content Panel) *Selectable

Создаёт новый Selectable, оборачивающий заданную панель. Всё состояние выделения начинается пустым.

func (s *Selectable) SelectedText() string

Возвращает текущий выделенный текст как обычную строку. Использует кэшированные строки рендеринга, чтобы система координат точно совпадала с тем, что видно на экране. Если View ещё не вызывался (например, в unit-тестах), откатывается к рендерингу с большими размерами (9999×9999).

func (s *Selectable) ClearSelection()

Удаляет текущее выделение, сбрасывая и HasSelection, и Selecting.

func (s *Selectable) Copy() tea.Cmd

Возвращает tea.Cmd, копирующий выделенный текст в системный буфер обмена через OSC 52. Предназначен для вызова при нажатии Ctrl+C пользователем. Возвращает nil, если выделение отсутствует.

func (s *Selectable) SelectAll(w, h int)

Выделяет весь видимый контент в пределах заданных ширины и высоты.

func (s *Selectable) View(w, h int) string

Рендерит оборачиваемый контент с подсветкой выделения. Кэширует рендерные строки для последующего извлечения текста. Ограничивает координаты выделения границами панели — ограничивается только конец-курсор, а анкер остаётся там, где пользователь изначально нажал, чтобы перетаскивание в обратном направлении продолжало работать корректно.

func (s *Selectable) Update(msg tea.Msg) tea.Cmd

Обрабатывает сообщения мыши и клавиатуры для выделения. Сообщения, не потреблённые логикой выделения, проксируются в оборачиваемый Panel.

Поведение

Выделение мышью

  • Нажатие (левая кнопка): Устанавливает анкер и курсор в позицию нажатия; Selecting становится true.
  • Перемещение: Двигает курсор; HasSelection устанавливается в true.
  • Отпускание: Финализирует позицию курсора; очищает выделение, если анкер и курсор совпадают.

Выделение с клавиатуры

  • Shift+Up / Shift+Down / Shift+Left / Shift+Right: Расширяет или создаёт выделение в заданном направлении. Shift+Tab намеренно не обрабатывается и проксируется в оборачиваемую панель (например, терминал), чтобы TUI-приложения внутри PTY его получали.
  • Ctrl+A: Выделяет весь видимый контент (откат к 80×24, если размеры неизвестны).
  • Esc: Сбрасывает выделение.

Рендеринг

View рендерит контент и применяет стиль reverse-video к выделенному диапазону. Диапазон вычисляется через sortedBounds, который нормализует анкер/курсор так, что start ≤ end. Строки вне диапазона выделения проходят без изменений. Подсветка применяется построчно с использованием визуального (rune) диапазона столбцов, поэтому корректно работает даже при наличии мультибайтовых UTF-8 символов в контенте.

Извлечение текста

SelectedText проходит по кэшированным строкам рендеринга и извлекает визуальный-диапазонный текст для каждой строки в выделении. ANSI escape-последовательности пропускаются, и собираются только rune в пределах запрошенного визуального диапазона. Это гарантирует, что извлечённый текст точно соответствует тому, что видит пользователь на экране.

Обработка ANSI / Unicode

Обе функции highlightRange и extractVisRange разбирают строку побайтово, отслеживая визуальную позицию rune. ANSI escape-последовательности (\x1b[...m) пропускаются без смещения визуальной позиции. Мультибайтовые UTF-8 символы декодируются через utf8.DecodeRuneInString. Это избегает некорректного нарезания сырых байт.

Детали реализации

  • Буфер обмена OSC 52: Метод Copy кодирует выделенный текст как base64 и излучает последовательность \x1b]52;c;<data>\x07. Это работает в альтернативном экране Bubbletea.
  • Перетаскивание в обратном направлении: Ограничивается по границам панели только конец-курсор; анкер остаётся как есть. Это гарантирует, что перетаскивание в обратном направлении по-прежнему работает корректно после изменения размера или повторного рендеринга.
  • Очистка выделения: Если после отпускания или шага с клавиатуры курсор и анкер совпадают, выделение автоматически сбрасывается.
  • Прокси-роутинг сообщений: Любое сообщение, не обработанное логикой выделения (нераспознанные клавиши, Shift+Tab, сообщения изменения размера и т.п.), передаётся в Content.Update(msg), сохраняя функциональность оборачиваемой панели.

Примеры использования

sel := NewSelectable(myPanel)
model.SetProgramView(sel)

// In the model update:
case tea.KeyMsg:
    if msg.String() == "ctrl+c" {
        return sel.Copy()
    }
    if msg.String() == "esc" {
        sel.ClearSelection()
    }

// To get the selected text (e.g. for paste or display):
text := sel.SelectedText()
