Selectable

Selectable обёртывает Panel с поддержкой выделения текста. Перетаскивание мышью и Shift+стрелки создают выделения текста. Выделенная область отображается с инвертированными цветами (инвертированный выделитель).

Обзор

Selectable — это обёртка для выделения текста, которая интегрируется с фреймворком Bubbletea TUI. Она предоставляет:

  • Выделение на основе мыши через перетаскивание
  • Клавиатурное выделение с Shift+стрелки
  • Копирование в буфер обмена через OSC 52
  • Выделение с инверсией цветов
  • Поддержка Unicode и последовательности ANSI для извлечения текста

Определение типа

type Selectable struct {
    Content Panel

    // Точка закрепления выделения (фиксирована при нажатии) и курсор (активный конец).
    // Обе координаты в клеточной системе относительно панели.
    AnchorX, AnchorY int
    CursorX, CursorY int

    HasSelection bool
    Selecting    bool // true во время активного перетаскивания мышью

    // Последние отрендеренные размеры и строки контента, используемые для извлечения
    // выделенного текста, который точно совпадает с тем, что сейчас видно.
    lastW, lastH int
    lastLines    []string
}

Тип Selectable поддерживает состояние выделения через:

  • Координаты точки закрепления: Фиксированная позиция, где началось выделение (при нажатии мыши или первом Shift+стрелка)
  • Координаты курсора: Активный конец выделения (куда перетаскивается мышь или куда последний нажатие стрелки)
  • lastW/lastH: Кэшированные размеры последнего отрендеренного контента
  • lastLines: Кэшированные отрендеренные строки для точного извлечения текста

Публичный API

NewSelectable

func NewSelectable(content Panel) *Selectable

Создаёт новую обёртку selectable вокруг Panel. Переданный контента становится обёрнутой панелью, которая будет отрендерена.

SelectedText

func (s *Selectable) SelectedText() string

Возвращает текущий выделенный текст. Если View ещё не вызывался (например, в тестовых функциях), возвращается большой рендер.

Детали реализации:

  • Использует те же отрендеренные строки, что и View для точности координат
  • Удаляет ANSI-escape коды перед извлечением текста
  • Запрещает координаты до границ линий
  • Корректно обрабатывает многобайтовые UTF-8 символы

ClearSelection

func (s *Selectable) ClearSelection()

Удаляет текущее выделение, очищая состояние выделения. Устанавливает HasSelection и Selecting в false.

Copy

func (s *Selectable) Copy() tea.Cmd

Возвращает tea.Cmd, который копирует выделенный текст в системный буфер обмена через OSC 52. Вызывайте это, когда пользователь нажимает Ctrl+C.

Реализация использует кодирование Base64 для совместимости с терминальными эмуляторами, которые поддерживают OSC 52.

SelectAll

func (s *Selectable) SelectAll(w, h int)

Выделяет весь видимый контент. Устанавливает точку закрепления выделения в (0, 0) и курсор в (w-1, h-1).

View

func (s *Selectable) View(w, h int) string

Отрендеривает контент с выделением. Запрещает выделение до границ панели. Если выделения нет, возвращает контент обёрнутой панели без изменений.

Детали реализации:

  • Кэширует отрендеренные строки для точного извлечения текста
  • Запрещает координаты выделения до границ панели
  • Применяет стилизацию инверсии цвета к диапазону выделения
  • Обрабатывает краевые случаи, когда курсор равен точке закрепления (очищает выделение, если всё ещё перетаскиваем)

Update

func (s *Selectable) Update(msg tea.Msg) tea.Cmd

Обрабатывает ввод мыши и клавиатуры для выделения. Обрабатывает:

  • ResizeMsg: Передаётся обёрнутому контенту
  • tea.MouseMsg: Обрабатывает перетаскивание левой кнопкой мыши для выделения
  • tea.KeyMsg: Обрабатывает Shift+стрелки для клавиатурного выделения и Ctrl+клавиши

Клавиатурные сочетания

Клавиша Действие
Shift+Вверх Перемещение курсора выделения вверх
Shift+Вниз Перемещение курсора выделения вниз
Shift+Влево Перемещение курсора выделения влево
Shift+Вправо Перемещение курсора выделения вправо
Ctrl+A Выделить весь видимый контент
Esc Очистить текущее выделение

Внутренние функции

sortedBounds

func (s *Selectable) sortedBounds() (sx, sy, ex, ey int)

Возвращает границы выделения с началом <= концом, меняя точку закрепления и курсор при необходимости для обеспечения правильной последовательности.

highlightRange

func highlightRange(line string, startX, endX int) string

Применяет выделение к визуальному диапазону [startX, endX). Проходит по строке, отслеживая визуальную позицию символа, чтобы корректно обрабатывать Unicode и ANSI-последовательности.

extractVisRange

func extractVisRange(line string, startX, endX int) string

Извлекает текст из визуального диапазона [startX, endX), пропуская ANSI-escape последовательности и обрабатывая многобайтовые UTF-8 символы.

Константы стилей

var (
    selectionStyleANSI = "\x1b[7m"
    resetStyle         = "\x1b[0m"
)
  • selectionStyleANSI: Стили инверсии видео (белый на чёрном)
  • resetStyle: Сброс к стилю по умолчанию

Важные замечания по реализации

Система координат

Все координаты в клеточных координатах относительно панели. Это отличается от позиционных значений в байтах, что важно для обработки:

  • Многобайтовых UTF-8 символов
  • ANSI-escape последовательностей
  • Различий между визуальным и байтовым позиционированием

Направление выделения

Точка закрепления выделения остаётся фиксированной там, где пользователь изначально нажал. Курсор движется. Это позволяет правильно работать с перетаскиванием в обратном направлении (например, перетаскивание влево, а затем вправо всё ещё выделяет тот же текст).

Точность извлечения текста

Реализация кэширует отрендеренные строки (lastLines), чтобы гарантировать, что извлечение текста использует ту же систему координат, что и рендеринг. Это предотвращает несоответствия между тем, что отображается, и тем, что извлекается.

Обработка ANSI

Обе highlightRange и extractVisRange корректно обрабатывают ANSI-escape последовательности,:

  • Пропуская escape последовательности, не учитывая их в визуальной позиции
  • Сохраняя escape последовательности в выводе, но переключая стиль вокруг них
  • Используя utf8.DecodeRuneInString для корректного обработки UTF-8

Поведение при сбросе

Если View ещё не вызывался (например, в тестовых функциях), SelectedText возвращается к рендерингу большого буфера (9999x9999), чтобы гарантировать, что границы выделения всё ещё правильно отображаются на строках контента.

Пример использования

s := warp.NewSelectable(contentPanel)

// Включить выделение
s.SelectAll(width, height)

// Или создать через перетаскивание мышью — обрабатывается автоматически в Update()

// Получить выделенный текст
selected := s.SelectedText()

// Скопировать в буфер обмена
copyCmd := s.Copy()
tea.Batch(func() tea.Msg {
    fmt.Println(copyCmd())
    return nil
})

// Очистить выделение при необходимости
s.ClearSelection()
