Ввод

Обзор

Компонент Input — это виджет однострочного текстового ввода, построенный на Bubble Tea. Он обеспечивает дружелюбный к TUI опыт текстового ввода с поддержкой клавиатуры, управлением курсором и настраиваемым рендерингом.

Когда высота составляет как минимум 3 клетки, ввод рендерится в обрамленной рамкой области. Иначе он рендерится встроено.

Типы

Input

type Input struct {
    Value   string
    Cursor  int // cursor position in runes
    Prompt  string
    Width   int // desired width (0 = auto from View w)
    focused bool
}

Поля:

  • Value — Текущее текстовое значение.
  • Cursor — Позиция курсора в символах (0 до len(Value)).
  • Prompt — Текст, отображаемый перед значением.
  • Width — Желаемая ширина; игнорируется во время рендеринга.
  • focused — Внутреннее состояние, указывающее, имеет ли ввод фокус.

Публичный API

Конструктор

func NewInput(prompt string) *Input

Создаёт новый Input с заданным prompt.

Управление значением

func (in *Input) SetValue(v string)

Заменивает значение ввода и помещает курсор в конец. Ограничивает курсор валидным диапазоном.

func (in *Input) SetCursor(pos int)

Устанавливает позицию курсора в символах. Автоматически ограничивает валидным диапазоном.

func (in *Input) Focused() bool

Сообщает, имеет ли ввод фокус.

func (in *Input) Focus()

Фокусирует ввод.

func (in *Input) Blur()

Убирает фокус с ввода.

Рендеринг

func (in *Input) View(w, h int) string

Рендерит ввод. Если h ≥ 3 он рисует обрамленную область; иначе рендерится встроено.

Ввод с клавиатуры

func (in *Input) Update(msg tea.Msg) tea.Cmd

Обрабатывает ввод с клавиатуры. Обрабатывает только tea.KeyMsg когда имеет фокус. Поддерживает:

  • backspace — Удаляет символ перед курсором.
  • delete — Удаляет символ под курсором.
  • left — Перемещает курсор влево.
  • right — Перемещает курсор вправо.
  • home — Перемещает курсор в начало.
  • end — Перемещает курсор в конец.
  • tab / shift+tab — Переход фокуса (обработка родительским).
  • enter — Отправка (no-op).
  • любой символ — Вставка символа под курсором.

Детали реализации

Ограничение курсора

Метод clampCursor обеспечивает, чтобы курсор оставался в допустимых пределах [0, len(runes)]. Вызывается после изменений значения и установки курсора.

Обрезка

Когда значение плюс prompt превышает доступную ширину, truncateTailToWidth сдвигает видимую часть, чтобы держать курсор видимым у правого края.

Стили

    inputStyle           = lipgloss.NewStyle().Foreground(lipgloss.Color(gbLight1))
    inputBorderStyle     = lipgloss.NewStyle().Foreground(lipgloss.Color(gbDark4))
    inputFocusBorderStyle = lipgloss.NewStyle().Foreground(lipgloss.Color(gbBlue))

Стили применяются на основе состояния фокуса:

  • Не фокусированный — inputBorderStyle
  • Фокусированный — inputFocusBorderStyle

Режимы рендеринга

viewBoxed — Рендерит с верхним/нижним/левым/правым обрамлением используя ASCII символы ╭╮╰╯│.

viewInline — Рендерит как одиночная строка, полезно для компактных макетов.

Вставка символов

Символы вставляются в позицию курсора. Многобайтовые UTF-8 символы обрабатываются через срезы runes, обеспечивая правильное позиционирование курсора.

Удаление

deleteBeforeCursor удаляет символ непосредственно перед курсором и уменьшает позицию курсора.

deleteAtCursor удаляет символ в позиции курсора.

Пример использования

in := NewInput("Username:")
in.SetValue("alice")

// Handle input
if in.Focused() && msg.String() == "a" {
    in.Update(msg)
}

// Render
view := in.View(termWidth, termHeight)

Заметки

  • Все позиции курсора измеряются в символах, а не байтах.
  • Поле Width хранится, но игнорируется во время рендеринга; фактическая ширина определяется контейнером.
  • Tab и shift+tab — no-op; переход фокуса должен обрабатываться родительским приложением.
  • Enter — в настоящее время no-op; может быть расширен для отправки пользовательских сообщений.
