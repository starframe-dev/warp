Dropdown Menu (dropdown.go)

Файл dropdown.go реализует переиспользуемый компонент TUI-выпадающего списка на базе фреймворка bubbletea. Он моделирует классическое взаимодействие «кнопка + разворачиваемый список»: свёрнутая кнопка, которая при активации раскрывается в вертикально выстроенный список элементов, один из которых можно выбрать.

Публичный API

DropdownItem (struct)

Представляет единственную запись в выпадающем списке.

type DropdownItem struct {
    Label    string
    Selected bool
}

DropdownMenu (struct)

Хранит полное состояние выпадающего списка: его метку, список элементов, флаг открытия, индекс наведённого элемента и回调 для обработки выбора.

type DropdownMenu struct {
    Label    string
    Items    []DropdownItem
    Open     bool
    Hovered  int // index of hovered item, -1 if none
    OnSelect func(idx int)
}

NewDropdownMenu

Конструктор, который создаёт закрытый выпадающий список.

func NewDropdownMenu(label string, items []DropdownItem) *DropdownMenu
  • label — текст, отображаемый на свёрнутой кнопке.
  • items — срез значений DropdownItem, отображаемых в открытом меню.

DropdownMenu.View(w, h int) string

Отрисовывает выпадающий список как многострочную строку. Метод переключается между свёрнутой кнопкой и открытым меню на основе d.Open и ограничивает высоту доступными h строками.

DropdownMenu.Update(msg tea.Msg) tea.Cmd

Обрабатывает сообщения мыши и клавиатуры для выпадающего списка:

  • Нажатие мыши по кнопке (строка y = 0) переключает открытие/закрытие.
  • Нажатие мыши по строке элемента выбирает этот элемент.
  • Клавиши up/down перемещают наведение; enter выбирает наведённый элемент; esc закрывает меню.

DropdownMenu.Close()

Программно закрывает меню и сбрасывает состояние открытости.

Поведение

Автомат состояний

Выпадающий список имеет два видимых состояния, управляемых флагом Open:

  • Закрыто: отрисовывается только строка кнопки, отображающая Label + " ▼".
  • Открыто: строка кнопки отображает Label + " ▲", а под ней отрисовывается список элементов. Состояние наведения и выбора отслеживается с помощью Hovered (индекс, -1 если отсутствует) и флага DropdownItem.Selected каждого элемента.

Взаимодействие с мышью

  • Если меню закрыто и пользователь нажимает на строку 0 (кнопку), Open устанавливается в true, а Hovered сбрасывается в -1.
  • Если меню открыто и пользователь нажимает на строку 0, меню закрывается.
  • Если меню открыто и пользователь нажимает на строку внутри списка элементов, соответствующий элемент выбирается (устанавливается его флаг Selected, другие элементы очищаются, Open устанавливается в false, и вызывается OnSelect, если оно не равно nil).

Взаимодействие с клавиатурой

  • up/down: перемещает Hovered в пределах границ списка элементов.
  • enter: выбирает наведённый элемент с той же логикой, что и при выборе мышью.
  • esc: закрывает меню, ничего не выбирая.

Семантика выбора

Выбор элемента (мышью или с помощью enter) очищает флаг Selected для всех элементов, устанавливает его для выбранного, закрывает меню и вызывает OnSelect(idx). Поле OnSelect является необязательным — если оно равно nil, callback не вызывается.

Замечания о реализации

  • Отрисовка выполняется через неэкспортируемые вспомогательные функции renderButton(w) и renderMenu(w, h), которые вызываются из View. Высота меню ограничивается значением h, поэтому выпадающий список никогда не выходит за пределы доступного вертикального пространства.
  • Метки усечаются символом …, если они длиннее доступной ширины w.
  • Выравнивание строк использует вспомогательную функцию padRight(label, w) (определённую в другом месте пакета), которая дополняет метки пробелами справа до ширины колонки.
  • Стили применяются построчно с помощью dropdownButtonStyle, dropdownItemStyle, dropdownItemHoverStyle и dropdownItemSelectedStyle (определённых в другом месте пакета). Текущая наведённая строка использует стиль наведения, а выбранный элемент — стиль выбора.
  • Обрабатываются только нажатия мыши (tea.MouseActionPress); другие действия мыши игнорируются. Update всегда возвращает nil, так как выпадающий список не планирует дополнительных команд.

Интеграция с bubbletea

Компонент встраивается в более крупную модель: принимающая модель должна вызывать View(w, h) в рамках собственного View() (передавая ширину/высоту области) и прокидывать релевантные значения tea.Msg в Update. Принимающая модель отвечает за размещение возвращаемой строки в финальном кадре и за вызов Close(), когда требуется закрыть выпадающий список извне компонента.

Пример

menu := NewDropdownMenu("Color", []DropdownItem{
    {Label: "Red", Selected: false},
    {Label: "Green", Selected: true},
    {Label: "Blue", Selected: false},
})
menu.OnSelect = func(idx int) {
    fmt.Println("selected:", menu.Items[idx].Label)
}
