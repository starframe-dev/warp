Выпадающее меню

Обзор

Этот модуль реализует виджет выпадающего меню для системы UI Warp. Он предоставляет компонент раскрывающегося меню, который можно открыть для отображения списка выбираемых элементов. Выпадающее меню поддерживает навигацию с помощью мыши и клавиатуры, выбор элементов и пользовательские обратные вызовы.

Типы

DropdownItem

type DropdownItem struct {
    Label    string
    Selected bool
}

DropdownItem представляет одиночный элемент выпадающего меню.

Поле Тип Описание
Label string Текстовая метка, отображаемая для этого элемента выпадающего меню.
Selected bool Указывает, выбран ли этот элемент в данный момент. Одновременно может быть выбран только один элемент.

DropdownMenu

type DropdownMenu struct {
    Label    string
    Items    []DropdownItem
    Open     bool
    Hovered  int
    OnSelect func(idx int)
}

DropdownMenu — это панель, которая отображает кнопку и раскрывающийся список элементов.

Поле Тип Описание
Label string Текст метки для кнопки выпадающего меню (отображается при закрытом состоянии).
Items []DropdownItem Список элементов выпадающего меню для отображения в меню.
Open bool Указывает, открыто ли выпадающее меню в данный момент (раскрыто) или закрыто.
Hovered int Индекс, используемый для стилизации. Устанавливается в -1 при открытии меню или клике по кнопке. Не обновляется при наведении мыши.
OnSelect func(idx int) Функция обратного вызова, которая вызывается при выборе элемента.

NewDropdownMenu

func NewDropdownMenu(label string, items []DropdownItem) *DropdownMenu

Создаёт новое выпадающее меню с заданным меткой и элементами.

Параметры:

Параметры:

  • h — Высота в символах для рендеримого вывода

Возвращает:

  • Строка, содержащая рендеримый вывод с использованием стилей текста Bubble Tea

Update

Обрабатывает ввод с помощью мыши и клавиатуры для выпадающего меню.

Параметры:

  • msg — Сообщение Bubble Tea (событие мыши или клавиатуры)

Возвращает:

  • tea.Cmd (nil в этой реализации, команды не выдаются)

Close

func (d *DropdownMenu) Close()

Закрывает выпадающее меню, устанавливая Open в false.

Это может быть вызвано вручную или через ввод с клавиатуры (клавиша Escape).

Подробности поведения

Открытие выпадающего меню

Клик по кнопке выпадающего меню (при закрытом состоянии) открывает меню. Кнопка находится в строке 0 рендеримого вывода.

Закрытие выпадающего меню

Выпадающее меню можно закрыть:

  • Нажав по кнопке выпадающего меню
  • Нажав клавишу Escape
  • Вызвав метод Close()

Навигация по меню

Когда выпадающее меню открыто, пользователи могут навигировать по элементам с помощью:

  • ↑ (стрелка вверх) — Перемещение выбора вверх
  • ↓ (стрелка вниз) — Перемещение выбора вниз

Поле Hovered устанавливается в -1 при открытии меню или клике по кнопке. Оно используется для рендеринга стилей, но не обновляется при событиях наведения мыши.

Выбор элемента

Элемент выбирается:

  • Нажав Enter при навигации по элементам
  • Нажав по элементу в меню

При выборе элемента:

  1. Все остальные элементы имеют Selected, установленный в false
  2. Выбранный элемент имеет Selected, установленный в true
  3. Выпадающее меню автоматически закрывается
  4. Обратный вызов OnSelect вызывается с индексом выбранного элемента

Поведение рендеринга

  • Текст обрезается, чтобы поместиться в доступную ширину, с … в конце при необходимости
  • Ряд с кнопкой показывает метку со ▼ (стрелка вниз) при закрытом состоянии, ▲ (стрелка вверх) при открытом
  • Выбранные элементы префиксируются ✓
  • Элементы с индексом Hovered получают особую стилизацию (но Hovered устанавливается только по клику на кнопку, а не по наведению мыши)
  • Выбранные элементы получают особую стилизацию

Пример использования

Создание и использование выпадающего меню

package main

import (
    "fmt"
    warp "your/module/path"
)

func main() {
    // Создаём элементы выпадающего меню
    items := []warp.DropdownItem{
        {Label: "Option 1"},
        {Label: "Option 2"},
        {Label: "Option 3"},
    }

    // Создаём выпадающее меню с обратным вызовом
    dropdown := warp.NewDropdownMenu("Select:", items)
    dropdown.OnSelect = func(idx int) {
        fmt.Printf("Selected item at index: %d\n", idx)
    }

    // Рендерим выпадающее меню (изначально закрыто)
    view := dropdown.View(40, 10)
    fmt.Println(view)

    // Открываем выпадающее меню
    dropdown.Open = true
    view = dropdown.View(40, 10)
    fmt.Println(view)

    // Закрываем выпадающее меню
    dropdown.Close()
    view = dropdown.View(40, 10)
    fmt.Println(view)
}

Стили

Выпадающее меню использует систему стилей текста Bubble Tea для рендеринга. Следующие константы стилей используются внутри:

  • dropdownButtonStyle — Стиль для кнопки выпадающего меню
  • dropdownItemStyle — Стандартный стиль для элементов меню
  • dropdownItemHoverStyle — Стиль для элементов при наведении
  • dropdownItemSelectedStyle — Стиль для выбранных элементов
