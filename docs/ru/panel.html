Панель

Пакет Panel предоставляет гибкий интерфейс для создания интерактивных контентных панелей в приложениях warp. Он построен на базе библиотеки Bubble Tea для управления состоянием UI терминала.

Обзор

Panel представляет собой контентную панель, которая может отображаться в терминальном приложении warp. Панели поддерживают:

  • Отрисовку контента при заданных размерах
  • Обработку событий ввода (клавиатура, мышь и т.д.)
  • Интеграцию с сообщениями и командами Bubble Tea

Интерфейс: Panel

type Panel interface {
    // View renders the panel content at the given size.
    View(width, height int) string

    // Update handles Bubbletea messages (keys, mouse, etc).
    // The panel receives only messages that arrived while it was focused.
    Update(msg tea.Msg) tea.Cmd
}

Методы

View(width, height int) string

Получает размеры терминала и возвращает строку, содержащую отрисованный контент.

Параметр Тип Описание
width int Доступная ширина в колонках
height int Доступная высота в строках

Update(msg tea.Msg) tea.Cmd

Обрабатывает сообщение Bubble Tea и возвращает опциональную команду для выполнения.

Параметр Тип Описание
msg tea.Msg Сообщение от Bubble Tea (нажатие клавиши, мышь, таймер и т.д.)

Примечание: Панель получает только те сообщения, которые поступили, пока она была сфокусирована. Используйте состояние фокуса, чтобы определить, должна ли панель реагировать на ввод.

Типы

BasePanel

BasePanel — это структура, которая предоставляет нетривиальную реализацию интерфейса Panel. Встраивайте его в свои собственные типы панелей и переопределяйте только те методы, которые вам нужны.

type BasePanel struct{}

func (BasePanel) View(width, height int) string {
    return ""
}

func (BasePanel) Update(msg tea.Msg) tea.Cmd {
    return nil
}

Встраивание BasePanel

Чтобы создать свою собственную панель, встройте BasePanel и переопределите конкретные методы:

type MyPanel struct {
    BasePanel
    title string
    rows  int
}

func (p *MyPanel) View(width, height int) string {
    // Implement custom rendering
    return p.title + "\n" + p.renderContent()
}

func (p *MyPanel) Update(msg tea.Msg) tea.Cmd {
    // Handle input
    switch msg := msg.(type) {
    case tea.KeyMsg:
        if msg.String() == "q" {
            return tea.Quit
        }
    }
    return nil
}

Примеры использования

Создание простой текстовой панели

import (
    warp "your/project/warp"
    tea "github.com/charmbracelet/bubbletea"
)

type TextPanel struct {
    warp.BasePanel
    text string
}

func (p *TextPanel) View(width, height int) string {
    lines := 0
    var output strings.Builder
    for _, line := range strings.Split(p.text, "\n") {
        if len(line) > width {
            line = line[:width]
        }
        output.WriteString(line)
        if lines < height-1 {
            output.WriteString("\n")
            lines++
        }
    }
    return output.String()
}

func (p *TextPanel) Update(msg tea.Msg) tea.Cmd {
    return nil
}

Создание интерактивной панели формы

type FormPanel struct {
    warp.BasePanel
    fields []string
    value  map[string]string
}

func (p *FormPanel) View(width, height int) string {
    var output strings.Builder
    for i, field := range p.fields {
        output.WriteString(fmt.Sprintf("%d. %s: %s\n", i+1, field, p.value[field]))
    }
    return output.String()
}

func (p *FormPanel) Update(msg tea.Msg) tea.Cmd {
    if enterMsg, ok := msg.(tea.KeyMsg); ok {
        if enterMsg.String() == "enter" {
            // Handle submission
            return tea.Quit
        }
        if enterMsg.String() == "tab" {
            // Move to next field
            return tea.Batch(
                tea.Key(func() tea.Msg { return tea.KeyEnter }),
                tea.Quit,
            )
        }
    }
    return nil
}

Важные замечания

  • Всегда обрабатывайте события изменения размера терминала (параметры width/height)
  • Возвращайте tea.Quit или соответствующие команды в Update при необходимости
  • Используйте состояние фокуса, чтобы определить, какие сообщения должна получать панель
  • Возвращайте nil для View, если вы хотите пустую панель
  • Возвращайте nil для Update, если не должна выполняться команда
