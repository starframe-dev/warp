theme.go

Обзор

theme.go предоставляет публичное API времени выполнения для изменения цветовой темы пакета пользовательского интерфейса терминала Warp. Она определяет ThemeColors — плоскую структуру с семантическими именами цветов — и SetTheme, которая сопоставляет эти цвета со всеми переменными стилей и цветов на уровне пакета, используемыми оверлеями и элементами управления (вкладки, рамки, плавающие панели, выпадающие списки, поповеры, модальные окна, поля ввода, раскрывающиеся блоки и другие).

Warp поставляется с палитрой Gruvbox Dark по умолчанию (объявленной в styles.go). Переменные в styles.go и в других файлах элементов (input.go, modal.go, popover.go, dropdown.go и т.д.) инициализируются этой палитрой, а SetTheme перестраивает их на месте во время выполнения, чтобы все существующие элементы немедленно принимали новые цвета.

Публичное API

ThemeColors

type ThemeColors struct { Background string Surface string Raised string Border string BorderMuted string Text string TextMuted string TextStrong string Accent string AccentMuted string Error string Success string Warning string SelectionBackground string SelectionForeground string }

ThemeColors хранит семантические имена цветов в виде простых строк (строки цветов CSS, например "#282828"). Это контракт входа для SetTheme. Полей — 15, сгруппированных по назначению:

ПолеНазначение

SurfaceПанели, плавающие окна, модальные окна и раскрывающиеся блоки
RaisedПовышенные элементы (кнопки выпадающих списков, hover в выпадающих списках, выбранные элементы выпадающих списков)
BorderОсновной цвет рамки для панелей и модальных окон
BorderMutedПриглушённая рамка для рамок полей ввода, рамок выпадающих списков
TextЦвет текста по умолчанию (используется там, где палитра на него ссылается)
TextMutedПриглушённый / вторичный текст (имена неактивных вкладок, затенённый текст, рамка плавающих окон)

SetTheme

func SetTheme(colors ThemeColors)

Перестраивает все переменные цвета и стилей на уровне пакета из переданных ThemeColors. Функция не выполняет проверку ошибок и не возвращает значение. Любой элемент, отрисованный после вызова — включая уже сконструированные элементы, отрисовка которых происходит лениво во время отрисовки, — примет новые значения.

Внутри SetTheme:

  1. Преобразует каждую строку hex-цвета в ThemeColors в lipgloss.Color и присваивает ей соответствующую переменную палитры Gruvbox (gbDark0, gbDark1, gbDark2, gbDark3, gbDark4, gbGray, gbLight1, gbRed, gbGreen, gbYellow, gbBlue).
  2. Выводит все семантические переменные цвета из переменных палитры: tabBarBg, activeTabBg, activeTabFg, inactiveTabFg, newTabFg, closeTabFg, borderColor, borderDragColor, borderHoverColor, floatBorderColor, floatTitleBg, floatTitleFg, floatBg, floatCloseFg.
  3. Перестраивает каждое значение Style из lipgloss, зависящее от переменных цвета, покрывая панель вкладок, разделительные рамки, плавающие панели, раскрывающиеся блоки, выпадающие списки, поповеры, модальные окна, затенённый текст и элементы ввода.

Пример использования

package main

import (
    "fmt"

    "github.com/starframe-dev/warp"
)

func main() {
    // Apply a custom theme. Warp's default is Gruvbox Dark;
    // any 15-color palette can be supplied.
    warp.SetTheme(warp.ThemeColors{
        Background:          "#1e1e1e",
        Surface:             "#252525",
        Raised:              "#333333",
        Border:              "#555555",
        BorderMuted:         "#666666",
        Text:                "#cccccc",
        TextMuted:           "#999999",
        TextStrong:          "#eeeeee",
        Accent:              "#4f8aff",
        AccentMuted:         "#7aa0d4",
        Error:               "#e55",
        Success:             "#4c4",
        Warning:             "#ee8811",
        SelectionBackground: "#336699",
        SelectionForeground: "#ffffff",
    })
}

Детали реализации

  • Палитра по умолчанию: Палитра по умолчанию — Gruvbox Dark (см. styles.go). Переменные, которые SetTheme переопределяет, объявлены через var (а не const), чтобы их можно было переопределить во время выполнения.
  • Перестройка стилей, а не просто замена цветов: SetTheme не просто подменяет константы цветов. Она перестраивает каждый производный стиль lipgloss Style из обновлённых переменных цвета, так что любой стиль, кодирующий фон, передний план, жирность, отступы или стиль рамки, получает все новые значения одним вызовом.
  • Нет персистентности: Тема привязана к процессу. Нет взаимодействия с файлами, переменных окружения или глобальной конфигурации.
  • Идиотентность: Повторный вызов SetTheme просто переопределяет тот же набор переменных; побеждает последний вызов.

Примечания

  • SetTheme не возвращает ошибку. Невалидные или пустые строки цветов передаются в lipgloss как есть; поведение зависит от разбора строк в lipgloss.
  • SetTheme следует вызывать до отрисовки элементов, если вы хотите видеть новую тему. Элементы, кэширующие отрисованные строки до вызова, не обновятся.
  • ThemeColors — это плоский тип значения: у него нет методов и нет интерфейса. Он существует исключительно как запись-вход для SetTheme.
