Плавающий раздел

float.go реализует систему плавающих панелей в мультиплексоре терминала Warp. Он обеспечивает перетаскиваемые и изменяемые по размеру панели, которые могут быть наложены поверх основного макета.

Обзор пакета

Тип FloatPane представляет плавающую панель, отображаемую над основным макетом. Он поддерживает:

  • Перетаскиваемое позиционирование через верхнюю панель
  • Изменяемые границы на всех сторонах и углах
  • Кнопка закрытия с поведением закрытия по клику вне
  • Обработка последовательности ANSI для правильного отображения в терминале
  • Наложение рендеринга поверх существующего содержимого

Типы

FloatPane

Плавающая панель, которая отображается над основным макетом.

type FloatPane struct {
    Panel Panel
    X, Y  int
    Width int
    Height int
    Title string

    // State
    dragging       bool
    resizing       bool
    resizeEdge     string // "n", "s", "e", "w", "ne", "nw", "se", "sw"
    dragStartX     int
    dragStartY     int
    origX, origY   int
    origW, origH   int

    // CloseRequested устанавливается, когда пользователь нажимает кнопку ×.
    // Владеющая Tab проверяет это после handleMouse и вызывает CloseFloat.
    CloseRequested bool

    // CloseOnOutsideClick закрывает плавающее окно, когда пользователь кликает вне его.
    CloseOnOutsideClick bool
}

Методы

render(w, h int) []string

Рендерит плавающий раздел в строки.

func (fp *FloatPane) render(w, h int) []string

Параметры:

  • w, h int — Ширина и высота (не используются, но часть сигнатуры)

Возвращает:

  • []string — Отрендеренные строки для плавающего раздела

Описание:

Создает новый слайс строк, представляющий плавающий раздел. Верхняя граница включает заголовок и кнопку закрытия. Область контента рендерит вид панели. Нижняя граница закрывает коробку. Метод обрезает заголовок, если он превышает доступную ширину.

handleMouse(msg tea.MouseMsg, mx, my int) tea.Cmd

Обрабатывает события мыши для этого плавающего раздела.

func (fp *FloatPane) handleMouse(msg tea.MouseMsg, mx, my int) tea.Cmd

Параметры:

  • msg tea.MouseMsg — Сообщение о событии мыши
  • mx int — Координата X мыши (относительно области контента, не абсолютный экран)
  • my int — Координата Y мыши (относительно области контента, не абсолютный экран)

Возвращает:

  • tea.Cmd — Команда, возвращаемая, если событие было обработано (например, для закрытия плавающего)

Описание:

Обрабатывает события левой кнопки мыши:

  • Нажатие: Проверяет клик по кнопке закрытия, перетаскивание по панели заголовка или изменение размера по краю. Если клик находится внутри области контента, оно перенаправляется в панель.
  • Движение: Обновляет позицию при перетаскивании или применяет изменение размера при изменении размера.
  • Отпускание: Очищает состояние перетаскивания и изменения размера.

hitEdge(x, y int) string

Определяет, над какой границей или углом находится курсор мыши.

func (fp *FloatPane) hitEdge(x, y int) string

Параметры:

  • x int — X мыши относительно плавающего
  • y int — Y мыши относительно плавающего

Возвращает:

  • string — Идентификатор границы/угла ("n", "s", "e", "w", "ne", "nw", "se", "sw") или пустая строка, если не на границе

applyResize(dx, dy int)

Применяет дельты изменения размера на основе текущей границы изменения размера.

func (fp *FloatPane) applyResize(dx, dy int)

Параметры:

  • dx int — Дельта X от начала изменения размера
  • dy int — Дельта Y от начала изменения размера

Описание:

Обновляет позицию и размеры плавающего на основе resizeEdge. Обеспечивает соблюдение ограничений минимального размера и поддержание неположительных координат:

  • width < floatMinWidth — Обрезается до floatMinWidth
  • height < floatMinHeight — Обрезается до floatMinHeight
  • x < 0 — Устанавливается в 0
  • y < 0 — Устанавливается в 0

Функции пакета

StripANSI(s string) string

Удаляет последовательности ANSI из строки.

func StripANSI(s string) string

Параметры:

  • s string — Входная строка, возможно содержащая ANSI-последовательности

Возвращает:

  • string — Строка с удаленными ANSI-последовательностями

Описание:

Удаляет последовательности вывода CSI (Control Sequence Introducer) (\x1b[...) из строк. Это необходимо для правильных вычислений визуальной ширины при рендеринге в терминале.

overlayFloat(lines []string, fp *FloatPane, totalW, totalH int)

Рисует плавающий раздел поверх существующих контента строк.

func overlayFloat(lines []string, fp *FloatPane, totalW, totalH int)

Параметры:

  • lines []string — Строки экрана (изменяются на месте)
  • fp *FloatPane — Плавающий раздел для наложения
  • totalW int — Общая ширина экрана
  • totalH int — Общая высота экрана

Описание:

Рисует плавающий раздел поверх существующего контента. Он:

  • Проверяет, находится ли плавающий внутри границ экрана
  • Получает строки, отрендеренные плавающим из render()
  • Обрезает ширину плавающего, чтобы он не выходил за пределы экрана
  • Правильно обрабатывает ANSI-последовательности, отслеживая визуальные позиции
  • Строит новые строки: префикс (контент перед плавающим) + стилизованный плавающий + суффикс (контент после плавающего)
  • Обеспечивает, чтобы обрезанный плавающий заканчивался последовательностью сброса (\x1b[0m) для предотвращения просачивания ANSI
