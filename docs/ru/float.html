warp — float.go (float pane)

Файл пакета float реализует всплывающую панель (floating panel), которая отображается поверх основного макета warp. Он владеет собственным прямоугольником (X, Y, Width, Height), отрисовывает заголовок и закрываемую рамку, обрабатывает взаимодействие с мышью (перетаскивание, изменение размера, закрытие, фокусирование) и, наконец, накладывается своё содержимое на уже отрендеренные строки экрана — всё это с учётом ANSI-последовательностей, чтобы стилизованный текст и рамки не порождали друг друга.

Публичный API

FloatPane

type FloatPane struct { Panel Panel X, Y, Width, Height int Title string // exported state used by the owner CloseRequested bool CloseOnOutsideClick bool // unexported interaction state (drag / resize bookkeeping) ... }

Всплывающая панель, которая состоит из обычной Panel плюс прямоугольник экрана. Экспортируемые поля:

  • Panel — провайдер содержимого. Вызывается с внутренним размером (Width-2, Height-2), чтобы 1-ячейная рамка не учитывалась.
  • X, Y, Width, Height — прямоугольник экрана.
  • Title — текст, отображаемый в строке заголовка.
  • CloseRequested — устанавливается в true, когда пользователь нажимает кнопку ×. Таб, владеющий панелью, отвечает за чтение этого флага после handleMouse и последующий вызов своей рутины CloseFloat.
  • CloseOnOutsideClick — если true, владелец может закрыть float, если пользователь кликнул вне его прямоугольника.

Поведение

Рендеринг — render(w, h)

Формирует фиксированный срез строк длиной Height. Первая строка — строка заголовка, последняя — нижняя рамка, а промежуточные строки — выход Panel.View, дополненный padContent.

  • Верхняя рамка строится из ╭ + заголовок + дефисы + × + ╮. Кнопка закрытия всегда занимает 4 визуальных столбца (╭ + " ×" + ╮). Если заголовок слишком широкий, он усечается многоточием (...), чтобы кнопка закрытия оставалась доступной.
  • Область содержимого — это padContent(fp.Panel.View(fp.Width-2, fp.Height-2), fp.Width-2, fp.Height-2). Каждая строка содержимого заворачивается в вертикальные символы рамки (│ ... │).
  • Нижняя рамка — ╰ ─ ... ─ ╯.

Обработка мыши — handleMouse(msg, mx, my)

Обрабатывает одно событие tea.MouseMsg с экранными координатами (mx, my) и возвращает tea.Cmd только когда событие было переслано во внутреннюю Panel.

Правила попадания (hit-testing):

  • Кнопка закрытия — ровно та ячейка, где relY == 0 и relX == fp.Width-2. Устанавливает CloseRequested и не пересылает событие в панель.
  • Перетаскивание заголовка — relY == 0 и 0 < relX < fp.Width-1. Переходит в состояние dragging и сохраняет точку начала.
  • Рёбра изменения размера — hitEdge мапит любое из восьми ячеек рамки в "n", "s", "e", "w" и четыре угла "nw", "ne", "sw", "se". Непустое ребро запускает жест resizing.
  • Внутренний клик — пересылается в fp.Panel.Update с координатами, сдвинутыми на одну ячейку, чтобы панель видела содержимое с нулевой основой.

Во время активного drag/resize проверка границ намеренно пропускается, чтобы указатель мог выйти за пределы прямоугольника float. В ином случае обработчик выходит, когда указатель вне [X, X+Width) × [Y, Y+Height).

ANSI-безопасность

Warp отображает стилизованный текст через lipgloss и Bubble Tea, поэтому сырые байтовые смещения не отображаются на визуальные столбцы. Два вспомогательных способа делают float безопасным для наложения:

StripANSI(s string) string

Удаляет из строки все \x1b[ (CSI) последовательности, пропуская байты параметров и последний байт. Результат — обычный текст, который можно безопасно измерить с помощью lipgloss.Width или ansi.StringWidth.

overlayFloat(lines []string, fp *FloatPane, totalW, totalH int)

Отрисовывает fp.render(totalW, totalH) поверх существующих lines, не трогая остальной экран. Для каждой строки он:

  1. Находит визуальный столбец fp.X, просканировав исходную строку побайтово, копируя полные ANSI-последовательности как непрозрачные единицы и считая визуальные ячейки одну за другой.
  2. Усекает стилизованную строку float так, чтобы она никогда не выходила за пределы totalW. Если усечение нужно, добавляется сброс \x1b[0m, чтобы усечённая строка не «пролила» цвет в суффикс.
  3. Пропускает исходные байты, которые float визуально покрывает.
  4. Добавляет оставшийся исходный суффикс как есть.

Функция идемпотентна: float, начинающийся в (0,0) при полном размере терминала, просто заменяет весь срез lines, оставляя каждый байт суффикса нетронутым.

Стилевые токены, используемые float

Float рендерится через четыре стили lipgloss, определённые в styles.go. Они намеренно собраны ровно из двух цветов из темы, чтобы рамка, заголовок, закрытие и фон легко перекрашивались через theme.go.

  • floatBorderStyle — символы рамки (╭│─╮╰╯).
  • floatTitleStyle — текст заголовка; жирный, фон и первый план из темы.
  • floatCloseStyle — глиф ×; жирный первый план.
  • floatBgStyle — непрозрачный фон для ячейки закрытия и угловых ячеек.

Пример

type FloatPane struct {
    Panel  Panel
    X, Y, Width, Height int
    Title string

    CloseRequested      bool
    CloseOnOutsideClick bool
}

// Typical owner loop:
func (t *Tab) handleMouse(msg tea.MouseMsg) tea.Cmd {
    fp := t.Float
    if fp == nil {
        return nil
    }
    cmd := fp.handleMouse(msg, msg.X, msg.Y)
    if fp.CloseRequested {
        t.CloseFloat()
    } else if fp.CloseOnOutsideClick && !fp.contains(msg.X, msg.Y) {
        t.CloseFloat()
    }
    return cmd
}

Заметки & ограничения

  • Float не является Panel. Это прямоугольник экрана, который содержит панель; сам float не владеет никакими клавишами, кроме тех, что потребляет handleMouse.
  • Кнопка закрытия занимает ровно одну ячейку (fp.Width-2, 0). Всё, что справа от неё, — часть угла ╮ и не является целью попадания.
  • Учёт drag/resize использует изначальный снимок (origX, origY, origW, origH), поэтому долгое перетаскивание никогда не накапливает ошибку округления.
  • render — единственная функция, которая создаёт стилизованные байты; overlayFloat и путь мыши только их потребляют.
