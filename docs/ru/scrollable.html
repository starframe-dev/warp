Скроллируемый

Обзор

Scrollable — это компонент-обёртка, который добавляет поддержку прокрутки к Panel. Когда контент превышает выделенную высоту, пользователи могут прокручивать колёсиком мыши или с клавиатуры. Он является частью пакета warp, созданного с помощью charmbracelet/bubbletea.

Определение типа

type Scrollable struct {
    Content Panel
    Offset  int // смещение прокрутки в строках
}

Scrollable обёртывает Panel с поддержкой прокрутки. Он поддерживает смещение, которое определяет видимую часть контента.

Публичный API

NewScrollable

func NewScrollable(content Panel) *Scrollable

Создаёт новую обёртку для прокрутки вокруг заданного Panel.

View

func (s *Scrollable) View(w, h int) string

Рендерит видимую область просмотра контента. Принимает выделенную ширину w и высоту h в строках. Возвращает строку, представляющую видимую часть контента, обрезанную до высоты области просмотра.

Update

func (s *Scrollable) Update(msg tea.Msg) tea.Cmd

Обрабатывает сообщения прокрутки (колесо мыши, клавиши клавиатуры). Возвращает команду для дальнейшего действия, если необходимо.

Подробности реализации

Поведение прокрутки

  • Колесо мыши вверх: прокрутка вверх на 3 строки
  • Колесо мыши вниз: прокрутка вниз на 3 строки
  • Клавиша стрелка вверх: прокрутка вверх на 1 строку
  • Клавиша стрелка вниз: прокрутка вниз на 1 строку
  • Клавиша Page Up: прокрутка вверх на 10 строк
  • Клавиша Page Down: прокрутка вниз на 10 строк

Все действия прокрутки ограничены валидными границами (смещение не может быть отрицательным или превышать высоту контента).

Рендеринг

Метод View рендерит полный контент неограниченной высоты, разделяет его на строки, а затем обрезает для показа только видимой части на основе текущего смещения. Пустые строки добавляются при необходимости для заполнения высоты области просмотра.

Заполнение строки (padLine)

func padLine(line string, w int) string

Вспомогательная функция, которая гарантирует, что строка имеет точно w символов в ширине. Если строка короче w, добавляются пробелы. Если длиннее, она аккуратно обрезается на правильной границе байта для сохранения последовательностей UTF-8.

Пример использования

package main

import (
    warp "your/module/path"
)

func main() {
    // Создаём панель с контентом
    content := &warp.Panel{
        Text: "Это длинный кусок текста, который переполнит область просмотра\nи потребует прокрутки.",
    }

    // Обёртываем его в скроллируемый
    scrollable := warp.NewScrollable(content)

    // Рендерим с размером области просмотра 80x24
    output := scrollable.View(80, 24)
}
