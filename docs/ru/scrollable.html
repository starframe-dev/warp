Scrollable

Scrollable — компонент Bubble Tea UI, который оборачивает любой Panel и добавляет поддержку прокрутки. Когда рендеруемый контент превышает выделенную высоту, видимая часть ограничивается h строками, а пользователь может прокручивать остальное содержимое колесом мыши или клавиатурой.

Публичный API

type Scrollable struct {
    Content Panel
    Offset  int
}
Поле Тип Описание
Content Panel Вложенная панель, содержимое которой рендерится и прокручивается.
Offset int Текущее смещение прокрутки в строках. Отрицательные значения ограничиваются 0, значения выше максимального ограничиваются len(lines) - h.

NewScrollable

func NewScrollable(content Panel) *Scrollable

Создаёт новый Scrollable, оборачивающий заданный Panel. Начальное значение Offset равно нулю.

View

func (s *Scrollable) View(w, h int) string

Рендерит видимую область просмотра (viewport). Полное содержимое рендерится один раз с запрошенным шириной и фактически неограниченной высотой, разбивается на строки, а затем нарезается так, что отображаются только h строк, начиная с позиции s.Offset. Строки за пределами содержимого дополняются пробелами для заполнения области просмотра.

Update

func (s *Scrollable) Update(msg tea.Msg) tea.Cmd

Обрабатывает входящие сообщения Bubble Tea. Настройка s.Offset по сообщениям прокрутки колесом мыши и клавиатуры, после чего сообщение переправляется в s.Content, если он не nil.

Поведение прокрутки

Метод Update обрабатывает два типа сообщений:

  • tea.MouseMsg:
    • MouseButtonWheelUp — уменьшает смещение на 3 (с ограничением до 0)
    • MouseButtonWheelDown — увеличивает смещение на 3
  • tea.KeyMsg:
    • "up" — уменьшает смещение на 1 (с ограничением до 0)
    • "down" — увеличивает смещение на 1
    • "pgup" — уменьшает смещение на 10 (с ограничением до 0)
    • "pgdown" — увеличивает смещение на 10

После обработки сообщения прокрутки смещение ограничивается в View:

maxOffset := len(lines) - h
if maxOffset < 0 { maxOffset = 0 }
if s.Offset < 0 { s.Offset = 0 }
if s.Offset > maxOffset { s.Offset = maxOffset }

Это гарантирует, что область просмотра никогда не прокручивается за пределы содержимого.

Детали реализации

  • Стратегия рендеринга: вложенный Panel рендерится с View(w, 9999), то есть с очень большой высотой, так что всё его содержимое производится за один проход. Результат разбивается по "\n" на строки.
  • Дополнение/обрезка строк: каждая видимая строка проходит через хелпер уровня пакета padLine, который использует lipgloss.Width для определения отображаемой ширины. Строки короче w дополняются пробелами справа; строки длиннее w обрезаются по границе байта так, чтобы видимая ширина укладывалась в выделенный бюджет колонок.
  • Пересылка сообщений: любое сообщение, не влияющее на прокрутку (то есть не-мышечное, не-клавиатурное или клавиши, отличные от up/down/pgup/pgdown), пересылается в s.Content.Update(msg). Если s.Content равен nil, команда не возвращается.
