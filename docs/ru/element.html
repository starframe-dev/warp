Пакет Element

Пакет warp предоставляет типы и функции для представления семантических UI-элементов с их пределами экрана. Этот пакет предназначен для работы с системой окон Warp, позволяя программный доступ к UI-элементам из кода на Go.

Типы

Element

Element представляет семантический UI-элемент с его пределами экрана и необязательными дочерними элементами.

type Element struct {
    Role     string    `json:"role"`
    Name     string    `json:"name"`
    Action   string    `json:"action,omitempty"`
    Bounds   Bounds    `json:"bounds"`
    Children []Element `json:"children,omitempty"`
}

Поля:

  • Role — Роль элемента (например, "button", "label", "container")
  • Name — Уникальное или описательное имя для элемента
  • Action — Действие, связанное с элементом (необязательно)
  • Bounds — Прямоугольные пределы элемента в координатах ячеек
  • Children — Дочерние элементы, вложенные в данный элемент (необязательно)

Bounds

Bounds определяет прямоугольную область экрана в координатах ячеек.

type Bounds struct {
    X int `json:"x"`
    Y int `json:"y"`
    W int `json:"w"`
    H int `json:"h"`
}

Поля:

  • X — Горизонтальная позиция (индекс ячейки)
  • Y — Вертикальная позиция (индекс ячейки)
  • W — Ширина в ячейках
  • H — Высота в ячейках

Методы

Bounds.Center()

Возвращает центральную ячейку пределов.

func (b Bounds) Center() (int, int)

Пример:

bounds := Bounds{X: 0, Y: 0, W: 4, H: 4}
cx, cy := bounds.Center()
// cx = 2, cy = 2

Интерфейс: ElementProvider

ElementProvider реализуется панелями, которые могут экспортировать свои UI-элементы.

type ElementProvider interface {
    Elements(width, height int) []Element
}

Метод Elements возвращает срез структур Element, представляющих UI-элементы, отрисованные в заданных измерениях.

ElementProviderFunc

ElementProviderFunc адаптирует простую функцию к интерфейсу ElementProvider.

type ElementProviderFunc func(width, height int) []Element

Этот тип позволяет использовать функцию напрямую там, где ожидается ElementProvider:

// Определить функцию
myElements := func(width, height int) []Element {
    return []Element{
        {Role: "button", Name: "Submit", Bounds: Bounds{X: 0, Y: 0, W: 1, H: 1}},
    }
}

// Использовать её
if ep, ok := somePanel.(ElementProvider); ok {
    elements := ep.Elements(800, 600)
} else {
    elements := myElements(800, 600)
}

Функции

collectElements

Возвращает элементы из панели, если она реализует ElementProvider.

func collectElements(panel Panel, width, height int) []Element

Использование:

elements := collectElements(myPanel, 800, 600)

Если панель nil или не реализует ElementProvider, возвращается пустой срез.

FindElement

Рекурсивно ищет элементы для первого совпадения role/name/action.

func FindElement(elems []Element, role, name, action string) (Element, bool)

Параметры:

  • elems — Корневой срез элементов для поиска
  • role — Роль для сопоставления (пустая строка означает любую роль)
  • name — Имя для сопоставления (пустая строка означает любое имя)
  • action — Действие для сопоставления (пустая строка означает любое действие)

Возвращает:

  • Сопоставленный Element или пустой Element, если не найден
  • Булево значение, указывающее, было ли найдено совпадение

Пример:

elem, found := FindElement(rootElements, "button", "", "submit")
if found {
    fmt.Println("Found button:", elem.Name)
}

Поиск рекурсивный и будет искать в дочерних элементах, если совпадение не найдено на текущем уровне.
