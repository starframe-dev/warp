Модуль Focus

Этот модуль обеспечивает управление фокусом с клавиатуры для панели Warp. Он определяет интерфейсы и функции для сбора, навигации и применения фокуса с клавиатуры по дереву панелей.

Типы

Focusable

type Focusable interface {
	Panel
	Focus()
	Blur()
	Focused() bool
}

Focusable — это панель, которая может принимать фокус с клавиатуры. Он расширяет интерфейс Panel и добавляет три метода:

  • Focus() — Передаёт фокус панели
  • Blur() — Убирает фокус с панели
  • Focused() bool — Сообщает, имеет ли панель в данный момент фокус

RawKeyReceiver

type RawKeyReceiver interface {
	Panel
	WantsRawKeys() bool
}

RawKeyReceiver — это панель, которая хочет принимать весь ввод с клавиатуры без перехвата. Это полезно для встраивания сырых эмуляторов терминала (например, PTY) внутри системы панелей.

applyFocus

func applyFocus(current, next Focusable)

Перемещает фокус от текущей панели к следующей, вызывая Blur() на текущей и Focus() на следующей.

Параметры:

  • current Focusable — Текущая фокусируемая панель (или nil)
  • next Focusable — Следующая фокусируемая панель (или nil)

Поведение:

  • Если current не равен nil и не совпадает с next, вызывает current.Blur()
  • Если next не равен nil, вызывает next.Focus()

Детали реализации

Система фокуса работает на структуре дерева панелей. Функция collectFocusables обходит это дерево и собирает все фокусируемые панели в визуальном порядке (слева направо, сверху вниз).

При навигации фокуса:

  • focusNext перемещает вперёд в визуальном порядке, оборачиваясь
  • focusPrev перемещает назад в визуальном порядке, оборачиваясь

Функция applyFocus обеспечивает корректные переходы состояний, убирая фокус со старой панели и устанавливая фокус на новой.
