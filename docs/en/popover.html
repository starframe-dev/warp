Popover

The popover package provides a context menu component that overlays on top of existing content lines in a terminal UI. It renders a bordered box containing menu items and handles mouse and keyboard interactions for item selection and actions.

Package Overview

The popover component is built using bubbletea and lipgloss for styling and rendering. It works seamlessly with the Warp terminal UI, overlaying content at a specified position while preserving existing text on the left and right sides of the menu.

Popover

A context menu rendered at a specific position, overlaying on top of existing content lines while preserving content left and right.

type Popover struct {
    Items   []PopoverItem
    X, Y    int       // Position in screen coordinates (0 = header row)
    Width   int       // Content width (0 = auto: 20)
    OnClose func()    // Called when popover is closed

    // rendered dimensions (set by Overlay)
    boxW, boxH int

    // selection
    selected int
}
Field Type Description
Items []PopoverItem Slice of menu items to display.
X int Horizontal position (in visual columns). 0 refers to the header row.
Y int Vertical position (line number in screen coordinates). 0 = header row.
Width int Content width in visual columns. 0 means auto (default 20).
OnClose func() Callback function called when the popover is closed (ESC, click outside, etc.).
boxW int Actual rendered width of the popover box (set by Overlay).
boxH int Actual rendered height of the popover box (set by Overlay).
selected int Index of the currently selected item (for keyboard navigation).

Public API

Overlay

Renders the popover on top of existing content lines.

func (p *Popover) Overlay(lines []string, totalW, totalH int) []string
Parameter Type Description
lines []string The original content lines (one per row).
totalW int Total terminal width in visual columns.
totalH int Total terminal height (number of lines).

Returns: A new slice of lines with the popover overlay rendered. If no items are set, returns the original lines unchanged.

Implementation Details:

  • If Items is empty, returns the original lines unchanged.
  • Automatically clamps Width to fit within terminal width (minimum 20 if 0).
  • Clamps X and Y to ensure the popover stays within terminal bounds.
  • Preserves original content on the left (leftPart) and right (rightPart) sides of the popover box.
  • Uses lipgloss styles to create a bordered box with the menu items.

HandleMouse

Processes mouse events for the popover.

func (p *Popover) HandleMouse(msg tea.MouseMsg) bool
Parameter Type Description
msg tea.MouseMsg The mouse event message from bubbletea.

Returns: bool indicating whether the event was consumed.

Behavior:

  • Mouse Press:
    • If click is inside the menu box, executes the selected item's Action and calls OnClose.
    • If click is outside the menu box, calls OnClose to close the popover.
  • Mouse Motion:
    • Updates the selected index based on mouse Y position for hover visual feedback.
    • Hover range excludes the top and bottom borders.
  • Mouse Release: Consumes the event but performs no action.

HandleKey

Processes keyboard events for the popover.

func (p *Popover) HandleKey(msg tea.KeyMsg) bool
Parameter Type Description
msg tea.KeyMsg The key event message from bubbletea.

Returns: bool indicating whether the event was consumed.

Behavior:

  • ESC: Closes the popover by calling OnClose.
  • ENTER: Executes the action of the currently selected item. Calls OnClose after execution.
  • UP: Moves selection up (wraps from first item to last).
  • DOWN: Moves selection down (wraps from last item to first).

Usage Example

// Create a new popover
items := []PopoverItem{
    {Name: "Copy", Action: func() { /* copy to clipboard */ }},
    {Name: "Paste", Action: func() { /* paste from clipboard */ }},
    {Name: "Cut", Action: func() { /* cut from source */ }},
}

popover := Popover{
    Items: items,
    X:     10,
    Y:     5,
    Width: 20,
    OnClose: func() {
        // Handle close (e.g., clear selection, reset UI)
    },
}

// Render popover on top of existing content
lines := []string{"Line 1", "Line 2", "Line 3"}
newLines := popover.Overlay(lines, 80, 24)

Important Implementation Notes

  • Position Coordinates: X and Y are screen-relative. Y=0 corresponds to the header row, same as mouse Y coordinate.
  • Width Clamping: If Width is 0 or negative, it defaults to 20. If it exceeds terminal width, it's clamped to totalW.
  • Position Clamping: The popover is automatically clamped to stay within terminal bounds during both Overlay and HandleMouse.
  • Content Preservation: The overlay preserves original content by splitting lines into left, box, and right parts.
  • Box Dimensions: boxW and boxH are set during the first Overlay call and used for hit-testing in HandleMouse.
  • Style Constants: gbDark1, gbDark4, gbLight1, gbBlue, gbDark0 are color constants from the warp theme.
