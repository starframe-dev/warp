Tab API Documentation

tab.go implements the Tab type and related functionality for managing terminal tabs with flexible panel layouts. It provides APIs for splitting panels, flex layouts, floating panes, focus management, and mouse/keyboard event handling.

Public API

Creating a Tab

// NewTab creates a standalone Tab with no parent TabGroup.
// Useful for embedding a warp layout inside a Panel.
func NewTab(name string) *Tab

Creates a new standalone Tab with the given name. The tab will have an empty root panel that can be populated later.

func newTab(name string, parent *TabGroup) *Tab

Internal constructor that creates a tab with a parent TabGroup.

Root Panel Access

func (t *Tab) ensureRoot()

func (t *Tab) RootPanel() Panel
func (t *Tab) SetRootPanel(panel Panel)

These methods manage the root panel of a tab. RootPanel() returns the current root panel, and SetRootPanel() replaces it. ensureRoot() creates a root panel if none exists.

Split Operations

// SplitVertical splits the panel vertically (left/right).
// fraction is the share for the left panel (0.0–1.0).
func (t *Tab) SplitVertical(parent Panel, fraction float64, newPanel Panel)

// SplitHorizontal splits the panel horizontally (top/bottom).
// fraction is the share for the top panel (0.0–1.0).
func (t *Tab) SplitHorizontal(parent Panel, fraction float64, newPanel Panel)

Split methods divide the current panel into two parts. The first parameter is the existing panel to split, the second is the fraction for the first part, and the third is the new panel to insert.

Flex Layout Operations

// FlexRow replaces the parent panel with a horizontal flex layout.
func (t *Tab) FlexRow(parent Panel, items []FlexItemSpec)

// FlexColumn replaces the parent panel with a vertical flex layout.
func (t *Tab) FlexColumn(parent Panel, items []FlexItemSpec)

Flex methods create flex layouts with multiple panels. items is a slice of FlexItemSpec where each item specifies a panel and its grow weight.

Floating Panes

func (t *Tab) Float(panel Panel, x, y, width, height int)
func (t *Tab) CloseFloat(fp *FloatPane)

Float() makes a panel floating above the main layout at the given position. CloseFloat() removes a floating pane.

Focus Management

func (t *Tab) Focus() Panel
func (t *Tab) SetFocus(panel Panel) tea.Cmd
func (t *Tab) FocusNext()
func (t *Tab) FocusPrev()
func (t *Tab) FocusFirst()
func (t *Tab) FocusPanel(panel Panel)

Focus methods manage which panel receives input:

  • Focus() returns the currently focused panel
  • SetFocus() sets a new focused panel and returns any commands from its update
  • FocusNext() / FocusPrev() move focus to the next/previous focusable panel
  • FocusFirst() moves focus to the first focusable panel
  • FocusPanel() sets focus to a specific panel if it implements Focusable

Split Fraction Operations

func (t *Tab) SetSplitFraction(panel Panel, fraction float64) bool
func (t *Tab) GetSplitFraction(panel Panel) (float64, bool)

SetSplitFraction() updates the fraction of a split containing a panel. GetSplitFraction() returns the current fraction.

Collapse/Expand Operations

func (t *Tab) Collapse(panel Panel, size int) bool
func (t *Tab) Expand(panel Panel) bool

Collapse() shrinks a panel to a fixed size. Expand() restores it to its saved split fraction.

func (t *Tab) ToggleCollapsible(panel Panel)

Toggles the collapsed state of a collapsible panel.

Mouse Handling

HandleMouse() is the public entry point for embedded tabs. It processes mouse events including:

  • Floating pane interactions (focus, drag, close)
  • Border dragging for split resizing
  • Panel clicking for focus and collapsible toggling
  • Event forwarding to panels

Key Handling

func (t *Tab) handleKeys(msg tea.KeyMsg) tea.Cmd

Forwards key messages to the focused panel. Warp does not intercept Tab/Shift+Tab automatically; use FocusNext() and FocusPrev() for explicit focus switching.

Resize Handling

func (t *Tab) Update(msg tea.Msg) tea.Cmd

Update() implements the Panel update interface. It handles window size changes, resize messages, and broadcasts messages to all leaf panels. BroadcastResize() sends resize messages to all panels after a drag ends.
