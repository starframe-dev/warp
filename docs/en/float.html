Float Pane

float.go implements a floating panel system in the Warp terminal multiplexer. It provides draggable and resizable panels that can be overlaid on top of the main layout.

Package Overview

The FloatPane type represents a floating panel rendered above the main layout. It supports:

  • Draggable positioning via title bar
  • Resizable borders at all edges and corners
  • Close button with optional outside-click-to-close behavior
  • ANSI escape sequence handling for proper terminal rendering
  • Overlay rendering on top of existing content

Methods

render(w, h int) []string

Render the float pane into lines.

func (fp *FloatPane) render(w, h int) []string

Parameters:

  • w, h int — Width and height (unused, but part of signature)

Returns:

  • []string — Rendered lines for the float pane

Description:

Creates a new slice of lines representing the float pane. The top border includes the title and close button. The content area renders the panel view. The bottom border closes the box. The method trims the title if it exceeds the available width.

handleMouse(msg tea.MouseMsg, mx, my int) tea.Cmd

Process mouse events for this float pane.

func (fp *FloatPane) handleMouse(msg tea.MouseMsg, mx, my int) tea.Cmd

Parameters:

  • msg tea.MouseMsg — Mouse event message
  • mx int — Mouse X coordinate (relative to content area, not absolute screen)
  • my int — Mouse Y coordinate (relative to content area, not absolute screen)

Returns:

  • tea.Cmd — Command returned if event was handled (e.g., to close the float)

Description:

Handles left mouse button events:

  • Press: Checks for close button click, title bar drag, or edge resize. If the click is inside the content area, it forwards to the panel.
  • Motion: Updates position if dragging, or applies resize if resizing.
  • Release: Clears dragging and resizing state.

applyResize(dx, dy int)

Apply resize deltas based on the current resize edge.

func (fp *FloatPane) applyResize(dx, dy int)

Parameters:

  • dx int — X delta from resize start
  • dy int — Y delta from resize start

Description:

Updates the float's position and dimensions based on resizeEdge. Ensures minimum size constraints and non-negative coordinates are maintained:

  • width < floatMinWidth — Clamped to floatMinWidth
  • height < floatMinHeight — Clamped to floatMinHeight
  • x < 0 — Set to 0
  • y < 0 — Set to 0

overlayFloat(lines []string, fp *FloatPane, totalW, totalH int)

Draw the float pane on top of existing content lines.

func overlayFloat(lines []string, fp *FloatPane, totalW, totalH int)

Parameters:

  • lines []string — The screen lines (modified in place)
  • fp *FloatPane — The float pane to overlay
  • totalW int — Total screen width
  • totalH int — Total screen height

Description:

Draws the float pane on top of the existing content. It:

  • Checks if the float is within screen bounds
  • Receives the float's rendered lines from render()
  • Clamps the float width so it doesn't extend beyond the screen
  • Properly handles ANSI escape sequences by tracking visual positions
  • Builds new lines: prefix (content before float) + styled float + suffix (content after float)
  • Ensures the truncated float ends with a reset sequence (\x1b[0m) to prevent ANSI bleed-through

Usage Example

// Create a new float pane
fp := &FloatPane{
    Panel:     somePanel,
    X:         100,
    Y:         200,
    Width:     300,
    Height:    20,
    Title:     "My Float",
    CloseRequested: false,
    CloseOnOutsideClick: false,
}

// Render the float
lines := fp.render(80, 24)

// Overlay on screen
overlayFloat(screenLines, fp, 80, 24)

Rendering Flow

  1. Call render() to generate the float's visual lines
  2. Call overlayFloat() to composite the float onto the screen
  3. Handle mouse events via handleMouse() for dragging and resizing
  4. Periodically check CloseRequested to close the float
