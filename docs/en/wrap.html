wrap

wrap is a Go package that provides text wrapping functionality. It offers two main wrapping strategies: word-based wrapping and space-based wrapping.

Public API

The package exposes the following public functions:

func WordWrap(text string, width int) []string
func SpaceWrap(text string, width int) []string
func WrapToString(text string, width int, useSpaceWrap bool) string

Functions

WordWrap

func WordWrap(text string, width int) []string

WordWrap wraps text at word boundaries so that no line exceeds the specified width. If a word is longer than the width, it will be broken mid-word to fit the constraint.

Parameters:

  • text — The input text to wrap
  • width — Maximum width in characters for each line

Returns:

  • Array of wrapped lines

Behavior:

  • Returns nil if width is <= 0
  • Processes multi-line input (splits on newlines)
  • Uses simple length-based width calculation
  • Breaks words if necessary to fit the width
result := WordWrap("Hello World this is a test", 10)
// Output:
// [Hello Worl
// d this is
// a test]

SpaceWrap

func SpaceWrap(text string, width int) []string

SpaceWrap wraps text at space characters only. If a word is longer than the width, it will overflow without breaking the word.

Parameters:

  • text — The input text to wrap
  • width — Maximum width in characters for each line

Returns:

  • Array of wrapped lines

Behavior:

  • Returns nil if width is <= 0
  • Processes multi-line input (splits on newlines)
  • Uses simple length-based width calculation
  • Preserves word integrity — words longer than width overflow
  • Uses strings.Fields() to split on whitespace
result := SpaceWrap("Hello World this is a test", 10)
// Output:
// [Hello Worl
// d this is a
// test]

WrapToString

func WrapToString(text string, width int, useSpaceWrap bool) string

WrapToString is a convenience function that wraps text and joins the lines with newlines to produce a single string.

Parameters:

  • text — The input text to wrap
  • width — Maximum width in characters for each line
  • useSpaceWrap — Whether to use space-based wrapping (true) or word-based wrapping (false)

Returns:

  • Wrapped text as a single string with newlines
wrapped := WrapToString("Hello World this is a test", 10, false)
// Returns:
// Hello Worl
// d this is
// a test

Implementation Details

Internal Functions

The following internal functions support the public API:

func wrapLine(line string, width int) []string

Internal helper that wraps a single line at word boundaries. Handles line width checking and word boundary detection.

func wrapAtSpaces(line string, width int) []string

Internal helper that wraps a single line at spaces only. Handles word overflow cases.

func isWordBreak(b byte) bool

Helper function that checks if a byte is a whitespace character using unicode.IsSpace().

Key Implementation Notes

  • Simple width calculation: Uses simple length-based width calculation instead of terminal-aware width calculation.
  • Multi-line handling: Both main functions split input text by newlines and process each line independently.
  • Whitespace handling: After wrapping, leading whitespace in subsequent lines is skipped.
  • Edge cases: Returns nil for invalid widths (<= 0).
  • String builder: Uses strings.Builder for efficient string concatenation in wrapAtSpaces.

Basic Word Wrap

package main

import (
    "fmt"
    "warp"
)

func main() {
    text := "This is a sample text that should be wrapped to fit a certain width."
    
    // Word-based wrapping
    lines := warp.WordWrap(text, 30)
    for _, line := range lines {
        fmt.Println(line)
    }
}
