Warp Module

Warp is a terminal UI toolkit built on top of Bubble Tea that provides a root application manager for terminal applications.

The module exposes a Warp root component for managing layouts and an HTTP server for exposing the element tree as JSON.

The root Warp component that manages the entire application layout.

Panel Interface

type Panel interface {
    View(width, height int) string
    Update(msg tea.Msg) tea.Cmd
}

The fundamental building block of Warp. Any type implementing this interface can be used as terminal content.

Methods

Method Signature Description
View View(width, height int) string Renders terminal content at the given size.
Update Update(msg tea.Msg) tea.Cmd Handles Bubble Tea messages (keys, mouse, resize).

HTTP Server

When ServeHTTP(addr string) is called, an HTTP server starts on the given address (or environment variable WARP_HTTP_PORT, or port 0).

Endpoints

Path Method Description
/elements GET Returns the element tree as JSON.
/healthz GET Health check endpoint returning "ok".

The response to /elements includes CORS headers (Access-Control-Allow-Origin: *).

Example Usage

package main

import (
    "fmt"
    warp "yourmodule/warp"
)

type MyPanel struct {
    title string
}

func (m *MyPanel) View(width, height int) string {
    return fmt.Sprintf("Hello %s!\n", m.title)
}

func (m *MyPanel) Update(msg tea.Msg) tea.Cmd {
    return nil
}

func main() {
    // Create warp with default tab
    w := warp.New()

    // Create custom panel
    mp := &MyPanel{title: "World"}

    // Set it as root
    w.SetRoot(mp)

    // Run the application
    if err := w.Run(); err != nil {
        fmt.Println("Error:", err)
    }
}

Or with tabs:

package main

import (
    "fmt"
    warp "yourmodule/warp"
)

func main() {
    // Create tab group with tabs on top
    tg := warp.NewTabGroup(warp.TabTop)

    // Add a second tab
    tg.NewTab("secondary")

    // Set as root
    w := warp.New()
    w.SetRoot(tg)

    // Run
    w.Run()
}
