Element Package

The warp package provides types and functions for representing semantic UI elements with their screen bounds. This package is designed to work with the Warp windowing system, enabling programmatic access to UI elements from Go code.

Types

Element

Element represents a semantic UI element with its screen bounds and optional children.

type Element struct {
    Role     string    `json:"role"`
    Name     string    `json:"name"`
    Action   string    `json:"action,omitempty"`
    Bounds   Bounds    `json:"bounds"`
    Children []Element `json:"children,omitempty"`
}

Fields:

  • Role — The role of the element (e.g., "button", "label", "container")
  • Name — A unique or descriptive name for the element
  • Action — An action associated with the element (optional)
  • Bounds — The rectangular bounds of the element in cell coordinates
  • Children — Child elements nested within this element (optional)

Bounds

Bounds defines a rectangular screen region in cell coordinates.

type Bounds struct {
    X int `json:"x"`
    Y int `json:"y"`
    W int `json:"w"`
    H int `json:"h"`
}

Fields:

  • X — The horizontal position (cell index)
  • Y — The vertical position (cell index)
  • W — The width in cells
  • H — The height in cells

Methods

Bounds.Center()

Returns the center cell of the bounds.

func (b Bounds) Center() (int, int)

Example:

bounds := Bounds{X: 0, Y: 0, W: 4, H: 4}
cx, cy := bounds.Center()
// cx = 2, cy = 2

Interface: ElementProvider

ElementProvider is implemented by panels that can expose their UI elements.

type ElementProvider interface {
    Elements(width, height int) []Element
}

The Elements method returns a slice of Element structures representing the UI elements rendered within the given dimensions.

ElementProviderFunc

ElementProviderFunc adapts a plain function to the ElementProvider interface.

type ElementProviderFunc func(width, height int) []Element

This type allows you to use a function directly wherever an ElementProvider is expected:

// Define a function
myElements := func(width, height int) []Element {
    return []Element{
        {Role: "button", Name: "Submit", Bounds: Bounds{X: 0, Y: 0, W: 1, H: 1}},
    }
}

// Use it
if ep, ok := somePanel.(ElementProvider); ok {
    elements := ep.Elements(800, 600)
} else {
    elements := myElements(800, 600)
}

Functions

collectElements

Returns elements from a panel if it implements ElementProvider.

func collectElements(panel Panel, width, height int) []Element

Usage:

elements := collectElements(myPanel, 800, 600)

If the panel is nil or does not implement ElementProvider, an empty slice is returned.

FindElement

Recursively searches elements for the first matching role/name/action.

func FindElement(elems []Element, role, name, action string) (Element, bool)

Parameters:

  • elems — The root slice of elements to search
  • role — The role to match (empty string means any role)
  • name — The name to match (empty string means any name)
  • action — The action to match (empty string means any action)

Returns:

  • The matched Element, or an empty Element if not found
  • A boolean indicating whether a match was found

Example:

elem, found := FindElement(rootElements, "button", "", "submit")
if found {
    fmt.Println("Found button:", elem.Name)
}

The search is recursive and will look through child elements if no match is found in the current level.
