styles

The warp styles package provides a comprehensive set of terminal UI (TUI) styles based on the Gruvbox Dark color palette. It uses the lipgloss library to create rich terminal UI components with support for background colors, foreground colors, bold text, and more.

Overview

This package defines color palettes and pre-configured styles for various UI components including:

  • Tab bar - styles for active, inactive, new, and close tabs
  • Splitters/borders - styles for normal borders, hover states, and drag states
  • Float panes - styles for floating window borders and titles
  • Collapsible headers - styles for collapsible UI elements
  • Dropdown menus - styles for dropdown buttons and items with hover/selected states

Public API

Tab Styles

Styles for the tab bar component:

var tabBarStyle = lipgloss.NewStyle().
        Background(tabBarBg)

var activeTabStyle = lipgloss.NewStyle().
        Background(activeTabBg).
        Foreground(activeTabFg).
        Bold(true)

var inactiveTabStyle = lipgloss.NewStyle().
        Background(tabBarBg).
        Foreground(inactiveTabFg)

var newTabStyle = lipgloss.NewStyle().
        Foreground(newTabFg)

var closeTabStyle = lipgloss.NewStyle().
        Foreground(closeTabFg)
  • tabBarStyle - Background style for the entire tab bar
  • activeTabStyle - Style for the currently active tab (bold foreground)
  • inactiveTabStyle - Style for inactive tabs
  • newTabStyle - Style for new tab indicators (green foreground)
  • closeTabStyle - Style for close button indicators (red foreground)

Border Styles

Styles for split/border components:

var borderStyle = lipgloss.NewStyle().
        Foreground(borderColor)

var borderHoverStyle = lipgloss.NewStyle().
        Foreground(borderHoverColor)

var borderDragStyle = lipgloss.NewStyle().
        Foreground(borderDragColor)
  • BorderStyle() - Returns the style used for normal split borders
  • BorderDragStyle() - Returns the style used while dragging a split border
  • BorderHoverStyle() - Returns the style used when the mouse hovers a split border

Implementation Details

Using lipgloss

All styles are created using the lipgloss library, which provides a simple API for creating rich terminal UI components. The library supports:

  • Background colors
  • Foreground colors
  • Bold text
  • Underline, blink, reverse, etc.
  • Padding and spacing

Style Composition

Styles are composed using method chaining:


style := lipgloss.NewStyle().
        Background(bgColor).
        Foreground(fgColor).
        Bold(true)

Color Variables

Individual color variables can be used directly in styles or exported for customization:


// Example: Creating a custom style with existing color variables
customStyle := lipgloss.NewStyle().
        Background(gbDark1).
        Foreground(gbLight1).
        Bold(true)

Usage Examples

Creating a Tab Bar


tabBar := lipgloss.JoinHorizontal(
    lipgloss.Top,
    tabBarStyle.Render("Tabs"),
    activeTabStyle.Render("1"),
    inactiveTabStyle.Render("2"),
    inactiveTabStyle.Render("3"),
)

Creating Split Borders


border := lipgloss.NewStyle().
        BorderStyle(BorderStyle()).
        Render("Content")

borderHover := lipgloss.NewStyle().
        BorderStyle(BorderHoverStyle()).
        Render("Hovered Border")
