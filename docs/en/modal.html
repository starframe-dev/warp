Modal — Starframe Warp

The Modal package implements a draggable modal dialog system for terminal user interfaces (TUI) built with bubbletea. It renders styled dialog boxes that overlay the main panel content, supporting drag-to-move, close buttons, and action buttons.

Overview

Modals are displayed on top of panel content with a dimmed background. They feature:

  • Draggable positioning — Users can reposition the modal by dragging the top strip
  • Close functionality — Click the ✕ button or press Esc to close
  • Button actions — Configurable buttons at the bottom that trigger functions
  • Auto-width — If width is not specified, the modal uses 3/5 of screen width (clamped 30-50 chars)
  • ANSI styling — Uses lipgloss for styled rendering with rounded borders

EnsureDimensions

func (m *Modal) EnsureDimensions(totalW, totalH int)

Computes and stores box dimensions if not yet set. Must be called before Overlay if Overlay hasn't been called yet.

This function:

  • Computes box width (auto or specified, clamped 30-50 chars)
  • Computes box height (fixed at 7 lines for rounded border + padding + 3 content lines)
  • Computes center position with drag offset

Overlay

func (m *Modal) Overlay(lines []string, totalW, totalH int) []string

Renders the modal on top of existing content lines. Returns the overlaid lines.

The function:

  1. Ensures dimensions are computed (calls EnsureDimensions)
  2. Builds the modal box with title, content, and buttons
  3. Dims the background content
  4. Overlays the modal box preserving dimmed content left and right

HandleMouse

func (m *Modal) HandleMouse(msg tea.MouseMsg) bool

Processes mouse events for the modal. Returns true if the event was consumed.

Supported interactions:

  • Close button — Click the ✕ at the right of the title line
  • Button clicks — Click buttons at the bottom to trigger actions
  • Dragging — Drag the top padding strip to reposition the modal

Modal Box Layout

The modal box uses a RoundedBorder with padding. The layout is:

box[0]: top border              → startY + 0
box[1]: top padding (draggable) → startY + 1
box[2]: title + ✕               → startY + 2
box[3]: content                 → startY + 3
box[4]: buttons (first row)     → startY + 4
box[5]: buttons (second row)    → startY + 5 (when wrapped)
box[6]: bottom border           → startY + 6

Total height is fixed at 7 lines to match lipgloss RoundedBorder + padding + 3 content lines.

Usage Example

package main

import (
    "fmt"
    warp "yourproject/warp"
)

func main() {
    // Create a modal
    modal := warp.NewModal(
        "Confirmation",
        "Do you want to proceed?",
        []warp.ModalButton{
            {Label: "Yes", Action: func() {
                // Handle yes
            }},
            {Label: "No", Action: func() {
                // Handle no
            }},
        },
        func() {
            // Called when modal is closed
            fmt.Println("Modal closed")
        },
    )

    // Get initial panel lines
    lines := getPanelLines()

    // Render modal on top
    renderedLines := modal.Overlay(lines, 80, 24)

    // Handle mouse input
    for {
        msg, ok := chan.Read()
        if !ok {
            break
        }
        if modal.HandleMouse(msg) {
            // Modal handled the event
        }
    }

    // Render again with new positions
    renderedLines = modal.Overlay(renderedLines, 80, 24)
}

Important Notes

  • Dimension order — Always call EnsureDimensions() before Overlay() if not already called
  • Drag offset — The modal remembers its offset from center position; this enables dragging
  • Clamping — Modal is clamped to screen boundaries when dragging reaches edges
  • Auto-width — Width of 0 or negative means auto-width (3/5 screen, clamped 30-50)
  • ANSI handling — The visualBytePos function handles multi-byte characters and escape sequences correctly using the ansi parser
