TabGroup

TabGroup is a Panel that renders a tab bar and switches between tabs. It can be used as a component inside splits, flex layouts, or as the root panel.

Overview

The TabGroup provides a tabbed interface similar to terminal emulators. It supports:

  • Multiple tabs with custom names
  • Horizontal or vertical tab bars (top, bottom, left, right)
  • Tab switching via keyboard shortcuts
  • Tab creation and closing via keyboard or mouse
  • Active tab highlighting
  • Tab name truncation for long labels

Types

tabRegion

type tabRegion struct {
    idx    int
    startX int
    endX   int
    closeX int // X position of close button, -1 if none
}

tabRegion describes a clickable area in the tab bar. It stores:

Field Type Description
idx int Index of the associated tab, or -1 for new tab region
startX int X position where the clickable region starts
endX int X position where the clickable region ends
closeX int X position of the close button, -1 if none

TabGroup

type TabGroup struct {
    tabs      []*Tab
    activeTab int
    width     int
    height    int

    tabPosition      TabPosition
    tabRegions       []tabRegion
    newTabRegion     *tabRegion
    verticalTabWidth int
}

Fields:

Field Type Description
tabs []*Tab List of all tabs in the group
activeTab int Index of the currently active tab
width int Current width of the panel
height int Current height of the panel
tabPosition TabPosition Position of the tab bar (Top, Bottom, Left, Right, None)
tabRegions []tabRegion Computed clickable regions for the tab bar
newTabRegion *tabRegion Region for creating new tabs (when clicking "+")
verticalTabWidth int Width of vertical tab bar (computed from widest tab)

Public API

Creates a new tab with the given name and switches to it. Returns the newly created *Tab.

Returns the currently active tab. Returns nil if no tabs exist or if the active index is out of bounds.

Switches to the next tab in a circular manner. Only works if there is more than one tab.

Switches to the previous tab in a circular manner. Only works if there is more than one tab.

Keyboard Shortcuts

Key Action
Ctrl+Tab Switch to the next tab
Ctrl+Shift+Tab Switch to the previous tab
Ctrl+W Close the active tab
Ctrl+T Create a new tab
Ctrl+C Quit the application

Tab Bar Click Behavior

Clicking on the tab bar handles the following actions:

  • Clicking a tab: Switches to that tab
  • Clicking the close button (×): Closes the tab
  • Clicking the "+" button: Creates a new tab
  • Clicking vertical tabs (left/right): Clicking on a tab switches to it, clicking the close button closes it

Rendering

View

func (tg *TabGroup) View(w, h int) string

Renders the tab bar and active tab content. The behavior depends on tabPosition:

  • TabTop / TabBottom: Renders tab bar above or below the content
  • TabLeft / TabRight: Renders vertical tab bar on the left or right
  • TabNone: Renders only the content without a tab bar

Elements

func (tg *TabGroup) Elements(w, h int) []Element

Implements ElementProvider. Returns the active tab's elements offset by the tab bar position. Used for hit testing and cursor positioning.

Internal Methods

closeTab

func (tg *TabGroup) closeTab(idx int)

Closes a tab at the given index. If the tab being closed was active, switches to the last tab (or first if only one remains). Prevents closing the last tab.

switchTab

func (tg *TabGroup) switchTab(idx int)

Sets the active tab index. Internal method used by other methods.

contentWidth / contentHeight

func (tg *TabGroup) contentWidth(totalW int) int
func (tg *TabGroup) contentHeight(totalH int) int

Returns the available content width/height after subtracting the tab bar width/height if present.

contentOffset

func (tg *TabGroup) contentOffset() (int, int)

Returns the (x, y) offset for content based on tab position. Used for positioning elements.

renderTabBar

func (tg *TabGroup) renderTabBar(width int) string

Delegates to either renderHorizontalTabBar or renderVerticalTabBar based on tab position.

renderHorizontalTabBar

func (tg *TabGroup) renderHorizontalTabBar(width int) string

Renders a horizontal tab bar (top or bottom). Creates tab regions, renders tab labels with truncation, and adds the new tab region ("+").

renderVerticalTabBar

func (tg *TabGroup) renderVerticalTabBar(_ int) string

Renders a vertical tab bar (left or right). Computes the maximum tab width and renders all tabs with right padding. Creates a new tab region at the bottom ("+").

handleKeyMsg / handleMouseMsg

func (tg *TabGroup) handleKeyMsg(msg tea.Msg) tea.Cmd
func (tg *TabGroup) handleMouseMsg(msg tea.MouseMsg) tea.Cmd

Handles keyboard and mouse messages for the tab group. Delegates to the active tab for messages not handled by the tab group itself.

isOnTabBar

func (tg *TabGroup) isOnTabBar(x, y int) bool

Checks if a given (x, y) position is on the tab bar. Returns true for positions on the tab bar, false otherwise.

handleTabBarClick

func (tg *TabGroup) handleTabBarClick(msg tea.MouseMsg) tea.Cmd

Handles click events on the tab bar. Performs hit testing against tab regions to determine which action to take (switch tab, close tab, or create new tab).

shiftElements

func shiftElements(elems []Element, dx, dy int)

Recursive helper function that adds offsets to all elements and their children. Used by Elements to apply the tab bar offset.

Update

func (tg *TabGroup) Update(msg tea.Msg) tea.Cmd

Handles various messages:

  • tea.KeyMsg: Delegated to handleKeyMsg
  • tea.MouseMsg: Delegated to handleMouseMsg
  • tea.WindowSizeMsg: Updates width/height and broadcasts to tabs
  • ResizeMsg: Updates width/height and broadcasts to tabs
  • PtyReadyMsg, PtyOutputMsg, etc.: Broadcast to all tabs

Example Usage

package main

import (
    "github.com/charmbracelet/bubbles/textarea"
    "github.com/charmbracelet/bubbles/tabgroup"
)

func main() {
    // Create a new tab group with tabs on top
    tg := tabgroup.NewTabGroup(tabgroup.TabTop)
    
    // Add initial tab
    mainTab := tg.NewTab("main")
    
    // Add more tabs
    tg.NewTab("config")
    tg.NewTab("settings")
    
    // Render the tab group
    output := tg.View(80, 24)
    println(output)
}

Notes

  • Tab names are truncated to 20 characters for horizontal tabs and 15 characters for vertical tabs
  • The close button (×) only appears on the active tab in horizontal mode
  • In vertical mode, close buttons appear on all tabs
  • Tab regions are recomputed on each render
  • The + button creates a new tab when clicked or via Ctrl+T
  • Tab switching wraps around (circular navigation)
  • The last tab cannot be closed
