Input

Overview

The Input component is a single-line text input widget built on top of Bubble Tea. It provides a TUI-friendly text input experience with keyboard support, cursor management, and customizable rendering.

When height is at least 3 cells, the input is rendered in a bordered box. Otherwise, it renders inline.

Types

Input

type Input struct {
    Value   string
    Cursor  int // cursor position in runes
    Prompt  string
    Width   int // desired width (0 = auto from View w)
    focused bool
}

Fields:

  • Value — The current text value.
  • Cursor — Cursor position in runes (0 to len(Value)).
  • Prompt — Text displayed before the value.
  • Width — Desired width; ignored during render.
  • focused — Internal state indicating if the input has focus.

Renders the input. If h ≥ 3 it draws a bordered box; otherwise renders inline.

Keyboard Input

func (in *Input) Update(msg tea.Msg) tea.Cmd

Handles keyboard input. Only processes tea.KeyMsg when focused. Supports:

  • backspace — Deletes character before cursor.
  • delete — Deletes character at cursor.
  • left — Moves cursor left.
  • right — Moves cursor right.
  • home — Moves cursor to beginning.
  • end — Moves cursor to end.
  • tab / shift+tab — Focus traversal (handled by parent).
  • enter — Submit (no-op).
  • any character — Inserts character at cursor.

Implementation Details

Cursor Clamping

The clampCursor method ensures cursor stays within valid bounds [0, len(runes)]. It is called after value changes and cursor setting.

Truncation

When the value plus prompt exceeds available width, truncateTailToWidth shifts the visible portion to keep the cursor visible near the right edge.

Styles

var (
    inputStyle           = lipgloss.NewStyle().Foreground(lipgloss.Color(gbLight1))
    inputBorderStyle     = lipgloss.NewStyle().Foreground(lipgloss.Color(gbDark4))
    inputFocusBorderStyle = lipgloss.NewStyle().Foreground(lipgloss.Color(gbBlue))
)

Styles are applied based on focus state:

  • Unfocused — inputBorderStyle
  • Focused — inputFocusBorderStyle

Rendering Modes

viewBoxed — Renders with top/bottom/left/right borders using ASCII characters ╭╮╰╯│.

viewInline — Renders as a single line, useful for compact layouts.

Character Insertion

Characters are inserted at cursor position. Multi-byte UTF-8 characters are handled via rune slices, ensuring proper cursor positioning.

Deletion

deleteBeforeCursor removes the character immediately before the cursor and decrements cursor position.

deleteAtCursor removes the character at the cursor position.

Example Usage

in := NewInput("Username:")
in.SetValue("alice")

// Handle input
if in.Focused() && msg.String() == "a" {
    in.Update(msg)
}

// Render
view := in.View(termWidth, termHeight)

Notes

  • All cursor positions are measured in runes, not bytes.
  • The Width field is stored but ignored during render; actual width is determined by container.
  • Tab and shift+tab are no-ops; focus traversal should be handled by the parent application.
  • Enter is currently a no-op; could be extended to emit custom messages.
