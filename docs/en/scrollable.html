Scrollable

Overview

Scrollable is a wrapper component that adds scroll support to a Panel. When the content exceeds the allocated height, users can scroll via mouse wheel or keyboard. It is part of the warp package, built with charmbracelet/bubbletea.

Type Definition

type Scrollable struct {
    Content Panel
    Offset  int // scroll offset in lines
}

Scrollable wraps a Panel with scroll support. It maintains an offset that determines the visible portion of the content.

Public API

NewScrollable

func NewScrollable(content Panel) *Scrollable

Creates a new scrollable wrapper around a given Panel.

View

func (s *Scrollable) View(w, h int) string

Renders the visible viewport of the content. Takes the allocated width w and height h in lines. Returns a string representing the visible portion of the content, clamped to the viewport height.

Update

func (s *Scrollable) Update(msg tea.Msg) tea.Cmd

Handles scroll messages (mouse wheel, keyboard keys). Returns a command for further action if needed.

Implementation Details

Scrolling Behavior

  • Mouse wheel up: scrolls up by 3 lines
  • Mouse wheel down: scrolls down by 3 lines
  • Keyboard up arrow: scrolls up by 1 line
  • Keyboard down arrow: scrolls down by 1 line
  • Keyboard Page Up: scrolls up by 10 lines
  • Keyboard Page Down: scrolls down by 10 lines

All scroll actions are clamped to valid bounds (offset cannot be negative or exceed content height).

Rendering

The View method renders the full content at unlimited height, splits it into lines, and then slices to show only the visible portion based on the current offset. Empty lines are added if needed to fill the viewport height.

Line Padding (padLine)

func padLine(line string, w int) string

Helper function that ensures a line is exactly w characters wide. If the line is shorter than w, spaces are added. If longer, it is carefully truncated at a proper byte boundary to preserve UTF-8 sequences.

Usage Example

package main

import (
    warp "your/module/path"
)

func main() {
    // Create a panel with content
    content := &warp.Panel{
        Text: "This is a long piece of text that will overflow the viewport\nand require scrolling.",
    }

    // Wrap it in a scrollable
    scrollable := warp.NewScrollable(content)

    // Render with 80x24 viewport
    output := scrollable.View(80, 24)
}
