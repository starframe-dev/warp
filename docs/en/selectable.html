Selectable

Selectable wraps a Panel with text selection support. Mouse drag and Shift+arrow keys create text selections. The selected region is rendered with reversed colors (inverse highlight).

Overview

Selectable is a text selection wrapper that integrates with the Bubbletea TUI framework. It provides:

  • Mouse-based selection via drag
  • Keyboard selection with Shift+arrows
  • Copy to clipboard via OSC 52
  • Selection highlighting with inverse colors
  • Unicode and ANSI escape sequence aware text extraction

Type Definition

type Selectable struct {
    Content Panel

    // Selection anchor (fixed on press) and cursor (active end).
    // Both are in cell coordinates relative to the panel.
    AnchorX, AnchorY int
    CursorX, CursorY int

    HasSelection bool
    Selecting    bool // true during active mouse drag

    // Last rendered dimensions and content lines, used to extract selected
    // text that matches exactly what is currently visible.
    lastW, lastH int
    lastLines    []string
}

The Selectable type maintains selection state through:

  • Anchor coordinates: Fixed position where selection started (on mouse press or first Shift+arrow)
  • Cursor coordinates: Active end of selection (where mouse is dragged or last arrow key)
  • lastW/lastH: Cached dimensions of the last rendered content
  • lastLines: Cached rendered lines for accurate text extraction

Public API

NewSelectable

func NewSelectable(content Panel) *Selectable

Creates a new selectable wrapper around a Panel. The content passed becomes the wrapped panel that will be rendered.

SelectedText

func (s *Selectable) SelectedText() string

Returns the currently selected text. Falls back to a large render if View hasn't been called yet (e.g., in unit tests).

Implementation details:

  • Uses the same rendered lines as View for coordinate accuracy
  • Strips ANSI escape codes before extracting text
  • Clamps coordinates to valid line boundaries
  • Handles multi-byte UTF-8 runes correctly

ClearSelection

func (s *Selectable) ClearSelection()

Removes the current selection by clearing the selection state. Sets HasSelection and Selecting to false.

Copy

func (s *Selectable) Copy() tea.Cmd

Returns a tea.Cmd that copies the selected text to the system clipboard via OSC 52. Call this when the user presses Ctrl+C.

Implementation uses Base64 encoding for compatibility with terminal emulators that support OSC 52.

SelectAll

func (s *Selectable) SelectAll(w, h int)

Selects all visible content. Sets the selection anchor to (0, 0) and cursor to (w-1, h-1).

View

func (s *Selectable) View(w, h int) string

Renders the content with selection highlight. Clamps selection to panel bounds. If no selection exists, returns the wrapped panel's content unchanged.

Implementation details:

  • Caches rendered lines for accurate text extraction
  • Clamps selection coordinates to panel bounds
  • Applies inverse color styling to the selection range
  • Handles edge cases where cursor equals anchor (clears selection unless still dragging)

Update

func (s *Selectable) Update(msg tea.Msg) tea.Cmd

Handles mouse and keyboard input for selection. Processes:

  • ResizeMsg: Passes to wrapped content
  • tea.MouseMsg: Handles left-click drag for selection
  • tea.KeyMsg: Handles Shift+arrows for keyboard selection and Ctrl+key shortcuts

Internal Functions

sortedBounds

func (s *Selectable) sortedBounds() (sx, sy, ex, ey int)

Returns selection bounds with start <= end, swapping anchor and cursor if necessary to ensure correct ordering.

highlightRange

func highlightRange(line string, startX, endX int) string

Applies selection highlight to the visual range [startX, endX). Walks through the line tracking visual rune position so that Unicode and ANSI sequences are handled correctly.

extractVisRange

func extractVisRange(line string, startX, endX int) string

Extracts text from visual range [startX, endX), skipping ANSI escape sequences and handling multi-byte UTF-8 runes.

Important Implementation Notes

Coordinate System

All coordinates are in cell coordinates relative to the panel. This is different from byte positions, which is important for handling:

  • Multi-byte UTF-8 characters
  • ANSI escape sequences
  • Visual vs. byte positioning mismatches

Selection Direction

The selection anchor stays fixed where the user originally pressed. The cursor moves. This allows reverse-direction drag to work correctly (e.g., dragging left then right still selects the same text).

Text Extraction Accuracy

The implementation caches rendered lines (lastLines) to ensure that text extraction uses the exact same coordinate system as rendering. This prevents discrepancies between what's displayed and what's extracted.

ANSI Handling

Both highlightRange and extractVisRange properly handle ANSI escape sequences by:

  • Skipping over escape sequences without counting them in visual position
  • Preserving escape sequences in the output but toggling style around them
  • Using utf8.DecodeRuneInString for proper UTF-8 handling

Fallback Behavior

If View hasn't been called (e.g., in unit tests), SelectedText falls back to rendering a large buffer (9999x9999) to ensure selection bounds still map correctly to content lines.

Usage Example

s := warp.NewSelectable(contentPanel)

// Enable selection
s.SelectAll(width, height)

// Or create via mouse drag - handled automatically in Update()

// Get selected text
selected := s.SelectedText()

// Copy to clipboard
copyCmd := s.Copy()
tea.Batch(func() tea.Msg {
    fmt.Println(copyCmd())
    return nil
})

// Clear selection when needed
s.ClearSelection()
