render.go - Warp Rendering Engine

Overview

The render package provides rendering functionality for the Warp terminal multiplexer. It handles the conversion of a node tree representing the UI layout into lines of text that can be displayed in the terminal.

The rendering system supports:

  • Leaf nodes - Panels with views (rendered via their View method)
  • Split layouts - Vertical and horizontal splits between panels
  • Flex layouts - Weighted flexbox-style layouts with multiple children
  • Collapsed panels - Panels that can be collapsed to a fixed size
  • Drag states - Visual feedback when dragging borders between panels

The rendering is done entirely in memory and returns a 2D slice of strings representing the terminal buffer, with each line properly styled with ANSI sequences.

Public API

renderNode

func renderNode(node *Node, w, h int) []string

Main entry point for rendering a node tree. Takes a root node and dimensions (width and height in characters), returns a slice of strings representing the rendered output.

Behavior:

  • If the node is nil, returns empty lines matching the dimensions
  • If the node is a leaf (has a Panel), calls its View method and pads the content
  • If the node has a Split, delegates to renderVerticalSplit or renderHorizontalSplit
  • If the node has a Flex, delegates to renderFlex

findBorders

func findBorders(node *Node, x, y, w, h int) []BorderHit

Recursively collects all draggable border positions from a node tree. Returns a slice of BorderHit describing each border with its position and the Split or Flex configuration it belongs to.

Use case: Used to identify which borders can be grabbed for splitting/reshaping panels.

padContent

func padContent(content string, w, h int) []string

Ensures content has exactly w×h dimensions by padding with spaces and truncating with ansi.Truncate. Each line ends with an ANSI reset style to prevent style leakage between panels.

Internal Functions

renderVerticalSplit

func renderVerticalSplit(split *SplitConfig, w, h int) []string

Renders a vertical split layout. Renders the first and second children side by side with a vertical border between them.

Key implementation details:

  • Calculates available width after accounting for the border
  • Uses computeSplitSizes to allocate space between first and second children
  • When either child is collapsed, omits the border to make panels sit flush
  • Uses different border characters for normal vs dragging state

renderHorizontalSplit

func renderHorizontalSplit(split *SplitConfig, w, h int) []string

Renders a horizontal split layout. Renders the first and second children one above the other with a horizontal border between them.

Key implementation details:

  • Calculates available height after accounting for the border
  • Uses computeSplitSizes to allocate space between first and second children
  • When either child is collapsed, omits the border
  • Borders are drawn as horizontal lines using strings.Repeat

renderFlex

func renderFlex(flex *FlexConfig, w, h int) []string

Renders a flex layout with weighted children. Supports both horizontal (row) and vertical (column) flex directions.

Key implementation details:

  • Calculates borders between flex items (one less than number of items)
  • Uses computeFlexSizes to determine each item's size
  • For horizontal flex: renders items in a row with vertical borders
  • For vertical flex: renders items in a column with horizontal borders

computeFlexSizes

func computeFlexSizes(avail int, items []*FlexItem) []int

Computes the size allocation for flex items. Implements a flexbox-like sizing algorithm that:

  1. First allocates basis size (1 for collapsed items, item.Basis or MinPanelSize for non-collapsed)
  2. Calculates remaining space after basis allocation
  3. Distributes remaining space by grow weights among non-collapsed items
  4. If total grow is 0, distributes equally among non-collapsed items
  5. Distributes leftover pixels to the last non-collapsed item

computeSplitSizes

func computeSplitSizes(avail int, fraction float64, firstCollapsed, secondCollapsed bool, firstSize, secondSize int) (first, second int)

Calculates sizes for a split's two children. Handles collapsed panels by using their fixed collapsed size.

Behavior:

  • If first child is collapsed: allocates firstSize (minimum 1), second gets remaining space
  • If second child is collapsed: allocates secondSize (minimum 1), first gets remaining space
  • Otherwise: splits by fraction, enforcing minimum panel sizes

makeEmptyLines

func makeEmptyLines(w, h int) []string

Creates a 2D slice of empty strings with given dimensions. Returns nil if w or h is <= 0.

Implementation Details

ANSI Style Handling

All rendering uses the charmbracelet/x/ansi package for ANSI style handling. Key patterns:

  • Border characters are wrapped in ansi.ResetStyle to prevent style leakage
  • padContent appends ansi.ResetStyle at the end of each line
  • Truncation uses ansi.Truncate which preserves UTF-8 and ANSI sequences

Collapsed Panel Handling

When a panel is collapsed:

  • The border between panels is omitted to make panels sit flush
  • Collapsed panels use their fixed CollapsedSize instead of computed size
  • This applies to both split and flex layouts

Border Dragging State

When a border is being dragged (split.Dragging or flex.Dragging is true):

  • Different border characters/styles are used
  • borderDragStyle is used instead of borderStyle

Coordinate System

The rendering uses 0-indexed terminal coordinates:

  • X is the column position (0 to width-1)
  • Y is the row position (0 to height-1)
  • Borders are positioned relative to the containing area

MinPanelSize

A constant representing the minimum panel size. Used to ensure panels don't become too small when computing split/flex sizes.

Example

// Example: Render a simple vertical split
lines := renderNode(rootNode, 80, 24)
// lines is []string representing the terminal buffer
for _, line := range lines {
    fmt.Println(line)
}

// Example: Find all draggable borders
borders := findBorders(rootNode, 0, 0, 80, 24)
for _, border := range borders {
    fmt.Printf("Border at (%d, %d), length %d\n", border.X, border.Y, border.Length)
}
