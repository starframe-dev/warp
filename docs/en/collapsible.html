Collapsible

Overview

Collapsible is a UI component that represents a panel which can be collapsed to a single-line title bar. When expanded, it displays its full content via an inner Panel implementation.

Type Definition

type Collapsible struct {
  Title string
  Collapsed bool
  Content Panel
}

The Collapsible type contains:

  • Title — The title string shown when collapsed. Gets truncated to fit the available width.
  • Collapsed — Boolean flag indicating whether the panel is in collapsed state.
  • Content — Optional Panel interface implementation to display when expanded.

Public API

NewCollapsible

func NewCollapsible(title string, content Panel) *Collapsible

Creates and returns a new Collapsible instance with the given title and content panel.

View

func (c *Collapsible) View(w, h int) string

Renders the view for the collapsible panel. When Collapsed is true, returns a single-line title bar. When Collapsed is false and Content is not nil, delegates to Content.View(w, h). Returns an empty string if content is nil and expanded.

Update

func (c *Collapsible) Update(msg tea.Msg) tea.Cmd

Forwards messages to the inner content panel if it exists. Returns nil if there's no content to update.

Toggle

func (c *Collapsible) Toggle()

Switches the panel between collapsed and expanded states by inverting the Collapsed flag.

renderCollapsed

func (c *Collapsible) renderCollapsed(w int) string

Private helper method that renders the title bar for a collapsed panel. Handles:

  • Indicator arrow (▶ when collapsed, ▼ when expanded)
  • Title truncation to fit available width
  • Padding to fill remaining space

Implementation Details

Collapsed View Rendering

The renderCollapsed method constructs a single-line title bar with the following structure:

  • Left corner character: ┌
  • Indicator arrow: ▶ (collapsed) or ▼ (expanded)
  • Space separator
  • Title text (truncated if needed)
  • Right corner character: ┐

Title Truncation

When the title exceeds the available width (after reserving space for indicator and corners), the title is truncated with an ellipsis (...):

if len(title) > w-reserve {
    maxLen := w - reserve - 3
    if maxLen < 0 {
        maxLen = 0
    }
    if maxLen == 0 {
        title = ""
    } else {
        title = title[:maxLen] + "..."
    }
}

Example Usage

collapsible := NewCollapsible(
    "Example Panel",
    &warp.Panel{
        Title: "Content",
        View: func(w, h int) string {
            return "This is the panel content."
        },
    },
)

// Toggle the panel
collapsible.Toggle()
