Focus Module

This module provides keyboard focus management for the Warp panel system. It defines interfaces and functions for collecting, navigating, and applying keyboard focus across the panel tree.

Types

Focusable

type Focusable interface {
	Panel
	Focus()
	Blur()
	Focused() bool
}

A Focusable is a Panel that can receive keyboard focus. It extends the Panel interface and adds three methods:

  • Focus() - Gives focus to the panel
  • Blur() - Removes focus from the panel
  • Focused() bool - Reports whether the panel currently has focus

RawKeyReceiver

type RawKeyReceiver interface {
	Panel
	WantsRawKeys() bool
}

A RawKeyReceiver is a panel that wants to receive all keyboard input without interception. This is useful for embedding raw terminal emulators (e.g., PTY) inside the panel system.

collectFocusables

func collectFocusables(node *Node) []Focusable

Returns all focusable panels in the tree, in visual order.

Parameters:

  • node *Node - The tree node to traverse

Returns:

  • []Focusable - List of focusable panels in visual order, or nil if no focusables found

Behavior:

  • Recursively traverses the panel tree
  • For leaf nodes, checks if the panel is focusable
  • For split nodes, collects from first and second children
  • For flex nodes, collects from all flex items
  • Returns nil for empty nodes

applyFocus

func applyFocus(current, next Focusable)

Moves focus from current to next, calling Blur() on the current and Focus() on the next.

Parameters:

  • current Focusable - The current focusable (or nil)
  • next Focusable - The next focusable (or nil)

Behavior:

  • If current is not nil and not the same as next, calls current.Blur()
  • If next is not nil, calls next.Focus()

Implementation Details

The focus system operates on a tree structure of panels. The collectFocusables function traverses this tree and collects all focusable panels in visual order (left-to-right, top-to-bottom).

When navigating focus:

  • focusNext moves forward in the visual order, wrapping around
  • focusPrev moves backward in the visual order, wrapping around

The applyFocus function ensures proper state transitions by blurring the old focus and focusing the new one.
