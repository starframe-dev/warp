Panel

The Panel package provides a flexible interface for building interactive content panes in warp applications. It is built on top of the Bubble Tea library for managing terminal UI state.

Overview

A Panel represents a content pane that can be displayed in the warp terminal application. Panels support:

  • Rendering content at given dimensions
  • Handling input events (keyboard, mouse, etc.)
  • Integration with Bubble Tea messages and commands

Interface: Panel

type Panel interface {
    // View renders the panel content at the given size.
    View(width, height int) string

    // Update handles Bubbletea messages (keys, mouse, etc).
    // The panel receives only messages that arrived while it was focused.
    Update(msg tea.Msg) tea.Cmd
}

Methods

View(width, height int) string

Receives the terminal dimensions and returns a string containing the rendered content.

Parameter Type Description
width int The available width in columns
height int The available height in rows

Update(msg tea.Msg) tea.Cmd

Handles a Bubble Tea message and returns an optional command to execute.

Parameter Type Description
msg tea.Msg A message from Bubble Tea (key press, mouse, timer, etc.)

Note: The panel receives only messages that arrived while it was focused. Use the focus state to determine if the panel should respond to input.

Types

BasePanel

BasePanel is a struct that provides a default no-op implementation of the Panel interface. Embed it in your own panel types and override only the methods you need.

type BasePanel struct{}

func (BasePanel) View(width, height int) string {
    return ""
}

func (BasePanel) Update(msg tea.Msg) tea.Cmd {
    return nil
}

Embedding BasePanel

To create your own panel, embed BasePanel and override specific methods:

type MyPanel struct {
    BasePanel
    title string
    rows  int
}

func (p *MyPanel) View(width, height int) string {
    // Implement custom rendering
    return p.title + "\n" + p.renderContent()
}

func (p *MyPanel) Update(msg tea.Msg) tea.Cmd {
    // Handle input
    switch msg := msg.(type) {
    case tea.KeyMsg:
        if msg.String() == "q" {
            return tea.Quit
        }
    }
    return nil
}

Usage Examples

Creating a Simple Text Panel

import (
    warp "your/project/warp"
    tea "github.com/charmbracelet/bubbletea"
)

type TextPanel struct {
    warp.BasePanel
    text string
}

func (p *TextPanel) View(width, height int) string {
    lines := 0
    var output strings.Builder
    for _, line := range strings.Split(p.text, "\n") {
        if len(line) > width {
            line = line[:width]
        }
        output.WriteString(line)
        if lines < height-1 {
            output.WriteString("\n")
            lines++
        }
    }
    return output.String()
}

func (p *TextPanel) Update(msg tea.Msg) tea.Cmd {
    return nil
}

Creating an Interactive Form Panel

type FormPanel struct {
    warp.BasePanel
    fields []string
    value  map[string]string
}

func (p *FormPanel) View(width, height int) string {
    var output strings.Builder
    for i, field := range p.fields {
        output.WriteString(fmt.Sprintf("%d. %s: %s\n", i+1, field, p.value[field]))
    }
    return output.String()
}

func (p *FormPanel) Update(msg tea.Msg) tea.Cmd {
    if enterMsg, ok := msg.(tea.KeyMsg); ok {
        if enterMsg.String() == "enter" {
            // Handle submission
            return tea.Quit
        }
        if enterMsg.String() == "tab" {
            // Move to next field
            return tea.Batch(
                tea.Key(func() tea.Msg { return tea.KeyEnter }),
                tea.Quit,
            )
        }
    }
    return nil
}

Important Notes

  • Always handle terminal resize events (width/height parameters)
  • Return tea.Quit or appropriate commands in Update when appropriate
  • Use the focus state to determine which messages a panel should receive
  • Return nil for View if you want an empty panel
  • Return nil for Update if no command should be executed
