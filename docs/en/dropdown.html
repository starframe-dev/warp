Dropdown

Overview

This module implements a dropdown menu widget for the Warp UI system. It provides a collapsible menu component that can be opened to display a list of selectable items. The dropdown supports mouse and keyboard navigation, item selection, and custom callbacks.

Types

DropdownItem

type DropdownItem struct {
    Label    string
    Selected bool
}

DropdownItem represents a single item in a dropdown menu.

Field Type Description
Label string The text label displayed for this dropdown item.
Selected bool Whether this item is currently selected. Only one item can be selected at a time.

DropdownMenu

type DropdownMenu struct {
    Label    string
    Items    []DropdownItem
    Open     bool
    Hovered  int
    OnSelect func(idx int)
}

DropdownMenu is a panel that shows a button and an expandable list of items.

Field Type Description
Label string The label text for the dropdown button (shown when closed).
Items []DropdownItem The list of dropdown items to display in the menu.
Open bool Whether the dropdown menu is currently open (expanded) or closed.
Hovered int The index used for styling. Set to -1 when the menu opens or the button is clicked. Not updated on mouse hover.
OnSelect func(idx int) A callback function that is called when an item is selected.

Behavior Details

Opening the Dropdown

Clicking on the dropdown button (when closed) opens the menu. The button is at row 0 of the rendered output.

Closing the Dropdown

The dropdown can be closed by:

  • Clicking on the dropdown button
  • Pressing the Escape key
  • Calling the Close() method

Navigating the Menu

When the dropdown is open, users can navigate items using:

  • ↑ (up arrow) — Move selection up
  • ↓ (down arrow) — Move selection down

The Hovered field is set to -1 when the menu opens or the button is clicked. It is used for rendering styling but is not updated on mouse hover events.

Selecting an Item

An item is selected by:

  • Pressing Enter while navigating items
  • Clicking on an item in the menu

When an item is selected:

  1. All other items have Selected set to false
  2. The selected item has Selected set to true
  3. The dropdown closes automatically
  4. The OnSelect callback is invoked with the selected item index

Rendering Behavior

  • Text is truncated to fit the available width, with … appended if needed
  • The button row shows the label with a ▼ (down arrow) when closed, ▲ (up arrow) when open
  • Selected items are prefixed with ✓
  • Items at index Hovered receive special styling (but Hovered is only set on button click, not on mouse hover)
  • Selected items receive special styling

Example Usage

Creating and Using a Dropdown

package main

import (
    "fmt"
    warp "your/module/path"
)

func main() {
    // Create dropdown items
    items := []warp.DropdownItem{
        {Label: "Option 1"},
        {Label: "Option 2"},
        {Label: "Option 3"},
    }

    // Create the dropdown menu with a callback
    dropdown := warp.NewDropdownMenu("Select:", items)
    dropdown.OnSelect = func(idx int) {
        fmt.Printf("Selected item at index: %d\n", idx)
    }

    // Render the dropdown (initially closed)
    view := dropdown.View(40, 10)
    fmt.Println(view)

    // Open the dropdown
    dropdown.Open = true
    view = dropdown.View(40, 10)
    fmt.Println(view)

    // Close the dropdown
    dropdown.Close()
    view = dropdown.View(40, 10)
    fmt.Println(view)
}

Styles

The dropdown uses Bubble Tea's text style system for rendering. The following style constants are used internally:

  • dropdownButtonStyle — Style for the dropdown button
  • dropdownItemStyle — Default style for menu items
  • dropdownItemHoverStyle — Style for hovered items
  • dropdownItemSelectedStyle — Style for selected items
