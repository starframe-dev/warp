# Styles

Warp uses the Gruvbox Dark color palette. All colors are defined in `styles.go`.

## Key Colors

| Variable | Hex | Description |
|----------|-----|-------------|
| `gbDark0` | `#282828` | Darkest background |
| `gbDark1` | `#3c3836` | Panel background |
| `gbDark2` | `#504945` | Active tab background |
| `gbDark3` | `#665c54` | Border |
| `gbDark4` | `#7c6f64` | Subtle border |
| `gbGray` | `#928374` | Inactive/muted text |
| `gbLight1` | `#ebdbb2` | Primary text |
| `gbRed` | `#fb4934` | Error/close |
| `gbGreen` | `#b8bb26` | Success |
| `gbYellow` | `#fabd2f` | Warning |
| `gbBlue` | `#83a598` | Accent/selected |

There is no public API for theme customization.
